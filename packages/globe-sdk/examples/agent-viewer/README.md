# 独立接入验证

需要 Node 24 和 pnpm 10.32.1。在本目录执行 `pnpm install`，再执行 `pnpm dev`，
打开本地 18894 端口。`pnpm build` 验证独立打包。

样例只依赖共用 SDK 和 Cesium，不引用 CoSpace 页面或 React。它展示两个独立图层、
图层开关、相机控制和选择回调：绿色为贴地轨迹，橙色为带椭球高的空中轨迹。
全部场景标识和轨迹为明确标注的合成测试数据，不登记到任何业务场景，也不调用私有 API。

实际产品接入时，移除合成数据，使用产品自己的后端代理取得已授权场景、固定发布版本
和智能体数据，再调用 `setScenes`、`setLayers`。服务令牌保留在后端。配置来自
`/api/globe/config`；静态资源目录必须与 Cesium 版本一致。不要把用户填写的海拔直接
作为椭球高，空中轨迹必须明确使用 `heightMode:'absolute'`。

CoSpace 是第一个真实产品使用方；本样例验证另一套页面能否独立消费 SDK，不能作为
外部真实智能体业务已集成的证据。
