# Spatial

权威空间模型模块，负责真值的对象身份、坐标、几何与覆盖语义、质量含义及内容约束。

输入为明确版本和来源的内容；输出为可解释的模型及校验诊断。模型不能通过缺点推断空闲，也不能把缺失质量信息解释为达标。

本模块不执行SLAM，不管理当前发布指针，不直接采用候选为正式真值。不依赖construction、views、service或lifecycle。

validation.py已实现合成坐标定义、目标范围和对象锚点检查。它是试验契约子集，不验证几何、覆盖或现场质量；具体存储仍在模块之外。

preview_objects.py负责本机真实预览的对象快照校验：固定本体、空间与模型绑定、对象规则及模型点证据；在线加载还核对锚点与点云。所有对象语义保留unverified，双视图共用快照。创建候选由construction编排，发布与离线包由各自模块负责。
