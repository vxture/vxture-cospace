# Service

空间态势服务模块，负责固定发布组合的解析、对象与空间查询、分发、追溯以及消费时的有效性检查。

首个增量先验证服务发布引用的真值与视图来源一致，再提供固定版本的本地读取。未知、占据和已观测空闲分别表达；缺文件、摘要错误或撤回返回相应错误，不伪装为空间未知或空闲。

依赖spatial与公开契约，通过边界接口读取内容及有效性记录。审核发布规则归lifecycle，具体读取实现由应用装配；不引用构建工作目录，不触发隐式真值更新。

sample.py已实现离线合成服务包的一致性校验，串联data、ontology和spatial的纯校验能力。它只读取本地固定内容，尚无网络服务、空间查询、指针切换或撤回实现。暂不作为正式消费SDK。
