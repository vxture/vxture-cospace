# 固定对象语义成果交付 v0.12.0

日期：2026-11-21。B06d收口B06a—c，生产基线v0.11.0。本文为发布候选说明，不预写生产成功；实际tag、CI、审批及部署状态以GitHub记录为准。

## 发布范围

服务发布时可以显式采用空间关联中的固定实例修订。预检并冻结模型对象与关系索引、定义依赖闭包、对象属性、关系映射、有效期、人工依据及局部校验报告。未勾选不读取消费实例，旧发布不自动增补语义。修订或来源变化使预检失效，确认框展示本次采用范围。

在线固定API `/publications/{id}/api/semantics` 与完整离线包profile 0.5消费同一成果，支持摘要、对象及UTC时刻查询。本地消费保留安装、激活、恢复机制；CLI restore --semantics查询摘要，加对象标识查询声明。公共资源—语义本体保持独立，消费修订及成果适配由CoSpace宿主持有。

局部校验不代替专业审核与现场核实。模型、附件保持外部证据引用；分区包明确不支持新增成果。地理配准/地图定位为B07，专业内容深化为B08，独立产品为B09，均不并入本版本。

## 状态与兼容性

不新增数据库结构迁移。定义、分组和消费数据库保留原位置；新成果成员写入既有 `/srv/md0/cospace/data/business/runtime/preview-builds/publications/{id}` 固定发布目录，不覆盖旧发布。单语义成果8MiB、完整离线包32MiB预算保持；未知profile、缺失成员、依赖遗漏、错误摘要/覆盖数/报告均拒绝，不能回退最新值或静默导出缺语义包。

新版读取旧profile；旧离线客户端拒绝0.5，消费新包须升级。固定发布继续要求场景预览权限，导出另需space.export；暂停与退役停止新的在线读取和导出，已下载副本不承诺远程收回。

## 部署与检查

源码经feature PR、五项必需检查和squash merge进入main。核对main目标提交的quality-gate、build、test-coverage、audit、gitleaks通过后，才创建未使用的v0.12.0标签。镜像由该提交构建并核对OCI revision，production Environment人工审批后部署到vx-worker-02的 `/srv/md0/cospace`。不得上传本地源码或以main推送替代发布。

替换服务前沿用180秒备份检查，逐库复制并quick_check：preview-directory内三个本体数据库，以及runtime根目录的preview-lifecycle.sqlite3。缺库显式记录absent；损坏库阻断替换，manifest complete=false；记录workbench、ifc-parser、ifc-worker的旧镜像ID。备份仅保留worker02私有目录，不包含认证密钥或全部模型资产，不承诺跨库原子快照。固定发布目录不在本次数据库checkpoint中，部署不删除/改写它；模型资产继续使用既有备份策略。

审批后核对checkpoint完成、三项服务健康、IFC通道就绪及VERSION/镜像提交一致。公网检查首页/工作台静态资源、认证配置，以及匿名读取场景、本体、预检、发布语义和导出均被拒绝。真实身份的正向发布UI验收需要登录会话；三类园区合成数据测试不能代替现场专业验收。

## 回退条件

优先通过审核后的修复版本前进。v0.11.0不了解新语义成果，直接恢复旧镜像可能导出遗漏语义的旧包，因此不能直接把所有新发布交给旧代码继续分发。

如确需回退：先停止新写入，使用当前发布管理逐个暂停所有包含semantic_artifact的新发布，核对持久生命周期记录及在线读取/导出已拒绝；已暂停或退役的记录保持原状态。再对暂停后的生命周期库、本体库和固定发布目录作受控备份，记录清单及旧镜像。无法确认全部新语义发布已隔离时禁止恢复v0.11分发，保持流量隔离并走修复版本。

随后从已验证的v0.11.0提交95825cfc22611c9de4d19cf1427f7e1e1d35bdf1创建新的未使用回退标签，仍经GitHub镜像构建和production审批。保留固定成果文件、现有数据库与暂停状态；旧代码只继续分发未采用新语义的旧发布，禁止在旧界面恢复新语义发布。恢复新发布需先重新部署支持0.5的版本并完整复核后显式恢复。

应用回退不自动恢复数据库。确需数据恢复时须人工确认、停止相关写入、另备份当前状态，再逐库恢复并检查UID/GID 10001、权限及quick_check；生命周期必须保留回退前的隔离状态，不能用发布前的active快照覆盖暂停记录。禁止在线覆盖SQLite/WAL、删除新成果或重打已有标签。
