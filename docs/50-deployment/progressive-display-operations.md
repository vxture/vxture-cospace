# 渐进点云显示派生运维

L01 主空间浏览及 L02 工程统一消费已分别随 v0.14.0、v0.15.0 上线。地图配准、独立编辑与空间关联复用成熟显示派生，工程确认仍按原始点证据核验。L03 可选策略默认关闭。

## L03 策略配置

配置属于本体、场景之外的系统运维配置，不新增业务导航或用户调试选项。`/srv/md0/cospace/etc/.env` 的 `COSPACE_DISPLAY_STRATEGY` 经 compose 传入服务，在进程启动时读取：

| 值 | 行为 |
| --- | --- |
| `baseline`（默认） | 原生 500,000 点、30 px 节点、4 个加载槽 |
| `task` | 有明确初始作业点时，在首轮原生选择前定位；没有目标则保持全图 |
| `adaptive` | 运动时临时 250,000 点、60 px；按网络、帧时间和解码压力约束原生加载槽为 2–6，静止后恢复基线画质 |
| `governance` | 运动时限制新加载槽为 1；页面隐藏或不显示人工几何时暂停原生可见性选择，恢复时继续；不取消同版本在途读取 |
| `combined` | 组合上述三项，必须单独对照验收 |

缺省、未知值均回到 `baseline`，未知值记录不含配置原值的警告。可选策略执行异常时恢复基线预算与同一引擎、模型版本；权限、版本、Range 完整性错误仍按原门槛停止/清屏，不被性能回退吞掉。同版本局部错误的重试重新应用当前策略，不能解除隐藏或计算视图的暂停条件。

调整配置后通过已审核镜像的现有运维流程重建应用进程，重新打开页面读取生效值；不重建点云或精确索引，不改固定模型 ID、源摘要或发布。恢复 `baseline` 是关闭策略的途径。此版本保持默认基线，任何启用仍须满足技术方案第 9–10 节的独立门槛。

诊断数据保留在画布宿主 `data-*`，包括策略/回退、预算、P95/最大帧间隔、稳定视野时刻、当前缓存点数及 Range 未使用/重复字节。未使用字节按“路径结束再等 10 秒，仍未用于可见帧的 octree 节点范围”解释；只有 `accounting_complete=true` 才可比较。当前不提供真实 GPU 峰值内存计量，不能拿缓存点数或引擎返回的零几何数冒充完整内存指标。就绪时刻是当前 iframe 的单调时钟，跨页面比较必须换算时钟，不表示工程原始点已可确认。

## 发布与首次补建

1. 通过 feature branch / PR 的五项必需检查后 squash merge，发布标签从同一提交构建镜像；部署仍等待 production reviewer。
2. 镜像内固定 `/opt/potree/PotreeConverter`，主应用使用 `COSPACE_POTREE_CONVERTER`。启动时后台逐个扫描已完成候选和固定发布，不在浏览请求中执行转换。
3. 显示派生存放在业务 runtime 的 `model-displays/<派生摘要>/`，源模型、原始成果和既有发布不变。文件写完、全量校验及来源核对后原子就绪。未就绪时页面显示准备状态并轮询轻量入口。
4. 首次验收逐一打开现有场景的候选和固定版本，确认 metadata 200、hierarchy / octree 206、授权响应 no-store，首屏没有 human.ply / views.js 请求。反向代理不得对范围资源重压缩或改成 200。
5. 同一版本缺块时保留当前画面并暂停继续细化；重试后恢复。401/403/409 必须停止读取并清空已失去访问依据的画布。

## 失败与人工重试

失败记录位于 `model-displays/<派生摘要>.error.json`，服务日志记录派生摘要。自动扫描不无限重试同一失败，源摘要或转换参数变化会生成新派生。

需要重试时先停止持有该 runtime 的主服务，再在相同生产镜像和数据卷内运行：

```sh
python -m experiments.scripts.prepare_model_displays \
  --runtime /data/runtime --converter /opt/potree/PotreeConverter --retry-failed
```

命令使用现有进程生命周期锁，拒绝与主服务同时运行；仅清除失败标记并补建缺少的显示派生，保留原始成果和已有就绪目录。实际 runtime 挂载以 worker02 的现有 compose 配置为准。完成后核查错误记录，再恢复服务。不可直接上传本地源码或绕过镜像发布流程。

## 坐标、回滚和清理

显示使用双精度原点平移后进行原生量化；保留 LAS 往返测量和局部 Float32 的保守数值误差界，超过 1 mm 预算则拒绝生成。该值不代表源测绘精度，显示 LOD 不能用于确认工程坐标。大范围模型可能超过首版局部精度预算，此时应拆分局部空间或进入后续多原点适配，不可放宽门槛后静默显示。

回滚到上一应用镜像无需改写原模型，旧查看器忽略新增显示派生目录。首版不自动清理派生，避免删除固定版本仍使用的数据；磁盘容量计入运维监控。任何清理须先核对所有候选和固定发布引用，并按现有备份流程执行。

浏览器首版只使用内存缓存。公共引擎资源在构建时压缩，稳定路径继续重验证；业务块不进入公共缓存或持久化私有缓存。
