# ADR-004 智能体可信分发与离线有效性

日期：2026-10-27。状态：设计决策草案；密码库、密钥运维及设备时间条件未确认，尚未实现。

## 背景与决策

现有发布API可检查数据库撤回，机器人离线读取无法立即获知服务端变化。R0/R1摘要校验和本地安装仅证明一致性，不提供来源信任或使用授权。

采用内容证明、能力凭据、状态快照三类独立对象；内容和授权生命周期分离，几何不随续期重新生成。设备预配信任根，根委托内容与状态签发者；消息自带公钥不能成为根。首批验证JWS/Ed25519候选，采用成熟库和受限协议，不实现自有密码算法。

状态以部署、场景和包摘要为键，持久化最高epoch/sequence及摘要，限制旧消息重放和冲突；epoch增加由根授权。完整状态快照减少离线消费对历史增量链的依赖。发布撤回首批为终止状态，重新采用须新版本。

离线可用性取凭据、状态、委托和用途策略期限的交集；可信时间无法确认则返回unknown。下载时间不等于可信签发时间，重启不能重置预算。会话固定内容但每次受限查询仍须检查最新已接受有效性。

## 取舍与重审

这种方案保持SDK轻量且不依赖平台数据库，但需要受控设备配置、签发管理和可信时间条件。接受断网设备在有界期限内尚未知晓撤回的事实；不承诺即时全网撤回或对管理员整盘回滚的抵抗能力。

不采用摘要即信任、包自带密钥即可信、无限离线、旧会话永久授权或仅靠HTTPS实现离线核验。暂不部署通用PKI或新增身份基础设施；是否使用企业证书、KMS/HSM或硬件计数器，在客户要求、设备能力及互操作证据明确时重审。
