# ADR-001 基础技术栈

日期：2026-10-26\
状态：接受首批开发路线；UI组件、渲染和机器人专项保持待验证

采用Python 3.14、FastAPI/Pydantic 2、JSON Schema标准验证器、PostgreSQL 18与SQLAlchemy/psycopg作为平台开发基线；工作台采用Node 24、React 19、TypeScript、Vite和TanStack Query。数据管理与本体共用事务存储，正式内容以不可变文件包分发。

依据与精确试验版本见[评估与确认](../architecture/技术栈评估与确认-v0.1.md)。本次验证是组合兼容试验，并非所有框架的竞争性基准；选择兼顾现有实现、空间算法生态、离线交付和受支持版本。

Ant Design因依赖声明冲突保持有条件暂定；Three.js编译成功不足以确认WebGPU表现。C++20与ROS2继续专项评估。PostgreSQL基础通过不代表完整发布或恢复机制已实现。

重审条件：真实数据性能不足、UI依赖问题影响交付、Linux依赖不兼容、机器人SDK约束变化、组件支持期或许可路径变化。升级先回归已有契约及版本语义，不通过换框架绕过领域问题。
