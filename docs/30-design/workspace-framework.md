# 全站页面框架统一

日期：2026-11-11
状态：本地首轮实施，未部署。

## 页面类型

| 板块 | 页面定位 | 框架原则 |
| --- | --- | --- |
| 我的场景（场景中心） | 应用展示入口 | 保留卡片、地图、封面和展示型标题，不套工作台 |
| 构建中心、服务发布、空间关联 | 场景工作台 | 场景基本信息、来源版本及功能导航；中央内容；按需右侧指引或详情 |
| 数据管理 | 数据工作台 | 按生命周期查看共用目录，进入具体场景管理资料；沿用场景上下文 |
| 语义本体 | 共用规则工作台 | 左侧区分编制与固定版本校验；保持规则共用，不将本体误作场景私有 |
| 配置与管理 | 管理工作台 | 左侧管理导航；中央配置、账户信息；保留真实权限与接口行为 |
| 空间服务 | 按任务组织的混合页面 | 共用导航与标题规范，子页按浏览、获取、监测和管理分别布局 |

## 空间服务的特殊性

服务目录回答有哪些可用成果，离线交付回答如何选择固定版本并获取成果；两者保留卡片／列表、版本选择和获取操作，不改造成编辑表单。在线服务展示监测与接入状态，使用工作台内容结构。态势反馈和服务对象是管理功能，在接口未开放前继续准确显示未开放，不虚构清单或操作。与生产侧“服务发布”分工保持明确。

## 共用规范

新增 WorkspaceNavigation 与 WorkspaceHeading 组合，供本体和管理页面复用；数据管理使用 DS ShellSidebarNav 的完整分组导航；空间服务仅复用标题规范，保留 DS 服务导航与子页布局。来源版本导航继续使用构建／发布已有组件，不为无版本内容制造版本选择。

桌面导航宽 280px，外侧 16px，内部浅色容器 8px，导航项高 40px、间隔 8px。窄屏按需展开导航，不占用内容宽度。标题 18px、说明 12px，语义图标覆盖标题与说明两行；下方浅色实线分隔。子区标题沿用系统浅色虚线。中间内容桌面左右 48px，较窄视口 32px／24px，顶部 20px。标准文本操作按钮 14px、高 32px，次级操作使用 secondary、行内轻操作用 ghost；保持焦点与 hover 反馈。

数据详情宽 400px，列表名称列左对齐、其他信息居中。场景资料页取消重复场景选择条，场景选择由顶栏承接，读取错误仍显示并可重试。基本信息仅属于构建、空间关联、服务发布等场景作业；数据管理不提供基本信息维护入口。数据管理的共用目录与场景数据使用同一完整导航，分组、收起及窄屏抽屉均沿用 DS。

## 实施边界

本轮只调整框架、导航和视觉层次，不重设计各业务表单、不新增业务接口或商业限制，不改动场景中心展示页面。数据目录的旧 hash 记录链接规范化为实际路径，保证记录可进入相应工作台。空间关联保留已实现简版，不继续扩展集合修订能力。


导航间距校正：以 Console 卡券页实际 DS 导航为对照，条目高 40px、条目间距 8px。产品的 32px 内容按钮规则必须限定在内容容器内，不能覆盖 ShellSidebarNav 的条目或分组标题；数据目录与场景数据沿用 DS 分组间距，不额外增加分隔线。问题同时涉及产品 CSS 作用域和 DS 15.0.1 对 Tokens 4.0.0 的导航尺寸适配：当前 control-xl 已从 40px 收紧至 32px、control-md 从 32px 收紧至 24px，但 ShellSidebarNav 仍使用旧映射。已在正式 DS 15.1.1 中修正：条目使用 control-2xl（40px），分组标题使用 control-xl（32px）和 label-small（12px），文字继承触发器的 text-muted-foreground 及交互态。数据管理与空间服务共同生效；保留 DS 原有 hover、焦点、折叠和抽屉行为，不修改全局令牌或内容按钮尺寸。当前项目使用正式归档并移除临时补丁。
