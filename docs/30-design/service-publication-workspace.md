# 服务发布工作区设计

日期：2026-11-11
状态：四功能页本地初版已实现；本文新增基本信息常驻与正式版本编码要求，相关功能待实现。

## 定位与布局

服务发布以一个固定发布版本为操作上下文，提供发布概览、服务接入、离线交付、发布管理四项功能导航，不设计成四步流程。沿用构建中心的 DS 控件、标题层级和三栏布局。

左栏宽 280px，中间内容区横向留白 48px、顶部 20px，右侧助手宽 320px，可加宽到 640px。窄屏时侧栏按需展开，中间内容独立滚动，避免压缩表单和卡片。按钮统一采用 DS，常用文字操作 14px、32px 高，导航条目 40px 高。

左栏外壳顺序：

1. 基本信息：icon + 名称，无外跳图标。
2. 发布版本选择：正式编码、分发状态、含年份的时间；展开支持版本与来源搜索。
3. 发布概览、服务接入、离线交付、发布管理。
4. 底部固定快照说明。

基本信息与选择器同级，位于同一外壳内，宽度一致，外壳内留白 8px。基本信息是场景级常驻入口，应在构建、空间关联、语义关联和发布环节沿用同一语义、icon 与维护表单。点击后在当前模块中间内容区显示独立页面，不跳系统配置、不打开抽屉；保留场景及之前选择的版本，返回功能页时恢复上下文。只读和编辑状态遵循场景权限。

## 版本与信息层级

版本规则以[版本编码与依赖快照设计](version-identification.md)为准，本文不另定义一套编码。发布主标题为 B01-P02，状态标签跟在标题后方；第二行按“发布于 2026-11-11 10:30 · 来源构建 B01”组合展示时间与可点击来源。版本号各段至少两位，超过 99 自然扩展；场景号使用全局去重的六位随机数字。时间不参与版本号唯一性。顶部保留“查看空间”次级按钮和“新建发布”主按钮。

版本选择、来源链接、离线交付、版本比较与消费者引用使用同一服务端持久化编码。当前日期加 ID 尾码的展示属于过渡，待编号接口与历史映射完成后统一替换，不在前端推算 B/P。

基本信息页展示当前场景信息；发布概览按需查看“发布时基本信息”，展示固定快照及其修订来源。两者明确命名，修改当前信息不会更新旧发布。快照缺失明确显示未记录，不能使用当前表单内容填补。

## 四个功能页

| 功能页 | 主要内容 | 主要交互 |
| --- | --- | --- |
| 发布概览 | 来源、流程核对、质量验收；三类成果；在线与离线入口；按需展示发布依赖快照 | 来源构建、版本比较、进入接入／交付 |
| 服务接入 | 固定版本链接、查询地址、坐标约定、三维范围验证 | 复制链接／地址、展开范围查询 |
| 离线交付 | 完整交付、分区交付、本地消费三个页签 | 下载、核对清单、阅读本地消费说明 |
| 发布管理 | 分发状态、暂停／恢复／退役、替代版本、操作历史、来源与技术记录 | 权限及引用影响校验、原因填写、确认操作 |

三类成果卡片统一 icon + 标题、状态、结果规模与文件大小、含年份发布时间，文字与标题对齐。背景轻微区分基准模型与两种表达。分发中只表达授权分发可用，不代表质量验收通过。

离线包沿用发布号，以规格、范围、摘要区分包，不因下载产生新版本。消费说明不能伪装为已观察到消费机器的安装或激活状态。

技术记录按需展开，常用操作外放，其余遵循 DS 菜单；提示使用轻量色彩。操作成功使用 DS 通知，失败保留可理解的原因与重试路径。版本不可访问时明确告知，不静默切换为其他发布。

## 新建发布与生命周期

确认框展示确切来源 B、候选技术引用、核对修订与发布范围。请求沿用预期修订检查；来自构建的目标与当前选定候选不一致时阻止发布，不能默默发布其他候选。服务端成功创建快照后才获得正式 P，重复请求返回同一结果。

新发布绑定构建、资料、关联、规则与基本信息的确切快照。当前实现中不可变候选和人工核对的约束继续有效，不能为了共享 B 而跳过重新核对。更新关联后使用新 P 仍需有完整、受核对的依赖绑定。

暂停、恢复和退役不增加 P；退役保留历史与替代引用。新查询和导出遵循接口门禁，已下载副本不能远程撤回。当前样例出现“来源或引用记录不完整”时保持操作禁用，不以设计改动绕过。

助手当前提供各页操作指引，智能问答尚未接入，不显示虚构的对话、执行日志或交付回执。

## 实施与验证顺序

1. 服务端实现持久化业务编号、候选到 B 的映射、幂等与唯一约束。
2. 演练历史补号，保留旧链接、ID、固定清单与包摘要。
3. 构建、发布、资料与消费界面统一采用正式编码；再接入发布依赖快照展示。
4. 共用基本信息表单，在发布左栏常驻并区分当前信息与发布时快照。
5. 验证场景切换清理旧记录引用、版本切换同步所有操作、权限与生命周期门禁、并发发布、旧版本可追溯以及窄屏布局。

现有本地初版已覆盖三栏框架和四功能页，并复用既有业务接口。本文新增规则是实施依据，不表示编号服务、历史迁移或基本信息常驻已完成，不表示已部署。
