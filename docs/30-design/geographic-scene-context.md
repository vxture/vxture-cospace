# 场景地理位置与高度

日期：2026-11-11。CoSpace 为首个真实 SDK 使用方，独立样例验证跨页面复用。

## 位置数据

基本信息继续按场景保存经度、纬度、可选高度和 WGS84/GCJ02，新增坐标来源及高度
基准：未明确、WGS84 椭球高、海拔（待转换）。高度范围为 −12000 至 100000 米。
新字段可选，旧记录不补造来源，也不把旧高度解释成椭球高。修改保留修订、操作者、
原因和前后值；旧客户端仅修改名称描述时仍保留全部位置元数据。

保存与未保存离开时共用位置校验，经纬度成对填写，拒绝非有限数或越界值。表单高度
基准无高度时禁用；不完整的位置不能通过离开时保存绕过浏览器校验。保存使用 DS toast。
保存事件刷新已挂载的场景目录，详情展示高度基准及坐标来源。

## 二维与三维

- 二维沿用高德官方 WGS84 到 GCJ02 显示转换，仅转换显示副本。
- 三维仅使用有效 WGS84 水平位置。GCJ02 显式显示待转换，不直接投到 WGS84 球面。
- 明确的椭球高用于绝对高度；海拔、未明确基准或无高度的场景标记采用贴地模式。
- 地理位置不改变点云 XYZ，也不意味着模型完成地理配准。

三维清单与标记选择联动；筛选移除当前场景时清除选择，避免详情展示筛选外内容。
原地图设置中的筛选后自动取景在三维启用，新增手动取景按钮；全球复位仍返回全球。
缺失位置或 GCJ02 点击时给出具体原因，不显示虚假的定位成功。

SDK 0.2.0 为点、线要素增加 `heightMode`：ground 贴地，absolute 保留椭球高。
未声明模式时保留 0.1 行为：点绝对定位，线贴地。新接入应显式声明模式。SDK 新增
fit 与 select，原协议及 Cesium 版本保持，运行配置报告准确 SDK 版本。

## 验收数据与后续范围

本地使用单独目录和认证状态的“定位验收 · 合成测试场景”，不得将合成经纬度保存到
真实演示项目。原真实场景无来源明确的位置时继续显示未登记。独立样例只展示标注清楚的
合成地面/空中轨迹，不写业务数据。

GCJ02 逆转换、海拔到椭球高的垂直转换、模型地理配准及真实外部智能体接入不在当前
实现范围。CoSpace 自身验证产品链路，独立样例验证 SDK 复用，两者验收结论分别记录。

## 地图交互与资源传输修正（2026-11-12）

场景卡片状态在标题行右侧固定对齐，名称弹性截断。定位汇总前使用信息图标，
二维与三维保持相同结构。正北在引擎就绪后始终可操作；复位在有坐标时框选筛选结果，
无坐标时恢复全球视图，不伪造场景位置。取消单独的重复全球复位按钮。

配置与管理属于本系统功能域，顶部齿轮在新标签页打开完整管理导航与内容框架。
组织名称使用 DS 正文字号，场景上下文保持次级字号。

线上基线：三维脚本 4,206,018 字节，未压缩且 no-store，单次下载实测 11.43 秒。
构建阶段为公开文本资源生成 gzip 副本，三维入口聚焦时预加载引擎。内容哈希资源
使用一年 immutable 缓存；Cesium 固定路径资源每次重验证，避免升级后复用旧文件。
页面、认证、业务接口与错误响应仍为 no-store。不得缓存带授权的业务数据。
本地新三维包 gzip 约 1.11 MB，传输减少约 73%；线上端到端耗时须发布后复测。
