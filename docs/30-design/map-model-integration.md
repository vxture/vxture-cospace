# 地图与三维模型衔接

日期：2026-11-11

## 引擎分工

高德 JS API 2.0 负责标准地图、卫星影像、地理标注及 2D/3D 地图；Three.js 负责自有点云和模型。现阶段不引入第三套三维引擎，不将底图楼块视为项目模型。

## 本轮接入

标准地图/卫星影像、2D/3D 选择接入真实 SDK，保存到原有浏览器偏好；旧偏好补入标准地图/2D，不覆盖用户原选择。卫星影像使用官方 Satellite，按道路开关叠加 RoadNet。视图模式改变时重建地图并保留中心和缩放，恢复场景标记；3D 初始俯仰 45°。独立图层随设置关闭和组件卸载释放。加载错误显示实际失败，不伪装成功。

名称采用标准地图、卫星影像、地图主题、视图模式、道路、建筑物、兴趣点（POI）。省级行政边界准确表示当前 Country/depth=1 的叠加层范围，底图自身边界不由该开关清除。

## 模型配准边界与后续数据契约

当前基本信息已保存经度、纬度、可选高度及 WGS84/GCJ02；原始点云保留原坐标，地图展示坐标单独转换。经纬度只能确定场景锚点，不能证明模型已经地理配准。

地图叠加自有模型前还需独立、可追溯的模型配准记录：绑定模型版本，明确局部原点、单位、轴向、地理锚点、水平坐标系、垂直基准、航向/俯仰/横滚及缩放；记录人工确认及验收状态。不能把未说明基准的高度当椭球高，不能默认点云原点就是经纬度锚点。未配准模型继续使用独立 Three.js 预览。

本轮不虚构配准参数、不改写原始点云、不在全国地图上放置未经确认的三维模型。后续按“选择固定模型 → 确认坐标及原点 → 调整朝向与高度 → 预览对齐 → 保存配准版本”实现。

## 验证范围

前端生产构建及 52 项前端测试通过；本地浏览器验证了模式选择、方向键切换及刷新后偏好保留。本地未配置高德 Key，真实卫星瓦片、三维俯仰和有定位场景的视野保留仍需接入环境验证。模型配准本轮仅完成数据与流程设计。

## 地图操作区

方向、视角与缩放使用同一竖向工具条，按钮命中区域为 32px，提供操作提示。正北按钮随地图旋转显示方向，点击归零；3D 提供俯视（0°）与倾斜（45°）切换，2D 隐藏该操作。复位同时恢复正北、当前模式的默认俯仰，并取景当前筛选结果；没有已定位场景时回到全国。放大、缩小保持当前方向与俯仰。切换 2D/3D 保留中心、缩放与朝向。地图未就绪时禁用相机操作，设置仍可访问。
