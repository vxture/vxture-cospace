# 地图与三维地球、模型衔接

日期：2026-11-11

## 引擎分工

- 高德 JS API 2.0：二维标准地图、卫星影像和地理标注。
- CesiumJS 1.147.0：真实三维地球、全球地形和地理场景承载。
- Three.js：独立点云与项目模型预览。

用户明确要求三维地球；高德倾斜地图不能代替地球。入口统一为“二维地图 / 三维地球”，默认进入地球，记忆用户选择。移除原高德 2D/3D 设置入口。地图与地球引擎按需加载，切换时释放各自实例和图层。

## 三维地球

采用 WGS84 椭球及全球初始视角，支持自由旋转、缩放、正北、围绕视图中心俯视/倾斜和全球复位。PaperPlaneIcon 默认朝上，根据相机航向显示北向；工具条按钮为 32px，提供悬停提示和不可用状态。

卫星影像使用 Esri World Imagery，地形使用 ArcGIS WorldElevation3D Terrain3D，保留提供者署名。基础纹理使用 Cesium 随包 NaturalEarthII。外部服务受可用性及其使用条款约束，不构成产品自有数据；服务失败显示状态，保留基础球体。地形元数据成功不代表全部瓦片已经加载，瓦片失败另行提示。渲染失败显示明确错误。

Workers、Assets、Widgets、ThirdParty 从发布镜像的 /assets/cesium/ 本地提供。开发服务与生产构建提供同一路径，不依赖 Cesium ion Token，不将运行凭证写入代码。

场景目录与详情保留。有效 WGS84 坐标展示标记并支持飞行定位；无位置、GCJ02 待转换或无效坐标不投点。当前演示场景没有登记位置，不为演示虚构坐标。GCJ02 到 WGS84 的地球定位转换待后续补齐。

## 二维地图

标准地图/卫星影像使用真实高德 SDK 并保存浏览器偏好；旧偏好兼容读取。卫星影像使用官方 Satellite，按道路开关叠加 RoadNet，不应用标准暗色地图的灰度处理。

地图要素采用省级行政边界、道路、建筑物、兴趣点（POI）。省级行政边界指 Country/depth=1 的增强叠加层，底图自身边界不由此开关清除。独立图层随关闭及卸载释放。

二维工具条提供正北、复位、放大、缩小和设置。复位恢复正北与俯视，并取景当前筛选结果；没有已定位场景时回到全国。地图未就绪时禁用相机操作。

## 模型配准边界

基本信息已有经度、纬度、可选高度和 WGS84/GCJ02。经纬度只能确定场景锚点，不能证明项目模型已地理配准，不能将底图建筑或全球地形当作项目成果。

叠加自有模型前需独立、可追溯的模型配准记录：绑定模型版本，明确局部原点、单位、轴向、地理锚点、水平坐标系、垂直基准、航向/俯仰/横滚、缩放及人工确认。不能将未说明基准的高度当作椭球高，不能默认点云原点就是场景经纬度锚点。

原始点云保留原坐标；未经配准的模型继续独立预览。后续流程为“选择固定模型 → 确认坐标和原点 → 调整朝向和高度 → 预览对齐 → 保存配准版本”。本轮不改写原始点云或叠加未经确认的项目模型。

## 验证

生产构建及 54 项前端测试通过，依赖审计未发现已知漏洞；资源打包验证包含 Assets、Workers、ThirdParty、Widgets。浏览器验证了全球球体、卫星影像与地形服务加载、缩放、俯视/倾斜、复位和二维/三维切换。当前真实场景无坐标，场景标记飞行需有定位数据的场景进一步验收。模型地理配准仍属于后续实施范围。
