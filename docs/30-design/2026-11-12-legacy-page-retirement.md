## 顺序与完成条件

按空间预览、配置管理四项、合成示例三项、候选与发布查看器的顺序逐项推进。每次只将有证据完成的项目改为已完成；其他项目继续保留在 Launcher 下方可收起的待迁移区域。

每项必须记录功能盘点、承接页面、调用替换、旧路由处理、源码及样式清理、验证结果。旧路由如需兼容，只保留明确的转向逻辑，不能继续挂载另一套旧页面。数据 API 与 HTML 页面分别判断，不以删除页面为由删除数据接口。

完成项目先在本台账留档；确认承接和清理均完成后，才从待迁移区域移除。全部项目完成前不得删除整个分区。不得把移除入口、已有外壳或保留旧页面运行视为完成迁移。
