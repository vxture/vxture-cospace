# 旧页面入口清理

日期：2026-11-12

| 原待迁移条目 | 承接方式 | 本次处理 |
| --- | --- | --- |
| 空间预览 | 我的场景负责选择与展示；空间服务负责发布服务发现 | 移除重复发布目录。普通 /space?space=… 使用我的场景框架；“进入场景”进入构建中心的基本信息页 |
| 业务配置 | 配置管理 /settings | 保留新版管理框架，移除 Launcher 的旧入口和本机虚假配置表单 |
| 成员与角色 | 配置管理 /members | 保留真实平台身份与授权信息，删除临时成员草稿界面；不创建成员管理 API |
| 登录集成 | 配置管理 /identity | 保留真实身份概览，删除“认证待接入”的历史演示内容 |
| 个人账户 | 配置管理 /account；账户菜单通向平台账号中心 | 删除模拟账户资料 |
| 设备间、水泵设备间、巡检设备区示例 | 真实场景成果查看 | 删除合成示例组件及专用 spaces.ts；旧示例链接回到我的场景 |
| 旧版候选查看器 | 构建成果和关联模型入口 | 移除 Launcher 重复入口；保留仍被业务引用的服务端固定成果查看及接口 |
| 旧版发布查看器 | 空间服务、固定发布的真实三维查看器 | 移除 Launcher 重复入口；保留 /space?screen=space&publication=… 和固定发布数据接口 |

Launcher 不再保留“待迁移”分区。配置管理由全局齿轮进入新标签页。

本次仅移除应用中重复导航、合成界面与未使用组件；不会删除场景、构建、发布、权限或历史运行数据。space.svg 仍由场景封面使用，保留。真实成果查看器和服务端 HTML 查看仍存在业务调用，不能以“旧版”标签为由删除。
