## 顺序与完成条件

根据本轮确认，优先迁移配置管理四项；空间预览、合成示例三项、候选与发布查看器继续待迁移。每次只将有证据完成的项目改为已完成；其他项目继续保留在 Launcher 下方可收起的待迁移区域。

每项必须记录功能盘点、承接页面、调用替换、旧路由处理、源码及样式清理、验证结果。旧路由如需兼容，只保留明确的转向逻辑，不能继续挂载另一套旧页面。数据 API 与 HTML 页面分别判断，不以删除页面为由删除数据接口。

完成项目先在本台账留档；确认承接和清理均完成后，才从待迁移区域移除。全部项目完成前不得删除整个分区。不得把移除入口、已有外壳或保留旧页面运行视为完成迁移。

- 四项配置管理逐项复核后移出 Launcher 待迁移清单，文档继续留档。其余 6 项仍保留入口；正式配置管理由全局齿轮进入。/members、/identity 旧书签保留兼容转向。

- 删除 main.tsx 内 Configuration、PlatformAccount、DataRows、模拟成员分支及弹窗、相关 state 和无引用的示例表格常量。
- 删除 SpaceSettings 的独立设置页渲染分支、独立场景选择器及重复目录请求；保留构建、关联、发布三个流程共用的同一个基本信息表单和保存接口。
- 模拟全局配置字段：工作区名称由平台身份承接；场景名称由基本信息承接；单位/坐标由真实资料及模型声明承接；本体由语义本体与空间关联承接；交付模板和发布方式由各版本的发布交付流程承接。原表单未曾影响真实构建或发布，其本机模拟默认值不写入真实业务数据。
- main.tsx 中合成示例仍需要的两个展示名称保留为固定示例值，随示例批次清理；本轮不删除示例页面、源码或真实业务数据。

## 空间预览迁移记录

- 旧页面的独有能力为单场景固定发布目录，已整合到我的场景详情；清单和地图共用同一个详情组件。保留封面、版本卡片、发布时间、当前工作候选对应关系与逐版本打开动作。正式编码优先 display_code / version_code，兼容未编码历史记录显示完整 ID。
- 当前指定发布与当前工作候选分别标识；候选关系通过只需 space.preview 的 workflow API 读取，失败提供重试且不阻断版本目录。没有授予构建或管理权限。基本信息改为 /build?space=…&tab=info；保存仍由服务端检查 space.manage。
- “进入场景”只打开 publication_id 明确指定且 active 的固定发布。缺失、暂停、退役或未知生命周期均回到详情，不以其他历史发布替代。历史发布仍可逐一查看，可用历史版本可打开，暂停/退役版本禁用。
- /space?space=… 旧书签由 SceneCatalog 承接，直接打开对应详情；关闭清除 URL 选择，浏览器返回恢复详情。不存在或无权访问的场景显示提示，不自动替代目标。/space?screen=space&publication=… 保留真实三维查看器。
- 删除 module-workspace.tsx 的 ScenePreview、专用候选匹配 state/import、旧路由挂载分支以及全部 module-preview-* / module-version-id / module-release-active 样式。SceneCover 和合成示例使用的 space.svg 保留；真实三维查看器的对象、图层、版本切换、复位及全屏能力保留。
- 真实查看器同步使用正式版本编码、明确生命周期可用性和“我的场景”返回入口；场景切换不再放行不可用的当前发布。
- 验证：25 项前端导航/权限/版本契约测试，37 项 workflow、发布退役和公开路由后端测试通过；生产构建及仓库/规则集检查通过。浏览器确认旧书签承接、版本卡片/候选关系、关闭与后退、基本信息入口及真实点云三维画布加载。
- 本轮仅移除 Launcher 的“空间预览”待迁移项，剩余 5 项：三个合成示例、旧版候选查看器、旧版发布查看器。其入口及源码均保留，继续按本台账逐项处理。
