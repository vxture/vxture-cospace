# 空间关联工作区设计

日期：2026-11-11
状态：第一批工作区已在本地实施并验证；尚未部署。第二、三批为后续设计。

依据：[服务发布工作区](service-publication-workspace.md)、[版本编码](version-identification.md)。本模块沿用构建中心的导航、标题、DS 控件与留白规则，不增加强制四步流程。

## 定位与边界

空间关联回答：模型中有哪些对象、对象在哪里、对象之间是什么关系、对象引用哪些业务记录。基本信息回答场景的名称、描述、地理位置和场景坐标声明；语义本体提供共用类型、属性和关系规则；本模块应用固定规则维护场景实例，不编辑共用规则。

现有对象模型将类型、属性与几何锚点保存在同一固定快照，暂不拆出另一套重复的“语义关联”编辑器。空间关系与语义属性在界面中区分，发布依赖按实际存储快照绑定；不能把一份保存记录包装成两套独立 R。后续独立存储语义修订时再明确迁移关系。

当前能力包括点锚定对象、规则约束的对象关系、固定设备台账绑定和 IFC 构件浏览。点锚定不等于对象轮廓或空间范围；连接不等于可通行；包含声明不等于几何包含已验证；规则通过不等于现场确认。页面必须准确显示这些能力边界。

## 当前问题

- 四个页面独立读取并选择候选，切换后容易操作不同快照；技术 ID 占据主信息位置。
- 对象创建、位置选择、完整集合保存混在长表单中，缺少以对象清单为主的工作面。
- 关系与业务页面缺少统一的来源、修订、未保存及待发布状态。
- IFC 只有资料浏览能力，当前并无自动配准、构件匹配或批量转对象接口，不适合作为独立主导航。
- 保存生成新候选后反复引导返回构建中心，用户难以判断是否重新构建、是否改变既有发布。
- 尚无完整关联集合的持久修订、乐观锁与恢复草稿能力；不能先在界面显示虚构 R 编号。

## 页面框架

采用左侧功能导航、中间作业内容、右侧助手。导航宽 280px；助手默认 320px，按既有规则折叠或加宽。窄屏侧栏覆盖展开，不挤压三维视图和表格。对象详情属于作业内容，不能与助手争用同一个面板。

左栏同一外壳内统一 8px 留白，条目 40px 高，顺序为：基本信息、来源构建选择、关联概览、对象管理、空间关系、业务关联。基本信息与构建、发布共用表单和 icon，不跳设置或抽屉。底部简要展示当前修订与最近保存时间；不重复列资料入口。

来源选择使用服务端 B 编码，第二行显示含年份时间与状态。构建下存在多个关联候选时，通过真实候选引用区分，不能只用同一个 B 标签掩盖差异。未实现修订前显示“历史快照 · 短引用”，技术 ID 可复制。

中间页头为两行：第一行“空间关联 · B01”和当前工作状态，第二行显示关联修订、更新时间及固定规则版本；icon 跨两行。右侧保留“查看模型”次级操作，以及有变更时的“保存修订”主操作。保存成功后才提供“核对发布”，将其作为明确的后续操作，不直接静默发布。展开历史为轻量按钮。

页头下方浅色分隔线；功能页标题采用共用 workspace-section-heading，标题与描述左对齐、icon 跨两行。正文不重复堆叠模块大标题。操作通知使用 DS 通知，不在正文长期占位。

## 内容规划

| 功能页 | 主要内容 | 主要操作 |
| --- | --- | --- |
| 关联概览 | 来源 B、固定本体、对象/位置/关系/业务引用数量、校验问题、与选定发布的差异 | 选择规则、定位问题、查看修订、核对发布 |
| 对象管理 | 搜索与类型筛选、对象清单、模型位置、类型与属性、来源证据 | 添加对象、定位、编辑、移除；按需浏览 IFC |
| 空间关系 | 归属树与关系清单；源对象、关系、目标对象、说明、校验结果 | 添加关系、定位端点、编辑、移除 |
| 业务关联 | 对象与固定台账版本的绑定清单、登记记录、来源摘要 | 关联台账、查看记录、解除关联、登记版本 |

概览统计只展示后端确实可计算的数量；不显示无依据的“完整率”。没有预期对象范围时不能把已标注数量除以模型点数当覆盖率。待核实状态与规则校验结果分别展示，不能合成“已完成”。

对象表列：序号、对象名称、类型、位置、来源、关联摘要、操作。列头居中，名称列正文左对齐，其余居中；长名称保留省略和完整提示。主操作“定位”外放；竖向三点菜单承载编辑、查看证据与移除，点击区域 32px、icon 24px，复用 DS 操作面板。

对象编辑时使用中间区的清单/模型与属性编辑布局，窄屏在清单、模型、属性之间切换。默认只展示名称、类型、位置和必要属性，其余属性按分组展开。对象 ID 稳定、可复制，由系统提供建议值；技术点索引归入高级操作，模型选点为主要入口，提供可见的选点模式与提示。

IFC 构件浏览从对象管理的“参考资料”入口进入，保留固定资料、GlobalId、类型与几何状态。目前只浏览参考；未经坐标变换验证，不提供“自动匹配”“一键关联”或将构件中心直接当作模型坐标的操作。

关系表以“源对象—关系—目标对象”为主体。归属树只从实际包含/位于关系构造；无归属对象单独列出，不按命名猜楼层。关系图可后续补充，不作为首版阻塞项。端点类型按规则筛选，提交时服务端仍校验自身引用、重复、单父归属与循环。

业务清单与台账登记分开。默认看对象绑定，登记表按需打开。一个对象当前最多引用一个设备台账版本，保留该约束；解除仅作用于新修订，不删除来源台账或旧发布引用。外部系统尚未接入时不显示同步状态或虚构更新时间。

## 编辑、修订与发布

1. 选择场景和来源构建，读取确切关联快照；四页共享同一上下文。无成功模型时显示构建入口，基本信息仍可维护。
2. 选择固定本体版本后创建或编辑对象；对象是关系和业务绑定的共同端点。切换规则先检查现有类型、属性与关系兼容性，不自动丢弃内容。
3. 每项编辑先进入当前草稿，清楚标注未保存；跨功能页保留，切换场景、构建或离开模块时统一处理未保存变更。
4. 保存前展示变更摘要与校验问题，包括对象移除对关系/业务引用的影响。存在引用时不得静默级联删除，需先处理或明确确认移除范围。
5. 服务端校验成功并原子保存后产生关联集合 R；无变化与幂等重试不增号。使用预期修订拒绝并发覆盖，冲突后允许查看差异及重新载入。
6. 保存使关联成为“已保存，待核对”，不等于发布或现场验收；核对后才能用新的 P 固定发布。来源 B 和旧 P 保持不变。

工作状态区分：未保存、已保存待核对、已核对待发布、已纳入发布。展示时依据真实候选/审核/发布引用，不把“已有任意发布”当作当前修订已发布。现场核实与机器规则结果独立，首版没有确认接口时保持“待核实”。

历史修订仅从真实保存记录读取，完整显示 R、时间、变更摘要与来源 B；查看历史只读。恢复历史应作为一次新的保存，不覆盖旧记录或回退计数器。

## 实施顺序与技术约束

第一批统一工作区、基本信息、来源选择和四个功能页，复用现有接口及校验；保留旧 tab/候选深链兼容。IFC 旧入口映射到对象管理的参考资料视图。此阶段继续准确显示“历史快照”，现有保存行为如仍为生成候选，应使用“保存关联候选”，不提前换成并不存在的“保存修订”。

第二批实现关联集合修订与共享草稿：服务端持久修订、完整依赖引用、幂等、预期修订、跨页完整集合保存，以及对象移除影响校验。现有三个候选接口分别修改对象、关系、业务，不能将三次独立请求伪装成一次原子保存；需要聚合服务或明确保持分项保存。先解决这一约束，再启用统一“保存修订”。

第三批对接核对与发布依赖，展示当前修订与固定发布差异。几何未改变不新分配 B，关联候选保留自己的技术 ID；发布绑定确切快照，不读取最新关联冒充历史。旧发布的签名和交付包不重写。

验收包括场景与模型切换、未保存保护、深链恢复、只读权限、缺失本体、空对象集、关系循环、对象被引用后移除、并发保存、幂等重试、无变化保存、旧发布稳定性、窄屏清单/模型交互及键盘操作。

## 对象管理的模型联动

对象清单、三维模型和属性面板共享同一候选及草稿。清单中的“定位”以已核验的模型锚点聚焦并打开属性；点击画布标记选中同一对象。添加或编辑对象时，原模型仍在工作面中，双击可见点提议位置，由服务端复核模型点索引、模型摘要和坐标基准后显示锚点。表单保留按点索引读取的备用入口。模型预览抽样展示；对象标记使用完整模型的精确锚点，不吸附到抽样近邻。切换到其他关联功能时释放三维画布，当前候选的表单和草稿仍保留。

模型上的标记是人工声明的点，不表示对象范围或现场核验。编辑提交仍使用固定本体、对象 ID、属性和原始点索引；界面持有的坐标不会作为客户端输入提交给服务端。归属由空间关系独立声明。关联候选经核对后发布，查看器按发布快照展示同一对象、属性、点证据和关系。

隔离环境用公开 NYU 室内点云（56,637 点）做浏览器验收：清单定位、画布标记反选、双击取得第 45,438 点、填写设备名和资产编号、保存对象候选、追加设备间归属、核对新增一个对象和一项关系且几何不变、固定发布并在三维人视图／智能体视图复查。设备和归属是流程测试声明，仍为待核实。跨工作台交接时曾需一次重试或刷新，未重新提交写入；本批未修改会话或构建读取逻辑。真实样本 HTTP 验收 48 项通过，包括旧发布不变和在线／离线一致性。

## 合成示例模板整合（2026-11-12）

对象管理统一承接设备间、水泵设备间、巡检设备区三套模板的 9 个名称及建议类型。模板不生成模型、不提供自动定位，不将示意图当作几何成果。逐个选择位置后才可加入本次对象草稿；类型不匹配时需先维护本体版本。泵组、控制柜、检测柜补充到设备规则 v0.3；语义本体可从此模板新建 Workspace 草稿，经校验后固定。

老示例书签转入对应模板并要求选择授权场景。三个 Launcher 条目和旧渲染器删除；真实发布查看器继续承接对象、属性、证据、图层及人/机视图。空间关系仍需人工建立，不从楼层名称推断包含关系。
