# 智能助手面板与授权模式

本次实现采用 2026-11-16 确认的 HTML 规范。下载包与设计预览属于本地成果，不随生产镜像分发。

- 全局 Header 使用 card 与 border 下边线，无阴影。
- 助手保留 DS ShellDock 的 420px / clamp(480px,46vw,760px) 宽度，surface-3 纯色、左侧淡阴影；全屏铺满 Header 下的工作区。
- 固定标题和底部输入/授权区；推荐按需折叠，空推荐整体隐藏。滚动条隐藏但内容仍可滚动。
- 用户消息靠右按内容自适应宽度、右侧头像；普通回复全宽，业务操作使用卡片。
- 授权三档：逐项确认（每项操作前请你确认。）、常规授权（常规自动，重要或存疑时确认。）、充分授权（授权范围内自动执行。）。图标使用 DS list-checks / target / agent。

## 当前能力与边界

目前是规则驱动的业务建议检索，不是模型聊天。输入只匹配当前可读任务，不创建任意可执行动作。每个动作仍进入既有业务表单；三档仅为当前工作面的确认偏好，不改变后端权限，也不会绕过既有普通/危险操作确认。界面明确显示此限制。

模式、输入和历史按当前账户、场景、路由及版本的 scope 重置，不持久化敏感对话。历史动作绑定任务 ID、证据、名称和操作标签；来源变化后禁用，点击时再次匹配当前任务。所有执行依旧受后端权限约束。

未来接入模型或连续执行前，需实现服务端动作风险注册表、对象/动作/有效期范围、绑定参数及版本的确认凭据、幂等、取消和审计。不能把前端模式当作授权凭据。危险操作所有模式均确认。

## 验证

契约测试覆盖三档文案、真实任务匹配、不可读状态不推荐、检索不执行动作、证据变化使历史动作失效。浏览器验证覆盖输入折叠、业务检索、三档图标及选择、窄宽全屏和小屏布局。生产上线走 PR 五项检查与 production reviewer。

## 入口与显隐调整

助手默认关闭，由 Header 独立入口打开；入口位于全局工具按钮组之外，32px 按钮、24px AI 图标。窄宽切换使用单个按钮：窄模式显示向左双箭头（扩展），宽模式显示向右双箭头（收回），名称和提示同步变化。
