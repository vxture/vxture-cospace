# 登录与非业务状态页调用规则

实现入口：`AuthBoundary`、`BusinessSession`、`PlatformIdentityPage`。
状态映射：`apps/workbench/src/layout/entry-state.ts`。
这些页面由真实接口结果驱动，不增加面向用户的状态演示路由或查询参数。

## 调用顺序

1. 读取 `/api/auth/config`。等待时显示“正在连接”，读取失败显示“暂时无法连接”。
2. `engineering_preview` 保留原工程预览；`identity_pilot` 进入独立账号验证；
   `authorized_workbench` 且启用业务授权时进入业务会话检查。
3. 读取 `/api/auth/session`；已有身份还须 POST 确认中央会话。
   尚未读取完成显示“正在恢复登录”。已存身份但未经服务端确认、确认失败或过期缓存显示“等待恢复登录”。
4. 确认身份后读取订阅和应用授权。只有平台返回 `business_allowed=true`
   且会话确认有效时，业务入口才开放。状态展示不另行推导或授予商业权益。

## 页面与条件

| 页面 | 实际条件 | 操作 |
| --- | --- | --- |
| 登录 | 服务端明确 `authenticated=false`，无需要恢复的工作面，也无本标签主动退出标记 | 继续登录，保留原路径和查询参数 |
| 已退出登录 | 主动账号退出成功，回到本站后服务端无会话 | 重新登录 / 账号中心 |
| 等待恢复登录 | 身份存在但确认不可用；或已有工作面且会话变为失效 | 重新检查；无身份且保留工作时提供新标签页重新登录 |
| 正在确认使用权限 | 独立身份入口还在读取配置或权限，或订阅结果尚未到达 | 禁用的核验按钮 |
| 尚未获得使用授权 | 可读的平台结果中 `application_authorized=false` | 前往工作台 / 重新检查 |
| 工作区订阅需要续订 | `business_allowed=false` 且平台明确 `status=expired`，用户没有先被应用授权拒绝 | 前往工作台 / 重新检查 |
| 当前工作区未开通 | 权限结果可读且业务不允许，其余未开通条件 | 前往工作台 / 重新检查 |
| 暂时无法确认使用权限 | 权限接口读取失败或不可用 | 重新检查，不展示为未开通或到期 |
| 平台账号已连接 | 仅独立身份验证模式：会话已确认、未启用订阅检查或权限已允许 | 重新检查；业务模式在允许后直接进入工作台 |

订阅 `status` 非空不等于到期。`active`、`trialing`、`overdue`、`suspended`
等不能据此显示“需要续订”。是否允许业务仍以平台 `business_allowed` 为准；
即便账单状态是 `expired`，平台明确允许时也不在产品侧二次拦截。

状态优先级：会话未确认 → 权限不可读 → 应用未授权 → 平台允许 → 明确到期 → 未开通。
服务端未返回结果不能默认为成功；独立身份入口初次读取期间也不能先显示已连接。

## 恢复与退出

- `BusinessSession` 中的重新检查重新 GET/POST 会话，再读取平台权益。
- 独立身份入口的重新检查同样重新确认会话，不仅重读订阅。
- 已有业务工作面被保留、遮挡并设置 inert；未确认会话时业务请求仍被拦截。
  恢复不会自动重放保存、构建或发布操作。
- 会话失效后的重新登录在新标签页执行，原标签页保留原路径。
  点击重新检查或恢复焦点可确认会话，授权通过后恢复原界面。
- 退出入口仍在业务账号菜单；状态卡片不增加第三个退出按钮。
- 退出页标记仅在退出接口成功且返回跳转地址通过原有校验后写入。
  重新登录时移除；新业务会话启动时移除旧标记。
  已确认的新会话与需要恢复的业务均优先于退出标记。

## 验证范围

- `tests/frontend/entry-state.test.mjs` 验证状态映射、优先级、缓存确认边界和重试结果。
- 平台登录、订阅、应用授权及公共入口现有 Python 回归保持通过。
- 本地运行实际构建前端，使用示例接口依次验证连接失败恢复、登录回跳目标、
  未确认身份、未开通、明确到期、未授权、权限接口失败和授权恢复。
- 使用业务账号菜单验证退出完成页；在已有工作面触发会话失效，验证新标签页登录和原路径恢复。
- 本地示例接口只验证前端调用和状态流转，不替代生产 OIDC、真实组织订阅及场景数据的验收。
