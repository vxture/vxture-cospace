# 智能助手接入约定

## 框架与显示范围

首页、空间全景、我的场景不显示助手；数据管理、语义本体、构建中心、空间关联、服务发布、空间服务及账户管理页面均使用同一外壳。每次打开业务外壳默认展示窄模式，可关闭后由顶栏“智能助手”重新打开。

直接使用当前 DS `ShellDock`（design-system 15.6.1），不复制三个业务页的旧面板：

| 模式 | DS 尺寸与本产品处理 |
| --- | --- |
| narrow | 26.25rem，即默认字号下 420px |
| wide | clamp(30rem, 46vw, 47.5rem)，即 480–760px；不是固定 672px |
| full | 接管产品标题栏下的内容区，四边保留 16px，移动端 8px；任务内容保留内边距 |

面板标题固定“智能助手”，模式固定“逐项确认”。具体模块、对象名称、检查结果、任务均在滚动内容区；标题和底部提示固定。窄屏停靠到右侧，避免压缩业务内容至不可用。全屏模式保留产品顶栏，不启动浏览器全屏。选择任务后桌面恢复窄模式，窄屏收起助手，露出任务处理界面；重新打开仍可继续选择。构建画布同样接入此外壳，不作为助手入口例外。

## 数据与推荐

`WorkspaceAssistant` 在业务外壳中只挂载一份。各业务页通过 `useAssistantReport` 提供当前已读取的记录、状态、证据与操作回调。助手不另外查询中央会话、订阅或商业权益；通用服务任务复用 `WorkspaceQueries` 中的授权场景目录，避免重复拉取目录。

| 板块 | 检查依据 | 可选任务 |
| --- | --- | --- |
| 构建 | 已登记资料、任务状态、模型、当前候选、固定发布 | 准备资料、预检、核查异常、跟进进展、核对成果、准备发布 |
| 关联 | 已加载来源快照、对象与关系记录 | 建立/核对对象、核对空间关系、核对业务关联 |
| 发布 | 当前固定版本、候选与生命周期、导出权限 | 接入核对、离线交付、生命周期核查 |
| 数据 | 当前筛选范围与分页元数据 | 核查失败、中断、登记变化等记录；进入场景输入资料 |
| 语义本体 | 已登记固定版本与本次草稿校验结果 | 选择固定版本、定位校验问题 |
| 智能设备 | 当前已读取且可管理的设备登记 | 补充厂家/型号、关联作业场景 |
| 在线服务/离线交付 | 授权目录中可见的固定发布 | 进入对应版本核对接入、交付 |
| 态势反馈 | 当前接入实现状态 | 未开放时明确说明，不虚构上报任务 |
| 账户/工作区 | 当前页面职责 | 前往账号、组织与工作区授权核对 |

这些是确定性业务规则，不是已接入的大模型问答。只基于实际返回的记录描述事实：设备已登记不等于在线，发布可访问不等于现场精度通过，元数据可读不等于文件完整。任务列表限制数量，分页或筛选结果不冒充全量诊断。

## 操作与隔离

每项推荐包含标题、证据、一个明确动作。自动检查只读，不自动构建、保存、覆盖或发布。选择任务后进入已有业务工作面/编辑器，继续沿用权限校验、未保存内容保护与 DS 危险确认；不能从助手直接绕过确认执行写操作。

报告按会话范围、路由及完整 URL 隔离，场景、模型、设备、发布版本或账户变化时旧报告不展示。组件卸载清理自己的报告，防止慢响应或不同页面覆盖其他报告；按钮执行读取最新回调。登录态恢复、商业授权仍由既有会话边界负责。

新增板块时提供 `AssistantReport`（loading/ready/error），不得把读取失败当作无异常。没有可确定的诊断时，说明范围或提供对应业务核对入口，不填充虚构任务。

## 验证

规则单测：`tests/frontend/assistant-contract.test.mjs`。浏览器验收覆盖三档尺寸、固定标题、关闭与重开、模块覆盖、详情切换、设备编辑、无权限/读取失败不生成可执行任务，以及公共入口页的底部操作与固定页脚。前端构建和既有危险确认测试同时执行。
