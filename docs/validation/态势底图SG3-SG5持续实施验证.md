## SG3：现有数据上的自动几何候选

`propose_ifc_registration` 重验固定 IFC、原网格和点云来源。以有界 IFC 三角形中心与 PLY 步长样本，生成 PCA 主轴的 24 个正旋转初值，各执行最多 30 轮、70% 截尾的点到点 ICP。只拟合旋转和平移；点云数值单位等于 IFC 米是明确假设，没有估计尺度或证明单位。按正反最近邻距离中位数之和排序，保留全部候选、变换矩阵、残差与迭代次数。样本摘要和原始成果摘要一并固定。

Anoeta 实跑 5,581 个 IFC 样本、16,948 个点云样本。首位候选 seed=11，迭代 30 次，截尾 RMSE 约 1.134、正向中位数约 1.030、反向中位数约 3.831（均为单位假设下数值）。这不是已证实的配准精度；首位候选仍有明显残差，不能采用。其他候选的存在、30 轮达到预算及场景对称/局部覆盖都会造成不确定性。三角形中心不是均匀表面采样，双向分数也不消除采样密度偏差；没有全局最优保证。

```text
python -m experiments.scripts.propose_ifc_registration --ifc-root <固定IFC目录> --cloud-root <固定点云目录> --ifc-sha256 <目录摘要> --cloud-sha256 <点云摘要> --output <新候选.json> --overlay <新叠加图.html>
```

叠加图使用共同坐标范围，蓝色为点云、橙色为首位候选变换后的 IFC 几何样本；三个正交视图各自适配共同范围。只能辅助判断整体误差，不能从投影点生成真实控制点。原始 IFC、点云和正式标注均不改写；unit_verified、alignment_verified、real_release_ready 均为 false，独立控制点数为 0。该输出没有进入既有独立控制点核验路线，也不满足该路线的验收条件。

## SG4：第二个独立语言消费端

SG1 的摘要编码保留 Python 数值序列化规则；它不是 RFC 8785。新增文件交换层，直接保存四个组件的规范化原始字节；manifest 最后写入，新目录不可覆盖。Node 消费端用文件原始字节核对长度与 SHA-256，避免解析 `1.0` 后重新编码成 `1` 导致跨语言摘要漂移。

```text
python -m experiments.scripts.export_scene_subset --input-root examples/scene-graph --package examples/scene-graph/sg1/corridor-subset.synthetic.json --expected-source examples/scene-graph/source-ref.synthetic.json --output-dir <新交换目录>
node examples/scene-graph/consumers/read-subset.mjs <交换目录> examples/scene-graph/source-ref.synthetic.json connections corridor-l1
```

Node 端独立校验来源引用、必需组件/依赖、原始成员字节、固定文件路径边界、选择 ID、实体/几何/连接/关系/观测的引用闭合，以及深度、数值有限性和字节预算。不依赖 Python 运行时或第三方 npm 包。该端只声明完整性与引用检查，没有重实现全部领域 Schema、重复 JSON 键检测或完整源选择对照，不能替代 Python 全域验证。清单没有签名，外部预期来源仍需可信上下文；仅复制包内来源不是信任建立。Node 始终声明 source_content_verified=false、incident_connections_complete=false；不将结果安装为生产底图。

## SG5：状态策略、变化和身份候选

`resolve_opening_state` 只读固定合成快照，必须指定现场时间 as_of 与平台已知时间 known_at。先按两个时间过滤，再对每个来源取最新观测时间；同一时刻的冲突记录全部保留。过期的新记录不会复活旧状态；多来源有效值不一致返回 conflict，不按到达顺序抢占。明确区分 unavailable、expired、unknown、conflict、known。游标固定快照摘要、策略版本和两个时间条件；同一快照重放可复现。没有来源优先级、纠正事件或时钟质量认证，不能替代完整线上事件流。

`compare_snapshots` 固定前后摘要，分开列实体、几何、普通关系、结构连接、观测、依据和来源的新增/移除/修订。沿用 SG1 修订规则、拆分/合并/未决提案校验，依据变化会标出引用者；输出影响实体集合供复核，不自动启动重构，也不把描述变化说成物理变化。跨坐标系或本体迁移继续拒绝。

`propose_identity_matches` 为移除/新增实体生成同类型、同坐标与本体上下文的近似范围候选。单一 AABB 的重叠率和中心距离只用于排名，最大候选对 20,000，top_k 为 1–10，距离预算显式输入；不使用名称相同作为身份依据。拆分样例同时提出两个空间候选，保留 unresolved，不继承旧 ID、不采用匹配。多范围或缺范围明确不支持。它不是三维语义识别器，也不能证明真实对象身份或完整拆分/合并关系。
