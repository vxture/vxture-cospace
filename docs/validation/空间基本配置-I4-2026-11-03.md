# 空间基本配置 I4 验证

日期：2026-11-03。本轮将授权模式的空间基本配置从浏览器草稿接入服务端；主页采用用户确认的全景方案，双栏比较版保留。

## 已实现

空间卡片新增“空间配置”入口，管理导航保留空间上下文。配置选择器只列获授权空间，管理员修改名称、用途描述并填写原因；保存后空间目录同步展示。查看者和工程师只读，跨空间访问被服务端拒绝。

SQLite保存目录展示覆盖值、递增修订和修改历史，原空间JSON及发布文件不变。事务内比较修订，拒绝覆盖他人新值；保存响应的字段和修订来自同一快照。actor来自已验签身份，时间为UTC，写请求沿用Origin与CSRF检查。读取角色不获取管理历史。

回归覆盖原目录不改写、读取不创建库、修改历史、重启、无变化不增修订、真实并发CAS、角色与跨空间、CSRF、撤权、字段限制、损坏数据库，以及提交后另一管理员更新时响应字段与修订的一致性。

HTTP实际保存新名称、验证目录联动、拒绝旧修订与无权请求、重启恢复配置与历史，并显式恢复原名称/描述；原构建及固定发布全部文件摘要一致。随后继续既有发布、暂停、撤权和第二次重启流程。所有操作在独立样本副本完成。

浏览器实际登录模拟管理员和查看者A。管理员从卡片进入配置，填写、保存、刷新并确认目录联动，再显式恢复；桌面与390px视口无横向溢出。另用同一管理员的两个页面验证旧修订409、冲突输入保留与重新读取最新值。查看者只读、无保存按钮和管理历史，直接访问其它空间403。控制台仅见站点图标请求的401/403/404及主动触发的拒绝请求；未把零控制台错误作为验收结论。
