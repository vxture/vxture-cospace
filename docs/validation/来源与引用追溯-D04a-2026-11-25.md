# 来源与引用追溯 D04a

日期：2026-11-25。范围为数据与引用详情中的只读追溯，延续平台数据管理与单导航，不创建独立版本平台。

## 本批行为

- 来源管理者可核对已登记版本、当前来源匹配及保存的共享快照；接收方只核对自己实际引用的固定版本，不开放原来源位置、未使用版本或其他项目引用。
- 引用影响按当前可见全集计算后分页，分别呈现关联、授权有效及历史数量；撤销、到期仍保留引用，解除仍保留历史。统计明确不构成全局删除或归档许可。
- 新源版本未登记时明确提示，既有引用不升级。来源不可读时返回 partial 并保留已登记记录，损坏登记或快照失败关闭。
- 不新增导航项；追溯放在现有详情抽屉中，多项目引用在同一抽屉选择追溯范围。DS token 管理尺寸与间距；窄屏抽屉最大宽度限制到当前视口，修复原 672px 面板在 597px 窗口左侧溢出的问题。

## 验证

后端追溯、资源目录、共享与原件联合回归 52 项通过；随后增加授权到期后的引用保留专项，1 项通过。前端导航、目录、共享、追溯、文件与场景记忆契约 27 项通过。TypeScript、生产构建和仓库门禁通过。

Playwright 使用明确标注的园区合成 API 夹具核对 1575×883 与 597×883 的详情抽屉；宽屏展示来源 / 版本 / 引用影响，窄屏修正后左边界为 0、内容宽度等于滚动宽度，刷新控件实测 32px / 12px。后端真实 HTTP 测试覆盖来源权限、跨项目不可见、只有授权未引用、源变更、来源缺失、分页、撤销 / 到期 / 解除、独立共用原件、损坏登记、伪造参数、未登录及禁止写入。

浏览器合成夹具用于布局与交互验证，不代表生产端到端验收，不修改生产业务数据。运行证据位于忽略目录 output/playwright/data-d04a/，不纳入 Git。
