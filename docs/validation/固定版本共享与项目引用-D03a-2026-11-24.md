# 固定版本共享与项目引用 D03a

日期：2026-11-24。完成范围为同工作区固定版本共享与参考关联；不包含项目级上传 / 工作区共用归属、版本升级、空间自动叠加或服务发布。

## 已实现

- 明确区分项目管理归属、共享授权、实际引用。指定项目 / 当前工作区共享不改变管理项目；无平台共用归属时不展示“平台共用”。
- 共享设置与关联已有数据使用抽屉；已共享 / 外部引用按真实记录显示。未引用授权不计入项目资产数量。
- 引用记录接入真实分页 / 搜索查询，显示项目或指定场景、固定版本、用途及当前授权。解除后保留历史；撤销 / 到期停止后续下载、新引用，旧引用显示受限状态。
- 参考附件首次共享校验 SHA-256 与长度并冻结原件，之后来源修改或不可读仍引用同一份已授权固定原件。其他类型只支持元数据参考，不虚构可下载或可直接应用的空间成果。
- 每次下载核验目标权限、准确授权修订、期限及载荷；重新授权不自动复活旧引用。来源场景私有 ID / 路径 / 记录链接不传给接收方，原来源端点权限不放开。
- 授权 / 引用 / 原件及审计存入既有项目数据库，同事务修订、幂等与审计。单附件 32 MiB、工作区冻结原件预算 512 MiB，记录查询预算 10000。项目归档检查 active 引用。
