# 态势服务消费版本保存与恢复 D2

日期：2026-11-02。目标：让真实预览离线包在独立消费端保存版本引用，普通重启后显式恢复，并保持旧会话固定和历史包可复查。

## 实现

- 新增`PersistentPreviewConsumer`及`apps.cli.preview_consumer`。独立目录按空间绑定，使用SQLite保存完整ZIP字节、安装引用和当前选择；原PreviewConsumer内存类保持兼容。
- 安装不激活；激活在事务内核对预期序号、重新检查完整包后保存引用。失败不修改保存选择或本进程会话。
- 新实例无查询会话；恢复须明确提交保存的发布ID、摘要和序号，重新检查模型/对象/本体绑定。恢复不递增保存序号。
- 已取得会话固定在原版本，另一进程或后续激活不会改写它；点、对象、范围查询均增加consumer_revision和package_sha256。
- 态势服务固定发布新增“本地消费”说明，使用实际offline.json生成命令。失败或绑定错误不生成命令；页面不读取机器人或本地消费库状态。
- 空间预览的六模块进度、功能架构和运行手册同步标记本批成果及下一步更新核对。

全部服务请求完成后，由独立子进程运行消费端。子进程在导入消费库前替换socket构造器，拒绝任何socket创建；允许标准库SSL等正常继承类型。
