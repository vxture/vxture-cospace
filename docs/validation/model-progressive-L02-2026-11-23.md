# L02 工程统一消费

日期：2026-11-23。状态：已随 v0.15.0 上线。承接已上线的 v0.14.0（L01），本批不包含 L03 策略、机器人协议或新本体能力。

## 交付边界

| 子批次 | 实现 |
| --- | --- |
| L02a 原始点查询 | 固定 `spatial.npz` 摘要及原始行号构成稳定 ID；后台流式读取原始坐标，生成 SQLite R*Tree 磁盘索引；局部球查询最多 32 点，单次查询半径 0.001–1 m |
| L02b 配准作业 | 配准展示和独立全屏编辑复用 Potree 渐进显示；双击只查询候选，用户选择后再次按原始行读取核验；check 与 save 均验证原始点证据；目标坐标不自动改变 |
| L02c 空间关联 | 对象选点、索引备用、已存对象核验复用同一服务；关联概览、空间关系、业务关联读取轻量元数据与有界对象快照，保留关系、业务绑定及原始点核验 |
| L02d 回归发布 | 固定版本、场景授权、撤权、完整性、容量及真实 UI 操作回归；PR 五项检查及生产 reviewer 之后才部署 |

原始 ID 对应固定模型文件的原始行，不承诺它是采集设备最初生成的点编号。Potree 的重排、LOD 和 GPU 点索引始终不作为原始 ID。源 double 数值参与保存、残差及核验；坐标显示的小数位不表示地图实测精度。

## 数据与容量约束

- 精确索引为可重建运行数据，不进入 Git、模型成果或既有发布；不修改历史原始文件。
- 按原始几何文件摘要复用索引：仅修改对象、关系或业务信息的候选无需重复建库。每次读取仍验证其自身场景、模型清单摘要、源摘要及点数；复用不沿用旧候选的访问依据。
- 每批读取 25,000 点，避免整份 NPZ 数组常驻内存。R*Tree 浮点边界仅筛选候选，最终距离及返回坐标使用 SQLite REAL 原始值。
- 每个返回点校验源摘要、原始行和坐标的校验和。对象快照先验证文件摘要、固定本体及语义规则，再逐个核验原始锚点，最多 100 个对象。
- 精确读与显示 Range 使用独立并发槽；精确读取最多 4 个并发、SQL 执行预算 2 秒、待建队列 16 项。容量不足、密集歧义或未就绪时拒绝确认，不静默选择最近点。
- 代码容量上限 2,000 万点、单索引 4 GiB；建立前检查磁盘预算。上限是保护边界，尚未实测 2,000 万点，不作容量承诺。
- 新建索引仍需后台遍历原始文件，千万点可能等待数分钟；画面不因此等待。当前没有持久化私有浏览器缓存或跨会话秒开承诺。

## 本地验证

Windows / Intel i5-10400，使用合成园区与大坐标数据，全部不是实测测绘成果。下列容量为单次本机验证，不能直接当作生产 SLA 或行业比较。

| 点数 | 索引字节 | 后台建立 | 三次按行及局部成对查询耗时 |
| --- | ---: | ---: | --- |
| 100 万 | 136,916,992 | 18.225 s | 31.0 / 5.08 / 5.03 ms |
| 1,000 万 | 1,381,380,096 | 195.156 s | 32.27 / 7.85 / 5.17 ms |

容量脚本为 `python -m experiments.scripts.check_model_exact --points 1000000`。CI 在生产镜像内追加 768 MiB 内存限制的百万点验证，结果以本次 CI 为准。

浏览器以系统 Chrome headless 验证：

- 配准展示、1575×883 独立全屏编辑、817×883 窄屏作业布局；适配全图图标按钮 32px。
- 实际 GPU 双击取候选，唯一候选仍须显式选择。确认后按原始行二次核验；控制点变更与残差即时联动，目标坐标保持原值。
- 六点合成草稿通过服务端检查并保存到修订 2，原始点 ID 与完整 double 保留，其他五点及变换矩阵保持一致。
- 实际 GPU 选取的第 304523 点与索引备用读取坐标一致；新增测试对象已保存为独立候选，并通过轻量接口重新读取。
- 网络未出现 `human.ply`、`spatial.npz`、`views.js`、`anchor-preview` 或配准抽样 geometry 下载。
- UI 截图、网络证据与本地运行数据保留在忽略目录，不纳入发布源码。

既有对象/关系/业务快照与原接口结果保持一致；非有限数、错误坐标、错误摘要、跨场景、撤权、重复参数、稠密点和磁盘预算有对应后端回归。前端原始点 ID、双精度和固定版本边界，以及关联流程与配准计算回归通过。

在已就绪索引上模拟 5 Mbps / 100 ms 网络，十次按原始行查询响应为 121.0–125.6 ms，每次响应 JSON 为 572 字节。一次 GPU 候选事件到可选择原始点展示为 583.6 ms，确认按钮在手动选择前仍禁用。该结果不含新建索引、人工核对和保存时间，也不是完整冷启动或生产 P75 指标。一次本地关联页读取的首帧为 698.4 ms、首帧模型字节 158,151；仅作为按需读取证据，不据此宣布达到全部性能目标。
