# 固定发布暂停与恢复 H3b

日期：2026-11-02。目标是补齐生命周期中的固定发布分发控制，优先跑通流程。未开展新的几何精度研究，样本质量仍为unverified、robot_ready=false。

## 已完成

- 沿用H3a独立SQLite控制账本，增加publication目标、pause_distribution及paused，支持附原因暂停与恢复，修订和完整历史保留。
- 发布请求通过统一门禁：HTML、清单、查询、对象、来源追溯、双视图成员及离线导出都检查状态；包括HEAD、Range、条件缓存、无尾斜线及编码分隔符。
- 暂停项保留管理元数据，移除分发链接和嵌入内容；比较接口两端均检查，成果目录保留历史但不提供资源。
- 最近发布暂停时，空间默认入口为空，页面禁用打开且不自动回退历史版本；逐空间流程指向态势服务核查。
- 态势服务和数据管理可进入发布管理；确认原因必填，失败清除旧操作，支持刷新历史后恢复。
- 分发及动态API响应no-store；禁止以发布快照作为根静态目录启动。
