# 智能体消息留存与原子提交验证

日期：2026-10-27。范围：J2独立Windows合成日志。依据[实现说明](../architecture/智能体消息留存与原子提交实现-v0.1.md)及[恢复协议](../architecture/智能体恢复独占与提交日志协议-v0.1.md)。

新增24项专项实例通过，耗时62.62秒；同一测试内的断言不额外计数。Python 3.14.3，Windows；复用Node原生Ed25519实验适配及J1 LockFileEx。未改依赖锁或原v1门禁/R1运行实现。

全量本地回归216通过、6跳过、22个子用例通过，耗时194.51秒。跳过项没有本次验收证据，不能据此称PostgreSQL或真实设备全路径通过。证据导出的20条intent/receipt另行通过Schema校验，五个场景的authorized均为false。

| 覆盖 | 结果 |
|---|---|
| 原始消息及凭据 | 原ASCII JWS保留、摘要匹配；导出intent及receipt符合现有Schema |
| 幂等/ID冲突 | 同ID同消息读取同一凭据；同ID换消息拒绝；重传不延长截止 |
| 确定性拒绝 | 回退等逻辑拒绝持久为rejected，版本/摘要不变 |
| 撤回及grant绑定 | 终止撤回不可恢复allowed，失配grant拒绝，重开仍revoked |
| 四处SQLite故障 | prepare提交前后、状态写后、receipt插入后注入异常，未出现状态与凭据单边提交 |
| 实际约束错误 | receipt插入触发约束失败，状态/版本回滚，保留未决intent |
| 响应丢失 | apply提交后异常，重新打开按ID读回唯一receipt，不重复应用 |
| 5处独立进程退出 | 子进程在prepare提交前/后、状态写后、receipt插入后、apply提交后调用os._exit(76)，重开结果符合提交边界 |
| 历史与不可变约束 | 状态被后续替换，旧消息/receipt仍保留；UPDATE/DELETE触发器禁止改动日志（本轮直接执行DELETE验证） |
| 配额 | 消息数、intent数、总token字节及状态数超限，在prepare前拒绝，保留既有历史 |
| 签名/委托/时间 | 无效签名不建intent；受限委托收紧截止为125，到期拒绝 |
| 当前状态不一致、缺库或配置变化 | 摘要失配拒绝；缺库不重建；配额配置变更也因context失配拒绝 |
| 两写入者竞争 | 两线程、两JournalStore对象、独立SQLite连接，同序不同状态单胜者；另一条为rejected/state_conflict |

独立进程故障属于进程内部立即退出，不是进程外强杀或物理断电；写入竞争属于线程并发，不把它称作独立进程写入竞争验收。J1真实进程锁证据独立保留。

证据目录：[p2-recovery-journal-001](../../experiments/runs/p2-recovery-journal-001)，含[专项与全量日志](../../experiments/runs/p2-recovery-journal-001/tests.log)、[JUnit](../../experiments/runs/p2-recovery-journal-001/tests.xml)、[五处边界报告](../../experiments/runs/p2-recovery-journal-001/scenario.json)及[环境/源码摘要](../../experiments/runs/p2-recovery-journal-001/environment.json)。场景程序保存签名合成消息和公共配置，不保存随机私钥；SQLite测试库仅存在临时目录。

原始首轮因测试连接未close导致Windows拒绝删除故障库，修正测试连接管理后专项全部重跑通过；不以延时/重试删除绕过问题。运行方法见[手册](../guides/智能体消息日志实验运行.md)。

所有输出仍synthetic，authorized=false、robot_ready=false。J2只实现接收与提交日志；尚无恢复begin/resume、计划CAS、全历史重放审计、v1迁移、真实机器人会话或硬件防回滚。下一批J3在保留未决阻断的前提下实现受控恢复状态机，不按“当前摘要匹配”直接解除。
