# SG4 坐标查找构件

日期：2026-11-17。为固定 IFC 设计资料增加点到最近三角表面的只读查询，并接入工作台。用途是回答指定坐标附近的设计构件及几何距离，不承担机器人决策，也不将设计资料升级为现场底图。

## 业务入口

IFC 构件资料 → 结构声明 → “坐标查找构件”。仅在结构声明可用时出现，默认收起。输入源 IFC 的 X/Y/Z（米）及查询半径，成功后显示构件名称、原 IFC 类型和距离，可“定位构件”切换到原构件资料。没有自动填入某个假定的机器人位置，没有把构件包围盒中心作为现场坐标。

修改任一输入会取消在途请求、清除旧结果；关闭面板或切换场景/目录时取消请求。前端核对来源、坐标系、原查询、声明覆盖、未核验标记、结果实体身份及距离与最近点坐标的一致性；这不是客户端重新验证三角网格。坐标属于 IFC 原坐标，点云单位和变换没有核实前不能直接把点云坐标粘贴成同一坐标。

## 接口与权限

`POST /api/scene-ifc/nearest-surface`，同源业务会话、CSRF 和场景 `association.edit` 权限先于资料读取。不是对外正式发布的空间服务端点，没有接入厂家或替代服务令牌的授权链。

```json
{
  "space_id": "space-1111111111111111",
  "catalog_sha256": "<固定目录SHA-256>",
  "frame_id": "ifc_world_<来源IFC摘要前16位>",
  "point_xyz_m": [1.0, 2.0, 3.0],
  "max_distance_m": 5.0
}
```

上例摘要与坐标系为占位，实际使用已授权目录返回的固定值。请求 Schema 在 `contracts/schemas/ifc-nearest-surface-request-v0.1.schema.json`。拒绝查询参数、额外字段、非有限/越界坐标和无效半径；坐标各轴限 ±1,000,000 m，半径严格大于零且不超过 1,000 m。接口不接受路径、客户端几何、目标身份或本体规则。

成功结果固定 source、frame、原查询、算法与同距规则。`found` 仅表示在本次覆盖的网格中找到距离不大于半径的最近表面；包含 GlobalId、element_id、IFC 类型/名称、原 NPZ 摘要、原三角形索引、最近点和距离。`no_match` 表示这些网格在该半径内无匹配，不能解释为附近没有现场物体。`geometry_unavailable` 表示结构声明没有任何已提取网格，与已搜索后无匹配分别表达。

`tested_components` / `tested_triangles` 说明实际计算量；`without_geometry` 单独报告未提供或提取失败的声明。仅搜索结构提取范围内全部 extracted 实体，不是 IFC 全类别、点云或完整世界。保留 `ifc_design_candidate`、`unverified`，alignment_verified / ontology_bound / real_release_ready 均为 false。

401/403 为会话/权限拒绝，422 为请求格式错误，409 为固定坐标系/来源冲突、损坏、缺失或超预算。错误不包装为 `no_match`，不泄露服务器路径。结果 `Cache-Control: no-store`，不保存、构建、发布或修改任何实例和关联。

## 算法、完整性与预算

共享 `packages/spatial/mesh_distance.py`，原 SG3 端点几何诊断复用同一实现，保留旧入口兼容。点在三角形内的投影、三条边和顶点都参与最近点计算；退化三角形按线段或点处理。无符号欧氏距离，同距先取 element_id 字典序较小者，再取原三角形索引较小者；不声称唯一对象或唯一接口。每块 8,192 个三角形，不对完整网格抽样。

查询先固定、验证目录和原 IFC，检查全部目标预算，再逐网格验证摘要、NPZ 数组/数量/范围及索引。任一目标损坏即拒绝整次查询，即使此前已找到零距离也不提前返回；否则会把缺失几何错误说成全域最近。计算结束重验源目录/配置/IFC；读取的网格由固定摘要约束，不假定跨存储事务。

单次最多 512 个组件、400,000 个三角形、32 MiB 源网格文件字节及 32 MiB 声明数组字节（顶点 float64 XYZ + 三角 uint32 索引）。预算在网格加载前拒绝，不缩减查询集合；分块只控制距离计算临时数组，不改变结果覆盖。当前顺序扫描，不宣称已有持久化空间索引、并发吞吐或生产容量验收；无需为每个诊断查询重复封装离线资料包。

不计算有符号内外、房间包含、碰撞、净开口、可视性、可达性或路线。距离为零不表示机器人所在空间、门已打开或可通过。本体仍独立提案和采用，不通过最近几何擅自映射语义。

## 验证

两套真实来源均从门构件原三角形取一个已知表面点，检查最近距离为零；再在全模型范围外取点，检查半径内无匹配。重复查询结果一致，源目录所有文件摘要前后不变。

回归涵盖三角面/边/顶点与退化、刚体不变性、跨块索引、同距组件、半径包含边界、无匹配/无几何区分、预算先于读取、其他组件损坏不能跳过、批次中源改写、鉴权先于存储、CSRF、跨场景/固定版本拒绝，以及前端错源、错帧、旧查询、虚构实体/距离和状态矛盾拒绝。生产构建及类型检查通过。
