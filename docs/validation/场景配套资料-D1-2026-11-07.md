# 场景配套资料 D1

## 范围

D1 为每个场景空间增加一个轻量配套资料区。管理员或工程师可保存 PDF、图片、CSV、TXT 和 IFC 原文件，查看名称、摘要和登记时间，并下载原文件。资料按场景权限隔离，使用 SHA256 去重，保存后不可被同名或重复上传覆盖。

配套资料是参考资料，不自动进入点云构建、真值、双视图或发布。IFC 的目录和构件预览仍使用 C2a 的离线解析结果；D1 不新增配准、工程建模或对象关联。

## 数据与安全

- 文件单个最多 32 MiB，每个场景最多 1,000 个文件；扩展名仅允许 `.pdf`、`.png`、`.jpg`、`.jpeg`、`.csv`、`.txt`、`.ifc`。
- 原文件写入 `runtime/preview-inputs/scene-attachments/<space-id>/<attachment-id>/original.bin`。标识使用摘要前 16 位，记录保留完整 SHA256，摘要前缀冲突时拒绝保存。元数据与内容原子写入；中断上传不会产生可见记录。
- 下载前再次核对字节数和 SHA256，响应不执行内容，使用 `attachment` 下载和 `nosniff`。
- 读取、上传和下载都要求当前 Workspace 下的场景 `data.manage` 权限；不暴露本机路径，跨场景访问拒绝。
- 资料目录进入存储用量观察和冷备份；恢复时复核记录、大小和摘要。
