# 真实资料登记与构建输入选择

本批解除本机预览构建入口对单一固定路径的依赖，将封存资料登记为独立记录，页面显式选择输入后构建。当前仅实现NYU封存RGB-D配已有轨迹的适配器，尚未支持任意点云或采集设备格式。

## 已实现

- 工程CLI登记本机资料路径、匹配轨迹及名称，生成独立不可覆盖的 `input-*` 记录；目录默认位于 `var/nyu/preview-inputs`。
- 检查封存报告格式、轨迹来源摘要、位姿数量/形状/有限值、齐次矩阵末行及全部接受帧的图像格式、尺寸、字节数和摘要。禁止跨目录图像成员引用。
- 登记结果记录格式、报告/轨迹摘要、帧数和图像成员数。公开列表省略实际路径。
- `GET /api/inputs` 返回已登记资料；构建中心使用DS Select选择，未选择时禁止发起。
- `POST /api/builds` 传递 `input_id`，服务按登记记录重新核对输入。未知ID、缺少选择、资料变化拒绝创建任务。
- 任务保存 `input_binding`；子进程重新核对登记的报告/轨迹摘要并检查实际消费的图像，模型 `source.input_binding` 保留同一绑定，可随固定发布和离线包追溯。
- 老任务及发布保留；旧测试使用的无目录构建模式兼容保留，实际本机服务已启用目录且必须显式选择。首次启动空目录时登记默认样本，不自动选择。

资料登记不是上传，也不复制整个数据集。登记后源文件仍应保持封存；数据变化需重新登记。页面列表是登记信息，提交构建时重新核对。登记期间、核对后至消费期间的任意外部并发改写没有完整文件快照隔离保证，不能据此声明生产不可变存储。

## 实测

登记 `input-fe8d37cf7b334ba7`：60帧、120个接受帧图像成员格式及摘要通过，匹配轨迹57帧。模型实际消费114个图像文件，登记核对与构建消费数量含义不同。

浏览器验证：未选择资料时“发起构建”禁用；展开列表选择NYU办公室样本后显示60/57帧并启用按钮；点击后生成候选 `build-2c4c625aeffa4117`。HTTP读取任务与模型，输入ID、报告及轨迹摘要一致。未自动改动当前空间选择或新增发布。

24项相关测试通过，新增4项覆盖持久登记、改动拒绝、错误来源与格式、非法成员路径、两条登记项选择、子进程参数绑定及来源限制；前端TypeScript检查与Vite构建通过。

证据：[checks.json](../../experiments/evidence/2026-10-29/nyu-inputs-001/checks.json)。

## 运行

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_inputs --label "办公室封存短序列" --snapshot var/nyu/office-0001a-short-001 --tracking var/nyu/office-0001a-interior-0-002/comparison.json
```

命令每次创建新的登记记录，不更新旧记录。刷新或等待构建中心定时刷新后可选择新资料。

工作台：`http://127.0.0.1:8767/workbench/layout.html?revision=inputs-1#build`。
