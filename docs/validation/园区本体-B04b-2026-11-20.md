# 园区本体 B04b 验证记录

日期：2026-11-20。状态：已有模块编辑、治理 HTTP 与业务表单首版工程验收完成；不表示专业标准正式发布、客户现场适用或生产部署完成。

## 实施

- `packages/service/ontology_definition_workbench.py` 装配纯编制服务与 SQLite 端口；新增 `/api/ontology-definitions` 读/写/准确版本/送审快照接口。
- 真实身份、作用域、管理权限来自宿主；普通读取用户不能查看私有草稿或审批正文；写接口沿用认证、中央会话、Origin 与 CSRF 检查。浏览器 body 不接受 actor/workspace/scope。
- 独立组件 `packages/ontology-ui/src/authoring.tsx` 从详情页进入，支持模块名称/范围/版本、概念与属性、关系方向与类型端点编辑。概念和关系行使用统一三点菜单；表单为 DS 抽屉，主按钮 32px / 14px，保留固定导航、开放表格及 64px 序号/操作列。
- 保存与校验分开；送审、审批、发布放在“版本与发布”抽屉。送审快照可查看；同一提交人不能自审；审批过期后不得发布；没有第二测试身份时本地预览保持门禁，不伪造审批。
- 支持已发布依赖版本选择、基版结构差异及历史固定版本读取。目录按作用域叠加各模块最新已发布摘要，发布日期来自真实发布记录；读取具体定义始终返回对应的冻结依赖闭包，不把不同目录版本拼成一个定义库。
- 准确内置候选引用继续兼容；普通目录不因保存私有草稿而变化。内容成熟度仍为 draft，与发布工件的治理状态分别表达。
