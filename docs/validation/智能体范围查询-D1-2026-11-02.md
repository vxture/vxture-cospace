# 智能体范围查询 D1 验证

2026-11-02，完成固定真实发布的范围查询、离线同义读取及服务与交付页工作面。精确协议见[范围查询契约](../../contracts/schemas/preview-range-v0.1.md)及[JSON Schema](../../contracts/schemas/preview-range-v0.1.schema.json)。本批保持原有模型、发布和ZIP格式，不创建新构建或发布。

## 实现

共享选择器扫描固定表面单元，按中心点是否落入半开AABB筛选。响应最多4096个单元，默认1024；匹配数超过limit时返回明确limit_exceeded、result_complete=false、0个单元及unlisted_state=null，避免部分结果被当成完整空间判断。空范围内没有表面证据时仍为unknown，不推断自由空间。

固定发布HTTP新增query-range，离线读取器新增query_range，CLI新增bounds/frame-id/limit。CLI超限打印结构响应后退出3，参数或加载错误退出2。服务与交付页每个固定发布新增“范围查询”，可编辑六个坐标和数量上限，展示实际匹配/返回数和固定版本响应；编辑、换发布/空间或读取失败清空旧结论。

## 检查结果

- 47项相关测试通过，包含20项范围查询实例：负坐标/十进制/半开边界、相邻范围拼接无重复、稳定排序、精确上限与超限、非法参数、旧选择切换后发布固定、损坏发布拒绝、CLI及断网在线/离线一致。
- 请求/完整响应/超限响应通过Draft202012 JSON Schema检查，矛盾的status与result_complete组合被拒绝；新增Schema后专项复查通过。
- TypeScript检查与Vite构建通过，既有Radix use client提示保留。
- 9项实际浏览器检查通过：整图超限、编辑清空、局部14单元、空范围未知、错误参数、模拟503、固定发布面板隔离、换空间/坐标系清空及恢复。两条控制台错误来自预期422与注入503，单独记录。
- 服务实际重启后完成新HTTP查询；核对原有193个运行文件摘要未变。

## 边界与下一批

当前只扫描小型包中已有单元，不是空间索引、3D Tiles分块、流式大地图或碰撞检测。result_complete与现场观测完整度分开；独立精度、时效和语义仍未验收。

下一批D2实现持久消费引用：明确安装/活动版本/固定会话的关系，重启后显式恢复同一发布，错误包或版本拒绝，并保留旧版本复查。沿用本机流程，不将合成签名/授权实验误标为当前真实包已具备的能力。
