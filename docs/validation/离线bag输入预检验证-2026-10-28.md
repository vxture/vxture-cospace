# P1/E01a 离线 bag 输入预检验证

日期：2026-10-28。范围：独立离线 ROS1 bag 适配器运行验证。用户确认当前未对接采集设备；全部日志为明确标识的合成夹具，没有实测序列或算法回放结果。

## 依赖与来源

通过项目可选 input extra 安装并固定 `rosbags==0.11.9`，已同步 pyproject.toml 与 uv.lock。根Python为3.14.3，实际运行环境为Windows11。

PyPI分发包元数据声明 Python>=3.10，含Python3.14分类，License-Expression为Apache-2.0。包内LICENSE实际为Apache2.0文本。项目来源为 https://gitlab.com/ternaris/rosbags ，文档为 https://ternaris.gitlab.io/rosbags 。来源及许可信息取自本次实际安装分发包，原始METADATA和LICENSE保存在运行证据中；不是完整传递依赖或商业分发审查。

本机实际锁定依赖：rosbags0.11.9、numpy2.5.4、apsw3.54.1.0、lz44.4.5、ruamel.yaml0.19.1。使用库内ROS1类型定义，不安装ROS发行版或依赖roscore。

- `packages/data/bag_preflight.py`：有限字节快照、标准消息类型/MD5、字段布局、逐点有限数值、IMU有限数值与整数纳秒时间预检。
- `contracts/schemas/bag-preflight-v0.1.schema.json`及说明：闭合报告格式和结果边界。
- `experiments/scripts/inspect_bag_offline.py`：CLI通过0/拒绝2，输出新文件，禁止覆盖输入或旧报告。
- `experiments/scripts/bag_fixture.py`、`smoke_bag_offline.py`：真实容器生成、CLI子进程调用及运行证据保存。
- `tests/test_bag_preflight.py`：39项专项测试。

## 实际运行

初轮p1-offline-bag-001保留为早期记录；后续改用公共分发元数据API、固定版本并明确超限前缀不冒充完整摘要后，正式证据在 `experiments/runs/p1-offline-bag-002`。

执行：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.smoke_bag_offline --output experiments/runs/p1-offline-bag-002
```

4组实际CLI：正常合成结构退出0；缺逐点时间、IMU倒退、损坏输入均退出2。summary.passed=true；记录每组原始命令、实际退出码、标准输出/错误、输入摘要与大小、实现和锁文件摘要、解释器/平台及依赖。输入bag被gitignore排除，报告和来源元数据保留；复跑必须使用全新输出目录。

相关回归：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_bag_preflight.py tests/test_trace_events.py tests/test_voxel_changes.py tests/test_spatial_changes.py tests/test_consumption_contract.py tests/test_voxel_profile.py tests/test_release_contract.py tests/test_quality_contract.py tests/test_observation_contract.py tests/test_structure.py tests/test_query.py tests/test_sample.py tests/test_agent_package.py tests/test_agent_local.py tests/test_agent_files.py tests/test_lifecycle.py -q --tb=short
```
