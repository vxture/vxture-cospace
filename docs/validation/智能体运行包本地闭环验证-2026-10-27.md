## 首批结果

新增8项测试通过：

随后全量本地SQLite路径为**84 passed、6 skipped、22 subtests passed**。PostgreSQL专属用例本轮跳过，没有新增PostgreSQL并发验证结论。测试后未修改运行代码。

| 用例 | 观察 |
|---|---|
| 安装后删除原来源与包，再打开本地库 | 仍可查询空闲、未知和范围外；不依赖原输入目录 |
| 新版本将同一合成区域从空闲改为占据 | 旧会话保持旧结果，新会话读取新包与revision |
| 两个连接使用同一revision并发激活 | 一个成功，一个state_conflict |
| 安装损坏包或注入零磁盘余量 | 拒绝，当前包及revision不变 |
| 重复安装及同ID不同摘要 | 前者复用，后者identity_conflict |
| 已安装内容损坏 | 激活拒绝，不切换指针 |
| 安装/激活提交前真实子进程os._exit(71) | 重新打开SQLite后旧活动包和revision保留；未提交安装不可见 |
| 场景不符、非法revision、无活动包及关闭会话 | 明确拒绝 |

这里的并发使用两个SQLite连接和线程；不是独立进程并发竞争证据。中断用例使用独立Python进程，在真实事务提交前退出，不是mock事务；不是操作系统重启或物理断电试验。
