# 资料预览与构建过程可视化 P17 验收

日期：2026-11-05。结论：P17.1／P17.2／P17.3 已完成本机实现及验收。认证仍为本机模拟，精度和实机可用性未验收。

## 1. 本批交付

|位置|实际行为|
|---|---|
|数据管理 → 导入资料 → 准备 PLY|文件检查后直接本机预览，不要求先填单位／坐标；登记继续遵守 P16 声明及确认规则|
|资料详情 → 内容预览|header 下方页面右栏按需请求受权抽样，可旋转、缩放、平移、适配全图及放大|
|构建中心 → 资料到双视图 → 构建过程可视化|真实阶段状态；固定模型、人视图、智能体视图分别查看。固定模型冻结即可查看，某个视图成功即可查看，不要求整个候选就绪|

未冻结、运行、失败和中断明确区分；不展示虚构百分比或实时 SLAM 几何。轮询不卸载已打开的画面；另一个视图失败时保留已成功产物的查看和原恢复入口。历史一体任务未保存独立阶段时解释限制。

显示最多 10000 点，响应最多 2MiB；点数和数值边界来自全量。相机只改变显示。未知本机单位不标米，RGB、中性及激光强度灰度分开表述；智能体单元为观测表面，其余未知。人视图先核验实际 PLY 任务与产物，再显示同源固定几何；智能体使用真实 agent.npz 表面单元中心。

原资料使用 data.manage；阶段使用 build.run，先检查场景、记录和固定模型来源归属，再读取几何。接口不推进 worker、不创建记录、不选择或发布。客户端核对摘要、场景、资料／任务、数量、颜色、有限值及预算；错误时清空旧画面。关闭、切资料／场景和迟到响应均受保护；无 GPU 保留数值及原业务入口。
