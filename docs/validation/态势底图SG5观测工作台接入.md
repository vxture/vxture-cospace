# SG5 观测只读工作台接入

日期：2026-11-17。本增量将观测日志接入现有 IFC 构件资料。只在结构声明中选中门时显示“状态观测”；墙、建筑等对象不显示该区域，不为尚未实现的设备动作增加入口。

## 实际入口

`GET /api/scene-ifc/opening-observation` 只接受 space_id、catalog_sha256、element_id，复用现有会话和 `association.edit` 场景权限；不重新建立平台权限会话。未经授权不会到达资料或观测读取。POST 不开放。响应 no-store，不暴露日志路径、生产者配置或证据对象路径。

服务端重新核对固定 IFC 目录及来源内容，并确认选中对象是目录中的门声明。查询作用域的 issuer、组织及工作空间来自已验证的登录主体，客户端不能通过参数替换。时间由服务器确定，当前接口不接受任意历史查询；内部日志仍支持固定时间和序号重放。

查询使用只读数据库连接；缺少数据库或该作用域登记，返回 configured=false，不创建登记、不创建数据库、不凭页面访问开启来源。真实接入仍需可信管理程序从固定目录登记实体与 producer，再由厂家网关完成认证、证据核对及上报。页面不提供伪造来源的配置按钮。

## 显示和状态

- 未登记来源：“尚未配置上报来源”；已登记但无有效记录：“暂无报告”。不展示“正常”。
- 有一致的有效报告：“来源报告：开启/关闭/部分开启”；始终保留待核验说明。
- 分别显示报告已过期、报告已撤销、状态未知、报告有冲突；冲突不选择某来源作为赢家。
- 最后上报使用本对象在查询条件下已收到的最后报告时间，包括迟到的旧观测和纠正，不等同于最终用于判定状态的观测时间。迟到旧报告能推进上报时间，但不能覆盖更新的观测状态。
- 无时间显示“最后上报：—”。故障显示“观测摘要暂不可用”，不沿用旧对象状态或显示正常。

切换所选门会取消旧请求并重建状态组件，防止旧门响应覆盖新门；摘要源结构仍在本地筛选，不因构件切换重复获取整个结构目录。提供显式刷新，无轮询。接口只返回计数、状态和时间，不将最多 5,000 条日志回传浏览器。

`catalog_content_verified=true` 只表示 IFC 目录与来源内容核对通过。`source_content_verified`、`evidence_content_verified`、`clock_quality_verified` 和 `real_release_ready` 均 false：来源报告、证据文件和设备时钟未因此得到认证，也没有声明现场门状态已核实。

## 失败与验证

未登录 401、无场景权限 403、非法参数 422、过期目录或非门声明 409、损坏数据库 503。旧 IFC 无结构声明时不能绕过校验查询。测试覆盖鉴权先于读取、无配置无创建、跨场景/目录拒绝、来源变化、迟到时间与有效状态分离、元数据不加载网格、损坏存储不伪装正常。

前端响应契约检查场景、目录、构件和未核验标记，拒绝伪造正常、通行值、非法时间、负计数及未配置却返回有效状态。TypeScript 和生产构建与专项测试共同验证；本轮没有向真实数据库写入观测，没有配置厂家或发布实时服务。

本机后端观测 HTTP、结构 HTTP、IFC 工作区、日志与既有业务授权专项共 108 项通过；前端结构与观测响应契约 5 项通过。真实 Anoeta 门声明在无上报登记时读取返回 configured=false、status=unavailable，IFC 来源内容核对通过，运行目录未创建。此实跑没有模拟厂家报告写入真实底图。
