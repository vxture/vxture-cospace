# 语义本体独立产品首批构建

日期：2026-11-20。范围：三层语义体系的候选定义、独立定义内核、公共资源目录与宿主适配。分支 `codex/ontology-three-layer-design`。本机验证完成，未推送、未发布或部署。

## 已构建

- 通用 Python 包 `vxture-ontology`，独立入口 `packages/ontology/kernel/pyproject.toml`；运行时依赖为空，定义资源随包携带。
- 独立 React 包 `@vxture/ontology-ui`，以客户端注入 transport；组件不依赖 CoSpace 路由、身份、场景选择、API 地址或实例库。
- “公共资源—语义本体”默认进入本体目录，提供层级筛选、语义搜索、概念/属性/关系详情、依赖跳转、定义集及闭包导出。旧规则编制、固定版本与校验入口保留。
- 8 个候选模块、37 个概念、10 类关系；核心、建筑、室外、供配电、给排水、消防、监测、运营分别组织，全部明确为 draft。
- 授权只读 `/api/ontology-library`，宿主负责认证和权益，目录读取不要求园区、不访问场景目录或私有规则库。
- [独立产品边界](../decisions/ADR-007-语义本体独立产品边界.md)、[首轮盘点](../architecture/本体语义盘点与首批定义-TO01-TO02-v0.1.md)、[契约](../../contracts/schemas/ontology-library-v0.1.md)及 CI 独立安装包检查。

通过真实下载取得 `ontology-electrical-draft.json`，再次交给 Python 内核解析，确认只含 electrical 和 core，版本摘要依赖正确。390/1440 宽度下 DOM 页面宽度分别为 390/1440，未发现横向溢出；控制台未记录 error。临时 viewport 已恢复。

此验证证明组件可独立挂载和消费定义，不替代完整 CoSpace 浏览器联调。测试页、构建日志和安装包保留于忽略的本地成果目录，不进入 Git。

## 当前限制与后续

新目录只读，不提供新模块草稿保存/正式封存，不绑定或迁移任何现有实例。属性单位/最小值/必填目前为定义声明，尚无通用实例校验、单位换算、推理或专业合规结论。已发布旧规则继续使用原解释。

旧 Workspace 编制/版本/使用查询仍是宿主历史实现，本轮未完成全模块剥离。下一批先深化时间/断言、单位量种、职责及连接语义，并定义独立编制、存储和审计接口，再迁移旧编制能力；不能让平台主体、场景存储和业务权限进入通用内核。

## UI 修订：单一目录与操作分离

按用户反馈取消正文中的第二套模块导航及三层架构卡片，左侧唯一目录按通用核心、领域模块展开概念与关系，并承担搜索。正文一次显示一个模块、概念或关系，URL 保存模块和术语选择，支持深链、刷新与历史返回。编辑和发布入口固定于同一目录底部。

便携 UI 拆为 `useOntologyLibrary`、`OntologyDirectory`、`OntologyLibrary`，宿主负责摆放目录、路由与工作区规则入口，独立包未引入宿主依赖。旧规则编辑仅校验和保存草稿，固定版本封存移到发布入口，封存页禁止编辑。模块级编制与发布尚未实现，界面明确说明；不会将旧规则封存描述为新本体模块发布。

本次前端相关契约/导航回归 16 通过，TypeScript 与生产前端构建通过。完整本地 Shell 预览验证目录搜索、概念/关系选择、版本状态、属性约束、历史返回及刷新，正文 nav 元素数量为 0。908px 保留侧栏且无页面横向溢出；390px 使用同一目录抽屉，选择后关闭，页面宽度为 390px。临时 viewport 已恢复。

本地预览没有接入工作区规则编制服务，因此编辑/封存页面只验证模式入口和未配置说明，没有验证真实服务的保存与封存操作。预览截图位于忽略目录 `output/ontology-preview/single-directory.jpg`；未推送或部署。

### 更正：操作状态不作为目录分组

上一轮将查看、编辑、发布拆为导航分组是错误设计，以上“入口固定于目录底部”的说明已被本次修订取代。左侧现在只保留本体模块、概念和关系目录，删除新目录中的旧工作区规则入口。编辑本体与发布版本放在当前定义的标题操作区，当前能力未开放，按钮禁用并有明确说明。旧路由保留兼容，未作为新本体操作呈现。构建及 4 项目录契约测试通过，浏览器刷新确认目录分组移除、对象操作在正文标题区。截图：`output/ontology-preview/corrected-actions.jpg`。

### 最终修订：DS 固定分类与内容清单

撤销将模块与术语堆入侧栏的设计，移除 OntologyDirectory。宿主改用既有 ShellSidebarNav / ShellSidebarFrame 及同项目链接适配方式，固定三个入口：全部本体、通用核心、领域本体。导航项数不随资源规模增加，正文没有第二套导航。

内容区由 OntologyCatalog 展示本体清单，支持分类、文本搜索、名称/标识排序和每页十条的本地分页；打开本体后，在正文展示概念与关系清单，点击术语进入详情并可返回。浏览器验证领域分类内搜索“额定电压”、打开供配电、配电柜详情和返回本体详情，导航始终只有固定分类。前端 TypeScript/生产构建通过。

当前 API 是受限的内置定义集，最多 32 模块；上述本地分页不代表完成海量资源能力。后续注册库必须支持服务端检索、稳定排序/游标分页、摘要列表与按版本读取详情，禁止全量拉取定义模拟海量分页。本次不更改内核边界及 HTTP 契约。最终预览为 `/ontology?tab=library&category=all`，截图 `output/ontology-preview/ds-catalog.jpg`；临时 viewport 已恢复。
