# 六模块导航与职责调整

日期：2026-11-02。目标：落实已确认的三类六入口，明确本体定义与空间关联的边界，并让实施进度可按业务模块查看。

## 变更

- Launcher统一为使用（空间预览、态势服务）、构建（数据管理、构建中心）、定义（语义本体、空间关联）；共享一份模块名称和分组配置。
- “我的空间”改名空间预览，“服务与交付”改名态势服务，保留既有路由与记录ID。
- 对象标注编辑器移至空间关联；引用已有固定本体和模型点锚点。构建中心保留任务、候选确认和关联入口。几何与语义已接通，台账及对象关系明确标为待实现。
- 空间预览页增加可展开的六模块进度；区分已接通能力和缺口，注明实施记录不等于验收。
- 本机目录明确未经用户权限过滤。正式产品要求服务端控制列表和直接访问，当前身份与空间ACL尚未实现。
- 更新功能架构、能力复核、项目入口和运行手册。此次未修改后端契约或存储格式。

## 验证

`pnpm --dir apps/workbench run build`通过，包含TypeScript检查与Vite构建；仍有上游Radix模块的use client打包提示。

使用Playwright CLI进行31项浏览器断言，全部通过，收集的浏览器控制台/页面错误及非取消请求失败均为0：

1. 三个分组、六个链接、名称及路由一致；六个入口均可进入对应页面。
2. 进度区域包含六模块及实施记录声明，空间预览显示身份权限限制。
3. 空间关联读取现有激光候选`build-a16bfad1237544bf`、固定本体和对象`os1-test-anchor-001`，显示传感器坐标系。
4. 从空间关联到本体，再通过Launcher到数据管理、构建中心和态势服务，保留所选空间ID。
5. 构建中心不再重复标注编辑器；前往空间关联保留空间ID。
6. 全屏真实空间的账户菜单显示空间预览，点击后新开目录标签页。

检查只读取已有空间、候选、本体和发布；未提交登记、对象修订、构建、候选选择或发布操作。该验证不重新证明建模质量、对象语义或机器人运行资格，也不代表ACL验收。
