# 场景概览轻量摘要与菜单调整

日期：2026-11-13

场景概览改为单次 `/api/scene-overview?space_id=...` 请求。原链路串行读取完整工作流、构建列表和派生阶段，会间接轮询任务、验证模型成员和加载点云。新摘要只读取保存的选择、任务头、模型清单及视图任务状态；验证场景归属、选择与清单摘要、任务与冻结模型绑定，不宣称重新验收成果完整性。接口返回 `basis=saved_metadata`、`jobs_polled=false`、`artifact_members_verified=false`。

有构建查看权限时返回摘要；仅有空间查看权限时不返回构建、候选及关联计数。跨场景访问被拒绝。没有选择候选时只回退到同场景最新保存任务，不用最新任务替换已选候选。没有构建记录时返回空摘要。

前端移除独占一行的加载说明，保留稳定字段与标题高度，摘要到达后同时更新；失败仍有错误与重试。移除指定脚注。发布记录按时间倒序，第一项的“最新版本”位于右侧状态标签之前。

更多操作分为三组：场景概览、空间服务；构建中心、空间关联、服务发布；数据管理。空间服务链接携带明确场景与当前发布；尚无发布的场景进入该场景服务对象页签。

验证：

- 新摘要专项9项通过，覆盖不轮询、不读取模型数组、选定候选、计数、空场景、篡改选择、视图任务归属、工程路由及身份权限。
- 相关平台业务回归84项通过（其中包含较早的7项摘要用例）；追加用例后9项摘要专项重新通过。
- 前端74项测试、TypeScript/Vite构建、仓库保护与差异空白检查通过。
- 本地合成已保存记录20次摘要读取，中位2.77ms、最大3.19ms；此数据不包含生产网络往返，不是生产性能测量。
- 浏览器确认菜单三组顺序、未发布场景服务跳转、概览加载不插入说明行；没有修改生产数据。

本轮为本地实现与验证，尚未发布到生产。
