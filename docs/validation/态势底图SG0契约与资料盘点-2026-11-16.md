# 态势底图 SG0：契约与资料盘点

日期：2026-11-16。仅本机实现与验证，未修改业务路由、生产数据、旧构建或已发布成果。

## 实现

独立 synthetic 空间图契约、严格模型/引用校验、两层合成样例、实体/连接只读读取器及 CLI。支持几何近似范围、参考点、矩形端口和观测记录。Schema 与 Python 绑定、样例生成函数与静态 JSON 均有一致性校验。

明确不实现设备通过性、导航路径、状态冲突决议、真实结构导入、身份变更或点锚自动迁移。SG0 是 D0 的首个可验收增量，后续批次见[计划](../architecture/态势底图实施批次与数据清单-v0.1.md)。

## 验证

执行：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_scene_graph.py tests/test_preview_objects.py tests/test_preview_relations.py tests/test_partitioned_preview.py -q
.venv/Scripts/python.exe -m experiments.scripts.inspect_scene_graph examples/scene-graph/two-level.synthetic.json --entity cabinet --connections-for corridor-l1
```

最终本机结果：新增 56 项通过；与既有对象、关系、分区回归合计 114 项通过。覆盖坏引用、重复身份、非法坐标/矩形、机体通行字段拒绝、真实标记拒绝、几何反向绑定、关系单父与组成环、错误端口/构件、未知状态源、时间反转、迟到观测保留、只读副本与 CLI 字节预算。关闭门的状态与结构连接并存，不推断可通过。

命令行实际读取了 cabinet 和 corridor-l1 的连接；报告明确 synthetic、未核实、未达正式发布条件。报告仅放忽略目录 `output/scene-graph-d0/`。

仓库静态保护和严格 ruleset 核查通过。后续 GitHub required checks 与本机测试分别记录，不能用本机检查代替 CI。

## 真实资料盘点

运行只读 `experiments.scripts.inventory_scene_structure` 的 inventory 函数，检查五份既有 IFC（Anoeta、Donor、Jolastokieta、Longyearbyen、Target），记录文件摘要、大小、Schema 和限定类的文本声明数。

五份均未显式声明 IfcSpace 和 IfcElectricDistributionBoard；Donor、Longyearbyen 有 CRS/MapConversion 声明，尚未验证它们与点云一致。没有解算原生几何、读取包含关系或自动生成真实空间图。本次源文件只读，资料位置保持不变。

需要核实/补充的是点云—IFC 对齐依据、房间/楼道边界及名称、资产辨识依据和实时状态源。它们不阻塞合成契约与独立 IFC 结构候选提取；数据缺项清单已写入批次计划。
