# 候选确认与我的空间联动

本轮接通“构建完成→人工选择→我的空间打开所选版本”，继续以流程为主，不增加精度试验。

构建中心成功任务增加“设为空间版本”。点击后用现有DS对话框确认，保存为本机空间预览选择；当前任务显示“当前空间版本”。选择不会把候选改称正式发布或精度已验收。旧候选仍可打开，也可再次选择。

接口：GET /api/selection、POST /api/selection（candidate_id、expected_revision）、GET /api/workspace-model。初始没有选择时仍展示初始模型；有选择时工作台卡片、缩略图、构建记录下载与打开链接均指向所选候选。选择变更事件刷新同页模型，页面重新获得焦点也重读选择。已打开的候选页使用固定URL和自己的查询接口，不随空间入口切换。

选择文件保存在 `var/nyu/preview-builds/selection.json`，含递增revision、候选ID、前一候选、候选清单摘要与确认时间。追加记录保存于selections目录，先写记录再原子替换当前指针；异常中断可能遗留未生效记录，只有当前指针表示生效选择，不宣称多文件事务。当前使用单进程线程锁，不支持多个服务实例共同修改。对话框固定打开时看到的revision，避免后台轮询改变提交前提；旧revision提交返回409，提示刷新。

只允许成功且通过内容检查的候选被选择。读取工作台当前模型时核对所选清单摘要，清单被替换返回409，不静默回退初始模型。选择持久保存，服务重启后继续读取；尚未接真实账户、多工作空间权限或正式发布管理。

实际验证：Playwright点击build-b45b290c4c7f416d的“设为空间版本”并确认；我的空间显示“已确认的预览版本”、版本尾号290c4c7f416d，缩略图和打开入口指向其独立候选URL，点击打开在新标签页显示该候选，原工作台保留。真实HTTP核对workspace模型ID、候选查询模型ID和所选ID一致，旧build-75bfff86f8a849fc仍可访问。

验证：8项相关测试通过，覆盖原流程、持久选择、旧revision冲突、外部来源拒绝、未成功候选拒绝、选中清单被改拒绝及候选缩略图。TypeScript及Vite构建通过。证据：`experiments/evidence/2026-10-28/nyu-selection-001/checks.json`。
