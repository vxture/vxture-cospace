# Windows进程所有权原型验证

日期：2026-10-26。范围：I4a独立试验；未修改LocalRunner、任务Schema、数据库或恢复入口。

## 结果

在Windows 11（10.0.26220）、Python 3.14.3上，原型通过7项真实进程试验。使用ctypes调用Windows API，不新增依赖。最终证据为[results.json](../../experiments/runs/p2-ownership-004/results.json)，脚本摘要包含在结果中。

| 阶段 | 实际观察 |
|---|---|
| 创建前强杀 | 未创建worker，内核互斥锁可重新取得 |
| 原子关联、挂起创建后强杀 | worker未执行启动确认；父退出后worker句柄达到已退出状态，尚无正式登记文件 |
| 身份登记后、恢复线程前强杀 | worker未运行；父退出后worker退出 |
| 执行许可后强杀 | worker已运行；父退出后worker退出 |
| worker主动退出、父仍存活 | 互斥锁仍被父占用；父退出后才可取得 |
| 正常结束 | worker与父正常退出，互斥锁正常释放 |
| 虚拟环境启动器负向检查 | active_process_limit=1时启动器退出码101，未产生worker启动确认；按预期识别为不兼容 |

强杀使用实验框架持有的Popen实例，只终止本轮创建的监督进程；worker由Job Object收束。观测使用预先打开的进程句柄等待退出，不通过PID消失判断。父被强杀后互斥锁返回128（WAIT_ABANDONED），正常结束返回0。放弃锁不直接等于可恢复，产品还需其他身份与状态核对。

运行中的worker尝试启动额外进程，被active_process_limit=1拒绝，Windows错误1816。已检查Job句柄不可继承、子进程属于指定Job，父与子身份记录包含PID及操作系统创建时间。

## 启动协议修订

使用STARTUPINFOEX及PROC_THREAD_ATTRIBUTE_JOB_LIST，在CreateProcessW调用内完成Job关联，同时指定CREATE_SUSPENDED；登记后ResumeThread，再由试验许可控制执行。采用这一方式避免“创建子进程后再AssignProcessToJobObject”的孤儿窗口。未在创建调用内部逐指令注入强杀；原子性的依据是该操作系统API语义，实测故障点覆盖调用前和返回后。

本机CIM进程清单查询返回拒绝访问，未尝试提权。当前方案无需依赖全机枚举修补该创建空窗；旧版或身份不明的进程仍不能据此恢复。

## 失败记录与限制

首次[001失败日志](../../experiments/runs/p2-ownership-001/running/supervisor.log)在运行阶段等待启动确认超时：.venv/Scripts/python.exe是启动器，需要额外进程，与单进程限额冲突。该轮失败未改写为通过。随后改用C:/Python314/python.exe运行仅依赖标准库的探针，[002](../../experiments/runs/p2-ownership-002/results.json)五项通过；最终003加入创建前故障、启动器负向检查及后代拒绝检查。

003中的“7项通过”包含成功识别启动器不兼容，不表示实际检查worker已兼容。004进一步改为直接使用基础Python创建监督进程，并断言其PID等于Popen返回的PID，避免通过虚拟环境启动器间接强杀；7项再次通过。基础Python运行标准库探针不验证虚拟环境中的jsonschema等依赖。下一步必须解决固定worker的解释器、依赖路径和环境指纹绑定，再验证原有检查任务。

本轮未验证host_id/boot_id、真实PID复用、权限不足下的产品错误分类、操作系统重启、跨主机、数据库fence/CAS、产物封存竞争、迁移或导入恢复。创建时间不符检查仅验证记录比较，不等于已实测PID复用。原型许可未绑定job/attempt/fence，也没有生产环境白名单，不可直接用作产品运行器。FR-01至FR-05只有相应进程阶段的局部证据，不能标记完整故障验收通过。

## 复跑与清理

从仓库根目录使用新目录复跑，现有证据不会覆盖：

```powershell
.venv/Scripts/python.exe experiments/scripts/probe_windows_ownership.py --root experiments/runs/p2-ownership-005
```

脚本保留每个阶段的登记/检查点、日志及JSON结果。监督进程和worker句柄在框架退出时关闭；不连接数据库、不启动服务、不创建容器。异常路径终止本轮监督进程并等待，Job句柄关闭终止其worker。保留001失败证据与002/003/004证据供审查。
