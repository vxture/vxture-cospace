# N2：共用支撑目录

日期：2026-11-07。依据[迭代批次规划](../architecture/共用支撑与场景工作台迭代批次-2026-11-07.md)。本批目标是现有原始／过程／成果的授权统一目录及独立支撑入口，不是完整数据平台的所有未来能力。

## 实施

- 新增 `/api/data-catalog`：按当前 Workspace 身份和 data.manage 范围投影输入、配套原文件、批次、最近预检、任务、模型候选、两类视图声明、固定发布及有权限的离线交付入口。任务／发布／导出分别补其操作能力校验。
- 不调用任务 poll、不加载几何、不导出内容；保存任务失败／运行中仍是过程记录，不能假冒候选。目录是 metadata_only，实际查看和写操作仍走原端点校验。
- 分类、搜索、场景筛选、有界分页及读取时间；损坏记录明确 partial，整体读取失败清空旧结果，避免伪空或跨范围残留。
- `#data` 不自动选首场景；带场景的普通入口只作为可清除筛选。保留所有显式场景资料／批次／版本深链，管理及导入入口绑定具体场景。
- 语义本体移到独立共用工作面，去除场景目录依赖，保留场景关联返回链接。规则存储、权限和封存流程保持原契约。

接口对象矩阵和范围见[Workspace 数据目录契约](../../contracts/schemas/workspace-data-catalog-v0.1.md)。现有批次与任务从原存储投影，无业务数据迁移、算法执行、发布、退役或跨场景复制。

## 限制与后续

此目录目前依托已有场景归属。无场景数据资产写入／跨场景复用尚无后端契约，本批不开放。已有模型输入归为“原始与输入”，不改其数据事实。只展示最近保存预检、现有候选与视图声明；未新增完整检查历史或每种算法中间文件的资产化。配套资料链接定位所属列表，完整离线包生命周期未虚构为导出历史。

元数据目录不显示当前分发放行结论；暂停／退役和内容完整性在原详情执行检查。当前 Workspace 内无 data.manage 时返回空管理范围，仍可独立使用有权的本体规则。用户请求的 N3 左栏／统一外壳和 N4 流程横栏尚未实施，不将它们计为 N2 已完成。

发布建议：N2—N4形成可评审完整体验后，再进行阶段版本候选；N5必要编辑保护和N6综合验收通过后才实际发布。各批保留独立验证和审查边界，生产发布仍须 GitHub 五项检查、release tag 和 production Environment reviewer。本轮未提交、推送或部署。
