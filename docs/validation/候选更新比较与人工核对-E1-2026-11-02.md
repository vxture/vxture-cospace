# 候选更新比较与人工核对 E1

日期：2026-11-02。模块：空间关联、构建中心及态势服务。目标：对象修订形成候选后，可以明确比较、人工核对、再选择及独立发布。

## 本批结果

- 空间关联新增对象修订，保持稳定ID，编辑类型、属性和模型点锚点；未保存编辑时不能生成候选。
- 构建中心将选择入口改为“核对并选择”，比较当前所选候选与目标的模型摘要、坐标/网格、本体、表面单元及对象新增/移除/修改。
- 记录核对说明、明确知悉限制及固定比较摘要。提交时重新比较，选择锁内再次重读快照；候选内容或空间序号变化时拒绝旧核对。
- 坐标/分辨率不兼容时不产生表面集合差且阻止本路径确认；移除表面证据不表示空闲，对象变化不代表现场设备变化。
- 当前选择与选择历史保存完整核对，新固定发布原样继承。旧发布不改写、不补造核对。离线ZIP沿用0.1/0.2格式。
- 更新模块进度、契约及操作手册，下一步为态势服务的新旧固定发布变化追溯。

## 浏览器

Playwright CLI使用8767的实际前端，通过路由转发将资料/候选/发布API定向至8768独立副本服务，所有写入发生在副本。**19项检查通过**：

- 对象ID锁定，未保存修订禁止生成；修订后仍为原对象ID。
- 新候选不自动选择，核对展示单对象修改及复用几何、未知声明。
- 未填说明/确认限制时不可提交。
- 另一操作改变所选序号后，弹窗失效；重新读取清除旧确认，再次填写及确认后才可选择。
- 发布继承正确目标候选的核对记录，旧发布仍可读；取消核对不改变选择。
- 使用DS宽对话框、无横向溢出，未捕获页面脚本错误。

另做919×902与375×902布局复查，对话框宽分别672px和311px，无横向溢出。初次尺寸采样受进入动画影响，等待动画完成后复核通过。原空间仅打开比较并取消，未提交确认。测试后已解除路由转发，关闭临时副本服务，8767继续读取原运行目录。
