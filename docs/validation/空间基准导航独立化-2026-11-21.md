# 空间基准导航独立化

日期：2026-11-21。基线：v0.13.0。此次只调整板块归属、导航布局和关联入口，不增加配准算法、审核流程或交付类型。

空间基准从关联概览移到“场景作业”一级入口 /registration，与构建中心、空间关联、服务发布同级。复用同一板块导航框架：280px 左栏、基本信息、固定模型选择、地图配准入口，以及选中、收起和窄屏覆盖状态。页头与内容区复用 WorkflowPageHeader 和 publication-content，内容宽度至多1440px；编辑、审核、采用仍使用原页面操作和抽屉。

Launcher、场景操作菜单、关联概览、场景概览、模型检查面板及发布准备同步链接到独立板块。概览只读显示资料状态、采用修订和参数检查结果。旧 /association?tab=registration 地址保留场景及模型并替换为新地址；切换场景清除旧模型，基本信息和配准之间切换保留当前模型。沿用 association.edit 权限，权限名称补充空间基准范围；独立审核限制不变。正式页面及登录返回白名单加入新路由，不启用任意 SPA 路径回退。

验证结果：

- 前端158项测试通过，生产构建与仓库规则检查通过。
- 正式页面路由、登录返回和配准 HTTP 专项共23项测试通过。
- 浏览器14项流程检查通过：280px 几何一致性、导航收放、Launcher、旧地址、场景操作菜单、两处概览摘要、发布准备、固定模型保持、未保存保护和908/390px布局。
- 页面导入使用本地工程测试资料，仅执行非持久服务端核对，最终放弃修改；未向生产写入场景资料。

截图、浏览器脚本、会话与运行数据保留在本地忽略目录，不进入 Git。本次修改尚未作为新版本部署；v0.13.0 的生产发布状态不因此改变。
