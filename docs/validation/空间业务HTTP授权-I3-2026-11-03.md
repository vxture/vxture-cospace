# 空间业务HTTP授权 I3 验证

日期：2026-11-03。目标是将已实现的平台身份、中央会话和空间策略用于真实样本业务HTTP，覆盖授权空间目录、固定链接、双视图资产、查询、导出及写操作。

## 实现范围

新增持久策略、完整策略CAS及历史、显式业务路由授权和独立授权工作台启动器。前端调用同源业务，授权模式只展示真实授权空间，账户展示保存的平台身份，写请求使用CSRF。六模块及原成果生命周期门禁继续使用现有实现。

## 验证结果

| 验证 | 结果 | 证据 |
| --- | --- | --- |
| I3专项 | 50项通过 | regression-final.log、test_platform_business.py |
| 相关回归 | 261项通过，含专项50项及既有211项 | regression-final.log |
| 真实HTTP | 30项检查通过，34次显式业务/会话请求，2个RP服务进程含一次重启 | checks.json、http-trace-redacted.json、server-1/2.log |
| 浏览器 | 查看者11项、工程师10项通过 | browser.json及三张截图 |
| 前端构建 | TypeScript及生产构建通过 | build-final.log |
| 原数据 | 195个受管文件摘要与路径集合均未变 | final-readonly.json |

回归覆盖角色、跨用户/空间/工作区、直接资产与导出、CSRF、先授权再轮询、引用归属、HEAD/Range/条件请求、未知与编码路径、策略缺失、撤权及CAS历史、中央失效、发布与暂停。HTTP使用隔离样本实际查询、导出、发布和暂停，验证外部用户403优先于暂停409、撤权即时生效及服务重启后工程师身份/授权恢复。

浏览器实际登录模拟查看者A和工程师B，分别只看到自己的一个空间；A从卡片新标签页打开真实三维大屏，展示数据与同源CSRF查询可用，导出及另一空间403。B可导出自己的离线包、访问资料目录，不能发布或访问A空间；桌面与390px移动视口无横向溢出。构建保留现有第三方包use-client与分包提示；浏览器检查包含主动触发的403和favicon404，未以零控制台错误作为验收结论。

## 复核边界

这是本地模拟accounts协议链路的授权验证，尚未使用真实平台CoSpace client联调。业务操作只发生在独立样本副本；原8767工程预览保持无认证内部入口，8768保持I2验证模式，8769为本轮授权入口。授权撤销不终止已准入请求、不删除已持有离线副本；展示许可不构成防复制。空间创建、浏览器成员授权编辑、私有本体编辑与多主机存储未验收。

证据目录：`experiments/evidence/2026-11-03/platform-access-i3-001`。含脱敏轨迹、测试/构建记录、浏览器检查及源码摘要；不含会话数据库、密钥、token、cookie或授权回调参数。操作见[I3运行](../guides/空间业务权限I3运行.md)，设计见[HTTP授权设计](../architecture/空间业务HTTP授权设计-v0.1.md)。
