## 新增验证

新增11项测试，覆盖以下路径：

随后全量本地SQLite路径为**95 passed、6 skipped、22 subtests passed**。PostgreSQL专属用例本轮跳过；本轮没有修改平台数据库或前端，不增加PostgreSQL并发验证结论。

| 检查 | 实际结果 |
|---|---|
| 文件内容分离、重开存储及会话切换 | SQLite无members列；旧会话保留空闲，新会话读到新包占据 |
| copying、复制首成员后进程退出 | 遗留copying记录，未提交包不可激活 |
| rename后、状态更新前进程退出 | 遗留verified和孤立目录，不被视作ready |
| ready事务提交前进程退出 | 遗留sealed，包登记回滚，旧活动包不变 |
| 持锁进程仍活着时recover | owner_alive，状态不变；强杀后可标记interrupted |
| 恢复后的再次安装 | 新install_id，重验来源后可复用完整孤立目录，旧记录保留interrupted |
| 已封存文件损坏 | 拒绝新会话及重复安装，不覆盖坏目录；旧内存会话仍读旧快照 |
| 注入写入磁盘满及DB提交失败 | 记录failed，保留旧活动指针；孤立内容不清理 |
| 新旧存储根混用、非法安装ID及终态恢复 | 拒绝 |
| SQLite文件损坏 | 报错，损坏字节未被空库替代 |
| 两独立进程竞争激活、激活提交前进程退出 | 一个成功一个冲突；提交前退出后revision保持原值 |

复制与提交中断采用真实独立Python进程os._exit；活安装锁测试由本轮Popen强杀并等待退出。磁盘满和数据库失败为可控注入，不是实际填满磁盘或破坏用户数据库。没有整机重启、物理断电或POSIX文件锁验证。

## 限制与下一步

文件块仍是原R0组件，单文件8MiB、合计32MiB；未验证大地图、流式内核或SDK内存。有效性仍为unverified_sample_only、robot_ready=false；恢复安装不等于恢复构建任务，也不提供签名或撤回检查。

下一步R1c增加只读完整性核对与遗留目录清单，不自动清理；真实资源指标和物理断电在明确设备后单独验证。设计与命令见[专题设计](../architecture/智能体运行包文件存储与恢复设计-v0.1.md)及[手册](../guides/本地智能体运行包参考运行.md)。
