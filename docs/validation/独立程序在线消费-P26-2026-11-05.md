# P26 独立程序在线消费

状态：实现与本机实际HTTP验收完成，身份源为显式mock；真实平台换票待P25。

## 已实现

- 依据平台源码接service模式RFC8693票据：RS256、iss／aud、act.sub、org_id／workspace_id、tool scope、jti及最多300秒有效期；拒绝人令牌、OBO与delegated票据。
- 固定场景／固定发布只读点查询；平台租户绑定与调用产品的显式场景授权同时满足才放行，配置撤权下一请求生效。没有浏览器Cookie或管理操作权限。
- 必须声明模型摘要、坐标和最大陈旧度。响应含来源摘要、served_at、as_of／valid_until、完整性及质量。本次真实激光样本观测UTC未核实，后两时间字段为null，实时用途明确拒绝。
- 显式历史用途返回实际表面候选或unknown；unknown不等于空闲。unverified、robot_ready=false。
- 独立Python客户端以自身客户端换票，校验票据及返回内容绑定；无Cookie、无令牌落盘／刷新／重定向。CLI输出保存查询收据，退出码0／3／2区分历史结果、拒答、错误。

## 验收

本机真实HTTP由独立子进程调用8790及19127；实际模型来自P27的10帧激光ICP，不是合成几何。所有service票据仅由明确的本地mock签发，不能计为真实平台换票。

| 证据 | 检查 |
| --- | --- |
| p26-online-denied.json | 有效票据仍因未配置场景授权被403拒绝 |
| p26-online-main.json | 表面／未知、实时时间拒答、版本／坐标／max_age、非法票据、Cookie混用和浏览器写接口，10项 |
| p26-online-paused.json | 暂停后409 |
| p26-online-restart.json、p26-online-cold-restore.json | 不同进程重新换票，恢复后结果一致，各10项 |
| p26-online-retired.json | 退役旧版409，不自动切新版 |
| p26-online-current.json | 显式切新版后10项通过 |
| p26-cli-acceptance.json | CLI实际历史结果0／实际拒答3 |

文件均位于output/playwright/。7个独立在线进程共43项，汇总p26-online-acceptance.json；34项机器专项涵盖短期令牌、签名、租户／场景隔离、权限变化、依赖失败、篡改、请求限额和客户端绑定。最终全量1,763项通过、13项跳过，另22个子用例通过；初次失败及定向复核另保留，见总验收报告。

当前仅单点、service模式、未验证UTC的历史样本，不提供导航、安全空闲判断、订阅、全场景完整度或真实在线设备能力。as_of／valid_until不能使用构建或发布时间冒充。后续接可信观测UTC时需扩展契约并另做新鲜度验收。
