# 空间成果目录与分类验证（F1）

日期：2026-11-02。归属“构建 → 数据管理”。本轮将已有真实流程成果按空间组织为可查询目录，保持资料登记、构建、固定发布及消费各自的职责。

## 实现结果

- 新增`GET /api/artifacts`，按显式空间或历史未关联范围返回四类成果：登记资料、模型候选、固定发布、按需离线包。
- 候选按实际语义快照区分几何/语义；成功任务才形成候选项，其余任务仅计数。标明当前所选候选，损坏或选择摘要不匹配时不显示为有效所选。
- 关系包含构建输入、标注基线、发布候选、发布保存的输入来源及包的发布来源；区分绑定一致、缺失、不一致和未记录。跨空间异常引用不形成可导航目标。
- 目录查询不调用任务轮询、不创建选择目录、不重新预检源文件、不生成ZIP或包摘要、不检查消费端安装状态。
- 数据管理默认打开成果目录，保留“登记资料”标签及旧input链接；支持分类、搜索、上下游导航和原模块定位。固定空间在新标签页打开。
- 补充[契约](../../contracts/schemas/preview-artifacts-v0.1.md)、[Schema](../../contracts/schemas/preview-artifacts-v0.1.schema.json)、[操作手册](../guides/空间成果目录运行.md)，同步README、运行手册和六模块进度。

## 边界与后续

这是请求时多文件聚合目录，不是原子事务快照或持久成果仓库。不扫描整个外部样本目录，不移动或重命名源文件，不改写历史登记/候选/发布。输入完整性须独立预检；固定快照完整性不代表语义、精度或交付通过。quality保持unverified，robot_ready保持false；正式身份及空间ACL尚未实现。

下一步推进“空间关联”的对象与业务台账绑定，保持固定本体、稳定对象ID及独立候选/发布链路。采集批次、成果生命周期编辑/归档及对象间关系后续分步补齐。
