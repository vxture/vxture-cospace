# 本体关系与空间对象关系验证（F3）

日期：2026-11-02。归属：定义 → 语义本体、空间关联；联动构建中心、态势服务、空间预览。本批打通人工关系实例流程，未验证现场归属、几何包含或机器人通行能力。

## 1. 实现范围

- 保留原类型词表0.1.0，新增独立关系词表0.2.0。类型及字符串约束兼容，增加包含、位于、连接的方向、端点及受限关系规则。
- 关系ID稳定，两端必须在同一固定对象集。拒绝自身关联、缺失端点、类型/方向不符、重复ID、包含/位于反向等价重复、连接反向重复、多重直接父空间及包含循环。
- 空间关联提供完整关系集录入、修订、移除、只校验、完整集确认及独立候选生成。旧基础显式选择新规则，服务端重读基础并重新校验，不自动改当前选择或发布。
- 候选核对和发布比较分别展示关系新增、解除、修订；新核对摘要覆盖关系。对象改名保留关系，移除对象清理相关关系，类型变更造成冲突则整批拒绝。固定业务台账继续保留。
- 双视图展示同一固定关系快照，点击关联对象可切换查看。离线0.4包含relations.json，可选保留business.json；读取器继续兼容0.1/0.2/0.3。

契约见[空间对象关系v0.1](../../contracts/schemas/preview-relations-v0.1.md)，操作见[空间对象关系运行](../guides/空间对象关系运行.md)。

## 2. 自动化验证

**153项相关测试通过，52.23秒**。覆盖关系、固定本体、业务台账、对象、候选/发布比较、成果目录、离线包、消费库、发布、血缘及核对单。F3专项26项，验证：

1. 新旧规则共存；未定义端点类型、不合法对称规则、缺失父端、重复类型及非对象JSON定义拒绝。
2. 规则升级、独立关系候选、人工核对、固定发布、在线/离线对象一致及新发布比较；旧发布不补关系。
3. 9类关系冲突及5类固定引用失败不产生候选；错误定位到关系集或关系项。
4. 稳定关系ID修订、完整集清空、对象改名保留、对象移除清理、对象改类型冲突拒绝。
5. 对象摘要、本体引用、空间、计数、非法自身关系、伪造确认及孤立声明，即使重算成员摘要仍被拒绝。
6. 业务绑定经规则升级和关系候选保持；含业务/关系的0.4包安装、激活后，删除源ZIP及本机台账、禁用网络，重新创建消费库实例（同进程）仍返回相同关系和业务记录。
7. 草稿校验不写候选，严格字段、空白说明和Origin错误拒绝。

前端TypeScript检查和Vite构建通过。依赖中的既有use client指令构建警告保留。日志见[tests.log](../../experiments/evidence/2026-11-02/preview-relations-f3-001/tests.log)及[frontend-build.log](../../experiments/evidence/2026-11-02/preview-relations-f3-001/frontend-build.log)。

## 3. 两类真实几何样本

从原运行区复制到新的 `var/validation/relations-f3-001`，仅在副本增加明确标注的测试设备间、走廊和柜体对象，端点锚点来自真实模型点，语义是人工测试声明，不能视为现场识别结果。

## 6. 边界及下一步

当前为小型本机规则包，包含类统一采用单一直接父空间和无环约束；不支持跨空间关系、复杂基数、本体推理、几何包含检测、路径规划或外部关系同步。没有真实身份/空间ACL或生产机器人授权。所有关系、对象和业务台账仍待核实。

定义层现已贯通语义与几何、对象与业务、对象与对象三条能力线。下一步以内部交付工程师任务为主线，对三类六入口进行端到端流程验收，汇总阶段状态、失败处置和产品缺口；继续优先流程可用性。
