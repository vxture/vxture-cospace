# N5 连续操作与编辑保护

日期：2026-11-08。基线为已上线 v0.2.0，分支 `codex/workbench-continuity-n5`。

## 操作约定

- 场景、板块、记录、候选及本体草稿切换，浏览器前进／后退，刷新编辑面和关闭导入弹窗，先处理未保存修改。取消保留内容与地址；放弃仅重置本标签页编辑器；保存后继续等待服务端成功回执。
- 场景信息、来源配置、资料说明、坐标说明、本体草稿、采集批次成员支持保存后继续；必填原因、权限、影响核查等前提不满足时禁用保存。保存失败停留；已收到回执的编辑不会在后续失败重试中重复保存。多个编辑的保存不是跨接口事务，前项成功、后项失败时成功项保持已保存。
- 对象标注、对象关系、业务绑定、区域资料参数、导入／上传／PLY准备、新场景及新批次参数，需要在原工作面明确核对、生成或登记。导航不自动生成候选、登记文件、封存批次、创建场景或发布。
- 草稿保留于当前标签页内存，不增加浏览器草稿或认证存储。刷新／关闭使用浏览器原生离开提醒，不承诺刷新后找回。已有场景创建请求回执与区域处理任务ID的恢复机制保留，均不自动重放写操作。
- 离开工作面不发送后台任务取消命令；任务已创建后可按原ID查看。离开尚未完成的文件上传仍可能中断上传连接，返回后须按原包核对登记结果。

## 会话与权限

平台不可用、登录失效或订阅状态无法确认时，遮挡并禁用已挂载工作面，拦截新业务请求。同组织、工作区、用户恢复后继续内存编辑，重新读取目录／本体权限；不重放保存、构建或发布。

组织、工作区或用户改变时清空旧编辑及URL记录参数，仅保留板块入口。确认期间等待的旧请求不发送到新身份，旧请求返回不交给新工作面处理。服务端仍执行每个请求的身份、能力、修订与固定引用核查。已经被服务端接受的写操作不会因前端丢弃旧响应而回滚，结果需按记录核查。

同身份目录重读保留原挂载编辑器，成功返回撤权或无场景时收回入口；临时读取失败显示提示，不将其误判为无场景。新工作区不复用旧目录。工作区业务权限不等于商业订阅，权益仍由平台判定。
