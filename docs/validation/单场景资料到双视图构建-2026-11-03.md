20 项真实链路检查通过：同场景资料去重、实际源文件核验、跨场景构建拒绝、真实构建完成、场景与资料绑定、构建不自动选择、模型先于视图生成、人视图逐点／颜色与模型一致、智能体单元与模型体素化一致、共同模型摘要、所有文件大小与摘要、未知不当空闲、固定发布绑定、无虚构语义前置、离线包完整性、表面与未知两类在线／离线一致、质量标识不升级、其他场景保持无资料，以及原工程目录不变。

脚本：`experiments/scripts/verify_scene_construction.py`。复跑必须使用新的输出目录：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_scene_construction --output var/validation/scene-construction-replay-001
```

相关回归首轮发现共用测试夹具只有空的人视图声明、不包含视图文件；已补足夹具，使其符合新增的双视图来源约束。修正后 **103 项测试通过**，包含模型、任务、发布、场景隔离、参考流程、本体候选及平台权限等。结果：`output/validation/scene-construction-regression.txt`。另补查激光、成果目录、关联、离线消费与发布变更的 111 项回归通过，共 214 项；下游结果见 `output/validation/scene-construction-downstream-regression.txt`。

浏览器额外执行了认证后的“资料详情 → 用于构建 → 执行预检 → 发起构建 → 新任务流程”路线，同一场景的旧模型与固定发布保留；新候选完成模型与双视图，不自动选择或发布。17 项浏览器主流程检查与 6 项最终布局／隐藏页停止轮询检查通过，共 23 项。结果见 `output/playwright/scene-construction-ui-result.txt`、`scene-construction-final-result.txt` 及 `scene-construction-flow-*.png`。最后一次界面构建产生 `build-70889cca2d8c42e1`，仍未选择或发布；首个固定发布继续保留。
