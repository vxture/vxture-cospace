# 发布生命周期验证

日期：2026-10-26。阶段：P2合成服务闭环局部验证，非正式现场交付。

## 本轮实现

新增lifecycle规则、SQLAlchemy存储、PostgreSQL本地管理CLI和只读托管API。注册前校验完整合成包，将小型元数据及coverage快照存入数据库；运行查询不依赖原始包目录。该做法仅适合当前小型样例，不能推广为把真实点云和体素全部存进JSON列。

同一场景的真值、视图及本体包身份被固定到内容摘要，服务发布不能通过换release_id沿用已改变的旧依赖身份。重复登记相同内容可重试；改变内容复用身份时拒绝。快照摘要用于发现存储损坏，不是签名或抵御数据库特权篡改的安全措施。

每个场景维护current指针和递增revision，激活须提交expected_revision。指针切换与激活事件在同一数据库事务中完成；过期修订号、依赖缺失、已撤回能力均不切换。revision防止指针回到原版本后旧请求仍被接受的歧义。

撤回追加事件，记录UTC时间、actor和reason，作用于该发布的synthetic_point_query。本轮只支持整项能力立即撤回，不支持区域/定时限制或撤回恢复。历史清单仍可追溯；已固定版本每次托管查询都检查撤回，回退激活也检查。

## 并发与失败语义

PostgreSQL事务锁定场景行，将切换、撤回和查询有效性判断串行化。撤回提交后开始的查询不能绕过；已在撤回前获得锁的查询可以完成。该方法适合当前小型验证，不是大规模高并发查询方案。

事件仅通过代码追加，数据库未配置不可变审计权限、触发器或外部归档，不能宣称审计防篡改。SQLite仅用于普通单线程测试；生产CLI及托管应用限定PostgreSQL，并发语义只在真实PostgreSQL测试。

## 验证与证据

测试涵盖切换、过期请求、固定历史读取、重新建立连接后的状态、撤回阻断、历史追溯、失败事务回滚、快照脱离原文件、身份复用冲突、存储损坏拒绝、托管API错误码、并发激活单一胜者以及撤回提交后的查询阻断。

完整PostgreSQL结果见[测试日志](../../experiments/runs/p2-lifecycle-001/tests.log)及[JUnit报告](../../experiments/runs/p2-lifecycle-001/tests.xml)，镜像信息同目录。运行脚本创建独立限额PostgreSQL18容器，数据为临时测试数据，结束后移除容器，不接触既有数据库。

最终实际结果：PostgreSQL路径41个测试、19个子用例全部通过，无跳过；普通本地路径39个通过、2个PostgreSQL专项跳过、19个子用例通过。

测试方式：普通开发用`uv run --locked pytest -q`，其中两项PostgreSQL并发测试跳过；实际数据库用`experiments/stack/run-lifecycle.ps1`执行全部用例。不同运行结果分别解释，不能将SQLite通过视为PostgreSQL并发通过。

## 剩余范围

本轮仍为synthetic通道，无真实质量审核、身份认证、数据库版本迁移、权限分离、备份恢复、三维浏览、定位或性能结论。actor是本地操作者声明，不是认证身份。初始化使用显式demo建表，正式部署需Alembic迁移及运行权限。

P2已形成可测试的“登记→切换→固定读取→撤回→历史追溯”合成路径；人视图消费和正式持久化交付仍需补齐。下一增量优先数据库迁移、可复跑演示及工作台最小浏览；P1真实数据和算法试验仍独立推进。
