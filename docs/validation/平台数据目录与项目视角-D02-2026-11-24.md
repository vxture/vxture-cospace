# 平台数据目录与项目视角 D02

日期：2026-11-24。范围：平台资源目录、业务项目筛选和管理抽屉、场景关联、资源管理归属及元数据版本登记。尚未部署生产，不包括跨项目共享授权。

## 已实现

- 数据资源：全部数据、基础数据、采集资料、参考资料、空间成果；业务记录：处理记录。项目、场景和数据项不成为导航条目。
- `/api/data-resources` 聚合授权范围内资料和成果；任务、预检、批次独立查询，未生成交付入口不计资产。已有 PLY 输入按空间成果归类。
- 搜索分页、项目与场景组合过滤；切换项目清除旧场景过滤。全局记忆场景不限制平台目录。
- 项目新建 / 更新 / 归档 / 恢复，场景重新关联 / 解除，以及资源登记均通过抽屉操作。登记保留管理项目和元数据版本，场景重新关联不转移管理归属。归档项目同时检查关联场景和管理资源。
- 管理权限、可信作用域、CSRF、乐观修订、请求幂等与审计接通；未知或损坏元数据保留 partial 状态。无几何载荷请求，不声明文件或现场质量重验。
- 保留场景资料、参考资料、点云、批次、版本和来源追溯六项原工具，通过场景工具菜单及来源直链到达。
