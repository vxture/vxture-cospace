# N1：导航范围与上下文

日期：2026-11-07。计划见[共用支撑与场景工作台迭代批次](../architecture/共用支撑与场景工作台迭代批次-2026-11-07.md)。

## 实施

- product-navigation 增加独立于旧菜单分组的业务范围元数据：数据管理、语义本体为共用支撑，其余四项为场景工作。元数据不授予权限，不改变资产归属或当前 API 读取范围。
- navigation-contract 区分普通板块切换与显式业务交接；Launcher 和场景页面六板块入口接入 moduleLink，普通切换只继承 URL 中的场景，清除旧记录定位。
- recordLink 保持明确交接的原行为，显式参数可覆盖场景、携带固定记录；无场景不自行选择场景。上层页面现有默认场景行为留待 N2／N3 迁移。
- 保留 App 对 URL 快照的订阅，确保同一板块内切换场景时，顶部菜单的链接同步更新。
- 新增确定性导航测试并接入 CI build job；未变更现有五项必需检查或生产发布规则。
