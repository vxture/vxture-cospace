# 对象与业务台账绑定验证（F2）

日期：2026-11-02。归属：定义 → 空间关联；联动构建中心、态势服务、空间预览。当前完成对象与业务固定版本绑定的工程流程，未进行现场台账确认或生产验收。

## 1. 本批实现

1. 本机设备台账登记：来源系统、业务标识、版本、名称，以及资产编码、制造商、型号、序列号。按空间隔离；同一业务版本不能覆盖，相同内容重复登记返回原记录。
2. 稳定对象ID引用台账record_id＋SHA256；生成完整绑定集的新候选，支持新增、解除、换版。基础几何不重新估计，语义及台账保持待核实。
3. 构建中心独立展示业务差异，人工核对后选择；态势服务另行固定发布并支持历史发布业务变化比较。登记或候选生成均不自动选择/发布。
4. 人视图、智能体视图及对象查询读取同一业务快照；新台账版本不影响历史发布。普通对象修订保留仍存在的稳定ID绑定，移除对象时清除其绑定。
5. 离线包0.3包含business.json及完整固定台账记录，支持独立安装、显式激活及重启恢复。旧0.1几何包、0.2语义包保持兼容。

契约见[preview-business-v0.1](../../contracts/schemas/preview-business-v0.1.md)，操作见[对象业务台账绑定运行](../guides/对象业务台账绑定运行.md)。

## 3. 浏览器与页面验证

**20项检查通过**：未变化禁止生成、台账待核实、登记不选择、完整集显式确认、生成不选择、移动端无页面横向溢出、候选换版差异及精确引用、人工选择、发布差异、固定对象记录、离线0.3元数据、人/智能体视图一致、重载恢复、解除需重新确认、纯几何候选清空旧绑定、跨空间无外来台账、无未捕获页面错误。首项额外校验独立副本的种子记录，防止向原运行区写测试数据。

最初的浏览器请求代理在清理时出现route已处理错误，未将该次结果作为最终验收。最终改为在确认无运行任务后，临时让独立副本直接使用8767，完成无请求拦截的真实HTTP操作；随后停止副本并恢复原服务。完整结果见[browser-checks.json](../../experiments/evidence/2026-11-02/preview-business-f2-001/browser-checks.json)。纯几何对象查询的404为预期失败分支。

检查了919px桌面和375px移动布局，以及全屏空间的固定台账展示；同时缩短对象修订/移除按钮的可见文字并保留完整无障碍名称，消除窄屏动作区溢出。页面沿用DS组件。移动端补查main及其子容器未发现横向滚动溢出。

## 5. 当前边界与下一步

每个对象本阶段最多绑定一个设备台账固定版本；一个台账可被多个对象引用。来源系统仅为标识，不表示已经连接。尚无外部实时同步、巡检事件关联、真实身份/空间ACL或机器人生产授权。所有对象及台账仍为unverified，robot_ready=false。

下一步以语义本体的关系规则和空间关联的对象关系实例为主线，先细化包含、位于、连接的方向、端点类型、数量与冲突约束，再接候选核对、双视图及离线发布，继续以流程贯通为优先。
