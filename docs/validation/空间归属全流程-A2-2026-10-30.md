# 空间归属全流程 A2

2026-10-30：本机资料、构建任务、模型候选、固定发布、在线查询和离线包已贯通项目与空间归属。工程目录、候选选择、固定发布分别保存，不以候选选择代替发布。

## 数据约定

| 位置 | 归属及规则 |
| --- | --- |
| 登记资料 | 可选 `space_id`；`project_id`由服务端读取空间目录确定，浏览器不能填写项目归属 |
| 登记去重 | 同一空间内，相同封存路径及内容摘要复用登记；同一公开样本在不同空间生成不同登记ID |
| 构建任务 | 请求空间必须与登记归属一致；任务、input_binding、model.json保存相同的两个ID |
| 候选选择 | 每空间独立CAS修订号；检查模型、任务及输入绑定；旧全局selection单独保留 |
| 固定发布 | 必须是该空间明确选中的候选及修订号；快照继承归属，后续选择不改变旧发布 |
| 消费与追溯 | 查询、追溯、包清单及包内发布/模型带归属；离线加载检查包、发布和模型归属相同 |
| 空间入口 | 展示该空间最近一次固定预览发布；历史固定版本仍在交付页，不随候选选择切换 |

已有预览profile沿用0.1，归属为可选增补字段；字段缺省严格表示历史未关联，不按路径、名称或几何相同推测归属。归属一经登记，不通过任务或发布请求重新指定。

GET `/api/inputs`、`/api/builds`、`/api/publications`、`/api/selection`省略 `space_id` 时读取历史未关联范围；指定时只读取该空间。`/api/workspace-model?space_id=...` 没有选择时返回404，不回退到初始或其他空间模型。POST登记、构建、选择、发布在JSON体传 `space_id`。无效空间、跨空间引用或过期修订号拒绝。

目录的state/publication_id是固定发布列表的读取投影，不回写空间身份JSON。空间记录ID、项目归属及创建时间保持原样；两条本机测试空间用途描述更新为“复用同一NYU公开样本验证空间归属与完整流程；非独立现场采集”。

页面从空间卡片进入资料、构建、交付，页面内和Launcher业务跳转携带空间；切换空间重置记录定位及未提交确认框。历史范围可复查，页面新资料登记需先选择空间。工程CLI增加 `--space-id` 与 `--directory`；省略空间仍可登记历史未关联资料。
