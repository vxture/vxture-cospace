# 园区地图配准全流程验证

本次用于区分“缺少轴向和控制资料”与“配准界面不可用”。历史模型只有
`x/y/z` 字段时，不能据此推断右手轴向；需补充来源轴向、单位和可追溯的
控制点资料。完整资料在独立园区样例中可以走通地图配准流程。

## 可重复的测试入口

先构建工作台，再启动仅监听本机回环地址的验收环境：

```powershell
pnpm --dir apps/workbench build
.venv/Scripts/python.exe tests/serve_campus_registration_acceptance.py --output D:/CoSpaceTest/campus-registration --port 18878
```

`--output` 必须是仓库外尚不存在的独立目录。脚本输出场景、模型和资料路径，
模拟登录提供资料工程师、独立审核管理员和只读查看者。此入口仅用于本机验收，
不得部署为生产认证模式；运行数据、凭据、截图及下载包均不入 Git。

## 样例范围

- 110 × 70 m 园区，地坪和三栋厂房，3,099 个点。
- 模型单位米，右手 X右 / Y前 / Z上。
- 配电房、配电柜、室外巡检点三个对象点锚。
- 目标控制网旋转 18°，平移 E28 / N18 / U3 m。
- 三个控制点、三个独立检查点，水平及高程门限均为 10 cm。
- 合成 WGS84 ENU 原点，用于对象地理转换验证，不是现场测量依据。

脚本同时生成正常合成资料、K3 超限资料、模型绑定错误资料及
`03-LOCAL-ONLY-lifecycle.json`。最后一份仅在回环地址、模拟身份和隔离库内
验证真实资料状态分支；不得将其导入生产或视为实测核准成果。

## 发现并修正的问题

生产 CSS 优化将全屏编辑器的 `translate:none` 合并进 `transform`，
DS Dialog 的 Tailwind `-50%` 独立位移仍生效，工作面向左上偏移半屏。
修正为同时归零 Dialog 使用的两个 Tailwind 位移变量，保留原有 DS 组件。
重新生产构建后验证：宽屏和窄屏工作面左上角均为 `(0, 0)`，尺寸覆盖视口；
K3 编辑为 52.0 cm 后重置恢复 2.2 cm，取消正常返回展示页。
