# 数据与本体核对验证

日期：2026-10-26。P2合成发布只读工作面增量，不代表两个平台的完整功能或真实数据验收。

## 实现与结果

固定发布新增/data与/ontology投影，见[契约](../../contracts/schemas/release-inspection-v0.1.md)。data模块组织固定资料清单；ontology模块按固定规则重新校验对象；service装配投影；lifecycle在同一场景事务中检查撤回；工作台只读展示。

内部快照保存原始manifest与本体UTF-8文本及已检查引用角色。读取重算原始字节摘要和本体版本，再校验实例；没有回读可变源目录。原始资料大小与摘要仍按登记时结果展示，明确没有记录登记校验时点、没有执行当前源文件重检。使用条件与现场质量分别显示未评估和未验证。

临时PostgreSQL18全量48个测试、19个子用例通过，无跳过，见[日志](../../experiments/runs/p2-inspection-001/tests.log)和[JUnit](../../experiments/runs/p2-inspection-001/tests.xml)。覆盖：

- 7份资料引用角色、固定发布/真值/坐标/摘要一致。
- 删除源manifest、修改源本体后，固定发布投影保持原内容；响应修改不能污染下一次读取。
- 原始manifest或本体字节改变被拒绝；实例缺失类型或必填属性时重新校验失败，定位对象和字段。
- 旧快照返回inspection_unavailable，撤回返回410，缺失发布404；撤回后元数据历史追溯仍可访问。

本地无PostgreSQL配置时46个测试、19个子用例通过，两项并发测试按条件跳过；正式本轮结论采用上述独立PostgreSQL结果。

前端严格类型检查及生产构建通过。主JS约259.9KB/gzip81.3KB；按需三维块约810.2KB/gzip220.2KB。保留TanStack use client打包警告，见[构建日志](../../experiments/runs/p2-inspection-001/web-build.log)。

浏览器实际核对7份来源资料、3类本体规则及3个对象，截图见[资料](../../experiments/runs/p2-inspection-001/data.png)和[本体](../../experiments/runs/p2-inspection-001/ontology.png)。撤回后刷新返回410并移除旧核对内容；修改发布也清空已选内容。合成覆盖证据没有被当作对象级证据关联。

## 限制与下一步

新内部快照增加inspection.version=1，不改变源包profile和数据库表。旧快照保持查询与追溯，但无法提供新增核对内容；使用新release_id登记增强快照，不覆盖已有发布。当前版本重复登记仍由全量快照摘要保证幂等。

已下载内容保留读取时语义，不能远程回收。没有认证、在线本体编辑、行业推理、原始采集目录管理、文件上传或任务调度。本轮校验是小型字符串规则及合成资料完整性，不涵盖现场语义或空间质量。

下一步为受控导入与构建任务的最小设计：先明确输入资料登记、任务状态、失败诊断与不可变产物边界，再实现本地执行闭环。真实算法与真实现场数据继续按P1/P3独立准备和验收。
