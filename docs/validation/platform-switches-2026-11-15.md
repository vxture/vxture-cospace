## 全平台清单

| 位置 | 用途 | 核对与处理 |
| --- | --- | --- |
| 我的场景 | 卡片／列表 | 从手工配置的 SegmentedControl 改用 DS ViewModeSwitch；不再传按钮尺寸、图标或内边距 |
| 服务目录、在线服务、离线交付、态势反馈、智能设备 | 卡片／列表 | 五页均已直接使用 DS ViewModeSwitch，无产品层形态覆盖 |
| 空间全景 2D／3D | 场景状态筛选 | 使用 DS SegmentedControl；移除伪装成 Tab 的本地尺寸、描边、选中态样式；窄屏允许横向滚动 |
| 地图设置 | 主题 | 保留 DS SegmentedControl，删除强制外框高度，避免槽与内部选项尺寸不一致 |
| 地图设置 | 底图、二维／三维 | 保留带图形预览的专用单选卡片；支持方向键、Home／End、选中态及三维预加载 |
| 地图实验页 | 卡片／列表、场景状态、模式与底图 | 清除手工拼接的视图按钮和滑块；分别使用 DS ViewModeSwitch／SegmentedControl；尚未实现的能力保持禁用 |
| 公共页与业务页顶栏 | 主题、语言、产品／组织／场景选择 | 已使用 DS ShellThemeToggle、ShellLocaleSwitcher 和标准面板／菜单；不改为列表视图切换器 |
| 业务表单、地图要素、空间图层 | 独立布尔开关 | 使用 DS Switch／Checkbox，保留各自的业务确认和禁用逻辑 |
| 设备形态、样例选择、对象或场景选择 | 业务实体选择 | 保留展示形态、说明或预览的选择卡／列表，不压成紧凑视图切换器 |
| 详情、构建、数据、本体及关联页面 | 页面或内容 Tab | 使用现有 DS Tabs，保留导航语义 |
| 空间预览 | 视觉／计算表达、全屏与面板开合 | 标准 DS Button 单次操作，保留当前可用性判断与目的地标签 |

## 搜索工具条

“我的场景”的搜索框桌面标准宽度为 240px。删除中等屏宽下 flex:1
无限拉伸的规则，筛选区仍整体居右，工具条中间自然留白。700px 以下
搜索框独占一行并适应容器，状态、排序和刷新保持可访问。

## 验证与边界

本地生产构建与 98 项前端测试通过。浏览器使用合成场景及设备，模拟
授权与目录响应，不修改线上数据。浏览器截图与发布源查询原文留在忽略
目录 output/，不将认证信息、运行数据或本地证据提交至 Git。

浏览器结果：1536／1052／800px 搜索框均为 240px，390px 为容器宽度 358px；全部卡片／列表切换按钮为 32×32px，连续点击不取消选中，键盘移动焦点后可激活，切换保留筛选且不重复请求数据。二维地图在 1052／390px 验证方向键、Home／End、主题及底图选择。三维地图使用生产构建验证状态筛选与主题禁用边界。地图实验页独立构建通过。地图验证覆盖控件与状态，未进行地图厂商联调。
