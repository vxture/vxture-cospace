# NYU短场景与单帧彩色点云验证

日期：2026-10-28。用户授权从本地offices选择短场景。源文件只读，原始数据与派生图像/点云保存在本项目忽略目录var/nyu，不进入合成examples或正式发布。

## 实际成果

选取office_0001a从第一张深度图起约2秒：实际覆盖1,967,172微秒，60张深度图分别匹配最近RGB。实验配对容差20ms，实际最大绝对差14,657微秒；60组全部接受、无拒绝。容差是本次实验配置，不是已验证同步精度。原始文件名时间保留整数微秒，不声明UTC映射。

已封存120个原始图像文件共92,161,920字节，每个记录长度/SHA256；未复制加速度dump，不将本次片段称为完整原生传感器包。全部片段用于配对核对，仅中间一组执行单帧点云生成，未对全部帧做重建。

成果目录：`var/nyu/office-0001a-short-001`。含raw原图、report.json、frame.ply、rgb.png、depth.png、cloud-preview.png、depth-valid-mask.u8、point-associations.npz、camera_params.m和index.html核对页。

点云以4像素间隔抽样，19,200个采样像素中12,448个有效点、6,752个无效/超范围/未收敛点。点云SHA256：`333e32e0e16f0915c55f5ab7655d40cfa4873af18afd764b4522e639f4d954b4`。所有有效点在本帧投影到RGB图内，不能据此认定颜色配准质量已通过。

坐标为深度相机局部光学系：X右、Y下、Z前，单位米。输出明确不是场景全局坐标。全部点来自单帧，未获得相机轨迹或执行融合。

## 处理口径

`packages/data/nyu_rgbd.py`与`experiments/scripts/build_nyu_short_scene.py`提供有限Profile：640×480原生PNM、深度little-endian解释（对应官方imread+swapbytes）、`351.3/(1092.5-code)`转换、深度相机畸变反求、官方相机参数和R/T约定的颜色投影、RGB畸变正投影及最近像素取色。坐标与采样像素关联保存在NPZ，PLY包含color_valid位。

深度编码小于600、2047及以上、非正/非有限结果、超过10m和畸变反求不收敛的样本不生成表面。没有将远距离值钳制到10m形成假墙，没有补洞。全分辨率depth-valid-mask是原始距离范围有效性掩码；点云还可能因反求不收敛进一步拒绝，不能将二者混为最终覆盖。未知区域没有转换为空闲。

此实现采用原像素反求/投影，并非逐语句复刻官方undistort栅格重采样实现；尚未与MATLAB官方输出数值逐点对照。官方R矩阵与坐标处理约定用于颜色投影，不作为本产品已通过刚体frame校验的外参直接登记。未做跨相机遮挡一致性、运动补偿、动态物体检查或独立配准精度验证。
