# 智能体有效性门禁验证

日期：2026-10-27。范围：R2b首批测试公钥、独立SQLite和可注入时间，不含正式授权。

全量本地测试为**153 passed、6 skipped、22 subtests passed**；PostgreSQL专属用例本轮跳过，不增加平台数据库验证结论。

新增19项测试，覆盖合成条件放行、重复消息不续期、时间边界和不确定区间、boot变化、计数回退、无锚时间、序号回放与冲突、未授权epoch、终止撤回、grant/status/策略绑定、重签grant限制、缺失能力、存储缺失/损坏、写入失败锁存、旧会话撤回、独立进程竞争与提交前退出、上下文变化及内容证明缺失/篡改。

正常判定只返回simulated_allowed=true，authorized和robot_ready始终为false。时间测试全为注入，不是设备时钟准确度或挂起/重启实测。独立进程测试中，同序号不同状态仅一个提交；另一进程报冲突。提交前os._exit(74)后原已提交状态保留，没有物理断电试验。

对真实R1文件会话的实验封装已验证：合成空闲查询成功 → 达到离线截止拒绝 → 接收更高撤回后同一旧会话拒绝 → 旧状态重放拒绝。原R1接口未修改，不能依赖此试验作为生产门禁。
