# 智能体委托与门禁加固验证

日期：2026-10-27。范围：R2b第二批合成实验。依据[设计补充](../architecture/智能体密钥委托与故障门禁补充-v0.1.md)。

新增11个参数展开后的测试实例，全量本地测试164通过、6跳过、22个子用例通过，耗时92.01秒。跳过项仍未取得本次验收证据，不能视为PostgreSQL或真实设备全路径通过。

| 核验 | 结果 |
|---|---|
| 预配测试根签发单层委托 | 原字节Ed25519验签，子密钥约束实际进入门禁 |
| 场景、角色、有效期、撤回 | 不匹配拒绝；委托到期125收紧原离线截止130 |
| 伪根、错误部署/版本、重复kid | 拒绝加载 |
| 信任上下文变更 | 拒绝重开已有状态库，无自动迁移 |
| 持久化注入失败 | 已打开及重新打开对象均因遗留标记拒绝放行 |
| 标记创建失败 | 当前对象锁存拒绝；不宣称跨进程持久化 |
| 逻辑冲突 | 删除本次标记，原状态仍可用于合成判定 |
| 查询/撤回交错 | 两线程、两连接屏障：旧快照可完成，提交后新判定revoked |
| 独立进程状态竞争/强退 | 原测试更新：单胜者，提交前强退后标记使重新打开对象拒绝 |

证据目录：[p2-validity-hardening-001](../../experiments/runs/p2-validity-hardening-001)。包含[测试日志](../../experiments/runs/p2-validity-hardening-001/tests.log)、[JUnit](../../experiments/runs/p2-validity-hardening-001/tests.xml)、[环境与源码摘要](../../experiments/runs/p2-validity-hardening-001/environment.json)及[可复跑场景结果](../../experiments/runs/p2-validity-hardening-001/scenario.json)。仅输出测试公钥与委托签名，不保存随机私钥。

从仓库根目录复跑：

```powershell
.venv/Scripts/python.exe -m pytest -q --tb=short
.venv/Scripts/python.exe -m experiments.scripts.validity_hardening_evidence
```

Python 3.14.3、Node 24.14.0；签名仍使用Node原生Ed25519实验适配。未新增生产密码库或改动依赖锁。历史证据的源码摘要保留当时版本，本批独立记录当前源码。

所有结果仍为synthetic，authorized=false、robot_ready=false。未验证物理断电、硬件防回滚、可信UTC来源、根轮换、动态信任更新、pending解除、跨进程查询交错或机器人动作门禁；原R1默认会话未自动获得实验门禁。下一批先做只读故障核对与恢复条件设计，不按文件年龄自动清除标记。
