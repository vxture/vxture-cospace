# 成果受控状态变更（H3a）

日期：2026-11-02。归属：数据管理，联动构建中心、空间关联、态势服务。H2只读影响检查之后，本批实施资料与候选的外部使用状态；固定发布分发控制留待H3b。

## 已实现

- 资料停用、归档、恢复，候选归档、恢复；默认旧成果active/修订0，状态与完整历史单独保存在运行区SQLite，不修改资料、模型或发布内容。
- 提交显式包含预期修订、范围摘要、操作和原因；服务重新核对引用和状态，在同一事务内CAS提交当前记录及历史，记录本机未认证预览身份。
- 运行区可重入线程锁＋OS字节锁排序协作变更、批次封存、资料登记、构建准入、候选选择、三类关联派生及发布；任务完成更新在同一锁内。单服务调度边界保持不变。
- 直接构建与批次入口均执行资料状态检查；停用成员不能封存。候选归档阻止新选择、语义/业务/关系派生和发布；已有后续候选与固定发布不级联失效。
- 数据管理增加DS状态面板、确认框、原因必填、引用提示和完整历史；目录显示停用/归档标记。构建资料选择排除归档、禁用停用，归档候选不能核对选择。409或刷新失败清空旧控件，切换空间关闭旧确认框。

契约：[接口](../../contracts/schemas/preview-artifact-control-v0.1.md)、[Schema](../../contracts/schemas/preview-artifact-control-v0.1.schema.json)。操作：[指南](../guides/成果使用状态管理运行.md)。
