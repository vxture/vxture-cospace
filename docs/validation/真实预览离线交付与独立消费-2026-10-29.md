# 真实预览离线交付与独立消费

本批跑通固定发布→轻量交付包→独立进程加载→查询→版本核对，继续以流程为优先，不增加建模精度实验。

## 已实现

- 服务与交付页面提供“下载离线交付包”和“离线包信息”。下载不创建新发布、不修改原快照。
- ZIP profile 为 `cospace.preview-offline/0.1`，仅包含 `package.json`、`publication.json`、`model.json`、`agent.npz`。
- 复用原发布及模型清单，保留坐标、来源与限制。清单列出的其他产物用于来源追溯，不要求在离线包内存在，也不被离线读取器访问。
- 必须指定预期发布ID及整个ZIP的SHA256；加载核对包成员摘要、字节数、发布与模型绑定、智能体数据绑定。固定发布重复导出字节一致。
- 读取器不解压到磁盘；ZIP成员白名单、重复成员拒绝、解压大小限制；NPZ内部仅允许 `cells.npy`，检查数组头、整数类型、三列结构及单元数量。
- 复用在线查询计算规则；响应附带固定发布ID及模型清单摘要。

## 真实数据结果

发布：`preview-e4ba91f7869745c4`，候选：`build-b45b290c4c7f416d`。

包大小：**38,465字节（约37.6 KiB）**，包含17,029个10厘米表面候选单元。

包SHA256：`99e1577ff6e11803334f24af9a3260c5c7c68ed811785736548cfe3022d45dc4`。

从HTTP下载真实包，启动独立Python进程并禁止创建socket。表面候选点、未知区域点的离线响应与同一发布的在线响应逐字段相同。测试没有物理断网，但消费进程不允许建立网络连接。

浏览器实际点击“下载离线交付包”成功，下载摘要与HTTP、独立进程验证使用的包一致。浏览器仅出现既有favicon 404，无业务脚本错误。前端TypeScript检查与Vite构建通过。

14项相关测试通过：既有模型、构建、发布10项，新增离线4项，覆盖网络禁用、在线离线一致、错误版本、改动文件、摘要绑定、非法ZIP成员、重复成员及大小限制。

证据：[checks.json](../../experiments/evidence/2026-10-29/nyu-offline-001/checks.json)。

## 运行方式

工作台：`http://127.0.0.1:8767/workbench/layout.html?revision=offline-1#delivery`，进入预览界面后下载。

```powershell
.venv/Scripts/python.exe -m experiments.scripts.query_preview_offline var/nyu/office-0001a-offline-001/offline.zip --publication preview-e4ba91f7869745c4 --sha256 99e1577ff6e11803334f24af9a3260c5c7c68ed811785736548cfe3022d45dc4 --point -10.85 -1.25 4.35
```

重新验证下载与独立消费（要求本机8767服务已启动）：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.verify_preview_offline preview-e4ba91f7869745c4 --output var/nyu/office-0001a-offline-001
```

离线消费需要项目Python代码及NumPy；ZIP是自包含数据包，不是带解释器的机器人安装程序。源图片、建模结果点云、人视图及在线模型服务均非离线查询依赖。

## 边界与下一步

`quality=unverified`、`robot_ready=false`。`surface_candidate`只是采样表面证据，缺少证据返回`unknown`，不返回可通行或自由空间。摘要用于版本与内容一致性核对，不代表生产可信签名；预期摘要来自同一服务时，也不建立独立信任。

下一步验证“新候选→新发布→消费方主动切换→旧包仍可复查”的版本更新流程，先复用固定发布与现有数据，不进入增量重建或精度优化。
