# 完整生命周期集成验收 H3c

日期：2026-11-03。本轮完成H1批次、H2引用检查、H3a资料/候选控制及H3b分发控制的联合工程验收。保持“使用、构建、定义”三类六入口，优先验证流程，不扩展建模精度研究。

## 结论与范围

NYU RGB-D＋已有轨迹、ROS1激光单帧两类样本，在同一独立运行副本中完成批次停用、资料停用、历史候选归档、固定发布暂停，以及逐层恢复和真实重建。联合状态跨两次服务重启保持一致；固定发布及当前选择不被状态操作或新构建替换。

这一结论属于本机工程流程验收。空间语义、现场精度、真实用户权限和机器人安全放行仍未验收。语义本体和关联能力在本轮沿用已固定的对象、规则、台账与关系快照，未重做本体编辑或现场关联。

## 验证证据

新工具为 `experiments/scripts/verify_preview_lifecycle.py`。基于空生命周期账本、无活动任务的H1副本，显式分配临时环回端口，不经过系统代理；全部变更在新output执行。工具检查输出路径、保留失败记录、成功结果和逐请求HTTP轨迹，并在结束时停止临时服务。

最终运行：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_preview_lifecycle --source var/validation/batches-h1-001 --output var/validation/lifecycle-h3c-003
```

- 86项联合检查、241次HTTP请求通过，包含预期拒绝请求；三个独立服务进程完成两次重启。
- 两次真实构建成功；四个独立消费进程禁用网络，分别完成安装和组合受限状态下的重启恢复。
- 每类样本保存六份阶段报告及一份缺失证据报告；控制报告、目录报告沿用既有JSON Schema和日期格式校验。
- 224项相关回归通过，包含两项新增组合行为测试，以及批次、控制、分发、来源、目录、选择、关联、范围、离线消费等既有测试。
- 扩展回归中的旧checklist测试曾预期非法发布ID为409，已按H3b公共门禁契约修正为404；损坏有效发布仍预期409。未因此放松服务端门禁。
- 前端TypeScript检查和生产构建通过。依赖的use-client及chunk大小提示仍存在，不声称零警告。
- Playwright在原演示区只读完成13项检查：进度日期与验收结论、下一阶段、六入口/Launcher、桌面/移动无横向溢出、消费阶段未核验、原发布/选择/下载及未写控制记录。未捕获页面脚本异常为0，控制台仍有既有favicon.ico 404。

最终证据位于 `experiments/evidence/2026-11-03/preview-lifecycle-h3c-001`。包含验收结果、HTTP轨迹、阶段报告、消费结果、回归/构建/浏览器日志、截图、脚本和最终只读核对。受管原文件清单和源副本全文件清单一并保存；大文件及消费库留在var，不重复入证据目录。

## 数据及运行区保护

原 `var/nyu` 的195个受管文件摘要未变，原生命周期数据库仍不存在。H1源runtime的162个文件（含批次SQLite）全部不变；目标副本除预期可变的批次库外，161个已有不可变文件逐项摘要一致。新构建和控制记录只新增在副本内。
