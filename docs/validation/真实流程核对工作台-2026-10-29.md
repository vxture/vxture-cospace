# 真实流程核对工作台

本批将真实数据闭环整理为按固定发布核对的工作面，不增加算法或精度实验。

## 页面入口

在工作台“服务与交付”的每条发布记录点击“流程核对”，展开七个阶段及剩余缺口。只展开人工选择的发布，不自动选最新记录。

`http://127.0.0.1:8767/workbench/layout.html?revision=checklist-1#delivery`

七阶段为资料导入、空间模型、双视图派生、固定发布、在线与离线查询、轻量离线交付、版本切换与复查。

| 标识 | 含义 |
| --- | --- |
| 本次通过 | 本次请求核对实际发布文件、包绑定或查询实现一致性 |
| 已有记录 | 来自模型清单或保存的版本切换证据，本次不重跑原实验 |
| 待补齐 | 证据缺失或没有绑定所选发布 |
| 核对失败 | 已有记录或当前对照检查失败 |

不可读或被改动的发布会直接拒绝生成核对单，页面显示错误，不保留原成功结果。刷新清空原结果后重读，不触发构建、发布或消费方切换。

## 实现与接口

新增只读 `GET /publications/{id}/api/checklist`，profile 为 `cospace.preview-checklist/0.1`。响应包含核对时间、发布ID、模型清单摘要、离线包摘要、各阶段状态和证据类型。

当前查询检查在服务端同进程调用在线查询实现及离线读取器，取一个实际表面单元和一个范围外未知单元作逐字段对照；不是网络连通性检查，也不重新执行断网消费。既有HTTP及网络禁用实验见此前专项记录。

模型清单记录资料摘要和57帧输入使用情况，本次不重新读取原始图像。双视图、发布和离线包检查实际文件及摘要绑定。

版本切换证据由服务端固定配置读取，必须匹配发布ID、模型清单摘要及离线包摘要；不接受浏览器传入任意本机路径。保存证据是本机实验记录，不构成可信签名、在线设备状态或授权。

## 验证结果

新发布 `preview-08268c149b764615` 的实际HTTP核对结果：5个阶段本次通过，2个阶段已有记录。原发布 `preview-e4ba91f7869745c4` 没有以其为新发布目标的切换证据，显示待补齐，未套用新发布的通过结果。

20项相关测试通过，新增3项覆盖缺失证据、跨版本记录隔离、错误绑定、失败记录、被改动发布拒绝及只读行为；TypeScript检查与Vite构建通过。浏览器验证展开新发布七阶段及剩余缺口、刷新核对，入口和固定版本绑定正确。

实测证据：[checks.json](../../experiments/evidence/2026-10-29/nyu-checklist-001/checks.json)。

## 剩余缺口及下一步

目前完成的是样本数据的本机预览流程：精度与完整度未独立验收、语义对象与可通行空间尚未实现、真实设备采集及机器人消费未对接，消费版本仅在内存中，生产认证与可信分发未落地。核对单不输出生产放行结论。

下一步优先补资料接入的可配置流程，将当前固定NYU样本的构建入口改为可登记、选择和核对输入资料的工程入口，继续使用现有样本验证，不依赖真实设备就绪。
