# 智能体测试证明验证

日期：2026-10-27。范围：R2a首批Schema、受限JWS验签和合成绑定；不包含正式授权或密钥管理。

## 结果与实现

新增28项测试通过，全量本地路径为**134 passed、6 skipped、22 subtests passed**。PostgreSQL专属用例仍跳过，本轮未改平台数据库、前端、R1安装或查询行为。

新增三类证明Schema及测试信任配置Schema。Python探针处理受限JSON、契约和上下文，Node 24.14.0的原生crypto执行Ed25519（OpenSSL 3.5.5），未自行实现密码运算。

最初尝试以uv引入cryptography开发依赖，在许可后仍遇PyPI TLS handshake eof，使用系统证书重试亦失败。未取得该依赖，pyproject和锁文件没有加入cryptography。转用本机既有Node完成实验；这不是生产Python/C++密码库选型确认，也不要求机器人安装Node。

| 检查 | 观察 |
|---|---|
| RFC 8032 §7.1 TEST 1空消息、TEST 2单字节消息 | 公钥和签名逐字节符合公开向量；修改消息后验签失败 |
| OpenSSL CLI复核TEST 2 | Signature Verified Successfully；工具版本3.2.4 |
| 内容、能力、状态三类证明 | 验签和绑定通过，但authorized=false、robot_ready=false |
| 同一对象改变JSON空白而保留原签名 | 拒绝；使用原编码字节验签 |
| 假签名、非信任私钥复用kid | 拒绝 |
| 错签发角色、issuer、部署、受众或包/范围/视图绑定 | 拒绝 |
| none、HS256、未知kid、消息取钥URL、crit及未知版本 | 拒绝，无网络取钥 |
| 真值数据类别伪装、未知payload字段、重复JSON键及深层结构 | 拒绝 |
| 非法时间区间、布尔计数器、重复能力及非法编码 | 拒绝 |

标准向量验证提供外部已知答案；OpenSSL CLI与Node是不同调用路径及版本，但均属OpenSSL体系，不宣称已完成独立密码实现或完整第三方JOSE互操作。C++和ARM64尚未验证。
