# 真实模型预览发布与固定版本消费

本轮接通“所选候选→人工预览发布→固定发布版本→服务查询”。沿用精度未验收声明，以跑通流程为主，不追加算法试验。

## 业务操作

在构建中心确认候选后，进入“服务与交付”，点击“发布所选候选”，确认框固定候选ID和选择revision。服务核对该选择仍有效后，复制模型候选、人视图、智能体视图和预览页面，保存为独立发布快照。历史列表显示发布ID、来源候选、时间、固定版本入口、发布清单、离线智能体载荷下载及查询地址。

候选选择与发布独立：切换“我的空间”展示版本不会改变已有发布。每个固定发布URL的页面、下载和查询读取自己的快照，不通过当前候选指针读取。查询响应附带publication_id、model_id、源模型摘要和发布模型清单摘要，可核对消费版本。无表面证据仍返回unknown，不推断可通行。

## 格式和接口

本机实验Profile为 `cospace.local-preview-publication/0.1`；未接既有正式发布Profile。publication.json记录发布ID、候选ID、选择revision、时间、内容摘要、固定URL、质量及production_ready=false。

- GET /api/publications：预览发布历史。
- POST /api/publications：candidate_id、expected_revision，创建成功201；选择已变或内容变化409。
- GET /publications/{id}/：固定版本双视图预览。
- GET /publications/{id}/api/preview：固定模型和发布记录。
- POST /publications/{id}/api/query：请求point_m三维米制坐标，返回固定版本状态。
- GET /publications/{id}/publication.json、agent.npz等登记文件：固定版本清单和下载。

发布目录位于 `var/nyu/preview-builds/publications/preview-*/`。先复制到.pending目录，重新验证模型和源清单摘要，再同目录重命名使完整快照可见；失败遗留的.pending目录不列入发布历史。无覆盖已有发布的接口。读取时检查登记文件字节数/摘要，损坏返回409；列表只是元数据目录，不代表每条已重新完成内容核查。

“不可变”指无更新接口、独立快照和内容检查，不是文件系统防篡改或签名。当前仍是单进程本机演示、未接生产认证、撤回、正式有效期或授权。未将预览发布称为生产交付，质量仍unverified。

## 实际验证

实际由Playwright在“服务与交付”点击发布并确认，生成 `preview-e4ba91f7869745c4`，来源 `build-b45b290c4c7f416d`。页面展示固定版本、清单、智能体下载和POST消费地址；点击固定版本入口新开标签页，原工作台保留。

真实HTTP核对该发布的表面示例和未知示例查询，响应publication_id一致、model_id为源候选、未知保持unknown，固定页面200。证据：`experiments/evidence/2026-10-28/nyu-publication-001/checks.json`。

10项相关测试通过，新增覆盖发布后切换候选/修改源候选不影响固定版本、旧选择发布拒绝、外部来源拒绝、发布载荷被改拒绝、非登记下载拒绝、非法查询及重建读取器后发布可读。TypeScript与Vite构建通过。既有正式发布及机器人链路不受此实验Profile影响。

入口：<http://127.0.0.1:8767/workbench/layout.html?revision=publication-2#delivery>。
