# 对象标注与双视图 B2 验证

日期：2026-10-30。目标：以真实模型点作为锚点，把固定本体规则、人工对象、独立候选、双视图、固定发布及在线/离线消费连起来。未重跑建模或精度实验。

## 实现与格式

- 构建中心使用DS组件提供对象工作面，显式选择空间、基础候选及本体版本；模型点索引由服务换算坐标并附几何摘要。
- `objects.json`保存稳定对象ID、类型、属性、米制锚点、点索引证据、标注版本及固定本体引用；`ontology.json`保存规则原文。对象JSON Schema在加载时执行。
- 标注生成独立候选，几何不重新估计。human_view与agent_view引用同一对象文件；修订提交完整对象集，维持对象ID。
- 候选选择与发布保持人工显式操作。旧版本不补造对象或本体，旧发布不改写。
- 在线按发布ID查询对象。离线包0.2增加对象及本体两成员，保留旧0.1读取兼容。离线仅校验固定绑定，无完整点云可供重新校核。

契约见[对象标注候选](../../contracts/schemas/preview-objects-v0.1.md)，操作见[运行手册](../guides/真实样本流程运行手册.md)。

## 验证结果

1. 101项相关测试及12个子测试全部通过；包括归属错误、摘要错误、点索引越界、未知类型、必填缺失、重复ID、非法字段、锚点/视图绑定篡改拒绝，以及离线兼容。
2. 前端构建成功。浏览器实际创建标注候选；修订保留同一对象ID与锚点，旧对象名称与旧发布文件不变。
3. 固定发布的人视图与智能体视图展示同一对象标记；独立子进程禁用socket后加载离线包，对象查询与在线逐字段一致。
4. A→B→A切换仅保留一套构建/对象工作面，B不残留A的对象或候选，切回A恢复其固定快照；919px宽度无横向溢出，最终页面控制台无错误。
5. 实际重启服务后，空间选择、对象及本体仍可读取；旧发布摘要、空间B和历史未关联记录保持不变。最新发布的追溯节点均matched，语义阶段recorded且仍声明待核实。

证据位于[本批目录](../../experiments/evidence/2026-10-30/objects-b2-001)：before.json、checks.json、revision-checks.json、browser-checks.json及final-checks.json。截图见[标注面板](../../output/playwright/b2-annotation-final.png)、[人视图](../../output/playwright/b2-human-final.png)及[智能体视图](../../output/playwright/b2-agent-final.png)。
