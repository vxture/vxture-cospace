# 点云尺寸及双视图切换回归

日期：2026-11-23。范围：修正 v0.14.0 引入并沿用至 v0.16.0 的两项显示回退，不启用 L03 进阶策略，不改变原始成果、派生格式、坐标或点预算。

## 原因及修正

- 旧查看器使用 2.2 CSS 像素固定点。Potree 接入采用 adaptive 点尺寸，原生最大尺寸为 50 个绘制像素；放大后点会膨胀为圆斑。恢复 fixed 2.2 CSS 像素，并按实际渲染 DPR 换算，不用扩大点径遮盖稀疏 LOD。计算单元恢复旧查看器的 3 CSS 像素固定点。
- 主空间页原先在点击计算视图后才读取、校验 `views.js`，同时立刻隐藏视觉几何，造成等待时黑屏。现在首个真实几何帧出现后准备计算表达；在通过摘要验证且缓冲送入同一画布前保留视觉几何，准备好后切换。状态及页脚分别反映等待状态和实际绘制视图。
- 往返切换不取消或重复读取同一个计算请求；准备失败保留视觉画面，下次显式切换重试。明确零计算单元时显示空状态，不进行无用读取；几何开关仍有效。

原始点数与当前绘制点数必须区分：转换器输出总点数须等于原始模型总点数，前端契约再次核对；当前视野按原生 LOD、50 万点预算及节点阈值选择节点，绘制点数可能少于整模。节点提交点数也不等于屏幕上可分辨的像素数。此修正不调整采样、节点阈值或预算，不能声称恢复了整模同时绘制，也不能据此宣布所有生产模型画质已验收。

## 验证

Windows / Intel i5-10400 / NVIDIA GT 1030，Chrome 157，1575×883 / DPR 1；使用既有百万点合成园区，非测绘成果。

同一源、相机及作业点下，修正前后提交 157,061 点，可见节点列表、相机位置相同，原始及派生总点数均为 1,000,000。前版 adaptive 近处出现大圆斑，fixed 版维持细点。仅改变尺寸，不将这次对照作为性能收益或总体视觉质量排名。

真实生产 React 构建经本地 `/space` 入口运行，浏览器只替换明确标注的合成业务响应。`experiments/scripts/model_display_regression.js` 验证：

1. 首帧不依赖计算响应；主动扣住计算响应并切换，持续保留真实视觉几何，提示准备中；页脚不提前声称已显示计算表达。
2. 快速切回再切入仍只有一个请求；响应校验后计算单元数与声明一致，已经就绪的往返切换不再下载。
3. 注入计算读取 502 后视觉仍可用，显式切换重新读取成功。
4. 显式零计算单元有空状态且不请求计算文件；等待期间几何关闭及恢复生效。

本地 Python 显示、权限、原始点及实验页回归 48 项、前端来源/精度/策略回归 11 项通过；TypeScript 与 Vite 生产构建通过。上述真实页面浏览器 4 组及原有故障/恢复浏览器 7 组均通过。截图及请求日志包含明确注入的 502 和权限故障，不把预期注入当成未处理的线上故障。

百万点全图条件提交 499,739 点，受同一 500,000 点预算约束。这是按视野读取的功能证据，不是完整模型的全量显示或性能 SLA。完整规模、薄结构及不同设备的画质验收仍属于后续工作。

现有浏览器安全脚本同时保留隐藏/恢复、几何切换、策略故障回退、局部失败与权限/版本失效的覆盖。新的尺寸基线改变了既有 L03 实验的绘制样式；正式启用策略前须在新基线上重做同质量对照，既有筛选结果不自动转为启用证据。

生产浏览器控制在本轮不可用，不能把本地合成验证写成用户截图所示生产场景的实际验收。截图、网络及运行输出保留于本地忽略目录。代码继续经 PR、五项必需检查、镜像及 production reviewer 发布。
