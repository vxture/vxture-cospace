## 服务与使用

服务绑定127.0.0.1:8767，本地预览入口：<http://127.0.0.1:8767/>。

- `GET /api/preview`：固定模型及视图清单、来源和 `preview_served` 状态。
- `POST /api/query`，请求 `{"point_m":[x,y,z]}`：返回模型ID、同一模型摘要、坐标、单元索引和候选状态。
- 命中有点单元返回 `surface_candidate`；无表面证据返回 `unknown`，不根据稀疏点推断空闲。
- 可下载PLY和轻量agent.npz。离线只读取模型清单/智能体载荷即可查询，不需要完整原始图片。

页面右侧展示已完成阶段与实际模型规模，提供表面示例点和查询。它是验证真实流程的独立预览页，未改动已确认布局的工作台首页。

从根目录复现，输出必须使用新目录：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.build_nyu_flow_preview --snapshot var/nyu/office-0001a-short-001 --tracking var/nyu/office-0001a-interior-0-002/comparison.json --output var/nyu/office-0001a-flow-NEW
.venv/Scripts/python.exe -m experiments.scripts.serve_nyu_flow_preview var/nyu/office-0001a-flow-NEW --port 8767
```
