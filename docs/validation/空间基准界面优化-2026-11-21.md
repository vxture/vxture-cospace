# 空间基准界面优化验证

基线：PR #178 的 B07a。此批调整展示布局与本地编辑交互，保持原参数核对、审核及地理能力边界；没有 HTTP、持久化或发布变更。

## 实现

- 展示页压缩页头/摘要，保留 1536px 外框、1440px 内容及左右留白；六个控制点、双视图和误差图在 1575×883 同屏可见。
- 编辑使用 DS 模态焦点边界下的全屏工程平面，独立于展示页；左侧控制点、左下模型对照和右侧属性面板均可收起。模型小窗可放大；主图可拖动、缩放、适配，取景避让面板，坐标变化不自动重置视角。
- 目标坐标按控制点身份编辑，本地数值错误或重复坐标阻止应用；“应用到预览”返回展示并重算误差。继续编辑保留草稿，放弃仅丢弃未应用变更。取消、Escape 及刷新保护未应用修改。
- 查看依据仍使用官方 512px 抽屉。全屏工作面使用 DS drawer 层级，抽屉在其上方显示，确认框使用 DS modal 层级，避免依据抽屉被上层遮罩拦截。
- 操作按钮 32px，正文按钮文字 14px，工具图标 24px；表头居中、点位名称左对齐、数值居中。窄屏使用互斥面板，表格仅内部滚动。
