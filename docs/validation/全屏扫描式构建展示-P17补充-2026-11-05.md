# P17 补充：全屏扫描式构建展示

日期：2026-11-05。用户反馈原阶段预览嵌入流程页，期望“类似机器人边扫描、边构建，纯底图展示”。本次补充已实现并完成页面验收，原 P17 业务闭环验收保持独立记录。

## 页面

构建中心 → 构建流程 → 构建过程可视化 → **打开构建画布**。新标签页打开，保留原流程上下文；画布铺满整个视口，隐藏通用 header、目录、卡片及边框。左上仅场景及真实任务阶段，底部悬浮播放／暂停、重播、展示进度、速度；返回链接固定原场景、资料和任务。

采用现有 DS 的暗色、品牌色、按钮及选择控件；扫描扇面扫过，真实点云显示抽样逐步显现，前沿高亮。拖动旋转、滚轮缩放、右键平移及适配全图。初始相机使用显示点的坐标中位数及90%距离半径聚焦主体，原坐标与全部显示点保留；适配全图使用完整数值边界。没有删掉远点或用展示抽样参与模型构建。

## 数据含义

当前 OS1 PLY 是已有静态点云，无采集时间顺序或机器人轨迹。画面明确标记“扫描效果演示”和“已有点云按方位渐显 · 非采集时间或机器人轨迹”。按显示中心的方位角排序点，保留每点与颜色的对应，扇面方向跟随当前显现点；扫描中心只是展示参考，不是设备位置。24秒、0.5×／1×／2×均为动画时长与速度，百分比是展示进度，不是后台任务完成率。

读取现有 build-stages、builds 及受 build.run 保护的 build-preview。真实任务状态与动画独立；构建运行时继续原状态轮询，冻结几何仅加载一次，不因轮询反复播放。未冻结先等待，失败／中断解释状态；绑定错误不显示其他任务。后台算法、采集设备、真实SLAM增量、机器人姿态及轨迹没有在本次补充实现，不能将其标为真实边采边建。

偏好减少动态的浏览器不自动播放，仍可手动播放；关闭／切页清理动画与渲染器。无GPU有可见提示并可返回流程；错误请求清空画面并停止动画。
