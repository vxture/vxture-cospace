# B06c 在线离线同源消费验证

日期：2026-11-20。基于已合并B06b main aa2f449（PR #175）。本批接通现有发布选择、固定语义查询和完整离线包，不独立部署；版本验收上线仍由B06d收口。

## 实现与边界

现有新建发布入口增加512px右侧准备抽屉，默认不纳入语义。用户选择正整数实例修订并预检后，原发布确认及POST携带固定修订、模型来源和快照摘要。改动修订即清除预检，失败无法继续；按钮行32px，抽屉底部按钮14px，工具行12px。未增加导航。

固定在线API为GET `/publications/{id}/api/semantics`，可加object_id及UTC时刻at。统一读取器核对成果/发布/来源、原对象与关系索引、定义闭包、覆盖数及局部报告。完整离线包采用profile 0.5并携带清单及四项语义文件，OfflinePreview.semantics使用同一校验和查询实现。旧包及未采用新成果的发布保持not_included；已声明成果不得缺文件后降级。分区包仍明确不支持新成果。

本地消费会话及CLI已接通同源语义查询，restore使用--semantics或--semantics OBJECT_ID，可选--at UTC；页面在纳入语义的包说明中给出命令。消费库激活修订和成果内实例修订分别返回。未指定对象时拒绝传查询时刻，避免在线离线处理不一致。

对象声明查询自包含，模型与附件仅为外部证据引用，不宣称离线几何重新验证、地理定位或机器人导航。局部校验不代表专业审核及现场核实。公共本体内核未新增对CoSpace地图、认证、消费数据库的依赖。

## 验证结果

- 217项后端回归通过，223.86秒。覆盖在线/离线摘要及对象结果完全一致、删除最新消费数据库后固定查询稳定、离线禁止网络、稳定重复导出、映射关系历史分类、报告重算、缺文件和重算外层摘要的伪造覆盖数拒绝、profile降级及未知成员拒绝、旧发布兼容、预览/导出权限区分、跨场景先授权、暂停/恢复/退役。
- 补齐本地消费入口后，27项成果/离线/内存与持久消费回归通过，24.10秒。真实包安装、激活后删除原ZIP，CLI重新恢复并查询摘要/对象，结果与在线一致；查询期间禁止网络，非法时刻参数拒绝。
- 28项前端既有确认、场景上下文及服务入口回归通过；TypeScript及Vite正式构建通过。仓库guardrails、strict ruleset通过。精确暂存树及内嵌归档在提交前执行密钥扫描，远程必需检查以PR记录为准。
- Playwright使用本地Vite和合成固定成果做浏览器验证，检查908及1575px布局、默认不采用、预检前禁用、改修订清除结果、无效修订阻断、固定定义/属性/依据及UTC结束边界。发现查询按钮缺少submit类型，修正后复验通过。
- 浏览器进一步挂载实际PreviewPublications及原OperationConfirmations，使用模拟HTTP验证准备、确认、POST和成功回到版本概览；这不是生产或真实身份端到端验收。后端真实HTTP、固定文件及离线包由上述pytest覆盖。

本地忽略证据：output/ontology-preview/stage6c-regression.log、stage6c-frontend.log、stage6c-build-final.log及output/playwright/stage6c-*。浏览器临时装配及身份状态均不入Git。
