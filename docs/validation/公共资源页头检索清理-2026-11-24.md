# 公共资源页头检索清理

范围：数据管理、语义本体。页头不再挂载 HeaderContext，移除这两个板块的组织 / 工作区及场景检索区域，不使用 CSS 隐藏。共享组件仍由场景作业等板块使用。

- 用公共资源的模块作用域统一决定是否挂载页头上下文。
- 清理本体页的旧页头例外及不可达的页头场景跳转分支；这两个板块不再从记忆场景自动补入 URL，也不接受全局页头场景切换。
- 内容区业务项目、关联场景筛选保留。旧资料工作面的场景选择移到内容操作行，使用 DS 尺寸和文字 token，切换遵循未保存改动保护。

验证：相关前端导航、本体和场景偏好测试 24 项通过，TypeScript 检查和生产构建通过。浏览器使用本地合成 API 响应核验两个板块无页头检索、记忆场景不注入 URL、内容区项目选择及旧资料工作面的场景切换，并核对构建中心仍有页头场景选择。覆盖 1575 / 817 像素窗口。此验证不代表生产端到端验收。

本地截图和浏览器状态仅保存在忽略的 output/playwright/resource-header/。本批只处理页头清理，不包含共享引用实现，也未发布生产。
