# 空间构建准备 I6 验证

日期：2026-11-03。接续I5，将来源、登记、预检与保存任务汇总到工程师看得懂的准备进度，不修改六模块边界。

## 完成范围

“查看流程”增加“构建准备”，列出空间来源修订、有效来源数、各份登记资料、上次预检、资料使用状态及绑定一致的保存任务数量。点击“跟进此资料”明确本次输入，不自动使用最新登记；预检详情提供返回此资料流程入口，构建链接携带同一input ID。

授权预检独立追加保存，带已验签actor、UTC时间、登记指纹和序列；刷新、实际服务重启均可恢复。登记变化不借用旧通过，后续失败取代旧通过。页面明确标记历史结果，构建提交仍重新校验。只读用户不读取准备记录或预检历史，无权工程动作不展示链接。

原当前候选、人工核对和匹配发布流程保持独立，准备新资料不替换它们。保存预检不是新增的构建或发布门禁，工程模式原预检仍为即时只读。

HTTP在独立副本实际登记激光资料、执行并保存预检，明确input读取流程，检查“不重新校验文件/不轮询”的声明；查看者无准备信息。真实重启后恢复actor、结果与登记绑定；临时修改该副本登记记录验证不能借用旧通过，再恢复原字节。随后完整执行停用来源、既有资料真实激光构建、候选来源继承及原发布/撤权/重启流程。

浏览器工程师实际选择I5登记的RGB-D输入、前往预检、保存、刷新读到“上次预检通过”、返回同一资料流程并进入构建中心；资料ID始终一致。桌面及390px视口无横向溢出。查看者能看已有成果流程，无构建准备、数据/构建动作链接，预检历史API403。控制台包含站点图标失败及主动触发的拒绝请求；停留构建页超过中央确认期限时自动轮询出现503，下一次真实用户操作触发会话确认后恢复200。这是既有认证门禁行为，本轮未改变其策略，不以零控制台错误作为验收结论。

## 边界与后续

这是本地模拟平台，真实平台客户端仍待登记联调。历史文件检查不保证当前文件未变化；任务数量来自已保存记录，不轮询进程。请求跨库读取不是事务快照；预检序列表示追加提交顺序。当前未实现检查记录管理、保留期限或多节点协调。质量、现场语义和机器人通行性仍未验收。
