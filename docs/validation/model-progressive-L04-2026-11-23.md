# L04 双表达渐进加载验证

2026-11-23。范围是空间预览候选和固定发布；配准、原始点查询和离线交付沿用各自的原始成果契约。L03 的可选策略保持默认关闭。

计算表达从固定 `agent.npz` 单元生成单独的 Potree 八叉树；两个显示派生共用模型版本、局部坐标系、相机及有界缓存。无需读取整份 `views.js`、`human.ply` 或 `agent.npz` 即可浏览。独立的原始单元示例点继续可用于坐标查询；稀疏显示不代表可通行，也不参与精确查询。

单画布采用原生视野和层级判断。另一视图在未切换时跟随相机继续准备，既不显示进度也不显示普通后台读取失败。切换复用已解码节点和已准备的 GPU 数据；慢速时保留原画面，待目标有可提交的节点再替换。已就绪的前台继续细化，权限或版本失效则清理两种表达。

## 本地验证

- 两套原生派生各自以候选/固定发布清单和源摘要绑定，分段读取校验完整性且不解码原始 NPZ；计算派生损坏不影响可视概览。后端相关回归 49 项、前端契约测试 12 项通过。
- 原生转换探针：100,000 个视觉源点和 98,652 个计算单元，核对全部原生二进制点的位置、计数和共同变换，两类最大坐标往返误差均小于 0.03 mm。这是显示编码验证，不能作为源数据或现场精度结论。
- 本地真实 React 构建，1,000,000 个合成视觉点、877,601 个计算单元。拦住计算根块时，可视先画出；快速往返没有重启请求，等待期间持续渲染。放开后保持可视表达并放大，计算派生继续读取并准备超过 17 万点，计算 octree 读取约 3.3 MB / 15.8 MB。切换保持相机并复用已准备内容；切到计算表达后跳到另一处，可视表达也在后台继续读取。
- Chrome 模拟 5 Mbps / RTT 100 ms：未切换时，计算首块已后台准备。首次切换以约 0.15 MB 的计算 octree 数据显示概览，后续继续细化。一次从操作到收到首次计算帧报告约 0.17 秒；数值包含报告间隔，仅描述本地样本、不作为外部网络或设备的 SLA。
- 模拟计算分段 502 时，可视表达继续使用且后台不出现提示；切换后可重新读取。明确零计算单元时不发范围请求。后台分段返回 403 时清除画面。

合成场景用于隔离功能和切换行为，不能替代生产实景体验。上线后须验证历史候选和发布计算派生已补建，并验证公网文件与服务状态；具备授权浏览器时再复验用户场景切换。
