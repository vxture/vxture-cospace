# NYU 成熟 RGB-D 里程计对照验证

日期：2026-10-28。在同一份 office_0001a 60 帧快照上，实际运行 Open3D 0.19.0 的混合光度/深度里程计，核验成熟实现能否解决上一轮断点。结果：环境和调用已接通，连续轨迹仍未通过，暂不进入可信表面融合。

## 固定输入与结果

| 实现 | 共同前向几何判据通过 | 额外双向判据通过 | 首断点前连续帧数 |
|---|---:|---:|---:|
| NumPy 多尺度 point-to-plane | 57/59 | 42/59 | 6 |
| Open3D 混合 RGB-D | 58/59 | 26/59 | 1 |

输入来源报告摘要相同，最终采用原始 stride=4 点云、同一几何指标与阈值。两种优化器内部目标、预处理和成功语义不同：Open3D 的 success 不能视为旧版收敛判据的等价替代。这是本输入配置下的对照，不是算法普遍优劣或独立精度排名。

Open3D 首条 frame0→frame1 就被拒绝：前向几何 RMSE 26.49mm，反向 27.55mm，均通过共同几何检查；双向组合平移 26.17mm，大于预先固定的 20mm，旋转 0.00940rad 小于 0.02rad。59 条边中 31 条出现双向不一致、2 条反向拒绝、1 条前向高残差，原因可重叠。只保留首帧锚点，没有伪造完整轨迹。

最终运行目录 `var/nyu/office-0001a-open3d-002`，本机本轮墙钟 40.56 秒；不是性能基准。首轮 `...open3d-001` 保留，修正累积点云必须包含每个已接受帧后，用新目录重跑，统计一致。因本例首边拒绝，最终 PLY 实际仅含首帧，不应称为融合地图。

## 输入格式及预处理

`packages/construction/rgbd_rectify.py` 与 `experiments/scripts/prepare_nyu_open3d.py` 生成封存的针孔 RGB-D NPZ，60 帧位于 `var/nyu/office-0001a-rectified-001`。

| 项目 | 本轮定义 |
|---|---|
| 深度 | 480×640 float32，米，0 表示无效；最大 10m，无填洞 |
| 颜色 | 480×640×3 uint8 RGB，按深度几何投影取色 |
| 相机 | depth_optical，深度反畸变后针孔网格，主点从 MATLAB 1 基转为 0 基 |
| 光栅化 | 最近像素、最近 Z；只保留具有有效投影颜色的点 |
| 元数据 | input.json 包含原始配对、时间戳、每帧字节数/摘要、内参、源码摘要和限制 |

每帧有效像素 132,628—272,470，其余保持无效。NPZ 是研究阶段中间格式，不是产品权威空间模型或机器人分发格式。颜色投影尚无独立标定验收、遮挡一致性和运动补偿；原始彩深非硬同步。最近像素光栅化也可能影响优化。当前不能从失败结果直接归因于某一个环节。

## 实现与环境

使用 `compute_rgbd_odometry` 和 `RGBDOdometryJacobianFromHybridTerm`，迭代 [20,10,5]，优化器深度差 0.03m，深度范围 (0,10)m，depth_scale=1；正反向各自从单位变换开始，不使用旧方法位姿作为初值。最终几何门槛沿用上一轮，双向组合平移≤0.02m、旋转≤0.02rad，没有因失败放宽。

库返回 source→target；正向调用 current→previous，位姿累计为 `T_anchor_previous @ T_previous_current`。报告反向子对象暂复用矩阵字段名，实际是 previous→current，应按调用方向解释。

Open3D 在独立 Python 3.12.14 环境运行，根 Python 3.14 和根依赖锁未变。官方源普通/提权访问都因 TLS EOF 失败；清华 PyPI 镜像成功。精确发行包摘要和传递依赖由 `experiments/stack/rgbd-open3d/uv.lock` 保存。Open3D 安装包的 METADATA、WHEEL 与 MIT LICENSE 原文随证据归档；未声称完成所有传递依赖或数据集的商用许可审核。

复现命令见 [隔离环境说明](../../experiments/stack/rgbd-open3d/README.md)。

## 验证与证据

- 根环境相关回归：98 passed、4 skipped；4 项跳过均为显式依赖 Open3D 的运行时测试。
- 隔离环境实际执行 4 项运行时测试全部通过：同图零运动、已知平移及反向组合、无效深度不填充、反射矩阵拒绝。
- 已知平移测试最初使用重复条纹和循环边界，恢复偏差超过原容差；改为固定随机纹理和无效边缘后，在原 4mm 容差内通过。该合成夹具修正不改变真实序列、优化参数或接受门槛，不证明真实标定正确。
- 独立脚本 `experiments/scripts/check_nyu_open3d.py` 使用根环境复算 59 条边的共同阈值、正反向组合、接受逻辑、前缀和完成标志，核对输入/源码/基线/输出摘要，共 130 项检查通过。不重新运行优化器或验证绝对位姿。
- 归档：`experiments/evidence/2026-10-28/nyu-open3d-002/`，含 comparison.json、prepared-input.json、checks.json 及安装包元数据。大图像和 PLY 留在忽略的 var 目录。

`algorithm_ready=false`、`real_release_ready=false`、`independent_accuracy_verified=false`。没有独立轨迹参考、回环、TSDF/占据更新、服务发布或机器人验收；未知不转换为空闲。已生成并请求打开核对页，没有执行浏览器自动化视觉验收。
