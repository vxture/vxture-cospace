# 平台登录与中央会话 I2 验证

日期：2026-11-03。本轮将I1验签与权限基础推进到可运行的CoSpace平台RP链路，参考yucer的中央会话约定以及平台现有`/oidc/session/status`接口。

## 本轮结果

登录按钮可顶层跳转身份源，经PKCE S256、浏览器绑定的单次state、nonce和id/access token验证回到CoSpace。服务端独立加密会话保存跨服务重启；中央查询决定登录是否结束，网络和令牌问题不直接登出。CSRF保护的退出操作会调用平台end_session并清本地Cookie。

当前为**本地模拟身份源验收**，没有真实平台认证结果。CoSpace client注册与环境参数仍待配置。I2服务只公开工作台构建资源和认证路由；未登录业务API返回401，已登录返回503空间授权未配置，固定发布、候选和根模型资产无静态直通。原8767保持内部工程预览，未把原样本自动归入模拟用户。

## 验证结果

| 验证层 | 结果 |
| --- | --- |
| I2登录专项 | 40项通过，包含真实本地HTTP换码/JWKS/状态查询、回调负例、CSRF/Origin、密钥不匹配、配置隔离、平台失败与刷新恢复限制 |
| 相关回归 | 合计211项通过，含I1签名/空间策略，以及原空间归属、分发、控制、流程、目录 |
| 独立子进程HTTP | 18项检查、16次显式HTTP请求通过；两个RP进程完成一次真实服务重启，沿同一加密库恢复 |
| 刷新并发 | 两个真实本地进程竞争同一会话，仅一次refresh请求，两个调用均得到新凭据 |
| 浏览器 | 13项会话/资源边界/刷新页面/桌面窄屏检查 + 3项全局登出检查通过；实际点击登录、模拟平台确认、会话检查与退出 |
| 前端 | TypeScript检查与生产构建通过，原use-client依赖打包提示仍在 |
| 原样本保护 | 195个历史受管文件与H3c基线一致，无认证库或权限记录写入原运行区 |

I2关键负例：回调缺少/错浏览器Cookie、nonce/sub/sid不匹配、state过期/重放/参数重复、外部returnTo、跨源操作、中央invalid/格式错误/不可用、refresh拒绝/已消费后丢响应/崩溃pending。失败刷新会保留accounts登录但阻止再次使用同一refresh token，供显式重新连接；不声称有跨平台分布式事务恢复。

测试中的弱RSA公钥负例有两条预期SecurityWarning。浏览器控制台有模拟平台favicon 404及主动负向请求的503/404；这些不是页面脚本异常，未声称零控制台错误。

浏览器首轮发现全局no-referrer会让Chromium的退出表单Origin变成null，导致403。已改为认证路径no-referrer、工作台same-origin，保留CSRF和严格Origin校验；修复后完整退出、清Cookie和回到登录页均通过。未放宽到接受任意Origin或Origin:null。
