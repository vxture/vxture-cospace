受`build.run`及场景／资料／任务授权保护的只读接口返回有界显示抽样，最多10,000点和2MiB，不触发worker。新标签页全屏画布自动识别有过程记录的任务，支持跟随已保存帧、源时间回放、暂停、重播、速度、回拖和返回原流程；估计相机朝向及轨迹只画到当前帧。

旧任务不回填过程。静态PLY／ROS单帧及无帧时间的旧RGB-D仍保留阶段预览和明确标注的扫描演示。部分失败保留已保存过程，重试沿原恢复入口创建新任务。

## 4. 发现与修复

1. 真实并发读取暴露Windows短暂文件占用，原子替换索引可能返回WinError 5，首次任务因此失败。已加入不到一秒的有界替换重试，期间保留上一完整索引；持久占用仍失败。新增短暂／持续占用测试，通过原恢复UI重新构建成功。原失败记录与分块未覆盖。
2. 首次后端真实worker测试使用的旧fixture深度码没有有效点；修正测试资料为有效深度，并重新核对源摘要后通过。此为测试样本修正，不改变正式原资料。
3. 连续跟随补验发现同一过程修订遇到任务中断时也应更新显示。页面现同时比较过程与任务状态，中断退出跟随并保留已验证几何；对应时序复测通过。
4. 模拟认证长时间空闲后业务接口返回503。验收通过既有中央会话POST确认恢复；仅GET会话不等于确认。保留此限制，不据本地模拟验收宣称生产认证完成。
5. 验收脚本补齐直接路由切换后的刷新及消费入口`from=consumer`上下文；失败尝试不计入通过数。一次查询计划文件编码不匹配已修正UTF-8，之后使用全新消费目录执行禁网验收。
