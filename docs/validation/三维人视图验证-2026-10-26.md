# 三维人视图验证

日期：2026-10-26。P2合成服务消费增量；P1算法及P3真实构建仍未完成。

## 本轮结果

- 在托管固定发布上新增只读人视图预览：复用已校验对象、人视图描述及覆盖证据，携带发布、真值、人视图版本、坐标与摘要。没有独立生成或修改另一套权威数据。
- 服务端按全部区域边界切分，当前合成样例得到60个互不重叠的半开分区。逐分区中点对照点查询规则；空闲、占据、未观测未知和冲突未知均一致。上限4096块，超限显式拒绝；非生产大场景表达。
- Three.js0.186.1采用WebGPURenderer，按需加载；实际内置浏览器显示WebGPU并呈现三维内容。对象仅展示3个已有语义锚点，不虚构设备或房间几何。查询点与同一固定快照联动。
- 临时PostgreSQL18全量46个测试和19个子用例通过，无跳过；包含人视图各分区与点查询的一致性、快照深拷贝、旧快照明确失败和撤回后410。见[日志](../../experiments/runs/p2-human-001/tests.log)及[JUnit](../../experiments/runs/p2-human-001/tests.xml)。
- 浏览器验证读取、三维显示、占据点查询与再次加载被撤回的发布时返回410、清除画面。刷新逻辑额外清除旧点结果，避免残留。
- TypeScript严格检查及生产构建通过，skipLibCheck=false。主JS约255KB/gzip79.5KB，按需三维块约810KB/gzip220KB；TanStack use client打包警告保留。见[构建日志](../../experiments/runs/p2-human-001/web-build.log)和[截图](../../experiments/runs/p2-human-001/workbench.png)。

## 边界与兼容

本轮实际验证WebGPU路径；WebGL2回退、移动设备、GPU丢失恢复与大场景性能尚未验收。渲染失败保留对象和分区文本，不将渲染错误转为空间unknown。透明分区仅用于示意，精确状态以服务端查询与分区明细为准。

新登记快照增加对象内容和人视图描述，无表结构迁移。旧已登记快照不自动改写，仍可查询与追溯；人视图返回human_view_unavailable。相同发布ID内容不可变，因此旧库不能通过覆盖登记补内容；应登记新发布ID。当前快照的重复登记仍幂等。

预览加载时检查撤回，已下载内容不能远程收回。当前沿用整个合成发布的保守撤回门禁；独立能力授权、身份认证、受保护审计、真实几何及可通行/重定位质量不在本轮结论内。
