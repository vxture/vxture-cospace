## 复跑及限制

从仓库根目录执行，build使用新目录：

```powershell
.venv/Scripts/python.exe -m apps.cli.agent_package check examples/agent-runtime --source examples/indoor-spatial
.venv/Scripts/python.exe -m apps.cli.agent_package build var/agent-runtime-new --source examples/indoor-spatial
.venv/Scripts/python.exe -m pytest tests/test_agent_package.py -q
```

失败样例由测试在临时目录生成，正常examples不混入坏包。校验需外部固定来源，不提供可信签名、在线撤回、安装或激活。没有后台进程、数据库或容器，证据与示例保留。
