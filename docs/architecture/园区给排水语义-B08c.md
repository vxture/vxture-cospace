# 园区给排水语义 B08c

在公共资源提供 `water@0.2.0` 预置草案，沿用核心 `0.1.0`。管段、物理端口和系统身份分别建模，证据、生命周期、资料编号和地图点锚属于实例。首批覆盖水泵、阀门、管段，与危险工艺介质或水力计算无关。

| 要回答的问题 | 定义与约束 | 反例 |
| --- | --- | --- |
| 是哪段管、内径是多少？ | 管段是独立物理对象。设计内径可选，以 mm 和长度量纲登记，范围为 1 mm 及以上。缺少明确设计或规格资料时留空。既有水泵额定功率定义保持原义。 | 不把 DN 当成实际内径，也不将米制值直接写入毫米字段。 |
| 端口归属和直接物理连接是什么？ | `has_water_port` 从泵、阀或管段指向其接驳端口；`water_connected_to` 表示两端口有来源记录的直接连接，含义对称。默认不从空间拓扑生成连接。 | 管线交叉、设备邻近、同属一个系统，均不足以证明连接；不能把管段或阀体当作端口。 |
| 现在哪儿在通水？ | 本批只交付资料中显式声明的直接连接、系统归属和规格；不表达实时流向、阀门状态、压力或可用性。 | 倒读对称关系不等于流向反转；没有记录不等于管线断开。 |

行业对照沿用 buildingSMART IFC 4.3 的 [IfcPipeSegment](https://github.com/buildingSMART/IFC4.3.x-development/blob/0f1c7acb287740d7d40e2d0021c216a9cdf638ab/docs/schemas/domain/IfcHvacDomain/Entities/IfcPipeSegment.md)、[IfcDistributionPort](https://github.com/buildingSMART/IFC4.3.x-development/blob/0f1c7acb287740d7d40e2d0021c216a9cdf638ab/docs/schemas/shared/IfcSharedBldgServiceElements/Entities/IfcDistributionPort.md) 与 [IfcRelConnectsPorts](https://github.com/buildingSMART/IFC4.3.x-development/blob/0f1c7acb287740d7d40e2d0021c216a9cdf638ab/docs/schemas/core/IfcProductExtension/Entities/IfcRelConnectsPorts.md) 区分对象、端口和连接。这里记录无方向的物理连接；没有声明与 IFC 自动转换或等价。

[研发办公园区合成样例](../../examples/ontology/parks/research-office-water-b08c.json) 验证固定发布及旧版水泵兼容、单位校验、直接连接可反向读取和邻近不能替代端口。现有发布不迁移，采用新定义时用 `python -m packages.ontology.kernel --module water` 导出，对照工作区最新发布，再按现有审批流程发布及关联。
