# 语义本体业务与配置边界及导航框架 v0.1

日期：2026-11-20。状态：设计草案；用户已确认业务与配置分离原则，本文具体导航和配置条目是据此形成的设计方案，未表示功能已实现。

本文修订此前把查看/编辑/发布作为导航分组、把模块及术语逐项塞入侧栏、把系统配置混入公共资源的方案。功能归属与导航以本文为后续实施依据；既有技术验证记录只说明当时实现，不作为最终信息架构依据。

## 1. 产品边界

| 区域 | 当前入口 | 独立产品入口 | 职责 |
| --- | --- | --- | --- |
| 本体业务 | 公共资源 → 语义本体 | 本体引擎 → 本体资源 | 查找、编制、校验、版本化、发布与引用本体资源 |
| 系统配置 | CoSpace 配置管理 → 语义本体配置 | 本体引擎 → 配置管理 | 配置分类组织、编制规范、流程策略和运行接入 |
| 消费应用 | 园区、场景等业务板块 | 各消费产品 | 实例、位置、几何、观测、业务事实及现场确认 |
| 平台主体 | 平台管理体系 | 对接身份与商业平台 | 组织、身份、订阅及商业权益；本体产品不重复建设 |

以上是信息架构，不声明新的已接通 URL。现有配置管理入口的实际装配位置与权限契约需接入时核对。不得因为配置页面暂未建设，就把配置表单临时塞入本体业务导航。

L1/L2/L3 是语义分层；资源分组是组织方式；草稿/已发布是生命周期状态；查看/编辑/发布是操作。四者不互相代替。

## 2. 本体业务功能清单

| 编号 | 功能 | 工作内容 | 页面归属 |
| --- | --- | --- | --- |
| B01 | 资源发现 | 按分组、层级、状态、关键字检索，排序和分页 | 本体清单 |
| B02 | 资源归组 | 从已有分组选择，将本体归组或移出；允许多个归组 | 本体清单批量操作或详情基础信息 |
| B03 | 查看定义 | 定义范围、概念、属性、关系、语义约束与规则 | 本体详情内部的分节、清单与详情 |
| B04 | 编制草稿 | 新建/复制本体、编辑语义、保存修订与原因、冲突处理 | 当前本体编辑工作面 |
| B05 | 执行校验 | 执行定义/依赖检查，显示问题位置与支持范围 | 当前本体操作及校验报告 |
| B06 | 版本管理 | 固定版本、差异比较、历史读取、内容摘要 | 当前本体版本工作面 |
| B07 | 发布本体 | 提交审核、发布、撤回或废弃的受控操作，保存结果 | 当前本体操作；仅展示实际具备的流程 |
| B08 | 引用依赖 | 模块依赖闭包、版本锁定、消费方上报引用、影响分析 | 当前本体详情；跨本体汇总可进入业务记录 |
| B09 | 导入导出 | 检查模块包、处理冲突、导出固定定义及依赖 | 资源清单/详情操作 |
| B10 | 查询业务记录 | 本体版本、校验和发布的跨资源记录 | 业务记录清单 |

概念/属性/关系不因为是数据实体就独立成为全局导航项。首阶段在所属本体详情中组织；有明确跨本体检索需求后，可作为本体清单的搜索范围扩展。不得复制出失去模块和版本归属的第二套语义库。

单位、量种、值域、必填、端点类型及推理规则的语义内容属于本体资源。即使看起来像“参数”，也不能挪入系统配置，导致历史版本无法独立解释。

## 3. 系统配置功能清单

当前统一归入 CoSpace 配置管理的语义本体配置域。独立产品时换宿主和入口，复用配置模型与用例，不改变字段含义。

| 配置导航组 | 配置条目 | 配置内容 | 与业务的边界 |
| --- | --- | --- | --- |
| 资源组织 | 分组配置 | 预置/自建分组、名称、说明、排序、启停与预置升级 | 本体归组关系是业务数据，不与分组定义一起删除 |
| 编制规范 | 标识与命名策略 | 标识生成、命名检查、命名空间分配策略 | 某本体的实际 ID/命名空间是资源身份，不能随配置改写 |
| 编制规范 | 编制模板 | 新建时采用的结构与录入默认值 | 从模板产生的本体须独立版本化，模板修改不追改资源 |
| 流程与授权 | 版本与审核策略 | 版本号检查、提交/审核/发布流程及职责要求 | 实际版本、审核任务及发布结果留在业务侧 |
| 流程与授权 | 操作权限策略 | 编制、分组配置、审核、发布、导出权限及身份映射 | 不替代平台身份、订阅和商业权益管理 |
| 运行与接入 | 校验与推理执行 | 执行器注册、支持能力、执行预算与隔离策略 | 本体中的约束/规则表达不因执行器变更被重写 |
| 运行与接入 | 存储与索引 | 存储/检索适配、索引与运行参数 | 不把数据库结构暴露给本体使用者 |
| 运行与接入 | 外部连接与分发 | 仓库、外部词表源、分发目标与凭据引用 | 导入后的映射声明、来源和发布记录仍属资源 |

这些是完整规划清单，不能据此一次性显示大量空页面。凭据只保存于宿主安全设施，通用配置中保存引用，禁止进入本体定义、导出包或源码。

## 4. 业务导航框架

规划为两个业务导航组，条目固定，资源规模不影响导航项数。第一组现阶段开放；第二组逐项具备真实能力后开放。

| 导航组 | 导航条目 | 内容区 | 实施状态 |
| --- | --- | --- | --- |
| 本体资源 | 全部本体 | 全部可访问本体的清单 | 现有只读入口 |
| 本体资源 | 通用核心 | L1 本体清单 | 现有只读入口 |
| 本体资源 | 领域本体 | L2 本体清单 | 现有只读入口 |
| 业务记录 | 版本记录 | 跨本体版本清单，打开具体版本及差异 | 后续 |
| 业务记录 | 校验记录 | 校验执行结果，定位问题与被检查版本 | 后续 |
| 业务记录 | 发布记录 | 本体发布结果、状态和审核关联 | 后续 |

侧栏不出现“编辑”“发布”“配置分组”“概念树”等入口。业务记录是结果资源，不是操作模式。引用与依赖先留在本体详情，避免未验证需要就增加全局导航。

正文只有清单、过滤条件与对象详情，不重复一套分类侧栏或顶部分类标签导航。详情的返回操作和对象引用链接不构成第二套全局导航。移动端复用同一 DS 导航抽屉。

当前导航采用项目共用 ShellSidebarNav、ShellSidebarFrame、链接适配、折叠和抽屉，不另造侧栏组件。未来独立 Shell 可替换挂载，通用本体 UI 仍不读取宿主路由。

## 5. 分组模型与预置内容

语义层级和分组分开建模：一个“供配电”分组可包含设备、系统、连接等多个本体模块；模块身份不等于分组身份。一个模块可在多个分组出现，定义和版本仍只有同一份。

首批预置业务分组：建筑与空间、室外空间与设施、供配电、给排水、安全消防、环境与监测、组织与运营。L1/L2 为层级筛选，不作为业务分组的父子关系强行编码。通用核心入口直接由语义层级确定。

| 对象 | 最小字段 | 管理位置 |
| --- | --- | --- |
| 分组定义 | group_id、name、description、origin（preset/custom）、status、sort_order、scope、revision | 配置管理 |
| 资源归组 | ontology_id、group_id、修订/操作记录 | 本体业务 |
| 预置分组来源 | 稳定预置 ID、定义集版本、升级记录 | 配置管理及安装迁移 |

分组 ID 稳定且不复用；名称不作为外键。预置项保留来源并可停用，升级不覆盖用户自建项或已有归组。自建名称冲突按作用域检查。分组停用后历史归组可解释，新增归组不再可选；已有归组不能因停用而丢失。永久删除、自动迁移和树形层级暂不作为首批功能。

初期用平面分组，避免无业务依据地增加分类树。新建分组在配置管理完成；业务侧缺少分组时可提供“前往分组配置”的动作链接，按权限开放，不在资源编辑器偷偷创建配置。

分组选择位于内容区筛选控件，选项支持检索与按需加载；业务导航不逐项列出全部分组。分组自身的数量也不能成为导航膨胀来源。

## 6. 规模与独立性

当前内置定义 API 有上限，仅服务首批草案。现有本地过滤/每页十条只适用于这一范围，不能宣称支持海量注册库。

后续独立接口至少分为：本体摘要检索、按固定版本读取定义、分组配置查询/变更、资源归组查询/变更、业务记录查询。清单在服务端执行权限过滤、稳定排序与游标分页；详情按需加载；分组元数据与本体定义不互相整包携带。查询结果数与统计不能泄露无权资源。

客户端通过注入接口消费业务与配置，不直接依赖 Workspace、场景表或宿主文件目录。scope 与 actor 由宿主转换，核心规则不读取 CoSpace 身份。配置权限在服务端执行，不能仅隐藏按钮。当前 Workspace 归属是 CoSpace 的装配策略，不预先固化为独立引擎唯一的租户模型。

分组变更不修改本体内容、语义摘要或已发布引用；编制/执行配置变更不静默改写历史定义。需要复现执行结果时，记录执行器版本和所用配置修订。

## 7. 分阶段实施与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| F01 边界与框架（本文） | 业务清单、配置清单、导航与对象归属 | 每项有唯一职责，语义定义不被当成系统参数 |
| F02 分组配置最小闭环 | 配置管理中的预置分组读取、自建、停用、修订与权限 | 重名/并发/越权拒绝；预置升级不覆盖自建项；多作用域隔离 |
| F03 资源归组与查询 | 内容区分组筛选、本体归组、服务端摘要分页/详情读取 | 导航项数量不随本体或分组增长；归组不改变语义摘要 |
| F04 本体编制与版本 | 草稿、编辑、校验、固定版本及差异 | 查看不能误改；编辑不隐式发布；冲突和失败不误报成功 |
| F05 发布及业务记录 | 受控发布、校验/版本/发布记录清单 | 绑定本体版本与执行配置；旧版本可解释；消费方显式升级 |
| F06 运行与外部接入配置 | 按实际需要引入执行器、存储、索引与连接适配 | 更换宿主不重写本体语义；凭据不进入资源包 |

F01 是设计交付。当前不以占位页假装 F02–F06 已完成，不把旧工作区规则接口当成新本体发布能力。下一步工程范围先是 F02，再接 F03；其他配置只规划，不抢先实现未决引擎选择。

2026-11-20 F02 首批已实现配置入口、7 个预置分组、自建/编辑/启停、四方向移动和修订审计，界面不展示排序数字。详见[配置契约](../../contracts/schemas/ontology-group-configuration-v0.1.md)与[验证记录](../validation/本体分组配置-F02-2026-11-20.md)。预置版本升级迁移仍未实现，F03 资源归组与查询仍待后续。

2026-11-20 F03 首批已完成内置定义集范围内的摘要查询、服务端筛选/分页、固定引用详情、分组筛选、多归组和默认归组。该接口尚无大规模索引或分组按需查询能力。详见[资源目录契约](../../contracts/schemas/ontology-resource-directory-v0.1.md)。
