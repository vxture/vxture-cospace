# 空间态势独立大屏 v0.4

## 导航与布局

工作台 `layout.html#space` 展示「我的空间」目录。目录、Launcher 与管理导航中的空间态势链接均使用 `target="_blank"` 和 `rel="noopener noreferrer"`；原工作台留在原标签页。大屏地址使用 `?screen=space&preview=1&space=equipment#space`，不渲染通用 Header，内容占满视口。

左上角：空间切换与当前版本。右上角：双视图、图层、属性、沉浸、浏览器全屏。移除底部操作菜单，底部仅保留简短示例状态。对象与属性浮层不压缩地图尺寸。

图形标注使用 DS label-small 的实际字号，ResizeObserver 根据 SVG 视口换算字号，避免文字随底图放大。线条采用 non-scaling-stroke；按钮、面板、字号和颜色继续使用 DS 组件与语义 token。

## 多空间原型

三个合成示例空间：设备间与相连走廊、水泵设备间、巡检设备区。目录数据在 `apps/workbench/src/layout/spaces.ts`；切换更新对象、属性、布局示意及 URL，重置选择、过滤、本体证据页签、视图与图层。

这些是复用示意几何的设计样例，不代表真实空间采集成果。真实实现需从服务端读取当前用户可访问空间，并对各空间及版本查询执行授权。`preview=1` 仅显式进入 UI 原型，不是登录凭证，不得作为正式认证依据。
