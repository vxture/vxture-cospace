# 独立语义本体工作台 B09d

独立工作台使用 `vxture-ontology 0.1.0.dev4` 和同一批次的静态界面。安装后只需要 Python 3.11 或更高版本和浏览器；界面不依赖 CoSpace、地图服务、平台登录、Node.js 或公网资源。参考宿主仍只监听 `127.0.0.1`，用于本地工作和集成验收。

## 安装和启动

解压发行包。`manifest.json` 记录包版本和每个文件的 SHA-256。用独立 Python 环境安装 `wheel/` 中的文件，指定 `ui/` 作为静态界面目录：

```text
python -m pip install --no-deps wheel/vxture_ontology-0.1.0.dev4-py3-none-any.whl
vxture-ontology-host serve --data-dir ./ontology-state --identity-config ./identity.json --ui-dir ./ui --port 8791
```

`ontology-state`、`ui`、`identity.json` 应独立存放。打开 `http://127.0.0.1:8791/`，输入本地管理员签发的令牌。工作台只将令牌保存于当前浏览器标签页内存；刷新或退出后重新进入。参考配置的顶层 `profile` 是 `vxture.ontology-local-host/0.1`，`principals` 中每条包含 `scope`、`actor`、`token_sha256` 和 `permissions`。为每个操作者用 `secrets.token_urlsafe(32)` 生成独立令牌；配置只记录令牌 UTF-8 编码的 SHA-256 小写摘要。不得在 Git 或 URL 中保存令牌。

| 角色示例 | 权限 | 工作入口 |
| --- | --- | --- |
| 查看人员 | `read` | 查看公开定义和固定版本，导出原生包。 |
| 编制人员 | `read`, `read_private`, `edit`, `submit` | 编辑和导入草稿，在发布入口校验并送审。 |
| 审批人员 | `read`, `read_private`, `review` | 核对送审快照、审批或驳回；不能批准自己提交的版本。 |
| 发布人员 | `read`, `read_private`, `publish` | 发布已审批的当前修订。 |
| 配置人员 | `configure_groups` | 单独管理系统分组和顺序。 |

导航条目只随权限变化。候选定义、已发布版本、私有草稿和分组都在内容区清单里。发布的定义及依赖按版本和摘要固定，导入外部定义仍先预检，再保存草稿，按本地流程审批。当前版本提供本机工作台；平台化身份、在线多租户及面向 CoSpace 的生产部署另行验收。

## 升级与回退

1. 停止旧宿主，用旧版 `vxture-ontology-host backup --data-dir ./ontology-state --output-dir ./before-upgrade` 保存快照。身份配置单独保留。
2. 将新 wheel 安装到另一 Python 环境，并将新的 `ui/` 保存在新的发行目录；用新版本启动原数据目录，验收私有草稿、分组和一个旧发布闭包。
3. 若需要回退，停止新宿主。B09c 与 B09d 使用相同数据库格式。可以用旧版 wheel 启动现有数据库的 API（B09c 无独立浏览器界面）；如需恢复升级前的数据，用旧版 `restore --backup-dir ./before-upgrade --data-dir ./restored-state` 恢复到新目录，保持升级后的数据目录供核对。升级之后新增的数据不会出现在升级前的快照中。

## 重建发行包

在源码仓库执行，Node.js 策略与 CoSpace 构建工具链一致，使用锁定依赖。输出到忽略提交的 `output/`，文件名可按版本调整：

```text
pnpm --dir apps/workbench install --frozen-lockfile
pnpm --dir apps/workbench build:ontology
uv build --wheel packages/ontology/kernel --out-dir output/ontology-dist
python -m scripts.guardrails.package_ontology_workbench --wheel output/ontology-dist/vxture_ontology-0.1.0.dev4-py3-none-any.whl --ui-dir var/ontology-workbench --output output/ontology-dist/vxture-ontology-workbench-0.1.0.dev4.zip
```
