## E01a 结构预检先落地

2026-10-28进展：独立 `rosbags==0.11.9` 离线适配器已在Python3.14/Windows实际读写ROS1合成日志，完成正常、缺点时间、IMU倒退、损坏输入4组CLI验证。新入口和范围见[报告契约](../../contracts/schemas/bag-preflight-v0.1.md)，证据在experiments/runs/p1-offline-bag-002；旧工具历史状态保留如下。真实序列和算法回放尚未完成。用户确认当前没有对接采集设备，后续按[无设备阶段计划](无采集设备阶段的数据与适配推进-v0.1.md)推进公开数据评估与隔离回放。

当前inspect_rosbag.py与smoke_rosbag.py依赖ROS1 rosbag，语法已核对但尚无实际运行证据。原固定镜像未下载成功，此事实不能写成工具已通过。

1. 只读确认已有解析库、容器及本机资源；历史环境记录不作当前可用保证。固定解释器和依赖版本，不混入其他项目运行环境。
2. 评估受维护的离线bag解析候选（如rosbags）的ROS1读取/写入与所需消息兼容性，核验官方来源、版本、许可及Python支持。此为候选任务，尚未决定安装或替换实现。
3. 可采用独立解析适配器，与原工具保持三态诊断及字段/时间规则可比较；若仍用ROS1，限定兼容试验并固定镜像摘要。不能只为跑烟测将过时ROS发行版定为产品基础栈。
4. 实际生成并读取三组小型合成日志：结构完整、缺逐点时间、IMU时间倒退；预期分别接受、拒绝、拒绝。“接受”仅表示结构前置检查通过，algorithm_ready必须false。
5. 附加检查缺话题、空数据、无效时间和损坏输入时产生明确错误；不得用空报告代替运行失败。逐点时间的单位、基准及外参方向仍列未验证。
6. 保存输入摘要、生成与解析实现摘要、依赖/环境、命令、退出码及报告到全新运行目录；不得覆盖原来源证据或把新解析结果冒称旧脚本已运行。

完成门槛：实际工具调用、合成正负例及可复跑记录均具备，失败不误报通过。没有真实日志也能完成这一子集。

## E01b 真实短序列准入

按[数据需求](数据采集与独立校核需求-v0.1.md)选择一份与候选输入相符、使用条件明确且可取得的序列。未确认资料下载条件前不把公开网页当已取得数据，不提交申请或对外联系来替代用户授权。

| 必填记录 | 接受条件 |
|---|---|
| 来源/使用条件 | 官方来源或明确提供方、用途限制和原文依据；不能只记代码许可证 |
| 内容固定 | 原字节摘要、时长/大小、话题类型及采集轮次；保留原件 |
| 时间 | 激光/IMU时间范围、频率、逐点时间字段/类型/单位/参考及同步说明；未知不能推断填充 |
| 几何前提 | 坐标、单位、外参方向/数值/来源、IMU约定；缺关键条件先判不适配 |
| 数据角色 | 开发集、保留集、独立参考分别标记；同源观测不能充当全部独立质量证据 |
| 算法适配 | FAST-LIO/LIO-SAM所需字段逐项原生、可解释转换、缺失或未验证，不要求伪造等价输入 |

完成门槛：至少一条候选明确可进入回放，或有证据说明当前数据不适配并选定补救动作。数值质量标准仍由用途先定义，不根据跑分倒定。

## E01c 首条算法回放

先跑输入条件满足且可解释的候选，不因预设“先进”标签强行选默认实现；另一主路线按原对照方案在条件满足时进入。记录固定提交、完整依赖与许可问题、构建环境、参数及输入转换。不把GPL或依赖冲突解释为单独进程即可消除义务。

隔离运行、只读输入、专属输出、资源限额、超时与日志限额；不挂整机设备、不复用现有业务容器、不自动发布到spatial或服务指针。产物保留轨迹/几何原生文件、坐标约定、初始化/失败区、执行日志及资源。退出码0但没有所需输出必须作为失败记录。

有独立参考才报告对应误差；无参考时说明缺口，不以匹配残差或画面连续证明几何、覆盖或定位正确。禁止把PCD直接标为权威真值；候选、独立质量和采用流程归P3/I5。
