# 固定发布来源与本体比较 N14—N17

## N14／N15：数据来源

复用既有固定发布与来源追溯，不新增权威库、不迁移数据。共用数据目录的固定发布增加“追溯来源”，URL携带场景与固定publication；刷新仍读取指定记录。读取失败不替换为当前发布，来源不一致不生成操作链接。

新增只读 `/publications/{id}/api/provenance`，复用固定发布完整性读取及输入／任务绑定核对。每次要求当前会话、订阅、场景归属、data.manage与space.preview；不接受查询参数。入口与目标工作面各自检查权限。历史源文件不重检、构建不poll、离线包不生成、选择不修改。旧`api/lineage`完整包核对接口保留兼容。

返回登记资料、构建任务、固定发布、来源候选及已有固定本体引用。候选指向发布保存的candidate_id，模型摘要来自固定发布。资料历史是追溯入口，构建未记录预检序号时返回null，不能把最新通过结果算成当时准入证据。旧模型未记录资料／本体时明确缺失，不按路径或当前选择猜测。来源当前不可读不影响已核对固定快照的独立性。

本功能不表示跨接口事务快照、可信签名、现场质量验收或消费端签收。仅从固定发布切入，不扩展为全部算法过程文件管理。

## N16／N17：规则比较

复用当前授权规则列表及固定版本GET接口，由服务端逐次校验工作区、规则摘要和完整性。只允许同一本体的两个授权固定版本比较；原版本为当前查看版本，目标版本由用户显式选择。切换原版本清除目标与旧结果，迟到响应忽略；请求失败不回退为其他版本。

比较全部定义内容，除ontology_id／version外逐项报告新增、删除、修改；类型、属性、必填、长度、关系端点／方向等均纳入。标题／描述变化单独提示为说明变化，其余需要人工评估，不宣称兼容或可安全迁移。键顺序不产生差异；数组保留声明顺序。差异总数完整计算，最多展示200项并明确截断，JSON固定规则可独立核对。

本批选择原计划允许的收窄范围：交付可信固定版本比较，暂不实现全量引用扫描。现有模型／发布记录分布于多种记录，尚无有界且完整的本体引用索引；临时扫描全部模型既扩大读取成本，也可能暴露无权场景。页面明确“未查询场景引用”，不能把未覆盖当成无人使用。引用影响定位作为后续独立批次，不能计作本轮完成。

不修改规则、实例、候选或发布，不自动升级或迁移。现有规则编制、封存和对象校验照常使用。两项扩展均无数据库迁移。
