## 2. 统一流程及完成定义

业务：**选择场景 → 导入资料 → 发起构建 → 查看与核对成果 → 确认发布 → 查看／调用／离线读取。**

技术：固定资料引用 → 文件与路线条件校验 → 固定模型 → 派生人视图与智能体视图 → 校验同源 → 固定发布清单 → 查询与交付。

“通过”要求：真实输入与输出可读；同一场景和版本引用一致；界面可连续操作；刷新后能找回；失败可解释并可继续；旧成果保留。精度等级、重定位成功率、导航表现不作为当前批次门槛。数据损坏、坐标缺失、未知当空闲、混合版本仍应阻断。

语义本体与空间关联按用途接入；本轮默认用途是空间浏览与流程验证，不要求创建测试设备台账来凑齐步骤。

## 3. 分批任务

### P1：连续核对与发布交接

优先级：当前。依赖：已有合法场景和完成的模型候选。

1. 在构建流程页直接核对本次模型，复用现有比较／核对接口。
2. 核对后主要动作变为“前往确认发布”，携带具体候选ID。
3. 发布页面核对目标与当前所选候选；不一致时阻止发布其他版本，并返回原构建。
4. 发布成功定位刚生成的固定发布；流程页可直接打开该发布空间。
5. 保留明确核对、发布确认和后台修订校验，不自动选中／发布最新任务。

验收：指定新候选 → 流程页核对 → 固定候选跳转 → 确认发布 → 新发布定位 → 返回流程打开匹配版本；指定其他候选时发布被阻止；旧发布不变。

实施位置：`construction-flow.tsx`、`preview-publications.tsx`。本批状态和验证见本文件末尾。

### P2：失败恢复与输入交接

依赖：P1。范围保持同一场景和现有构建任务，不新增流程引擎。

1. 区分等待资料、运行中、任务失败、服务中断、成果损坏、依赖停用与读取失败。
2. 失败与中断时提供“使用原资料重新构建”；沿用明确输入和合法批次，提交前再校验。
3. 缺文件、来源停用、资料归档或批次不合法时，提供对应数据管理定位；不自动解除门禁。
4. 重试生成新任务并保留失败任务；提交结果不明时先查记录，避免重复任务。
5. 刷新／返回不丢场景与明确任务，运行中按实际服务状态恢复。

验收：至少覆盖成功、真实构建失败或中断、资料不可用、重试成功四条路线；刷新后状态可追溯，旧发布仍可读。可以使用可控故障样本验证；不得破坏原始采集资料制造失败。

### P3：三维模型与双视图的独立派生

依赖：P2 的状态、引用及重试约定。先做必要任务拆分，不为展示流程图增加额外服务。

1. 将模型完成、视图派生完成、可发布三个状态分开，不把任务成功和发布混为一谈。
2. 模型快照固定后，视图任务绑定模型摘要、派生类型与参数；独立记录运行和错误。
3. 支持只重试失败的人视图或智能体视图，保持模型不变；旧视图和发布不覆盖。
4. 发布清单固定确定的模型和两类视图组合；不一致／未完成时阻止发布。
5. 保持旧样本契约的读取兼容，新任务与新产物采用显式版本契约及适配。

验收：一次完整生成；人视图失败单独重试；智能体视图失败单独重试；相同模型生成新视图记录；不同模型视图不能组合发布；模型摘要及历史发布不变。

### P4：使用与版本更新闭环

依赖：P1、P2。可先用当前一体任务完成基线验收，P3 完成后补验新组合。

1. 发布后直接打开独立全屏空间，正确显示两类视图。
2. 在线点／范围查询与同一固定发布的离线结果一致。
3. 离线包校验、安装、显式激活、重启恢复按消费端实际证据显示；下载不等于启用。
4. 同一场景第二次构建、核对、发布保留旧版；失败新任务不影响旧版使用。
5. 同一流程测试中补权限不足、候选修订冲突、暂停分发与跨场景引用负例。

验收：一套独立短场景从资料到消费的可重放脚本和人工操作手册；每步输入／输出标识、状态与限制完整，无重复选择、无静默换版。

### P5：场景初始化与样本预置

依赖：已验签的平台 Workspace 身份、平台owner产品基线及产品自有创建／来源分配配置。本批不阻塞已有场景主流程；P5b已核对平台规范，创建三维场景为CoSpace自有业务，无需等待独立的平台场景创建接口。

1. 创建一个场景空间并建立明确 Workspace 归属与初始权限。
2. 将不同物理样本分别初始化为自己的场景空间；同场景可以有多资料、多传感器、多版本。
3. 允许在已有同场景内登记样本，但不默认把其他真实场景并入。
4. 样本初始化幂等、错误清理可追溯；不迁移或覆盖历史测试 A/B 数据。

验收：同 Workspace 多场景、不同 Workspace 隔离、重复初始化不重复造空间、无权创建拒绝；真实平台未联调时保持“本地模拟验证”标识。

执行拆分：**P5a受控本机初始化**完成按Workspace绑定的样本场景、显式接管旧场景、幂等与中断恢复；**P5b在线创建**按平台080 §2.6的workspace owner基线或产品显式创建授权，在配置允许的Workspace创建空场景并绑定。单场景manager不自动取得新建授权；缺配置仍关闭，旧工程创建API仍拒绝。具体来源按Workspace分配并固定指纹。
