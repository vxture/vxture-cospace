# 智能体运行包文件存储与恢复设计

日期：2026-10-27。状态：R1b首批参考实现与故障验证完成；实际大地图性能、物理断电和可信有效性未验收。

依据：[R1a设计](智能体运行包本地安装与会话设计-v0.1.md)、[消费架构](智能体视图运行包与在线离线消费架构-v0.1.md)。

## 1 存储边界

R1c后续已实现独立[完整性核对](智能体运行包完整性核对设计-v0.1.md)，使用只读数据库与有界目录扫描，不改变本页安装和恢复语义，也不授权清理。

新增infrastructure/agent_files.py的FilePackages，复用现有安装/活动版本/会话接口，CLI显式选择`--backend files`。默认blob后端保留，不静默改变既有本地库。

专用本地根目录包含runtime-files.sqlite3、staging/install-ID、packages/清单摘要及locks/install-ID.lock。SQLite只存清单、回执、安装状态及活动指针，不存组件内容；每个组件仍为原字节文件。本轮“文件块”为清单声明成员，不等于新增空间瓦片、压缩或全局内容去重。

文件后端拒绝包含旧runtime.sqlite3的根目录；旧后端也拒绝文件后端根目录。现有blob包迁移需另行实现，当前使用新根目录重新安装。文件库user_version=1，不支持的版本拒绝，不自动重建损坏库。

## 2 安装及事务

1. 检查包/来源与存储根互不重叠，执行R0完整来源及组件验证；摘要变化拒绝。保留单文件8MiB、合计32MiB合成限额及三倍体积加1MiB余量预检。
2. 分配install_id，先取得对应内核文件字节锁，再提交copying状态。锁持续覆盖复制、封存和数据库登记，不按时间过期。
3. 在独立staging目录以排他创建写清单及成员，flush并fsync每个文件；核对复制字节，并再次完整验证来源与暂存包，然后提交verified状态。
4. 在同一本地文件系统内rename到packages/清单摘要。目录存在时不覆盖，使用固定来源重新验证已有目录；一致才允许本次安装复用，不一致则拒绝。提交sealed状态。
5. 单一短数据库事务登记ready包及回执，同时将该安装转为ready；包ID只能对应唯一清单摘要。失败不切换活动版本。

数据库登记前文件存在也不能激活。重复安装产生新的安装过程记录，复用同一不可变包；空间无效性或损坏不会通过重复请求被覆盖修复。目录被复用时，新的暂存目录可能保留；当前不自动清理任何孤立文件。

## 3 安装状态与恢复

正常状态为copying → verified → sealed → ready；阶段推进增加revision。捕获到执行异常，尽力记录failed与诊断；若数据库不可写，原状态保留，不能保证错误诊断一定持久化。

进程中断可能留下copying、verified或sealed。CLI提供installations列表、installation详情和recover-install。恢复先取得同一安装字节锁，在事务中匹配预期revision及非终态，将其变为interrupted并追加到该记录诊断字段。它不登记包、不激活、不删除目录；本轮不是完整的追加审计事件系统。

锁由操作系统在进程退出时释放；活进程持锁时返回owner_alive。恢复器与安装器遵循同一锁协议，锁文件从不主动unlink；锁文件存在本身不代表活进程。首批Windows使用msvcrt字节锁，POSIX分支未在本轮运行；网络文件系统、不同锁命名空间或不遵循协议的外部进程不支持。

中断之后使用新install命令重新验证来源并完成全流程，分配新install_id。完整孤立目录可在此流程中核对后复用；不能只执行recover就把文件升级成ready。ready、failed及interrupted均拒绝再次recover，过期revision返回冲突。

## 4 读取、切换与损坏

激活与会话固定继续复用R1a语义：读取已登记包，核对数据库清单、磁盘清单、回执与各成员摘要，场景一致且revision匹配才切换；两个进程争抢相同revision只有一个成功。

打开会话仍把小型合成成员读取到内存，旧会话不受新包切换或磁盘后续损坏影响；新会话发现缺件或坏摘要则拒绝，不自动回退。没有自动删除，当前不需跨进程文件引用计数。未来真实大图按需加载及缓存淘汰需要独立设计，不能由文件存储分离推导其已实现。

数据库不合法时初始化报错并保留原字节，不以空库替代；文件损坏也不自动覆盖。路径仍采用本地静态目录和链接/重解析点检查，适用受信任工程师账户，不抵御恶意并发替换或管理员篡改。

## 5 一致性承诺与验证出口

本轮保证经测试的进程中断和数据库失败路径下，未登记文件不可激活，已有活动指针不被安装失败改变。文件逐个fsync、SQLite synchronous=FULL和同卷rename不等于已验证物理断电持久性：目录元数据刷盘、文件系统/控制器差异、整机重启与损坏修复尚未验收。

证据见[验证记录](../validation/智能体运行包文件存储验证-2026-10-27.md)。下一步R1c先补运行包就绪/损坏核对和遗留目录清单，维持不自动删除，再确定大文件/分块性能与目标设备。R2可信同步、撤回、有效期及R3机器人SDK仍独立未实现；I4任务恢复未由本轮安装恢复完成。
