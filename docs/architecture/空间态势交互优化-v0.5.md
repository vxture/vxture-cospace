# 空间态势交互优化 v0.5

后续布局调整：右上角展示工具与人／机视图图标合并为一行；图层开关移至右下角开放排列，移除左侧图层卡片。原左下角状态信息移至图层开关下方并右对齐。窄屏图层开关采用两列排列；右侧概览保留底部操作区。以下双板块说明保留为迭代历史，当前布局以本段为准。当前验证使用 `experiments/scripts/space_corner_browser.js`，检查桌面与 390px 窄屏布局、图层和视图切换。

左侧信息栏拆为两个独立的 DS Card + Collapsible 板块，展开状态互不影响：

- 设备对象：空间说明、楼层与版本、搜索及设备列表。
- 显示图层：几何、标签、未知区域、网格的显示开关。

板块只保留一层背景与边框，标题直接作为整行折叠入口，移除 CardHeader 包裹按钮的嵌套结构。标题、搜索框、对象列表与图层文字统一使用 DS body-small 字号，通过中等字重与弱化颜色区分标题和说明；主图标使用 sm，折叠箭头使用 xs。标题高度采用 control-2xl，搜索与列表行高采用 control-xl，均引用 DS token。

左右信息栏使用边缘图形按钮控制滑入与滑出；收起时设置 inert，避免隐藏内容获得焦点。折角图片来自 yucer 项目的 `portals/app/public/screen/fold-bracket.png`，保存为工作台公共资源。动效遵循 DS 时长与缓动 token，并支持减少动态效果偏好。

右上角工具分为展示控制与双视图两行；右侧信息栏展示空间概览。设备详情贴近选中对象，名称与属性集中显示；面板根据视口尺寸调整位置，避免越界。切换空间关闭详情并重置选择。

保持独立大屏、新标签页打开和全屏空间展示。当前仍为合成数据界面原型，预览参数不作为认证依据。

验证脚本为 `experiments/scripts/space_refinement_browser.js`，覆盖两个板块独立收放、侧栏交互、详情位置、空间切换、窄屏与运行错误等 18 项。此前 v0.4 的大屏脚本保留为历史验证记录。
