# 智能体密钥委托与故障门禁补充

日期：2026-10-27。R2b第二批合成实验，补充[门禁参考设计](智能体有效性门禁参考设计-v0.1.md)。本批未接入原R1默认入口，authorized=false、robot_ready=false保持不变。

## 测试根与受限委托

预配测试根只验证一层签名委托，格式见[契约](../../contracts/schemas/test-delegation-v0.1.md)。调用方明确传入部署和期望版本，证书不能自行升级根或信任版本。子密钥限制角色、场景、签发时间及有效期；标记撤回的密钥拒绝使用。查询截止取三类证明、策略、离线时限和各签名子密钥有效期的交集。

状态库指纹增加子密钥角色、场景、有效期及撤回字段。不同信任上下文拒绝重新打开旧库，本批没有配置迁移和密钥轮换操作。测试根不提供根有效期、硬件锚、多层证书链或生产密钥管理。

## 未确认写入标记

accept先验签，再创建独立UUID文件到pending目录，写入消息类型及token摘要并flush/fsync；随后执行原数据库事务，成功提交后删除自己的标记。任何遗留条目都使新判定返回storage_error，不推断文件名或内容可用于清理。

| 情形 | 行为 |
|---|---|
| 逻辑冲突、回退等明确拒绝 | 回滚并删除本次标记，不影响原有效状态 |
| 数据库或文件操作失败 | 对象内锁存故障，保留已创建标记 |
| 提交前进程中断 | 标记遗留，其他已打开对象及重新打开对象拒绝放行 |
| 提交后、删除标记前中断 | 即使事务已提交仍拒绝，等待显式核对 |
| 创建标记前即无法写文件系统 | 仅能锁存当前对象，无法保证跨进程持久故障证据 |

没有自动解除或修复接口。未知条目同样阻断，不按超时删除。目录项持久化和物理断电未验证；管理员删除标记、恶意回滚数据库不在当前防护能力内。标记涵盖该库所有场景，优先保证保守拒绝，尚未细分故障范围。新增消息仍可能写入库，但遗留标记存在时不能放行查询。

## 查询与撤回顺序

判定先检查pending，再读取数据库状态快照；快照读取是本轮并发顺序边界。已经读取旧快照的查询可能在撤回提交后返回先前结果。撤回提交之后开始的新判定不能返回旧allowed；提交期间开始的新判定可能直接因pending返回storage_error。

已用两个线程、两个独立SQLite连接和明确屏障验证上述交错。另有独立进程的序号竞争和提交前强退测试；不能把线程查询试验称为跨进程查询/撤回验收，也不能承诺追回在途响应或已经执行的机器人动作。
