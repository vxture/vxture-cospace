# 内部交付流程验收清单

日期：2026-10-27。范围是合成报告的生成、归档和核对流程，面向内部工程师，承接[受控生成设计](交付报告受控生成与选择-v0.1.md)。流程通过不等于空间质量、生产交付或机器人授权。

## 自动流程及判定

experiments.scripts.delivery_acceptance使用现有测试合成工厂，临时创建文件运行包与恢复日志；需要Windows、Python3.14、Node及开发依赖pytest。测试私钥只在内存，源库在临时目录，结果只保留报告、回执及核对证据。工厂来自tests并非生产数据初始化接口，不接受外部现场资料或生产密钥。

生成调用真实Python CLI子进程，每阶段限时30秒；读取使用真实Uvicorn服务和本机HTTP，禁用代理、单请求限时5秒。服务预留系统分配的loopback端口，避免先找空闲端口再绑定的竞争；退出请求关闭服务并有界等待。只配置报告归档，无发布管理器，不覆盖发布/查询/PostgreSQL全链路。

| 自动用例组 | 必须观察到的结果 |
|---|---|
| clean | CLI退出0；无待处理项；生成前后源文件字节一致 |
| pending | 注入prepare提交后中断；CLI退出2；component_needs_attention |
| planned | 测试驱动建立恢复计划；CLI退出2；component_needs_attention |
| reconciled_missing_grant | 测试驱动对账完成；CLI退出2；proof_fields_missing，不能变成运行许可 |
| 四阶段共有 | 每次新批次；报告保留未授权、未评估有效性及无修复权限 |
| 归档 | 4个不同批次；无未清理临时名；回执键绑定实际报告摘要 |
| 实际HTTP列表及详情 | 列表4份，不自动选择；按每个固定键重新读取，批次及摘要一致，no-store |
| 旧报告 | 底层状态变动后clean历史报告仍是原观察，不自动改为实时结果 |
| 错误目标/缺报告/写请求 | 目标列表空、错误目标详情409、缺报告503、POST405，不回退 |
| 只读 | HTTP操作前后主归档字节一致 |
| 损坏 | 修改隔离副本的原字节，详情及列表503，不返回旧报告或部分成功 |

脚本内REQUIRED_CHECKS列出31个固定ID，成功必须执行全部且每项通过；空执行、只有部分成功或任一异常不能判通过。输出目录必须此前不存在，不能覆盖旧运行。输出创建成功后失败仍保存acceptance.json，记录已执行步骤和失败ID；一般异常只记录类型，不保留原异常正文或子进程原输出，避免测试私钥/敏感文本进入证据。故障发生在环境证据落盘时仍可能导致写入失败，不能保证磁盘不可写时一定有完整记录。

输出的passed只表示本脚本范围；production_accepted、authorized、robot_ready和repair_authorized始终false。browser_executed在此报告始终false，页面步骤由独立浏览器报告记录，不能通过修改标志补算。

## 页面核对

独立脚本experiments/scripts/delivery_acceptance_browser.js读取本次四份实际报告，共24项检查。它从实际API取得报告身份和诊断，再核对页面一致，不模拟底层数据。

| 页面用例 | 验收条件 |
|---|---|
| 刷新列表 | 4份报告，默认无选择，读取按钮禁用 |
| 逐份选择 | 切换清除旧内容；批次、摘要及待处理状态与实际API一致 |
| 问题呈现 | 原因码实际可见，缺grant不能显示为运行授权 |
| 刷新与场景变化 | 刷新清空选择与报告，换场景清除列表；错误场景无候选、不回退 |
| 工程师复核 | 展开完整绑定，核对真值/视图/用途/范围；区分观察时间与读取时间 |

前四行由独立浏览器脚本执行；最后一行为操作者复核要求，本批不冒称人工签章或生产身份验收。桌面截图仅辅助可读性检查。之前批次的故障响应、手机布局和迟到请求验证保持独立证据，本脚本不重复冒算。
