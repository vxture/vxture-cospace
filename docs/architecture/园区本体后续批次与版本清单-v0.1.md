## 版本冻结原则

第二阶段到 B05d 收口，交付“空间关联持有实例并能在固定模型中联查”。B06 服务交付、B07 地理配准、B08 专业完善和 B09 独立产品不并入本版本。现有人工消费草稿允许待修正状态，但不能以此宣称通过完整园区规则或现场验收。

B05c 原计划中的地图消费在本版本落实为明确的坐标与不可用交接契约，实际地理定位排入 B07。这是为遵守当前版本边界作出的实施拆分，不表示地图定位已经完成。

详细实现沿用 [第二阶段设计](空间关联本体消费第二阶段-v0.1.md) 与 [实施总表](园区本体实施批次与任务-v0.1.md)。生产 Environment reviewer 仍是上线必经步骤，不由 PR 合并代替。
