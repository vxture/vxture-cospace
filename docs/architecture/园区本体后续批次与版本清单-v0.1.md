## 版本冻结原则

B06按已确认的空间态势数据架构分为B06a数据合同、B06b固定采用、B06c在线离线同源消费、B06d验收上线。B06a—d已合并（PR #174—177），v0.12.0已完成生产审核与worker02上线（部署run 44864540163成功）。合同见 [对象语义成果](../../contracts/schemas/object-semantic-artifact-v0.1.md)，总体依据见 [统一数据架构](空间态势服务统一数据架构-v0.1.md)。

B05c由PR #172合入main，B05d已完成v0.11.0上线（部署run 44709310464成功）。B06d的验收、发布及回退条件见 [v0.12.0发布及回退说明](../50-deployment/object-semantic-delivery-release-2026-11-21.md) 与 [B06d验证](../validation/对象语义成果-B06d-2026-11-21.md)。

第二阶段到 B05d 收口，交付“空间关联持有实例并能在固定模型中联查”。B06 服务交付、B07 地理配准、B08 专业完善和 B09 独立产品不并入本版本。现有人工消费草稿允许待修正状态，但不能以此宣称通过完整园区规则或现场验收。

B05c 原计划中的地图消费在本版本落实为明确的坐标与不可用交接契约，实际地理定位排入 B07。这是为遵守当前版本边界作出的实施拆分，不表示地图定位已经完成。

详细实现沿用 [第二阶段设计](空间关联本体消费第二阶段-v0.1.md) 与 [实施总表](园区本体实施批次与任务-v0.1.md)。生产 Environment reviewer 仍是上线必经步骤，不由 PR 合并代替。
