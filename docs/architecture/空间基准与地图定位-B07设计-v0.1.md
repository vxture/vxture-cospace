# 空间基准与地图定位 B07

日期：2026-11-21。v0.12.0 已上线，B06 完成。B07 为后续独立版本；B07a 完成合同与交互预览；B07b—d 持续实现正式场景资料、独立审核、显式采用、WGS84 局部 ENU 地理适配与固定交付。阶段代码及浏览器验收完成后再发布，生产状态以部署记录为准。

## 产品目标与归属

将固定模型的局部坐标，通过有依据、有检查和审核的固定转换关系，映射到园区目标坐标，再由明确支持的地理适配器投放到地图。首版定位单位为对象点锚，不表示实体轮廓、模型完整覆盖或机器人定位精度。

当前目标收拢为精准地图成果：关注坐标与高程基准、控制资料质量、配准计算残差和地图成果精度。机器人运行时定位精度留到具体应用阶段，不纳入本批验收。地图成果精度须由真实控制资料和独立检查支持，不能用显示小数位、配准残差或设备标称值代替。

空间关联管理模型到目标基准的关系；公共资源—语义本体仍只管理 L1/L2，不依赖场景、地图、转换库或宿主数据库。场景登记经纬度仅用于入口标记，不能隐式作为模型原点。地图供应商、允许的参考系/适配器和审核政策属于配置管理；具体控制资料、参数、检查与采用属于场景工作数据。

## 数据架构

| 数据 | 必需内容 | 生命周期 |
| --- | --- | --- |
| 模型基准 | 场景/候选、模型清单与内容摘要、frame、单位、轴向、手性、适用范围 | 绑定固定模型；来源改变则重新核对 |
| 目标基准 | 园区控制网或投影坐标系、完整定义引用、轴/单位、高程及依据 | 不因填写 EPSG 字符串就声称可转换；地理适配能力另行记录 |
| 控制资料 | 同名点、源/目标坐标、拟合或检查用途、证据引用 | 检查点不得作为同次拟合输入；资料责任人核实真实独立性 |
| 转换候选 | 明确源→目标方向、方法、矩阵、输入摘要、适用范围 | 计算产生候选，不产生批准 |
| 检查报告 | 逐点水平/垂直差值、两组各自 RMSE/最大误差、用途门限 | 从原输入重算，客户端摘要不替代服务端复核 |
| 核准修订 | 责任主体、审核依据/时刻、允许用途/范围/有效期、固定来源和报告 | 后续 B07b 设计持久化；不得由客户端布尔值授予能力 |
| 地理成果 | 核准转换与地理适配的依赖闭包、点位、误差和能力限制 | B07c/d 进入地图及固定发布；旧发布不读最新参数 |

B07a 输入/候选仅支持米制、右手源框架到 east/north/up 米制目标的已知三维刚体参数核对。单位换算须预先有依据地完成；不估计尺度，不接受镜像、剪切、任意矩阵或把角度坐标送入刚体计算。目标可以是工程或投影坐标，但当前没有 CRS 到经纬度的适配器，始终 can_focus_geographic_map=false。目标高程必须明确；未知高程的水平路线在后续单独支持，不以 0 补高。

拟合与检查各至少三个非共线点，避免重复源点/目标点冒充独立资料。平面点可用于刚体参数核对，但不证明全高程或全园区精度。门限按用途给定，报告不把 RMSE 当作绝对精度或独立专业验收。所有点必须位于当前声明模型范围；未来消费还须检查点是否位于核准适用范围与有效期。

## 可视化工作面

沿用空间关联既有导航，关联概览内容区进入“空间基准”，返回沿用原场景/候选。对象、控制点与方案放内容清单，不扩充左导航，也不增加二次导航。B07a 在独立开发预览中验证布局，尚不向真实场景展示合成资料。

展示与编辑使用不同工作面。展示页采用紧凑页头、行内状态/指标、并排模型与目标视图；下方控制点清单独占整行，检查点残差紧随其下。宽屏按 1536px 外框、1440px 内容宽度控制，残差区三个点位等宽横向排列，窄屏改为纵向排列。清单与残差图保持完整宽度及上下阅读顺序，不再单独铺设重复的选中点摘要行。

编辑进入全屏底图框架，工程平面铺满工作区，控制点清单、可放大的模型对照小窗和点位属性面板浮于图上并支持收起；画布提供平移、缩放和适配。默认取景避让展开面板，修改坐标时保持当前视角，用户显式适配才重新取景。窄屏面板互斥展开。沿用 DS 的焦点约束、退出修改保护和抽屉，工作面层级低于依据抽屉及确认面板。

目标尚未接入地图时明确写“米制工程平面 · 非地理底图”，保留坐标轴与比例尺，不能绘制虚构街道/瓦片。模型显示真正三维可旋转的合成点云，控制点编号与目标视图、表格和误差图共享 selected_control_id。

目标视图提供配准前/参数变换后比较。同名点的实测位置用方形、变换位置用圆形，拟合/检查兼用编号 F/K 和图例区别，颜色不单独承载含义。误差图单列检查点，每点呈现水平及垂直误差与明确门限；不在地图上偷偷放大位移。列表选择、画布选择、误差条选择一致，选中时展示真实数值。

查看依据通过右侧 512px 抽屉，不将长参数编辑铺满主画面。查看、编辑、审核采用不同操作状态。B07a 编辑原型仅调整本地目标坐标，明确使用“应用到预览”，应用后返回展示页并重算误差；刷新或切换算例重置本地资料，不产生服务器保存、审核或发布。非法/重复坐标阻止应用，取消及刷新前保护未应用修改。正式持久化与审核仍属于 B07b，发布另行固定。

操作行 32px、文字 12px；正文按钮 32px/14px；序号/操作列 64px 居中，三点按钮外 32px、内 icon 24px，菜单仅图标+条目与分隔线。表头居中、名称列居左。使用既有 DS、开放式表格和细分隔，不做多层卡片嵌套。宽屏双视图、窄屏纵向排列，表格自身横向滚动，页面不溢出。深浅主题、键盘选择及渲染失败时的坐标清单均可用。

控制点清单用两层分组表头和独立数值列表示坐标：模型 X/Y/Z 按来源轴向标注含义，目标 E/N/U 分别标注东/北/高，局部坐标不能冒作地理方向。坐标单位为 m，清单显示至 0.01 m；输入保留原始数值，不因显示舍入而写回。计算残差、RMSE 和门限统一用 cm 并显示一位小数，原始计算、存储和门限比较始终使用未舍入的米值。0.1 cm 是计算读数的显示分辨率，不构成毫米实测精度承诺；实际成果精度及适用范围仍待控制资料核验。

## B07b—d 实施补充

正式入口是空间关联的关联概览内容区“管理空间基准”，沿用固定场景/候选，左导航保持既有分组。没有资料时展示真实空状态；下载绑定来源的空白模板、导入资料、服务端非持久核对、全屏修改目标坐标、保存草稿、提交审核、另一位场景管理员核准、显式采用分别执行。合成标记资料不能进入真实审核。新草稿不移动原已采用指针，核准不自动采用，工作数据改变不影响已发布成果。

宿主持有 preview-directory/scene-registrations.sqlite3，按可信 issuer/org/workspace 与场景/候选分隔，追加修订、幂等请求和乐观锁。GET 不建库；权限在模型 I/O 前；CSRF、严格字段、资料大小、来源轴/单位、模型范围、三维刚体、控制/检查几何和服务端重算均独立校验。审核保存责任主体、依据、核准范围及有效期；采用固定 approve 修订，重复采用不得漂移。读取完整性损坏直接拒绝，不回退最新草稿。部署 checkpoint 纳入新数据库。

首条地理路线是 wgs84_local_enu/1，通过宿主 COSPACE_REGISTRATION_ADAPTERS 显式启用，配置示例 deploy/config/registration.env.example。该配置属于宿主引擎配置，不属于公共本体目录。仅接受 WGS84 局部 ENU 的目标资料，记录 WGS84(G1762/G2139/G2296) 实现、十进制年坐标历元、测量原点经纬度、原点椭球高及证据。实现与历元用于标明坐标来源，本版不执行不同实现/历元之间的转换，不支持 CGCS2000、投影 CRS、GCJ02 作为成果基准或正高/大地水准面转换；不推断缺失基准。

E/N/U 为原点切平面局部坐标；U 不是绝对椭球高。采用 WGS84 椭球与 ENU/ECEF 数学转换，限制原点周围 20 km，模型边界、核准范围及有效期共同限制对象点锚输出。无需外部网格或在线转换服务即可离线重算。二维地图通过既有高德官方转换服务生成 GCJ02 显示副本，三维地球保留标准地理坐标与绝对椭球高；高德/影像显示偏差不构成测量精度验收。缺配置、过期或范围外明确给出原因，不借场景入口经纬度定位。

发布准备中显式勾选“纳入核准配准成果”，预检固定 registration_revision/source_manifest_sha256/snapshot_sha256。冻结 registration-artifact.json（控制资料、参数、服务端报告、核准依据、有效范围/时间、地理适配闭包），发布指针保持与模型摘要一致。在线 /publications/{id}/api/registration 与完整离线 profile 0.6 使用同一验证和投影函数。未纳入的旧版本保持未纳入；旧客户端拒绝0.6，新客户端可继续读取旧包。分区包不支持配准闭包，明确拒绝，不静默遗漏。本地消费会话与两个离线 CLI 提供 registration/--registration 查询；默认按当前 UTC 时刻检查有效期，可显式 --at 复核历史时刻，不切换包或工作采用。

本阶段所有自动检查和浏览器数据均为工程验收证据，不是现场成果精度验收。真实园区仍需有来源可核实的控制资料与独立检查，并由不同责任人审核；不能将复选框、残差读数、数学往返精度或底图显示当作厘米/毫米现场精度。
