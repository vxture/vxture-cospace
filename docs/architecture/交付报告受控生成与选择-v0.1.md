# 交付报告受控生成与选择

日期：2026-10-27。承接[生成上下文契约](../../contracts/schemas/delivery-generation-v0.1.md)，本批实现本地生成、独立归档和工作台固定选择。“受控”指显式输入、输出隔离及不覆盖，不表示生产身份认证。

## 生成和发布

独立CLI experiments.scripts.delivery_generate要求files、journal、binding、output及可选limit。生成前检查输出目录与两个数据根及binding文件不能互相包含，复用链接/重解析点检查。输入为可信本地操作者指定，不是恶意本地用户沙箱。源数据只读，输出目录可新建；不修复或迁移源库。诊断存在待处理项但形成合法报告时仍保存，退出码2；参数或保存错误输出error，不能当成保存回执。

保存器只接受经结构与上下文关联校验的0.2报告，以canonical生成UTF-8字节，上限2MiB。最终名为`<UUID4>.<SHA256>.json`。摘要覆盖实际保存字节，因此可能不同于原格式化文件；批次与完整摘要共同组成report_key。同批次不同内容保存为不同键，不以时间或UUID单独推断相同内容。本批无全局批次注册或来源认证。

先在同目录独占创建随机.writing-UUID，写完flush/fsync，再用os.link原子发布完整字节，目标存在立即冲突，不覆盖、不回退复制。不支持硬链接的文件系统失败。最后删除本次临时名，保留最终链接。并发相同键只有一方成功，不把冲突自动当幂等成功。

link前进程退出可能遗留临时文件；link后清理前退出可能保留两个名称，最终文件仍可读。发布后清理失败可能返回错误但最终文件已存在，操作者须核对键及字节，不盲重试。本批无自动清理。原子可见和fsync不代表目录fsync、物理断电、网络盘或磁盘故障恢复已验收。

## 目录与只读接口

配置COSPACE_DELIVERY_ARCHIVE固定服务端目录，客户端不能指定路径。旧COSPACE_DELIVERY_REPORT单文件入口独立保留。

- GET /scenes/{scene}/releases/{release}/delivery-reports：目标报告列表，按固定键字典序。
- GET /scenes/{scene}/releases/{release}/delivery-reports/{report_key}：重新读取并校验原字节摘要及内部report_id，失败不回退。

目录最多200项，包括被忽略的临时和不识别条目；只处理UUID形状及摘要命名的.json，再验规范UUID4。目标报告最多50份，超限拒绝，无分页、不截断成功。每份最多2MiB。目标不匹配报告跳过，在目标筛选阶段即跳过，不承诺验证其文件键；目标报告损坏或其他读取失败拒绝整个列表。

列表读取多个独立文件，不是目录事务，可能看到并发新增前/后的集合。选择后再次核对固定键。文件可被外部操作者修改，“不覆盖”是保存器规则而非系统权限；旧键字节不符会拒绝，无签名不防伪造来源。缺目录不初始化；503为未配置、不可读、超限或键无效，409为详情目标不匹配。所有响应no-store，Web无写方法。

## 页面与下一步

刷新列表清除旧列表、选择和报告，不自动选最新。显式选择后展示版本、用途、普通时钟观察结束及可展开完整绑定，再读取固定键。切换选项清除旧摘要，失败不回退单文件或其他批次。场景/发布变化继续取消旧请求。旧单文件按钮只读原配置，不随目录选择改变。

选择不改变发布、运行包或门禁；Web不触发扫描或保存。见[运行](../guides/交付报告归档运行.md)和[验证](../validation/交付报告归档与选择验证-2026-10-27.md)。下一批整合内部交付端到端验收脚本和用例，覆盖生成、归档、刷新、选择及异常核对，再细化长期存储与权限。真实构建、机器人授权及I4仍独立未完成。
