# 空间态势服务数据责任与交付边界 v0.1

日期：2026-11-20。产品边界设计；不表示下列规划能力均已实现。完整机器人数据需求保留在《机器人消费数据需求与行业对照》，本文件确定 CoSpace 的责任范围；B06 据此收敛。

## 产品职责

空间态势服务提供有空间基准、有对象语义、有时间与来源、可查询和固定发布的环境及态势数据成果。机器人、业务系统和人员都是消费方。机器人能够独立使用其中某项成果，但机器人的完整作业能力不由本平台交付。

完整行业需求是分析参考，不是产品交付清单。区分两条轴：一条是本平台负责、外部接入或外部负责；另一条是当前已有、待建设、当前不可提供。属于产品职责不等于本版本已有，外部数据可显示不等于平台成为其原始权威或控制方。

## 数据责任矩阵

| 内容 | 本平台应提供的成果 | 接入方/消费方负责 | 当前发布边界 |

| 本体与实例语义 | 固定定义闭包、对象分类、显式属性/关系、有效期、依据、局部校验 | 专业审查/现场核实由相应责任人完成 | B06新增固定成果采用与分发；不将局部校验升级成现场事实 |

| 环境通行特征 | 有证据的通道尺寸、坡度/台阶、地面条件、覆盖和未知区域；后续可发布经验证的空间通行成果 | 机器人厂商负责尺寸/载荷/制动/转弯能力及适用判定，集成方验证现场 | 当前表面单元不能当自由空间或可通行区域，不纳入B06新增 |
| 空间拓扑与设施资源 | 有依据的入口/通道/楼层连接、门梯/充电点位置、资源身份和能力描述 | 外部系统提供设施状态、接口及控制权限，机器人/调度负责调用与交通执行 | 环境资源图属规划职责；调度路权分配和设施控制不交付 |
| 任务的空间上下文 | 目标对象/区域、空间位置、管理方提供的检查区域/兴趣点；可纳管经验证的作业站位 | 任务系统制定动作/顺序/判据，机器人确认可达性、观察条件并执行 | 对象点锚不是作业站位；B06不新增任务执行成果 |
| 动态态势 | 接入后对齐到对象/区域的状态、告警、临时封闭等，提供来源、时间、新鲜度、历史窗口或固定快照 | 设备/业务系统产生观测；机器人执行实时感知、局部避障及控制 | 属产品方向但仅交付实际接通的数据；失效显式标识，不承诺实时性或完整性 |
| 质量、来源与版本 | 各成果的清单、固定依赖、摘要、范围、证据引用、校验结果和已知缺失 | 原始权威方负责资料真实性；专业与现场验收按职责签核 | B06必须明确；不能以摘要完整性替代专业质量与授权 |
| 机器人专用定位地图 | 可提供已获授权的环境参考成果及框架绑定；可纳管外部定位成果并记录适配范围 | 厂商/集成方负责算法所需地图、标定、定位实现与验证 | 通用点云不自动成为定位地图；不作为默认标准交付 |
| 机器人自身与运行数据 | 仅在确需态势展示时接入必要状态及其来源 | 机体/传感器模型、URDF、标定、TF、里程计、实时位姿/置信度、原始障碍观测由机器人侧负责 | 不生成、不保证、不打包为园区标准成果 |
| 调度、动作与安全控制 | 提供环境信息和授权的数据服务 | 车队调度、实时预约、轨迹、速度控制、底盘/机械臂、门梯控制、急停/安全回路由相应系统负责 | 不属于本平台交付责任；接口接入也不转移控制责任 |

动态态势属于本产品，机器人内部的实时闭环数据不属于本产品交付。即使某项机器人位姿或设施状态被接入地图，也只是带时效和来源的外部状态，不能将其包装为平台产生的定位能力或控制能力。

## 对外交付的成果目录

1. 空间基础成果：所选范围、框架及实际具备的几何/表达/覆盖；不默认带全部原始资料。
2. 对象语义成果：对象索引、固定定义与实例、关系、有效期、依据及声明范围。
3. 环境约束与资源成果：空间规则、通行特征、连接与设施资源；每项仅在建设和验证完成后启用。
4. 态势成果：实际接入的观测、事件及空间关联，区分在线状态和有截止时刻的快照。
5. 派生分析成果：实际支持的分析结果，固定输入、方法、参数及适用范围；不预设已具备影响分析或机器人路径规划。

每项成果均附版本、依赖、质量和访问说明；上述为可独立选择的成果类别，不要求每次交付五类齐全。“未建设”“无来源”“未授权”“已过期”“超出范围”分别标识，不能空包冒充完整。

机器人专用格式或任务系统协议是后续面向具体客户的适配输出，独立声明版本和测试范围；不通过接上VDA5050、ROS或Open-RMF名称来宣称完整兼容与可作业。

## B06 冻结范围

B06交付“已有固定空间发布 + 可选对象语义成果”，明确包含的成员与证据引用，不默认补齐原始点云或全部视觉表达。显式固定消费修订及定义闭包，在线与离线同源，旧发布不读取最新值。已有业务/关系快照沿用原合同，分别展示与模块化语义的职责。

B06不新增：定位地图生成、自由空间重建、交通调度、机器人任务控制、实时感知避障、门梯联动、机器人专用运行配置、安全控制及现场适配认证。规则/资源/动态态势等属于产品总体方向，但需要独立数据来源、合同和批次，不以本文件将其纳入当前交付。

对外能力表述为“空间数据查询、对象语义查询、固定成果消费”等实际能力，保留机器人导航/执行未验证状态，不以robot_ready笼统表示全部能力。按产品边界逐项声明外部依赖，已发布且声明可离线自包含的成果不得隐藏依赖在线最新数据。
