# P24 激光多帧建图接入

状态：已完成本机验收，见对应P24验收报告；沿用场景空间、资料、批次、构建、双视图及固定发布。

## 范围

使用封存的 multi/1 OS1-16 一秒真实样本，10帧点云。选择纯激光、相邻扫描、双向ICP检查与首帧局部累积，一种路线先跑通。不使用Leica位姿或IMU冒充建图输出，不做精度排名。原始资料、旧单帧格式及历史成果不改变。

## 执行顺序与验收

1. 样本核对与离线实际配准：逐消息摘要、递增时间、一致坐标系、每帧有效点；记录真实估计位姿、配准诊断与运行依赖。非首帧必须实际参与模型，失败停止且保留已保存前缀。
2. 接入现有冻结模型、独立双视图、发布链路：新格式 `ros1_lidar_multiframe_icp`，保留旧格式语义；新增激光过程剖面，复用已有点块写入及全屏回放。
3. 本机验收：真实样本UI导入→预检→封存批次→建图→逐帧回放→双视图→核对→发布→在线／独立离线消费；失败恢复、篡改拒绝、归属隔离、重启、旧路线回归。

## 已知边界

2～20帧受支持ROS1样本，bag≤32MiB；源消息时间未验证UTC同步。模型基准为首帧激光，未对齐现场坐标。无回环、全局图优化、运动畸变补偿或IMU融合，无独立精度验收。质量unverified、robot_ready=false，其余空间状态未知。标定包YAML与URDF存在差异，本批不消费跨传感器外参。
