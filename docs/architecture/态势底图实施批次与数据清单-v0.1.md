## 3. 需要补充或核实的资料

## 4. SG0 已实现边界

- `cospace.synthetic-scene-graph/0.1`，独立于现有 preview / agent-package 协议。
- 11 个实体、17 个简化几何表达、12 条关系、3 个结构连接、1 条门状态观测；全部合成且未核实。
- 几何表达限近似 AABB、参考点和矩形连接端口，不能当精细表面、完整房间实体或实测截面。
- 本体为合成内嵌词表；证据和状态源均为合成来源。
- 校验身份唯一、引用闭合、类型/角色、坐标和形状、关系单父/无环、端口所属构件、观测对象与时间。
- 读取实体及空间连接；门的 closed 状态不会删除结构连接，也不会产生可通行判定。
- 保留观测原记录；SG0 不按接收时间覆盖、不解决冲突、不计算“当前最新门状态”。
- 缺块、真实数据、额外的通行字段、错误端口等不能借校验通过升级为正式能力。
