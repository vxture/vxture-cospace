## 3. 需要补充或核实的资料

| 缺项 | 当前影响 | 可以先做什么 |
|---|---|---|
| 点云与 IFC 的可靠对应点、已知变换或同坐标说明 | 不能把 IFC 设计构件直接声称与实测点云一致 | 独立解析 IFC 原坐标与点云来源；算法配准只出候选，后续核验 |
| 房间/楼道边界、名称或可核对的平面图 | 五份 IFC 未显式提供空间单元，不足以直接确认房间结构 | 检查实际几何，半自动划分与人工标注；存在平面图时再补入依据 |
| 配电柜等资产的可辨识图像、资产表或人工位置确认 | 不能可靠认定某几何对象就是指定资产 | 先做门/楼梯等已有语义；柜体可标待核实，不能虚构真实身份 |
| 门状态等当前观测、来源与时间 | 不能发布当前开关态势 | 静态底图照常推进，状态明确未提供；不把设计门扇姿态当实时状态 |

以上不阻塞 SG0/SG1 和 IFC 结构候选提取。需要补充时优先提供上述事实依据，无需重发已有点云。如果既有目录已有对应资料，后续先查找并核对，不要求重复采集。

## 4. SG0 已实现边界

- `cospace.synthetic-scene-graph/0.1`，独立于现有 preview / agent-package 协议。
- 11 个实体、17 个简化几何表达、12 条关系、3 个结构连接、1 条门状态观测；全部合成且未核实。
- 几何表达限近似 AABB、参考点和矩形连接端口，不能当精细表面、完整房间实体或实测截面。
- 本体为合成内嵌词表；证据和状态源均为合成来源。
- 校验身份唯一、引用闭合、类型/角色、坐标和形状、关系单父/无环、端口所属构件、观测对象与时间。
- 读取实体及空间连接；门的 closed 状态不会删除结构连接，也不会产生可通行判定。
- 保留观测原记录；SG0 不按接收时间覆盖、不解决冲突、不计算“当前最新门状态”。
- 缺块、真实数据、额外的通行字段、错误端口等不能借校验通过升级为正式能力。

验收记录见[SG0 实施验证](../validation/态势底图SG0契约与资料盘点-2026-11-16.md)。
