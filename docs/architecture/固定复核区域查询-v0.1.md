# 固定复核区域查询 v0.1

日期：2026-11-17。将 SG3 的已填写区域/端点候选变为 SG4 可消费的坐标查询，并为 SG5 的同快照观测读取提供显式对象选择。不是导航、真实区域识别或正式发布。

## 输入与核验

内部方法 `packages.service.ifc_review_regions.query_review_regions` 接收快照原始字节、严格 query、固定设计包、外部可信 SourcePin 和必要的本体原文件。复用整个复核快照读取校验：摘要、规范 JSON、包内完整组件、区域几何和引用、任务/端点、固定本体与类型提案；损坏不能降级成无匹配。调用方须先授权来源、快照及本体，不新增公开 HTTP、平台鉴权请求或写入。

query Schema：contracts/schemas/ifc-review-region-query-v0.1.schema.json。字段为 snapshot_sha256、frame_id、point_xyz_m（三个有限米制数值）、boundary_tolerance_m（明确输入 0–1 m）。点坐标与每轴值沿用 ±1,000,000 预算；不接受自动换坐标、猜单位、设备外形或其他参数。frame 必须等于快照原 IFC 坐标系。单位/对齐未现场核验的限制仍保留，不能把机器人自身坐标直接当 IFC 原坐标。

## 区域形态与边界

仅支持现有标注的单环简单 XY 多边形乘统一 Z 区间形成的 2.5D 棱柱，无洞、斜顶或任意三维闭合体。扫描全部最多 512 个区域、每环最多 128 个顶点，不使用 AABB 代替多边形包含。几何核验在查询之前完成，不以“无效区域跳过”掩盖缺陷。

对每个区域计算点到棱柱边界的欧氏距离：XY 线段距离包含投影内部/端点；XY 在外且 Z 也在外时使用两个距离的平方和开方，避免把角点附近的方盒扩张当成欧氏容差。XY 内部采用射线穿越规则，正反绕序一致；凹多边形凹口不归入内部。

- interior：点位于区域内，距所有边界超过输入容差。
- boundary_candidate：点距边界不大于容差，**包括紧邻边界外侧**；不强制归入某一区域。容差为 0 时仍保留数学边/顶点/上下表面。
- 不命中该区域：不输出该区域。总体无命中返回 no_match。

返回所有命中区域及其原局部 ID、名称、声明楼层和证据引用、分类与 boundary_distance_m；重叠区域/共享边界不挑一个“正确房间”，顺序沿用工作表。距离不是点云测量精度、净空或物理可行性。浮点计算不是任意精度谓词，临界值会有舍入；应根据具体复核需求显式设置容差，不能用它声称现场误差已达标。

## 连接与状态衔接

返回明确关联到任一命中区域的原连接标注，每个任务只出现一次。保留所有已填写端点（含对侧区域）、原来源实体/element_id/类型、证据引用和 complete/partial 标注状态。complete 只表示标注与引用自洽，不等于已确认连接；无端点任务不会凭邻近关系关联到区域，不推断相邻、通道或路径。

door_element_ids 是所涉门的显式编号，供[同快照观测上下文](复核快照与观测上下文-v0.1.md)读取；不自动访问日志、登记来源或获取权限。door_observation_batch_supported 仅在 1–128 项时为 true，调用方先检查该值；0 项不需查询，超过 128 项必须显式分批，多个批次不保证一个全局观测截面。编号不含楼梯，报告或门 closed 状态不删除结构标注，也不决定通行。

响应 `cospace.ifc-review-region-query/0.1` 固定请求、来源及结果，cursor 对上述完整响应计算摘要，绑定快照、坐标与容差。它不是签名或授权令牌，不与观测 cursor 混用；若再读状态，应保留两份结果及相同 snapshot_sha256。实时状态改变不修改本查询的静态结果。

## 覆盖与失败

区域为空时 annotation_coverage=no_regions_provided；存在区域但无命中时为 provided_regions_only + no_match。两者都不能证明点在建筑外、空间空闲、模型完整或可以通行。数据损坏、坐标系不符、非法参数、缺本体等保持错误，不返回空数组充当成功。

alignment_verified、ontology_bound、real_release_ready 均 false；confirmed_connections 为空。证据引用来自未核实标注，未读取证据文件，不认证其内容或现场事实。本轮使用同一固定设计源，不处理跨版身份迁移或发布。

## 本地使用

```text
python -m experiments.scripts.ifc_review_regions --snapshot <snapshot.json> --design-package <design.bin> --source <可信SourcePin.json> --query <query.json> --output <新结果.json>
```

有本体映射时增加 --ontology。query 示例结构：

```json
{"snapshot_sha256":"<可信快照摘要>","frame_id":"<快照坐标系>","point_xyz_m":[1,1,1],"boundary_tolerance_m":0.01}
```

摘要和 frame 必须从可信固定上下文获得，不照抄占位符。CLI 为有文件权限的本地工具，未执行线上认证；输出独占创建，拒绝覆盖。读取数据和结果留受控目录，不进入 Git。验证见[实施记录](../validation/态势底图SG3-SG5区域查询.md)。
