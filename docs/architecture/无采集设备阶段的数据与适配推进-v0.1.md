# 无采集设备阶段的数据与适配推进 v0.1

日期：2026-10-28。用户已确认当前未对接采集设备。首版目标仍为普通设备间及相连走廊，不将设备采购或现场资料到位设为所有研发的前置条件。

## 三类资料分别验收

| 资料 | 当前用途 | 不能替代的证据 |
|---|---|---|
| 合成容器与空间样例 | 验证格式、字段、数值、失败分支、版本和服务契约 | 实际传感噪声、标定、同步、建图效果和现场质量 |
| 经确认可用于本项目的公开短序列 | 首轮离线输入适配和隔离算法回放，保留原始格式与来源 | 目标设备间的覆盖、设备适配及独立现场验收 |
| 未来设备接入与现场资料 | 验证实际硬件、时间/标定、声明用途、独立复测及消费能力 | 不能反过来删除已记录的公共数据或合成失败结果 |

## 当前已推进

E01a新增离线 ROS1 bag PointCloud2/Imu 解析器；实际合成容器读写与拒绝路径已验证。原 ROS1 脚本和未成功下载镜像的历史记录保留，不将本次结果归到旧工具。依赖固定在可选 input extra，既有 API 与安装器无需依赖它。

适配前按 bag、MCAP、PCD、PLY、LAS/LAZ、ROS2 db3 扩展名盘点时未发现实测日志；用户已确认当前未对接采集设备，现场资料接入列为后续任务。后续已从官方源取得NCLT传感包并完成ms25原生CSV预检，见[公开输入选择记录](公开输入选择与NCLT首批适配-2026-10-28.md)；激光数据和算法回放仍未完成。

## 后续执行顺序

1. 首批选择NCLT 2013-01-10原生传感数据，已经核对官方数据许可并取得sensor archive/ms25；下一步处理原生激光分包和短序列时序。不将IMU单项通过等同完整序列准入，沿用[已有来源记录](算法数据与运行环境核验记录-2026-10-26.md)。
2. 优先与现有适配器匹配的 PointCloud2 + IMU 日志；若合适资料只有 MCAP、ROS2 或自定义消息，按实际数据补相应适配器，不为适配现有代码伪造点时间/ring。
3. 对实际字节执行预检并补点时间单位、时间参考、同步、外参和IMU约定。缺失项明确阻止算法准入；仅格式通过可以用于诊断，不自动进入回放。
4. 输入适配明确后，建立固定算法与环境的隔离回放。FAST-LIO/LIO-SAM仍是对照候选，需分别满足数据条件；不同时安装所有候选。
5. 保留算法原生轨迹/几何与配置，按证据修订空间候选契约。具有独立参考的部分才开展误差评估；正式真值采用、双视图与发布按 P3 单独推进。

## 设备接入时的最小交接内容

传感器型号/固件、原生日志及消息定义、点时间和IMU单位/轴向、时钟与同步说明、外参方向与来源、采集运动/静置条件、资料用途角色。设备尚未确定时不预填标定矩阵或精度等级。现有[数据需求](数据采集与独立校核需求-v0.1.md)继续作为后续现场采集依据。
