# 工作台公共内容容器

普通页面统一使用 `WorkspaceContent`，内部复用 DS `ShellPageContainer`。导航、滚动视口与内容容器独立；1536px 上限只包含内容外框，不包含板块导航。各页面不再单独声明外框宽度或左右、底部留白。

| 用途 | DS token / 工具类 | 默认密度、16px 根字号下的结果 |
| --- | --- | --- |
| 外框上限 | `width="wide-2xl"` / `--container-content-wide-2xl` | 1536px |
| 窄区域左右留白 | `--space-md` | 各16px |
| 中等区域左右留白 | `--space-xl` | 各32px |
| 宽区域左右留白 | `--space-3xl` | 各48px，正文上限1440px |
| 顶部留白 | `--space-lg` | 24px |
| 底部安全留白 | `--space-6xl` + `env(safe-area-inset-bottom)` | 80px + 设备安全区域 |
| 工作页内容间距 | `--space-md` | 16px |

左右留白使用 DS `@page-sm/workspace`、`@page-lg/workspace` 容器查询，由 `.workspace-content-viewport` 提供导航后的实际可用宽度。查询阈值由 DS 生成，业务 CSS 不复制断点数值；默认16px，中等区域32px，宽区域48px。尺寸随 DS 密度和字号偏好响应。

页头、工具栏、清单和正文位于同一容器。构建、配准、关联及发布保留外层滚动区域；数据工作面采用外层页面纵向滚动，保留表格横向滚动和右侧详情面板，避免长内容将表格压缩至零高度。加载、错误、无场景与无权限状态同样使用公共容器。

首页连续区域共用同一横向容器；前两个区域采用 `section`，最后一个区域保留完整底部安全留白。地图模式、独立三维空间和全屏配准编辑器沿用其画布布局，不嵌套普通页面容器。

接入范围：首页、我的场景、空间服务、公共数据目录、场景数据、语义本体目录及详情、构建中心、空间基准、空间关联、服务发布、配置管理与个人信息。
