# 园区环境与运维语义 B08d

在公共资源中提供 `monitoring@0.2.0` 和 `operations@0.3.0` 两个独立预置草案。两者只依赖固定的核心 `0.1.0`，可独立发布；场景能在同一固定修订中组合消费。

| 要回答的问题 | 定义与约束 | 反例 |
| --- | --- | --- |
| 哪次空气温度观测，由什么设备按什么方法得到，观测的是哪处空间？ | 单次观测有 Celsius 温度值、量纲和方法。用有依据的关系分别关联来源传感器及被测空间；采样时刻由来源记录保留。 | 安装走廊不代表观测走廊；K 值不能直接登记为 °C；没有方法的观测不能采用。 |
| 某次巡检报告针对哪个点，巡检点查什么？ | 巡检点指向对象或空间，巡检报告指向指定点并保留来源中的结果表述。巡检点、受检对象、报告和工单有独立身份。 | 工单存在不能充当已执行报告；巡检报告不能充当设备最新状态；点锚不保证可达。 |

环境部分参考 [W3C SOSA/SSN 推荐标准](https://www.w3.org/TR/2017/REC-vocab-ssn-20171019/)，区分传感器、观测活动、被测对象、结果和程序。运维部分参考 buildingSMART 的 [IfcTask](https://github.com/buildingSMART/IFC4.3.x-development/blob/0f1c7acb287740d7d40e2d0021c216a9cdf638ab/docs/schemas/core/IfcProcessExtension/Entities/IfcTask.md)，区分任务/过程、涉及对象及外部来源记录。本批不实现标准交换。

[制造园区合成样例](../../examples/ontology/parks/manufacturing-monitoring-operations-b08d.json) 验证独立版本审批、混合闭包及固定交付，旧版本及定稿均保持可读。程序校验类型、必填属性、单位、关系方向、端点和声明有效期；采样时刻仍是来源证据的一部分，不做时间查询或数据新鲜度判断。采用前须核验真实证据，不提供实时遥测、健康判断、巡检派单或专业结论。
