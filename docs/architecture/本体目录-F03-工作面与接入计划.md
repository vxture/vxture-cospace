# 本体目录 F03 工作面与接入计划

日期：2026-11-20。

## 导航与内容

沿用一个 DS 业务导航组“本体资源”，条目为全部本体、通用核心、领域本体。分组、单个本体、概念及关系均不进入导航；不增加顶部分类导航或第二侧栏。

内容区是本体清单。首批表格列：序号、本体名称 / 标识、语义范围、层级、概念 / 关系、版本与状态、操作。序号与操作均固定 64px、居中、左右各 16px 内边距；操作按钮外框 32px，图标 24px，菜单项采用图标加名称。名称可直接打开详情。当前只有真实可用的查看操作。

## 分组接入

分组配置独立保留于配置管理。业务内容区使用可检索的分组筛选，另提供“未归组”；分组不作为第二导航。清单将增加分组字段，允许一个本体归属多个分组，归组不改变本体定义、版本及摘要。归组操作位于行操作面板，不能从业务界面创建分组配置。

读取目录所需分组元数据应通过业务只读契约开放，不复用要求管理员身份的配置管理接口。写归组单独检查业务权限及并发修订，作用域和操作者由宿主注入。停用分组保留已有关系与名称解释，禁止新增关联，但允许移出。

## 接口与实施顺序

1. 统一现有只读目录表格规范，保持固定导航、搜索、排序、分页与详情路径。
2. 独立归组存储及查询用例：多归组、未归组、有效分组校验、作用域隔离、并发冲突、幂等提交；配置与业务持久化边界明确。
3. 提供业务分组查询、本体摘要检索及固定版本详情读取接口。摘要执行服务端筛选、稳定排序和有界分页；分页不携带完整定义集。详情及依赖按需获取。
4. UI 注入业务客户端接入真实筛选与归组；返回清单恢复筛选及分页位置；权限不足只开放读取。
5. 验证普通读取身份、归组权限、跨作用域隔离、停用分组、并发变更、分页稳定性与摘要不变。

当前完成第 1 项。现有内置目录仍限于小规模草案集，不能将其浏览器分页宣称为海量目录能力。第 2–5 项尚未实现。编辑、发布及跨资源业务记录仍按 F04/F05 分阶段推进，不在此步增加占位导航。

## 2026-11-20 首批接入进展

已实现第 2–5 项在内置定义集范围内的闭环：独立归组用例与持久化、7 个默认归组、业务摘要接口、服务端筛选与分页、固定引用详情、内容区分组筛选和多归组编辑。仍使用有上限的内置定义集和整体分组元数据；索引、游标和分组按需加载属于规模化后续工作。详见[资源目录契约](../../contracts/schemas/ontology-resource-directory-v0.1.md)。
