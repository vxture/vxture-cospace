## 1 本轮结论

本机存在可用的Linux Docker引擎，可以作为隔离算法试验的基础。首轮继续保留FAST-LIO与LIO-SAM两条候选，但其输入与授权条件不同，不能直接视为可互换实现。

本记录推进P1准备，E01已开始输入工具实现，真实序列与算法运行尚未执行。P0具体现场、独立参考及用途限差仍未完成。

## 3 算法核验

### 3.1 FAST-LIO

官方仓库：[hku-mars/FAST_LIO](https://github.com/hku-mars/FAST_LIO)\
本轮固定提交：`7cc4175de6f8ba2edf34bab02a42195b141027e9`

| 项目 | 核验事实 | 对试验的影响 |
|---|---|---|
| 定位 | README说明激光惯性里程计及增量建图，FAST-LIO2支持直接点匹配 | 不能仅凭增量地图输出宣称已具备经校核全局真值 |
| 环境 | README列Ubuntu、ROS、PCL和Eigen等依赖，并要求livox_ros_driver | 建立独立Linux试验环境，后续检查所需驱动消息依赖 |
| 输入 | 明确要求激光与IMU同步，逐点时间影响运动补偿；不同传感器有不同参数与消息要求 | 必须先检查日志，不把所有PointCloud2视为等价 |
| 外参 | README明确外参为激光在IMU坐标中的位姿，提供已知外参时建议关闭在线估计 | 在资料登记中固定变换方向及估计开关 |
| 时间同步 | README提示简易软件同步无法保证精度 | 软件同步开启不代表已经达到融合要求 |
| 输出 | 可保存累积PCD | 累积PCD不等于完整覆盖、质量和证据已具备 |
| 主仓库许可证 | 固定提交LICENSE为GNU GPL Version 2文本 | 需要结合实际组合与分发方式审查义务；不能直接作为闭源再授权结论 |

固定提交的package.xml声明BSD，与根LICENSE的GPLv2文本不一致。暂按存在声明冲突记录，不能仅凭包元数据认定BSD授权；后续结合来源、实际采用内容及上游说明明确适用条件。

FAST-LIO固定的ikd-Tree子模块提交为`e2e3f4e9d3b95a9e66b1ba83dc98d4a05ed8a3c4`。该提交根文件树只有README和两个源码文件，未找到根LICENSE文件；已读取README及两份源码，未发现明确许可声明。另取到的ikd-Tree当前main许可证为GPLv2文本，但不能据此证明固定旧提交的完整授权边界。上游授权来源仍待确认。

README链接的重定位扩展属于另外的实现，不能因链接存在就归为本主仓库已经交付的独立重定位能力。

### 3.2 LIO-SAM

官方仓库：[TixiaoShan/LIO-SAM](https://github.com/TixiaoShan/LIO-SAM)\
本轮固定提交：`0be1fbe6275fb8366d5b800af4fc8c76a885c869`

| 项目 | 核验事实 | 对试验的影响 |
|---|---|---|
| 分支 | master说明为原始ROS1实现，ROS2实现另有分支 | 不把ROS2分支的兼容性与许可审核结果自动用于本轮固定提交 |
| 环境 | 说明列ROS及GTSAM，提供基于旧版ROS的构建说明 | 后续显式核验可重建环境，不直接复制旧安装步骤为长期部署基线 |
| 激光字段 | 要求逐点相对时间和ring；主要支持机械雷达，其他类型另有适配说明 | 与FAST-LIO共用日志前必须逐项检查字段和传感配置 |
| IMU | 原始实现说明要求9轴IMU，推荐至少200Hz；Ouster内置6轴IMU不被该说明直接支持 | 不能假定任何激光内置IMU都适配；6轴扩展属于独立候选 |
| 外参 | 加速度角速度与姿态可能采用不同外参约定 | 单独核验两类变换，不盲目复制矩阵 |
| 回环 | README将内置回环描述为概念验证性质的ICP方案 | 有回环功能不等于重复走廊中的回环可靠性已经达标 |
| 主仓库许可证 | 固定提交LICENSE为BSD 3-Clause | 主仓库分发路径较明确，但仍需依赖、来源及NOTICE核验 |

固定提交的package.xml许可字段仍为TODO，属于包声明不完整；本轮BSD 3-Clause结论来自根LICENSE，而不是包声明。LIO-SAM不是因为主仓库许可证较宽松就自动优于FAST-LIO。必须同时满足数据、质量、资源和维护条件，再讨论实际分发方案。

## 4 公共数据核验

### 4.1 Newer College

官方说明：[数据集主页](https://ori-drs.github.io/newer-college-dataset/)；[下载与使用条件](https://ori-drs.github.io/newer-college-dataset/download/)。

主页说明包含Ouster激光、IMU和图像，并有基于测量地图推算的位姿参考。下载页面明确列CC BY-NC-SA 4.0，面向非商业学术用途，商业使用需联系维护者；页面通过表单提供访问流程。

本项目用于产品研发，不能默认属于已获准的非商业学术使用。因此暂不下载或采用该数据作为商用研发默认资料。参考轨迹也需进一步理解其生成方式、误差及与被评算法的独立性，不能因主页标称精度就直接充当全部现场真值。

### 4.2 M2DGR

官方仓库：[SJTU-ViSYS/M2DGR](https://github.com/SJTU-ViSYS/M2DGR)。

README描述室内外序列、激光、多个IMU及多类位姿参考。仓库LICENSE为MIT文本，但README同时写明面向学术用途，商业目的需联系作者，数据授权范围存在需要澄清的表述。

README还在2026-10-22公告旧下载链接不可用，正在迁移。因此不把MIT徽标等同于数据商业授权已明确，也不把旧链接当作可取得试验资料的保证。当前暂缓作为首个默认数据源。
