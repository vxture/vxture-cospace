# P14：已有点云接入

状态：已完成本机实现与验收。承接 P13；用户已同意执行和逐批验收。

## 目标与归属

在一个已有场景空间内，将带明确坐标声明的已有点云登记为资料，走通预检 → 固定几何模型 → 独立双视图 → 审阅选择 → 固定发布 → 在线查询及离线安装、激活、恢复。几何流程不要求先定义本体或关联。

首个真实样本：`var/samples/multi-1-os1-lidar-1s-001/first-frame.ply`，12,884 点；归属已有 OS1 场景 `space-0004d0e3c133f5fb`。这是采样 ROS 消息派生的单帧中间成果，保留传感器局部坐标，没有配准、SLAM 或独立精度验收。此批验证接入路线，不新增物理场景，不将其描述为测绘真值。

## 首版边界

- 仅 binary little endian PLY 1.0，单个 vertex element，float32 XYZ，可选完整 uchar RGB；无网格、列表属性、任意附加属性或编码猜测。
- 米制局部坐标，显式 frame、三轴标签、坐标作用域。场景对齐标记 unverified；不自动应用坐标转换。
- 最大 100 万点、32 MiB 文件、8 KiB 头、64 KB JSON 清单；沿用上传及场景存储预算。
- 无 RGB 时用中性灰，并在视图标识 neutral_not_rgb。机视图仅生成 0.1m 表面候选单元，其余未知。
- 上游来源保存摘要和提供者描述，不声称重新验证完整采集日志。精度、生产和机器人可用性均未验收。
- 在独立 P14 运行副本验收，保留既有服务及发布。
