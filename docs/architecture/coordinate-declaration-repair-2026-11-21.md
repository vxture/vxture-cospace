# 坐标声明兼容与来源修复

配准需要来源模型具有明确、可核验的米制右手轴向。历史点云只声明 X/Y/Z 时，重复读取或原样重新构建都不能补充方向；旧资料没有新版 source.json 附件时，原编辑入口还会被隐藏。本批打通来源诊断、审计修订、预检和新模型构建，不修改历史成果。

## 导入与语义解释

文件适配与坐标语义解释分开处理。保留既有 RGB-D、ROS1 激光及 PLY 适配器的文件、摘要和预算检查；本批没有新增 LAS、E57、ASCII PLY 等文件解码器。浏览器准备及服务端 PLY 声明兼容明确的中英文方向、大小写、单字母方向和对应轴前缀，例如 Right、右、E、X(right)、Y_forward、Z-up。三轴分别声明，不从几何形状、文件名、设备名、X/Y/Z 或 sensor_x 推测方向。

相对方向和地理方向分别解释；上/下可与各自水平轴组合。三轴必须正交且为右手，不接受左右手混淆、共线、重复或相对/地理水平轴混用。原始声明保留，解释结果单独返回；别名解释不旋转、翻轴或换算坐标。

导入准备和坐标编辑可主动选择 RFU、FLU、FRD、相机 RDF、ENU、NED 约定，默认不选择。选择只填写声明，仍需提供者核对资料。米制和局部范围沿用现有契约；需要实际单位换算或坐标变换的文件应先经过专门转换再导入。

## 预检与修复流程

预检原 status 继续表示文件是否通过普通构建核验；附加 registration_readiness 单独表示地图配准轴向准备情况。文件无效时该字段为空。仅有不明确轴名可通过普通构建，但配准仍要求补齐声明；历史预检缺少此字段时提示重新执行。

配准阻断页通过只读 GET /api/scene-registrations/source 获取固定模型的来源诊断。按场景预览及候选授权检查后读取模型，核验来源绑定与原始登记或已有审计修订，响应不包含服务器路径；不创建配准修订或改写模型。资料管理能力决定是否展示操作入口，不改变资料编辑接口的权限要求。

具备权限的成员从阻断页打开准确的来源资料，核对原始说明，填写修改原因与来源依据，确认引用影响后保存。有效旧 PLY 清单本身已绑定坐标与点云摘要，无需伪造新版附件即可追加审计修订。变更前仍实时验证原始文件。修订保留原声明、操作者、时间、原因及固定绑定，支持并发检查和幂等重试。

修订后必须重新预检，显式确认修订并新建构建，再在空间基准选择新模型。既有控制点资料、历史模型、当前模型选择及固定发布不会自动迁移。新的别名模型可直接通过轴向检查，固定模型仍保存原始写法。

## 平台模型辅助

导入准备和资料坐标编辑可主动粘贴说明或 JSON 元数据，经平台 Atlas 生成三轴及单位候选。用户文本以不可信资料传入；只发送这段说明，不读取服务器文件、不发送点云。通过 CoSpace 既有客户端身份，以当前用户票进行 RFC8693 OBO 换票；服务端验证 aud=atlas、scope=tool:atlas、act.sub=cospace、mode=obo、主体、组织、工作区及最长300秒有效期。推理计量由 Atlas 负责。

服务端配置选择 endpointCode，业务代码不绑定厂商或模型。2026-11-21 从运营台确认 CoSpace 有12项生效的产品级路由授权，采用其中服务中的 chat/extract；879项 Runos 能力不是此文本解析的依赖。本批不接入 Runos。调用前读取 Atlas /v1/model-routes，核对唯一生效的聊天入口、关闭思考支持、上下文、输出及请求容量，再用 /v1/chat，stream=false、thinking=off、maxTokens=2048、timeoutMs=45000。没有重试或换路由；计量不重复上报。

候选必须符合严格 JSON 契约，每个非空方向和单位都须带有用户原文的精确摘录。确定性轴向规则再次核对右手、正交、米制、无缺项或冲突；单位缺失不会默认米，厘米/毫米不会仅靠改声明被换算。原文摘录是人工核对的依据，不等同现场测量或模型结论已获验证。请求和回执绑定场景、资料、修订、任务及原文摘要；文本或坐标上下文改变清除旧建议。

用户逐项核对后显式填入表单，仍走原有引用影响确认和审计保存；模型不能直接保存、构建、发布或修改历史成果。未配置、失效授权、并发繁忙及上游失败时显示真实状态并保留手工入口。停止等待仅中止客户端等待，不保证上游推理已取消。建议 POST 不发送全局资料变更通知，避免重置正在编辑的表单。

发布 checkpoint 增加 data/business/runtime/preview-inputs/input-coordinates.sqlite3，使用 SQLite backup 读取已提交 WAL 并 quick_check；缺库记录 absent，损坏或符号链接阻断替换。原始点云、模型和固定发布不在此逐库 checkpoint 中，沿用已有资产备份。应用回退不自动还原审计数据库；需恢复时先停止写入并按同一时点核对登记资料、修订历史、任务和固定成果，禁止在线覆盖 SQLite/WAL。
