# 技术栈时效核验

核验日期：2026-10-26\
范围：官方版本、维护状态与关键演进方向；未完成全量依赖、性能或许可证审查。

## 官方资料结果

| 技术 | 本轮读取到的事实 | 对项目的影响 |
|---|---|---|
| React | 官方版本页列最新19.3，发布时间2026-09-09 | React仍持续演进；优先采用19系列并验证UI依赖 |
| Vite | 官方仓库latest正式发布v8.3.5，2026-10-21 | Vite仍活跃；8系列作为兼容试验候选 |
| FastAPI | 官方latest正式发布0.162.0，2026-10-23 | 没有因“Python后端”判为过时的依据；实际版本锁定后回归 |
| Pydantic | 官方latest正式发布v2.14.1，2026-10-11 | 使用2系列，不以旧1系列接口作为新设计基础 |
| Node | 官方页面列24为LTS、26为Current、20为EOL | 当前优先24 LTS；不能提前把26称为LTS |
| Python | 官方支持表列3.15、3.14为bugfix，3.13至3.11为security；3.10于2026-10-01 EOL | 新平台优先验证3.14，兼容测试覆盖3.15；当前试验3.12不等于新产品版本定案 |
| Three.js | 官方WebGPURenderer文档说明优先使用WebGPU，不支持时回退WebGL2 | 改为WebGPU优先验证，同时检查实际功能与回退能力 |
| PostgreSQL | 官方支持表列18、17等受支持，18支持至2030-11-14；页面列19 RC1公告 | 新项目优先18；不将RC当作正式生产版 |
| ROS 2 | 官方文档源码列Lyrical支持至2031-05、Jazzy至2029-05、Kilted至2026-12 | 新适配优先比较Lyrical及Jazzy；不将将近EOL版本作为长期基线 |

资料能说明生命周期与方向，不能证明某项产品性能，也不能据此认定整套技术组合最优。本轮没有穷尽所有竞争框架，不能声称已找到唯一“最先进”的方案。
