# 智能体恢复日志实施与验收清单

日期：2026-10-27。依据[恢复日志协议](智能体恢复独占与提交日志协议-v0.1.md)。本表定义组合验收目标；Schema样例通过不能标记本表通过。

J1进展：JL-01/02取得本机独立锁原型证据；JL-03已验证本地别名、硬链接、目录联接和文件身份限制，仍有竞态/网络文件系统边界；JL-04仅验证begin与模拟对象的代次失效，resume和真实会话仍待实现。其余组合用例未完成，见[原型记录](../validation/智能体恢复锁与代次原型验证-2026-10-27.md)。

J2进展：JL-05至JL-09取得独立合成日志证据，含五处进程内立即退出、SQLite异常/约束错误、幂等及历史留存；JL-10验证未决项阻断新写入，恢复对账仍待J3。并发状态竞争为双线程/双对象，不是独立进程状态竞争；物理断电未验证。见[记录](../validation/智能体消息留存与原子提交验证-2026-10-27.md)。

J3进展：JL-04取得begin/resume/完成的实验对象代次证据，真实运行包会话仍待J4；JL-10至JL-17取得独立恢复实验的全部或部分证据，包括历史重放、计划变化拒绝、多项合成回滚、证据缺失阻断、期限和响应丢失，见[记录](../validation/智能体恢复状态机验证-2026-10-27.md)。未决多项以SQL种入，独立进程中断为os._exit，仍不算正常批量接收、进程外强杀恢复或物理断电验收。JL-18/19仅有版本拒绝和实验门禁证据，旧入口迁移、组合审计与实际会话尚未通过。

J4首批进展：JL-04/19增加实际FilePackages合成文件会话与只读审计组合证据，begin与完成后旧会话拒绝，新会话仍检查绑定/时间/撤回，见[记录](../validation/智能体恢复与文件会话组合验证-2026-10-27.md)。不是实机机器人；resume的会话组合、并发屏障、跨进程会话恢复、维护权限和迁移仍未完成，不将部分证据标为全部SS-02/JL通过。

J4第二批补充：JL-04/19及SS-02的恢复交错新增跨进程屏障证据，含resume、判定持锁时busy、持有者外部强杀后释放及门禁后迟到响应，见[记录](../validation/智能体查询恢复跨进程验证-2026-10-27.md)。消费仅合成文件会话；机器人执行器、响应取消、维护权限、物理断电和迁移仍未验收，不能称全部SS-02通过。

| 编号 | 批次 | 场景与必须结果 |
|---|---|---|
| JL-01 | J1 | 两真实进程争同一稳定锁，一次只有一名持有者；超时返回busy |
| JL-02 | J1 | 持有者正常退出/强杀均由OS释放；存活挂起者不可按TTL偷锁 |
| JL-03 | J1 | 相对/绝对路径指向同库时保护一致；链接/重解析点及锁替换路径拒绝或明确能力边界 |
| JL-04 | J1/J3 | 恢复begin/resume增加代次，旧对象/旧会话随后查询和写入均拒绝；不能自动刷新 |
| JL-05 | J2 | 准备事务前中断无应用成功；准备提交后中断有原消息与未决intent，所有新查询拒绝 |
| JL-06 | J2 | apply提交前强退整体回滚；提交后响应丢失可按intent_id查唯一receipt |
| JL-07 | J2 | states与receipt不能出现单边提交；注入SQLite异常/约束错误也如此 |
| JL-08 | J2 | 同ID同消息幂等，同ID换消息拒绝；幂等不增加state_revision或期限 |
| JL-09 | J2 | 状态被更新替换后，历史消息及receipt仍可核对；达到配额拒绝新接收，不清历史 |
| JL-10 | J2/J3 | 一个intent未决时普通写入不能越过；故障中的撤回不能被后续allowed掩盖 |
| JL-11 | J3 | blocked/planned崩溃后mode继续阻断；只能显式resume且旧计划不可执行 |
| JL-12 | J3 | store/context/generation/revision/前态摘要/未决集合/计划摘要任一变化，提交拒绝 |
| JL-13 | J3 | 多项对账中途失败整批回滚；没有部分清标记或部分解锁 |
| JL-14 | J3 | 未决消息丢失、签名失败、未知历史撤回均retain_blocked；人工确认不能代替证据 |
| JL-15 | J3 | 旧序号、epoch越权、终止撤回恢复allowed及失配grant仍拒绝 |
| JL-16 | J3 | 历史消息过期不擦除撤回；恢复不续期，日志恢复后查询可仍expired/grant_missing |
| JL-17 | J3 | 完成响应丢失按同recovery_id读取结果，不重放；重复resume已完成任务拒绝 |
| JL-18 | J4 | v1库/pending、未知版本、坏库、缺库拒绝迁移或自动初始化，不用v2结果解除v1 |
| JL-19 | J4 | 不持锁的只读报告不授予恢复；真实门禁每次核对代次/模式/未决项 |
| JL-20 | 独立设备验收 | 物理断电、磁盘回滚、管理员替换文件、目标设备锁语义需单列；本机进程强退不能代替 |

每项证据固定源代码与契约摘要、SQLite模式、OS锁实现、平台、进程身份和屏障位置，保存前后状态、消息/intent/receipt摘要、代次与返回值。只保留合成测试数据，不保存私钥。

J4首批组合之后，下一批补会话查询/恢复并发屏障与跨进程证据，再实现维护身份及操作审计入口；旧库迁移及实际设备独立验收。I4任务锁与本方案职责不同，复用前需验证语义，不能将I4的Windows Job所有权试验直接计为JL-01通过。
