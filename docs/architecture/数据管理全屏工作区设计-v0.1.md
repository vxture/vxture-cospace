## 1. 页面目标

保留全局 Launcher、品牌、主题及账户；不要求浏览器进入原生全屏。空间三维大屏仍按原约定在独立标签页打开。

## 2. 布局与视觉规格

- 全局 header 复用 DS，当前高度 48px；数据工作区使用余下全部宽高，不使用 ShellPageContainer 的居中限宽。
- 左侧目录默认宽 224px，超宽屏 248px；显示当前 workspace 实际标识、可访问场景、检索与当前选中项。可收起。
- 分区层级修订：宽屏四周与侧栏/主区之间留 12px，1200px 以下留 8px；左侧目录采用 DS 卡片色、轻品牌色边框、圆角和柔和阴影，呈独立浮层。主内容去除外层边框、圆角和白色卡片背景，融入由 DS primary 与 card 混合的极淡品牌色渐变（1.5%—6%）；概览透明、表头为 2% 品牌色，避免灰色块。620px 以下取消外间距，侧栏保持实色抽屉；收起侧栏时主区左侧保持同值留白。
- 中间区域弹性占满。概览采用一行轻量统计，避免大型仪表盘卡片；计数取自当前场景接口，加载或失败时不伪造零值。
- 详情为页面级右面板，位于通用 48px header 下方并延伸至页面底部，右侧贴边；与场景目录、主内容同级，不再嵌于表格区域。宽屏并排，宽 352px，超宽屏 380px；小于 1200px 改为覆盖整个工作区高度的右侧抽屉，宽 320px，手机宽度不超出视口。列表与详情独立滚动。
- 620px 以下默认收起场景目录；表格允许区域内横向滚动，页面整体不横向溢出。
- 主操作、搜索与筛选采用 32px 高；标题 23px，记录名称 13px，次级内容 11—12px，元信息 10—11px。保留键盘焦点与减少动画偏好。
- Button、Input、NativeSelect、Table、StatusBadge、Dialog 使用 Vxture DS；字体、颜色、边框和圆角使用现有 DS token，图标沿用现有 Phosphor 依赖。

## 3. 三个主视图

| 视图 | 默认信息 | 行为 |
| --- | --- | --- |
| 资料 | 名称、格式、规模、登记/使用状态 | 搜索、按格式筛选、展开详情、进入当前资料构建 |
| 场景版本 | 模型快照名称、形成时间、关联发布数、快照检查 | 按形成时间倒序；筛选当前候选、已有关联发布、需核查版本；查看构建记录 |
| 来源追溯 | 成果、关系、来源、绑定检查 | 按关系或问题筛选，点击任一端展开详情，继续查看上下游 |

未实现正式模型版本命名之前，显示实际保存的模型标识和快照类型，不根据排序伪造 V1/V2 标签。不把“当前候选”称为“正在服务”，不把快照完整称为质量验收。

资料行点击后打开详情，右侧保留“用于构建”和上/下游记录；文件路径、摘要与预检进入折叠区，展开前不请求技术详情。详情关闭恢复完整列表宽度，Escape 可关闭正在操作的详情。

## 4. 辅助入口与现有能力

- “导入资料”当前调用既有服务端允许来源登记，弹窗明确不复制源文件、不启动构建。文件上传和任意格式接入尚未实现。
- 采集批次与来源配置收至辅助弹窗，继续使用既有功能与门禁，不要求用户逐项经过。
- 资料/候选使用影响和管理状态放入详情高级区，继续复用已有受控操作。
- 固定发布详情可进入态势服务；允许预览且完整可分发的固定空间可独立标签页打开。
- 本次不新增算法执行、全格式解码、版本命名服务或多 workspace 切换接口。

## 5. 上下文与错误行为

1. 只从服务端授权场景目录选择场景。URL未指定场景时，展示首个可访问场景作为初始浏览上下文；不替换显式指定但不可访问的场景。
2. 切换场景清除旧资料/版本选择、检索及筛选，取消旧请求。目录与保存数据必须匹配当前场景，旧响应不能覆盖新场景。
3. Workspace来自平台会话；workspace切换后重新获取场景。当前产品未另造workspace切换器，跨workspace服务端隔离沿用既有授权机制。
4. 无权限、服务不可用、无资料、筛选无结果、显式记录不存在分别给出说明；发生读取错误时清除旧数据，提供重试。
5. 读取时间只表示目录读取时刻；未记录的采集和登记时间不补造。数量、关联和状态均来自保存记录，不展示虚构文件或进度。

### 6.1 导航与内容间距复核

行业管理工具常见两种框架：导航与内容紧邻、依靠分割线区分，或使用窄间隔与独立工作区表面。两者均可保留高密度布局；是否留 gap 取决于层级辨识和空间利用，不是统一行业强制值。

初版主内容已有约 28px 内边距，继续增大内部留白不能解决全部横线与背景紧邻带来的观感。当前采用 12px/8px 外间隔与单层工作区表面，内部继续平铺，保留全屏工作区的宽高利用。

本次样式修订经生产构建及11项浏览器检查：1440、919、390px下的间距和无全局横向溢出，详情保持宽度及侧栏收起后的左侧留白。证据见 `output/playwright/data-spacing-result.txt` 与 `data-management-spacing-*.png`。

### 6.2 表面层级调整

按页面反馈将浮层层级移至左侧目录；主区与品牌色渐变背景融为一体，保持现有字号、表格密度及 12px/8px 间距。侧栏切换保持 32px 点击区域、16px 线性图标，常态透明无边框，仅悬停或键盘聚焦时出现反馈。

背景细节：品牌色渐变由左上 6%、中段 1.5%、右下 4% 与 DS card 混合；右上为渐隐点阵，右下为 9% 不透明度空间线框，窄屏进一步减淡。修饰层 aria-hidden、pointer-events:none，置于内容后方，不参与布局和操作。

### 6.3 资料详情面板调整

资料详情从表格区域迁至工作区右侧，同级复用模型/发布详情。1440×960 下实测 top=48、bottom=960、right=1440、width=352；919×902 下 top=48、bottom=902、width=320；390×844 下 top=48、bottom=844、width=352。通用 header 始终保留，三种尺寸均无全局横向溢出，生产构建通过。截图：`output/playwright/data-page-detail-1440.png`。
