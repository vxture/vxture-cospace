## 1. 入口与职责

| 分类 | 入口 | 职责 | 主要对象 |
| --- | --- | --- | --- |
| 使用 | 空间预览 | 浏览有权限的空间，打开固定发布的人视图与智能体视图 | 空间、发布、对象 |
| 使用 | 态势服务 | 发布固定版本、在线查询、离线交付及消费版本管理 | 发布、数据包、消费引用 |
| 构建 | 数据管理 | 管理原始资料、采集批次、参考资料和空间成果来源 | 资料、来源、成果、血缘 |
| 构建 | 构建中心 | 调度构建、检查任务、核对候选、确认所选版本及更新 | 任务、模型候选、校核记录 |
| 定义 | 语义本体 | 定义类型、属性、关系和约束，管理规则版本 | 本体及其固定版本 |
| 定义 | 空间关联 | 将本体应用于具体空间，关联对象、几何、业务记录及关系实例 | 对象、锚点、关联实例 |

“空间定义”由语义本体和空间关联共同承担。语义本体回答“有哪些类型和合法关系”，空间关联回答“这个具体对象是什么、在哪里、关联什么”。空间关联不是另一个本体编辑器。

账户、成员、登录集成和业务配置保留为通用管理入口，不占六个业务模块。发布与离线交付归入态势服务，不另设交付模块。

## 2. 数据流及边界

数据管理登记输入 → 构建中心生成几何候选 → 空间关联引用固定本体并创建对象与几何绑定 → 生成独立语义候选 → 构建中心确认候选 → 态势服务固定发布 → 空间预览及程序消费。

语义候选的生成仍调用已有构建后端；移动工作面不改变原始资料、候选或发布的存储格式。空间关联不直接覆盖已发布模型。现有对象修订提交完整对象集合，尚非通用关联变化集。

空间上下文通过稳定空间ID在数据管理、构建中心、空间关联、语义本体及态势服务间传递；旧路由 `space/data/build/ontology/delivery` 和既有记录ID保留，新入口使用 `association`。全屏空间仍在独立标签页打开固定发布。

## 4. 空间预览的权限约定

正式产品只展示当前用户有权限预览的空间，权限由服务端判定。用户可能拥有多个空间的访问权限；空间不是单个用户的私有文件夹。

列表过滤、空间详情、固定发布、几何资产、对象查询、在线查询和离线下载均需执行权限检查；隐藏卡片不能替代直接URL/API授权。构建、编辑关联、发布等写权限分别配置，不能从“可预览”推导出来。

**I3独立授权模式已接入平台RP及服务端空间ACL，本轮以本地模拟平台验证。** 8769的空间目录与实际业务按已验签身份和当前策略检查；预览身份及本机成员草稿不具备授权效力。原8767目录仍无认证，只保留内部工程用途。真实accounts客户端尚待登记配置和联调，不能据本地模拟结果宣称生产认证完成。
