# 数据采集与独立校核需求

版本：v0.1\
日期：2026-10-26\
状态：P0准备设计，待现场与设备条件确认

## 1 目标与范围

为普通设备间及相连走廊准备构建真值、人视图核查、机器视图查询与重定位所需资料，落实[首版用途与验收矩阵](首版用途与验收矩阵-v0.1.md)。数据准备必须同时覆盖构建与独立消费，不能只有一份可出图日志。

首轮以激光与IMU为候选采集组合，设备型号在算法输入适配检查后选择。可见光用于人工解释、对象确认和可选着色，不作为首轮几何重建的必要依赖。是否加入相机几何约束留待路线验证。

本文件规定需求，不宣称资料已经取得。公共数据集、设备精度、算法适配和许可均需核验；具体现场尚未选定。

## 2 数据包分组与使用隔离

| 数据组 | 用途 | 使用约束 | 对应验收 |
|---|---|---|---|
| D0 场景说明 | 定义目标范围、对象与排除条件 | 先于正式覆盖统计确定，不由已建地图反推 | A02—A04、H01—H03 |
| D1 构建与调参序列 | 比较算法、确定参数、构建候选 | 允许开发使用，不能同时充当全部独立测试资料 | A01—A03 |
| D2 独立检查资料 | 检查绝对、局部几何和覆盖 | 独立检查点不得用于拟合；若用于调参则失去该轮独立性 | A02、A03、H03、M04 |
| D3 独立消费序列 | 验证机器视图定位与查询 | 不参与被检真值构建和定位参数调优 | M01—M05 |
| D4 变化与维护资料 | 验证几何、语义更新和视图影响 | 先保存变化前基线，再采集可确认变化 | H04、S03—S05 |
| D5 故障及边界样例 | 检查拒收、未知、失败与恢复 | 构造数据单独标识，不能混入正式观测 | A01、A03、H02、S02、S05 |
| D6 第二场景资料 | 检验同产品构建的配置复制 | 与首场景不同布局，仍在声明支持范围内 | S06、S07 |

数据组是逻辑角色，不强求不同文件格式。D2的现场测量可以同时包含控制资料和独立检查资料，但必须记录点位角色，按用途分开使用。

### 2.1 对照试验分集

算法比较先共用明确的开发集，再在预先保留的验证序列上复核。正式重定位评测采用D3，冻结对应真值、定位实现、参数和初始条件后运行。

若根据验证失败修改算法或参数，应保留原结果并记录该序列已被开发使用，补充保留序列或明确本轮验证独立性降低。不能删除失败样本后重新定义成功率。

## 3 场景准备与采集要求

### 3.1 场景说明D0

需记录目标平面范围、空间高度或楼层、房间与走廊关系、可进入区域、不可达及排除区域、目标对象清单、现场时间及已知变化。无可靠CAD时，可用标明测量来源的现场草图起步。

首个场景应能重复进入、布设或识别检查位置，并允许在不同轮次重复经过相同区域。覆盖至少包含设备遮挡、门口过渡、普通走廊和可识别结构；具体面积不在未选现场前强行指定。

对象清单区分正式空间实例与仅供试验的标签。不能为了降低误差而移除全部困难区域后仍声明覆盖完整场景。

### 3.2 原始观测与时间资料

| 类别 | 必需说明 | 不满足时的处理 |
|---|---|---|
| 激光点云 | 坐标与单位、帧时间含义、点时间或扫描时序、量程及无效点语义 | 无法解释时隔离；无逐点时间不自动判定可去畸变 |
| 传感器专有字段 | ring、扫描线、回波及点时间等字段是否存在、单位与取值定义 | 按候选算法能力检查，不虚构字段适配 |
| IMU | 时间戳、加速度和角速度单位、轴向、重力约定、采样实际频率与缺帧 | 单位和方向不明则禁止融合；缺帧单独统计 |
| 时钟关系 | 激光与IMU时钟来源、同步方式、已知偏移及漂移处理 | 未验证同步不能仅凭同名时间戳视为对齐 |
| 标定 | 激光至IMU及载体坐标变换、方向约定、测定方法与适用时间 | 无可靠值时设标定任务，不能默认为单位变换 |
| 初始与运动条件 | 静置初始化、采集速度、姿态变化、启停及回环情况 | 按算法要求记录，不允许隐含补充先验 |
| 原始日志 | 格式、解码说明、生成工具版本和数据清单 | 原样保留并校验，转换文件与原件分开 |

实际频率、丢帧及时间间隔从日志统计，设备标称频率仅作说明。输入协方差缺失时明确缺失，不能填固定常数冒充实测不确定性。

### 3.3 采集轮次

| 轮次 | 操作目的 | 记录要求 |
|---|---|---|
| 预检轮 | 检查记录、时钟、标定和解码 | 短序列即可，先发现输入问题再正式采集 |
| 构建轮 | 建立基线真值及覆盖 | 包含必要视角、静置与闭合，记录补采位置 |
| 消费轮 | 独立运行定位与查询 | 单独日志，采用声明条件内的不同经过方向、初始化与采集时刻 |
| 维护轮 | 记录可确认变化 | 保存变化位置、类型、时间及人工确认依据 |

优先人工携带或外部工具采集，不把机器人导航能力作为数据准备依赖。不得为试验擅自移动真实设备或改变生产环境；维护样例可以使用获准调整的试验物体或可控测试场景。

## 4 独立校核设计

### 4.1 检查对象分开

| 检查对象 | 资料及方法需求 | 能证明的结论 |
|---|---|---|
| 坐标与绝对位置 | 有明确基准的控制资料及未参与拟合的检查位置 | 指定工程坐标中的位置误差 |
| 局部几何 | 独立量测的墙距、设备外形尺寸、门洞或通道尺寸 | 局部尺寸及必要净空误差 |
| 重复性 | 独立轮次、相同对象和可解释基准 | 重复测量差异；不能单独证明绝对正确 |
| 覆盖 | 预先定义的区域、表面或对象检查集合 | 指定目标集合中的已观测、缺口及不可判定 |
| 对象身份 | 现场确认、照片或可信资产关联资料 | 身份、类型、位置和外部绑定质量 |

每项记录方法、工具、日期、操作者、误差或不确定性说明。检查基准需要比用途限差更可靠，具体比例随误差预算确定；没有足够可靠基准时，该能力标记为待验证。

### 4.2 点位与范围安排

控制及检查位置需覆盖房间、走廊、过渡区和关键设备附近，避免全部集中在容易建图的一角。点数与分布由场景尺度、坐标求解和用途限差决定，不用固定几个点承诺所有场景精度。

坐标对齐求解只能使用指定控制资料。检查点在求解完成后用于评估，不能再用它们调整变换后仍称独立检查。用于复核局部尺寸的端点定义应可重复识别。

### 4.3 重定位参考

优先选择独立测量或经过验证的参考系统，说明其坐标与时间关系及自身误差。连续参考轨迹可评价连续位置姿态；只有稀疏测量位姿时，只评价对应点位及相应成功条件。

另一条SLAM轨迹或构建算法自身输出不能自动视为真值参考。scan-to-map残差、重叠点云视觉效果、回到起点的闭合差只能作为辅助诊断。

首轮重定位任务先明确有界初始位置及方向误差，测试范围在执行前冻结。全局未知初值重定位另行验证。对错误匹配应统计错误接受，而非仅报告匹配器返回成功的比例。

## 5 公共数据试验准备

公共数据优先检查原始激光与IMU、时钟和标定、是否有适用参考、室内或走廊序列、算法可适配性、使用与分发条件。缺少某类资料的数据集只承担其能够支持的试验。

候选线索包括Newer College、Hilti相关数据集、M2DGR及其他具有明确原始资料的室内数据集。此处仅列待核验线索，未核验具体版本、传感器、参考精度、下载条件或许可，不作为已选数据。

数据使用许可与代码许可分别检查。公开下载不等于允许商业使用、重新分发或打包给客户；不把大型原始日志直接提交到代码仓库。

每份选定资料登记原始页面、版本、许可、下载清单、校验、传感器及可支持验收项。先取得满足输入检查的短序列，再决定是否下载更多数据。

## 6 资料登记与进入试验的条件

采用[试验资料登记模板](../../experiments/templates/试验资料登记模板.json)登记资料，模板中的空值表示待提供，不能当作合法默认配置。模板是准备清单，尚未作为产品接入schema冻结。

进入算法试验前至少确认：来源及使用条件、数据完整、可解码、坐标单位、时钟资料、必要标定和候选算法字段前提。缺独立参考时允许进行流程试验，但结果必须限制为流程和内部诊断。

进入正式质量或消费验证前，还需冻结目标用途限差、独立资料角色、测试条件、实现及参数版本。每份资料明确支持哪些验收项、哪些不能验证。
