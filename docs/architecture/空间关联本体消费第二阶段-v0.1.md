# 空间关联的本体消费：第二阶段

日期：2026-11-20。第一阶段语义本体已由 v0.10.0 独立交付。本阶段的产品入口沿用「空间关联」，用户所说的空间链接不另建导航。

## 产品边界

公共资源的语义本体维护 L1/L2 定义、依赖和发布版本。空间关联持有模型对象、定义引用、后续实例属性和关系，属于 L3 消费方。依赖方向为宿主消费适配器调用本体服务和独立内核，独立内核/UI 不导入空间、数据库、认证或地图。

已有对象来自固定模型候选。原有轻量规则与新的模块化定义不是同一契约，不按相似名称自动迁移，不将保存引用表示为完成实例校验。模型点锚、空间归属和现场核实仍分别表达。

## 批次

| 批次 | 范围 | 验收 |
| --- | --- | --- |
| B05a 固定定义引用 | 关联概览中的对象清单；引用、调整、查看定义、解除；仅选择当前工作区真实已发布的固定版本 | 权限和 CSRF、场景/候选绑定、并发控制、幂等、无变化不增修订；升级不自动改引用；原对象/模型/发布不变 |
| B05b 实例应用与校验 | 在既有对象/关系工作面维护显式属性映射、类型值和关系映射；接入独立实例校验器与消费侧实例存储 | 固定依赖闭包兼容、继承属性、类型/单位/有效期、端点与证据；未记录/未知/冲突分别返回；采用前预览诊断 |
| B05c 模型及地图消费 | 按固定实例修订联查对象、定义、证据和有效期；复用已有模型定位，并按坐标契约提供地图交接 | 本地坐标不当作经纬度；无地理配准不提供地理地图定位；旧修订读取稳定；三类园区验证 |

B05a 是第二阶段的第一批工程交付，并不代表 B05 全部完成。下一阶段的服务发布集成需明确固定引用和交付包契约，不能把当前引用的最新值注入旧发布。

## B05a 实现

`/api/scene-ontology-links` 经宿主统一认证和场景授权。读取要求 `space.preview`，修改要求 `association.edit`；两个操作都检查候选真实归属，拒绝授权前读取模型。工作区和操作人取自可信主体，不接受请求中的身份参数。

服务端读取并核验已有模型对象；请求中的候选和模型摘要共同限定来源。引用以对象 ID、模块 ID、版本、摘要及概念 ID 标识，并在消费库保存完整固定定义闭包。定义来源必须是正式发布记录，禁止使用可读的内置候选回退。概念定义查询包含继承后的属性说明，但不自动填入旧对象属性。

消费库为运行目录中的 `scene-ontology-links.sqlite3`，不放入本体模块。分区包含可信工作区、场景及模型候选。每个实际变更保留不可变快照；预期修订拒绝并发覆盖，幂等请求重试不产生重复修订，重复设置同一引用不增号。解除只更新消费引用，不删除空间对象、几何或已发布成果。

页面置于关联概览内容区，沿用原导航。所有对象作为清单数据呈现，不将模块、版本或对象堆入导航。操作通过 64px 居中操作列、32px 三点按钮、24px icon 聚合，操作面板使用 icon 与分隔线。编辑和查看在右侧抽屉完成，底部按钮 32px/14px。

当前界面明确显示「已引用 · 待实例校验」；接口返回 `instance_validation=not_performed` 和 `included_in_publication=false`。没有已发布本体时呈现空状态，引导回公共资源完成定义审批，不自动发布预置草案。

本地原有的 `semantic_instance_store.py`、`semantic_instances.py` 及其试作测试继续保留，尚不作为 B05a 的生产依赖；待 B05b 按新的服务权限与实例采用契约评审接入。


## B05b1 实例属性闭环

B05a 已由 PR #169 squash 合入 main，第二阶段尚未发布。B05b 分两步收敛：本批先完成实例属性，关系映射放在 B05b2 原有「空间关系」工作面，不增导航；B05c 定位、地图和后续服务交付不混入本批。

关联概览的同一清单提供实例属性抽屉，按固定概念继承后的属性生成字符串/数字/整数/布尔输入，显示定义单位和量种。录入依据显式填写，有效时间可选，原对象属性不自动转换。只读身份可查看已保存声明和诊断，具有 association.edit 的身份可保存。保存创建消费侧修订并调用独立内核，错误草稿可保存后修正。列表只显示「属性校验通过（局部）」或「已引用 · 属性待修正」，不将局部通过称为完成实例应用。

固定依赖闭包冲突不选择最新版本；已有声明更换引用时必须明确清空后重填。所有声明来源及审计人由宿主生成，浏览器不能伪造。结构错误导致整批语义检查未执行时，其他对象不误报通过。几何缺失信息不会导致属性报告错误，但地图和关系仍未校验。详见增量 [接口契约](../../contracts/schemas/scene-ontology-links-v0.1.md)。


## B05b2 关系映射闭环

在已有「空间关系」内容区加入本体关系映射清单和右侧抽屉，保留原关系候选编辑。先将关系保存到模型候选并核对切换该候选，再显式映射真实已发布关系。默认沿原方向，用户可明确选择反向；原声明方向与本体映射方向均保留可查，不猜测旧 type_id 的含义。

关系映射与对象引用共用消费侧修订，避免跨库采用竞态。两端固定概念必须存在，已有映射时调整/解除概念引用须先解除映射；更新属性则保留关系并重新校验。独立内核读取冻结的对象及关系定义闭包，校验继承端点、属性与断言有效时间。只读用户可以查看定义、方向、依据和集合状态；编辑通过原 association.edit 和 CSRF 授权。

列表单列未映射计数，通过文案为「已映射集合校验通过（局部）」，始终标明现场含义待核实。当前范围不包含园区完整性/基数、地图几何、专业审核及服务发布。旧轻量规则仍由原关系工作面维护，两种契约不做隐式迁移。B05c 单独推进模型定位及地图消费。
