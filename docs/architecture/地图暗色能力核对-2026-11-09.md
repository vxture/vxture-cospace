# 地图暗色能力核对

日期：2026-11-09。范围：官方文档和官方在线示例只读核对；尚未替换本地引擎、申请账号、购买服务或部署。

用户已确认：地图采用高德，当前优先推进功能。该决策覆盖下文“验证对象”的候选表述；正式接入采用高德官方 SDK，海外权限和商业授权仍须核验。

## 结论

天地图有官方暗色显示能力，不能表述为“天地图没有暗色模式”。JavaScript API 4.0 的“地图参数设置 → 设置地图样式”示例明确提供 `map.setStyle('black')`、`map.setStyle('indigo')` 和 `map.removeStyle()`。本次实际点击两种样式，均显示暗色地图。

但应区分暗色显示与独立暗色地图样式：在官方 black 示例中，检查渲染 DOM 的瓦片图片，计算样式为 `filter: grayscale(1) invert(1)`。这证明该示例使用客户端栅格变色，不能据此声称天地图提供可分别定制道路、文字、水系颜色的暗色矢量底图。indigo 示例也观察到瓦片图片具有相同 filter；其整体蓝黑效果不应仅由这一条 CSS 推断全部实现。

现有 CoSpace 接入为 MapLibre + 天地图 WMTS vec_w/cva_w，并非天地图 JS API。官方 WMTS 服务文档列出矢量、影像、地形、注记和境界等服务，示例 STYLE=default，未找到独立暗色图层或自定义配色接口。JS API 的 setStyle 不能直接当作 MapLibre 或 WMTS 参数使用。上述结论限于本次公开资料与示例，不推断未公开的企业产品。

## 替代选择

高德 JS API 2.0 官方明确提供 `amap://styles/dark`（幻影黑）和 `amap://styles/darkblue`（极夜蓝），支持初始化 mapStyle 和运行时 setMapStyle，以及控制台编辑发布自定义地图样式。

对于中国大陆为主、强调稳定暗色视觉层次的场景入口，推荐高德 JS API 2.0 作为下一步对照验证对象。不要将高德未公开瓦片 URL 填入 MapLibre。若采用高德，应增加地图适配层，以官方 SDK 承载底图；搜索、筛选、场景授权与卡片继续复用。业务位置保留原始坐标及来源，按官方坐标要求完成显示适配并验证控制点，不覆盖原始 WGS84 数据。

高德“世界地图”文档说明：海外详细道路和 POI 覆盖 200+ 国家和地区，但属于高级地图能力，需工单商务咨询、为 key 开通权限，初始化 showOversea=true。因此海外详细覆盖、海外暗色样式一致性和商业许可费用均不能在尚无授权实测时宣布通过。

## 执行建议

1. 不因“天地图没有暗色”直接废弃现有方案，该判断不成立。
2. 若接受官方栅格变色效果，可保留天地图；应作为底图显示方案单独验收，避免处理场景标记、浮层和地图署名。
3. 以高德官方极夜蓝为高质量暗色方案的首选验证对象。先在隔离验证页对照昼夜样式、中文注记、点聚合、物理位置对齐及目标网络表现，再决定生产引擎迁移。
4. 高德接入需要该平台 Web JS API key 及安全配置，天地图 key 不能复用。账号开通与商务承诺尚未执行。
