# P25–P27 平台、在线消费与稳定试用

业务主线不增加新实体：Workspace → 场景空间 → 资料／批次 → 本次模型 → 双视图 → 核对 → 固定发布 → 使用。

## P25 平台联调

公开发现文档已核对：accounts.vxture.com、RS256、PKCE S256、授权码／刷新、RFC8693换票。CoSpace沿用现有RP会话及本机场景授权；不会借用Yucer客户端或登录凭据。

当前缺少CoSpace的Client ID／Secret、正式Origin和会话加密密钥。公开契约检查、配置工具和本机认证回归可以完成；实际登录、Workspace切换、平台授权撤权及中央会话状态仍须在真实客户端下验收。公开发现文档不能证明会话状态扩展或成员权限数据接口已联调。

## P26 独立程序在线消费

调用产品以自己的confidential client在平台换取短期service票据：aud为CoSpace产品代码、act.sub为调用产品、显式org_id与workspace_id、scope=tool:{audience}、TTL最多300秒。本批只接service模式；OBO和delegated票据不能借此取得权限。

平台换票判定产品覆盖与订阅；CoSpace另校验该Workspace对应场景和调用产品的明确场景授权。唯一接口为固定发布的只读点查询；没有默认最新版本、资料读取、构建或管理权限。浏览器Cookie与程序Bearer凭据分离。

请求必须固定publication、model_manifest_sha256、frame_id并声明max_age_s；返回携带模型摘要、坐标、新鲜度、完整性与质量。当前样本无可信UTC映射，as_of／valid_until显式null，实时查询拒绝。只有显式历史模式并接受时间未验证时才返回surface_candidate或unknown；unknown不转为空闲。精度unverified、robot_ready=false。

每次重新读取场景授权和分发状态；暂停／退役后拒绝新查询，不替换请求版本。客户端重新换票，不保存令牌、不使用浏览器会话。真实换票依赖P25及调用产品授权，本机mock交换仅验证接入实现。

## P27 稳定试用

固定入口与目录，Windows单机、loopback绑定，沿用现有受管理服务锁、业务目录和冷备份。原始样本与批次验收目录受保护。业务根仅runtime／policy／setup；会话与服务凭据放独立state目录。consumer-access只含非秘密授权配置并纳入冷备份。

启动前核对源码、编译资产、锁文件、解释器与关键依赖版本。配置有明确mock／platform模式；platform配置缺失即失败。Windows进程Job绑定使服务异常退出时子进程同时结束，重启后现有恢复机制标记未完成构建为interrupted。

停服通过当前实例的请求文件，服务排空HTTP后退出，无按任意PID杀进程的控制。业务备份仍限同机原路径恢复；保留旧根再恢复，不能覆盖运行目录。无自动升级、跨机迁移或新的运维平台。

本机自动化演练与真实平台部署、另一工程师交接分别记账。后两者需要外部环境与实际参与者，不能以mock自动化替代。
