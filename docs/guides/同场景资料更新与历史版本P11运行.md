## 业务操作

1. 在同一场景的数据管理导入新资料，保留旧资料；本次新包为原序列前30帧，不是第二轮现场采集。
2. 新建“导入样本”批次，保存新资料成员，预检并封存，使用准确的批次成员提交构建。
3. 查看模型冻结、人视图、智能体视图三个阶段；核对与当前候选差异后选择，再单独确认固定发布。
4. 态势服务同时保留新旧发布。点击新版“版本比较”，明确选择第一版作基线，再比较；打开任一固定版本都会新建三维标签页。
5. 需要回切工作候选时，在构建任务找到旧候选并“核对并选择”；这不修改任何固定发布，也不切换消费机器。
6. 离线安装新包后保持旧引用。在目标发布点击“本地消费”，按实际消费库revision显式激活；需要回切时采用旧发布的包ID与SHA-256重新激活。重启后显式恢复保存的版本。

## 重放样本与验收

原封存资料只读，输出目录必须不存在：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.prepare_input_prefix --snapshot <原封存snapshot目录> --tracking <匹配tracking.json> --output <新样本目录> --frames 30
```

输出 `input.zip` 可通过数据管理上传；`preparation.json` 记录原报告与轨迹摘要及截取方式。只支持严格短于已有观测位姿数量的前缀，保持原首帧锚点。

后端与前端：

```powershell
.venv/Scripts/python.exe -X utf8 -m pytest tests/test_prepare_input_prefix.py tests/test_uploaded_batch_flow.py tests/test_preview_publications.py tests/test_preview_publication_changes.py tests/test_preview_consumer_store.py tests/test_preview_offline.py tests/test_preview_changes.py tests/test_platform_business.py -q
pnpm --dir apps/workbench run build
```

离线重放使用已有浏览器回执和真实下载包，输出目录必须不存在：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_uploaded_versions_consumption --browser output/playwright/flow-batch-p11-versions-result.txt --output var/validation/p11-consumer-new-replay
```

专用故障环境重放，不在运行中的演示服务注入故障：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_uploaded_version_failure --source var/validation/input-upload-p9-2026-11-04-001/runtime --output var/validation/p11-failure-new-replay --space space-d7a370b8107c30f7 --input input-74de27ff3c274b47 --batch batch-5dfe47a7b87943d3
```

浏览器脚本包含固定样本ID，只用于该隔离运行区，不直接对用户业务环境执行回切。详见[P11验收](../validation/同场景资料更新与历史版本-P11-2026-11-04.md)及 `output/playwright/flow-batch-p11-acceptance.json`。
