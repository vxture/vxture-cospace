# 交付核对工作台运行

日期：2026-10-27。只读保存报告展示；服务仅绑定本机，仍无生产认证。

后续支持独立目录与固定选择，另配COSPACE_DELIVERY_ARCHIVE，见[归档运行](交付报告归档运行.md)。本手册保留单文件入口，两配置独立可并存。

后续已支持0.2报告，页面展示批次、观察起止、单调耗时和来源上下文；0.1继续读取且显示缺失元数据。下文“未记录”描述适用于旧版；新版区间来自生成端普通时钟，不是可信时效或有效期。见[契约](../../contracts/schemas/delivery-generation-v0.1.md)和[验证](../validation/交付报告上下文验证-2026-10-27.md)。

## 配置已有报告

先用[原CLI](智能体只读交付核对运行.md)生成单份报告，保存到被核对库以外。使用PowerShell 7.4或更新版本重定向原始stdout，保留UTF-8字节；报告存在待处理项时CLI退出码2也会输出诊断。参数错误输出的error对象不能作为报告加载。

```powershell
.venv/Scripts/python.exe -m experiments.scripts.delivery_audit --files D:/local-data/agent-files --journal D:/local-data/recovery-test --binding D:/local-data/binding.json > D:/local-data/delivery-report.json
$env:COSPACE_DELIVERY_REPORT = 'D:/local-data/delivery-report.json'
pnpm --dir apps/workbench run build
```

路径均为示例，父目录须已存在。报告必须是schema_version=cospace.test-delivery-audit/0.1或0.2的单个对象，不接受四阶段scenario.json包装文件。只配置本地操作者明确指定的报告；页面不能输入服务器路径。新版元数据与内容关联不符会拒绝，不能手工复制generation到另一份报告。

按[原托管服务手册](本地工作台与迁移运行.md)准备专用PostgreSQL及COSPACE_DATABASE_URL，再启动：

```powershell
.venv/Scripts/python.exe -m uvicorn apps.api.managed:managed_app --factory --host 127.0.0.1 --port 8000
```

现有临时演示脚本也会继承COSPACE_DELIVERY_REPORT；报告与演示发布是独立数据，不会自动重绑。结束后如不再需要，执行Remove-Item Env:COSPACE_DELIVERY_REPORT清除当前终端配置，不删除报告文件。

## 页面操作

访问http://127.0.0.1:8000/workbench/，顶部输入与报告一致的场景/发布，再点导航“智能体交付 · 只读核对”，点击“读取 / 刷新交付报告”。无需先点击读取当前发布。报告无待处理项也不表示机器人能运行。

展开完整绑定，核对真值/视图版本、所有摘要、用途和范围。时间为北京时间显示，来自服务端普通时钟；底层观察时间未记录。刷新不会重新核对底层文件或日志，先重新生成报告，再刷新页面；建议生成到独立临时文件，完成后替换配置文件，减少读到未写完文件的机会，仍无跨库原子性保证。

503表示未配置、缺文件、不可读、格式不符或超过2MiB；409表示目标不匹配。页面会清除旧报告。GET只返回摘要及行动，原组件细节仍通过CLI报告查看。

## 复核

```powershell
.venv/Scripts/python.exe -m pytest tests/test_delivery_reading.py tests/test_lifecycle.py tests/test_jobs.py -q --tb=short
pnpm --dir apps/workbench run build
```

本批[浏览器验证脚本](../../experiments/scripts/delivery_workbench_browser.js)通过Playwright CLI run-code执行。需打开已挂载新构建的本机工作台，配置与默认场景/发布对应的clean报告，再执行脚本。故障和延迟路径使用浏览器路由注入；clean与目标不匹配访问实际本机接口。脚本写截图至output/playwright/delivery；不准备数据库、修改报告或调用写接口。真实未决报告的额外浏览器检查记录见[验证](../validation/交付核对工作台验证-2026-10-27.md)。
