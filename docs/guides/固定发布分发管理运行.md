# 固定发布分发管理（H3b）

用于本机内部流程预览。操作变更的是指定发布的分发状态，不修改固定内容。原演示区只读浏览；验证写操作使用独立副本。

## 页面操作

1. 在“态势服务”选择当前工作空间，找到固定发布，点击“管理分发”。数据管理的成果目录也可从发布或来源离线包进入同一管理工作面。
2. 核对目标、修订、引用及阻断；点击“暂停分发”，填写原因后确认。取消不写入，原因不可为空。
3. 暂停后管理列表保留，查询、打开固定版本和下载入口隐藏；空间卡片禁止打开，最近发布暂停时不自动回退到旧版本。已保存的直接链接同样返回409。
4. 在同一管理区查看原因与历史，点击“恢复”、填写原因并确认。恢复前重新检查证据，成功后恢复同一发布的查询、文件及下载。

操作失败、409或网络响应不确定时，先点击“刷新使用状态”读当前修订与历史；不能假定未提交或直接重发旧请求。旧操作控件会清除。账本、模型或来源损坏时先核查，不能用恢复绕过。

暂停不撤回已下载、安装或缓存的副本，暂停前已准入的响应也可能完成。在线消费逐请求检查，离线消费不依赖远程撤回。资料、候选和其它发布分别管理。

## 隔离复跑

已有H3a验收副本时，在项目根执行；output必须是不存在的新目录：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_preview_distribution --source var/validation/control-h3a-001 --output var/validation/distribution-h3b-new
```

脚本复制runtime，在新副本的临时HTTP服务中对NYU和激光两类样本暂停/恢复，测试查询、资产、离线ZIP及管理元数据；暂停期间，另一组禁用网络的消费进程安装并恢复之前持有的包，证明离线副本不会被伪称撤回。最后停止临时服务并比较原演示区及源副本的成果摘要。该命令会写新副本，不在源副本或var/nyu提交操作。

```powershell
.venv/Scripts/python.exe -X utf8 -m pytest tests/test_preview_distribution.py -q --tb=short
```

同一运行区只运行一个服务；状态账本和引用记录一起备份，不在运行时删除锁或修改数据库。未来真实身份和空间ACL接入前，保持本机内部预览范围。

接口见[分发契约](../../contracts/schemas/preview-publication-distribution-v0.1.md)及[受控状态](../../contracts/schemas/preview-artifact-control-v0.1.md)，结果见[H3b验证](../validation/固定发布暂停与恢复-H3b-2026-11-02.md)。浏览器写验证脚本含隔离测试ID，不要在原演示区运行。
