# 成果生命周期影响检查运行

H2提供停用、归档或停止分发前的只读检查。它显示引用、阻断原因和未来操作范围，此检查入口不执行操作。资料与候选已可通过独立[管理使用状态](成果使用状态管理运行.md)入口受控变更；发布分发控制仍未开放。

## 页面操作

1. 按[真实样本运行手册](真实样本流程运行手册.md)启动8767服务并构建前端。
2. Launcher → 构建 → 数据管理，选择工程空间，打开“成果目录”。
3. 点击某项“查看成果”，在关系详情点击“检查生命周期影响”。离线包点击“检查来源发布生命周期”，检查对应固定发布。
4. 对照引用统计、每种规则的阻断原因及历史保留范围。点击“查看引用”前往相同空间的批次、构建或态势服务记录。
5. 记录发生变化后点击“重新检查影响”。空间或成果切换会清除检查；点击“收起检查”关闭。

本机已有激光样本可[直接打开资料成果](http://127.0.0.1:8767/workbench/layout.html#data?space=space-6fe7d4c455774cb2&artifact=input%3Ainput-d61dc8fd9f294e6a)，再点击检查按钮。此空间的资料归档应显示“当前所选候选依赖此资料”；资料停用规则可能显示“保存记录符合规则”，但仍没有执行按钮。

## 如何解读

- “存在阻断”：按提示核查活动批次、保存任务、当前选择或缺失记录；不自动替换所选候选。
- “保存记录符合规则”：只代表本次检查，没有执行许可或质量结论；页面仍显示“仅规则预检 · 操作尚未开放”。
- “离线包入口”：按需导出关系，不代表包已下载、消费端安装或交付完成。
- 发布停止分发只是一项未来规则；历史消费副本无法由本服务追溯收回。

刷新失败时旧计划与引用列表会清空；恢复服务后重新检查。若报告与当前成果不一致，先核对空间和记录后刷新。损坏JSON可能使整份检查返回409；来源缺失但仍能构建目录时，报告显示缺口并阻断所有计划。

本阶段不轮询构建进程、不重新预检原文件、不生成ZIP、不写记录。保存的running/queued仍按活动处理；原文件是否变动须使用已有资料预检，消费端状态须另行核验。
