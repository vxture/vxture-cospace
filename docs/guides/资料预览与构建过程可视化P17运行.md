# P17 资料预览与构建过程可视化操作

## 1. 打开本批入口

[构建可视化](http://127.0.0.1:8781/workbench/layout.html#build?space=space-0004d0e3c133f5fb&input=input-9129e7b23b4d4ea6&job=build-bfacf6b9b7f94b64&tab=flow)。这是 P17 独立副本，旧 8779／8780 页面不作为本批验收入口。

尚未登录时点击“登录”，选择“模拟场景管理员”。查看者可看授权发布，不能看原资料或构建阶段。长时间停留后若提示会话或网络不可用，先点“确认会话并重试”，再刷新构建流程。

## 2. 全屏扫描展示与三个阶段

在构建中心“资料到双视图”页找到“构建过程可视化”，点击“打开构建画布”在新标签查看铺满屏幕的点云渐显效果。当前为静态成果按方位展开的扫描演示，非真实采集时间或机器人轨迹；底部可暂停、重播、调速和拖动展示进度。主体视角不删除点，适配全图返回完整范围。见[补充验收](../validation/全屏扫描式构建展示-P17补充-2026-11-05.md)。

原页面点击“查看阶段产物”，切换固定模型、人视图、智能体视图。拖动旋转、滚轮缩放、右键平移；“适配全图”恢复完整范围，“放大查看”打开大画面，关闭返回当前流程。

新构建仍从明确的资料和封存批次发起。真实阶段状态自动更新；模型已冻结即可看，某类视图成功即可看，不必等另一类完成。当前仅展示已保存的阶段产物，没有实时重建动画或虚构百分比。失败时使用原独立派生／重试入口，不会因查看而启动任务。

## 3. 构建前看资料

[资料详情](http://127.0.0.1:8781/workbench/layout.html#data?space=space-0004d0e3c133f5fb&tab=inputs&input=input-9129e7b23b4d4ea6) → 内容预览 → 查看点云。

导入资料 → 准备 PLY → 选择原始文件 → 检查文件并预览，可先看本机内容再填写声明；此时不会上传或登记。后续填写坐标、单位、来源并确认才登记。仍支持 P16 严格二进制小端 XYZ／XYZRGB，32MiB／100万点；不支持任意 PLY 或其他点云格式。

显示抽样与完整数值范围同时列出。没有 RGB 使用中性显示；激光强度灰度不作为原始 RGB。智能体单元只代表观测表面，其余未知。内容预览及流程成功不代表精度或机器人可通行性验收。

## 4. 本机服务恢复

当前服务端口 8781，业务目录 var/validation/p17-001/runtime，认证位于 var/validation/p17-restart-001/auth。仅在该端口无监听且需要恢复时，从项目根目录启动；输出目录需用全新名字，避免覆盖历史证据：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.serve_scene_journey_demo --source var/validation/p17-001/runtime --output var/validation/p17-manual-001 --candidate build-c8445a7aa7744502 --port 8781 --existing-runtime
```

重新启动模拟身份源后需重新登录。不要为查看本批而停止其他端口。完整测试证据见[验收记录](../validation/资料预览与构建过程可视化-P17-2026-11-05.md)。
