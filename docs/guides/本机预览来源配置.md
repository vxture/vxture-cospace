# 本机预览来源配置

默认配置文件：[preview-sources.json](../../deploy/config/preview-sources.json)。工程师修改文件后重启服务，无需修改Python代码。路径相对项目工作目录，服务应从项目根目录启动。

```json
{
  "profile": "cospace.preview-sources/0.1",
  "sources": [{
    "id": "office-short",
    "label": "办公室封存资料",
    "enabled": true,
    "format": "nyu_rgbd_with_existing_poses",
    "snapshot": "var/project/scene-short",
    "tracking": "var/project/tracking.json"
  }]
}
```

`id`须唯一，以小写字母开头，仅小写字母、数字及连字符，最多64字符。名称1至100字符；enabled必须是布尔值。停用来源可暂不存在，但格式及路径声明仍需合法。当前支持两种显式适配器：

| format | 启用时必要文件 | tracking |
| --- | --- | --- |
| nyu_rgbd_with_existing_poses | snapshot/report.json与轨迹文件 | 必填 |
| ros1_lidar_single_frame | snapshot/sample.json与sample.bag | 省略，不支持非空值 |

第二种来源配置项示例，可加入sources数组：

```json
{
  "id": "os1-single-frame",
  "label": "OS1-16 单帧局部样本",
  "enabled": true,
  "format": "ros1_lidar_single_frame",
  "snapshot": "var/samples/multi-1-os1-lidar-1s-001"
}
```

激光适配器仅处理有逐消息证据清单的受限封存样本，首帧用于候选，其余消息只核对来源；不直接接受任意原始大包。详见[格式契约](../../contracts/schemas/preview-lidar-single-frame-v0.1.md)。

资料路径仅允许项目内相对路径，拒绝绝对路径、越界路径及解析后越出项目的链接。未知字段、重复ID、未知profile或适配器、缺失启用文件会拒绝启动，不回退默认清单。最多100项，配置文件最多256KB。

完整文件校验（不登记、不构建）：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_sources --full-check
```

指定项目配置并启动：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.serve_nyu_flow_preview var/nyu/office-0001a-flow-001 --port 8767 --sources-config deploy/config/preview-sources.json
```

单独检查其他工程根目录可使用CLI的 `--project-root`；服务以启动工作目录作为工程根目录。启动读取配置、校验结构与必要文件存在，不遍历全部图像；登记提交始终执行完整校验。

配置只在启动时读取。`GET /api/registration-sources` 的configuration返回本次加载的摘要、启停数量、来源状态及重启策略，不公开配置路径和资料路径。登记窗口显示启用/停用数量及加载提示；configured表示已配置，不代表完整文件验证已通过。CLI的full-check报告为validated。

空sources合法，表示不允许页面新增登记，不会自动登记样本。停用来源仅停止其页面新增登记，不撤回已有登记、构建或发布，CLI权限不受此文件约束。配置仍由本机工程师维护，本批没有生产认证或远程配置管理。
