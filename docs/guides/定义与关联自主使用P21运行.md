# P21：本体维护与场景对象关联

## 操作路径

1. 以Workspace所有者登录，打开“定义 → 语义本体”。新建草稿或复制所选固定版本。
2. 维护对象类型、文本属性、必填／长度，以及包含或连接关系的允许端点类型。填写原因，校验，保存草稿，再保存固定版本。
3. 打开一个场景空间的“空间关联 → 语义与几何”，明确基础候选和固定规则版本。
4. 输入对象ID、类型及属性；在真实三维点云上双击选位置，核对坐标和原模型点索引，加入本次完整标注集。可拖动旋转、滚轮缩放。渲染不可用时可展开“按模型索引选择（备用）”。
5. 生成标注候选。再到“对象间关系”，选择该新候选，建立关系，校验完整集合并明确确认后生成关系候选。
6. 前往构建中心，核对几何／对象／规则／关系差异并选择；到态势服务单独发布。打开固定空间或下载离线交付包进行查询。

草稿历史可再次打开查看。已固定规则的修改通过新版本完成；旧发布固定原规则，对象不会因规则升版而自动迁移。场景manager可应用规则，不能维护Workspace规则。

## 出现问题时

- 草稿修订冲突：重新读取草稿与历史后修改，避免覆盖其他人的保存。
- 规则校验失败：检查ID、属性长度、关系端点类型；可先保存草稿，再修正并校验。
- 固定版本冲突：读取原版本；确需改规则时复制为新版本。
- 模型位置不可读：刷新固定候选，确认场景及坐标声明；不要填写屏幕坐标代替模型点。
- 构建／发布失败：保留原发布继续使用，查看新候选或发布错误并重试。
- 离线使用：安装不自动激活，重启需显式恢复。规则、对象、关系和几何必须来自同一交付包。
