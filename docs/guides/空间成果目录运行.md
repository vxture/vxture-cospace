# 空间成果目录

1. 按[真实样本流程运行手册](真实样本流程运行手册.md)构建并启动本机服务，从Launcher进入“数据管理”。
2. 选择工作空间，默认显示“成果目录”。分类统计区可以筛选登记资料、模型候选、固定发布、离线包，也可用名称、ID或“语义候选”等分类文字搜索。
3. 点击“查看成果”，页面定位到成果关系详情；查看“上游来源”“下游引用”，点击“查看关联成果”沿链路浏览。
4. 登记资料可进入原“详情与预检”；候选可定位构建中心；发布可定位态势服务或在新标签页打开固定空间；离线包可查看包信息及下载。
5. “刷新成果”重读目录；“登记资料”标签页保留原资料登记、搜索及预检流程。不会因为进入成果目录而执行预检或创建新候选。

当前激光空间`space-6fe7d4c455774cb2`共7项：1份登记资料、2个候选（几何/语义各1）、2个固定发布、2个按需离线包入口。语义候选`build-a16bfad1237544bf`上游同时包含构建输入与标注基线；对应发布为`preview-9b422a246ffb4ea5`。

NYU空间`space-30515836b1cd4d55`共10项：1份登记资料、3个候选、3个发布和3个离线包入口。历史未关联范围独立查询，部分早期成果没有输入登记绑定，显示“未记录来源”，不会按路径猜测。

目录显示“本次快照完整性通过”只表示当前记录及文件绑定一致。输入仍需单独预检；离线包“按需导出”不表示用户已下载或机器人已安装。只有点击包摘要或下载入口才调用已有导出接口。

原候选或登记记录丢失时，完整固定发布仍可查看，其来源显示缺失；损坏发布隐藏离线包入口。出现“当前候选选择指向缺失或不一致的记录”时到构建中心核查，目录不会自动修复、重新选择或回滚。
