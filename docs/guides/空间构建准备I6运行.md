# 空间构建准备 I6 运行

日期：2026-11-03。入口仍为六模块，本轮补齐工程师可见的准备进度。

1. [打开本机工作台](http://127.0.0.1:8769/workbench/layout.html)，模拟管理员或工程师登录。
2. 空间卡片点击“查看流程”，上部“构建准备”列出来源许可、各份资料上次预检与关联构建数量。
3. 点击某份资料的“跟进此资料”，流程页明确当前跟进资料。未检查、检查失败或停用时，进入“查看资料与预检”。
4. 执行预检后，结果保存；刷新详情仍显示“上次预检”。点击“查看此资料的流程”，返回同份资料的准备进度。
5. 上次通过且资料启用时，可前往构建中心。已有候选或进行中任务会提示核对选择/刷新；提交构建仍重新校验，历史通过不豁免文件检查。

查看者只浏览既有成果流程，不查看准备记录、执行预检或构建；界面隐藏无权动作链接。来源配置与资料使用状态分开，停止新登记不阻断已登记资料；停用资料按原生命周期操作。

默认本机数据是独立副本，原195个受管文件不写。认证仍使用本地模拟平台，真实平台客户端待联调。预检不是精度或机器人通行性验收。
