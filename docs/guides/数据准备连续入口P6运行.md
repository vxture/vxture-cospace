# 数据准备连续入口 P6

数据管理围绕当前场景空间运行：**来源配置 → 导入资料 → 预检 → 用于构建**。六模块与场景归属保持一致。

## 操作

1. 在数据管理选择已有场景，或新建一个场景空间。不同真实场景分别管理。
2. 顶部准备提示显示下一步。空场景没有启用来源时，点击“配置来源”，选择当前Workspace分配的来源，填写原因并保存。
3. 点击“继续导入资料”，直接进入当前场景的导入对话框。尚未保存来源改动时不能继续；普通导入框没有可选来源时，也能返回配置入口。
4. 导入成功自动定位资料，打开页面右侧详情。重复导入相同内容会定位已有资料。
5. 在默认可见的“预检与构建”中点击“执行预检”。列表及准备提示同步显示保存结果；文件缺失或服务不可用时按提示处理并重试。
6. 点击“用于构建”，进入绑定当前场景、当前资料的构建中心。检查批次要求后显式提交任务；成功后按既有模型、双视图、核对与发布流程操作。

预检结果是带时间的历史文件检查，构建提交仍重新核验。技术路径、来源修订和操作者等明细放在“资料技术信息”中。关闭详情后需重新选择本次资料，不自动选择最新登记。

切换场景会清除上一场景的详情、资料选择及准备提示。停用来源限制新登记，已经登记的资料按自己的使用状态管理。停用或归档资料的构建入口禁用。
