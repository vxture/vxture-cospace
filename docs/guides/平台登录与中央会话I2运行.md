# 平台登录与中央会话 I2 运行

日期：2026-11-03。CoSpace 按 yucer / accounts 约定实现独立 RP 登录链路。当前是可启动的认证验证模式，空间业务接口保持关闭；原8767样本工程预览独立运行。

## 1. 先看本地流程

本地模拟入口为 `http://127.0.0.1:8768/workbench/layout.html`，页面点击“登录”后进入明确标注的“本地模拟平台”，使用模拟身份继续后回到 CoSpace。可检查会话、重新连接和退出平台登录。该入口只验证协议与页面行为，没有真实平台账号授权，也没有连接原样本数据。

复跑时使用新的目录；模拟配置、密钥在内存中临时生成，结束进程后不保留可恢复身份：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.serve_platform_auth_mock --runtime var/validation/platform-rp-i2-demo-rerun --port 8768
```

不能与当前8768进程同时监听。模拟器仅允许环回监听，切勿作为真实身份提供方部署。

## 2. 接到真实平台

平台需要为 CoSpace 独立登记 confidential OIDC client。回调路径固定为 `{COSPACE_ORIGIN}/auth/callback`，登出返回固定为 `{COSPACE_ORIGIN}/workbench/layout.html`；授权码和refresh token交换使用 client_secret_basic + PKCE S256。不复用 yucer client、cookie 或 Redis session。

服务端环境变量名称见 `deploy/config/platform-oidc.example.json`，该文件只是说明，不会自动加载：

| 变量 | 含义 |
| --- | --- |
| COSPACE_OIDC_ISSUER | 对外 issuer，默认 accounts.vxture.com；精确验 iss |
| COSPACE_OIDC_BACKCHANNEL | 服务端访问平台的基址，默认同 issuer，可与容器外公开地址不同 |
| COSPACE_OIDC_CLIENT_ID / SECRET | 平台登记给 CoSpace 的客户端凭据 |
| COSPACE_ORIGIN | CoSpace 公开 origin，无尾斜杠和路径；用于回调与 Origin 校验 |
| COSPACE_SESSION_KEY | 稳定 Fernet 加密密钥；服务重启必须保持一致，不能进源码或前端变量 |
| COSPACE_OIDC_LOOPBACK_HTTP | 本机开发显式设1才允许 localhost/127.0.0.1 HTTP；其它地址仍须HTTPS |

准备好环境后启动：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.serve_platform_auth --runtime var/auth/cospace-rp --port 8768
```

服务仅绑定127.0.0.1，真实HTTPS由部署代理终止并路由到该端口。真实平台配置不完整会拒绝启动，不回退为匿名模式。`runtime`须独立于`var/nyu`。密钥不会在启动错误中回显，不要把环境变量值粘贴到聊天或日志。

## 3. 本轮实现

登录回调使用服务端600秒单次state、随机nonce、PKCE和HttpOnly浏览器绑定Cookie；同时校验id/access token的签名、issuer、audience、sub及sid。成功回调替换浏览器原RP会话，防会话固定。浏览器只持opaque Cookie和用于同源操作的CSRF值，不持access/refresh token。

中央`/oidc/session/status`决定登录状态与下一检查时间；后台GET仅读保存状态。界面只在真实鼠标/键盘操作时报告active，并在服务端按中央时间表合并查询。过期access token不等于登出；网络错误、5xx、invalid_client和格式错误保留会话。需要access token的服务方法对过期中央确认采用拒绝调用，后续业务路由需使用该方法。

加密SQLite适配器为**本机单宿主**实现，跨本地进程通过OS锁避免并发刷新；不是多主机Redis/HA方案。刷新前先保存pending标记，崩溃或丢失响应后禁止重用可能已消费的refresh token，保留登录供重新连接。会话数据库恢复需要同一稳定密钥；密钥不匹配返回暂不可用，不误判成退出。

退出必须同源POST+CSRF，清除本地记录并顶层导航accounts `/oidc/end_session`。认证路径用no-referrer避免回调参数泄露，工作台用same-origin保持表单Origin。生产Cookie是`__Host-cospace_rp`，Secure/HttpOnly/SameSite=Lax/Path=/且无Domain；开发HTTP使用`cospace_rp`。

## 4. 复验

```powershell
.venv/Scripts/python.exe -m pytest tests/test_platform_login.py tests/test_platform_identity.py tests/test_space_access.py -q --tb=short
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_platform_login --output var/validation/platform-rp-i2-http-rerun
```

HTTP工具启动本地模拟平台和独立RP子进程，经过一次真实服务重启，最终自动停止；输出18项检查、16次脱敏HTTP轨迹和195个原文件基线核对。它不输出token/密钥/cookie或授权码，也不调用真实accounts。加密会话库留在var，证据归档只拷贝脱敏结果。
