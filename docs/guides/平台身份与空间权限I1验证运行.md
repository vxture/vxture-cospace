# 平台身份与空间权限 I1 验证运行

本批验证服务端认证适配器与空间权限规则，不访问真实平台账号。

```powershell
.venv/Scripts/python.exe -m pytest tests/test_platform_identity.py tests/test_space_access.py -q --tb=short
```

预期：112 passed。测试使用进程内生成的 RSA 2048 密钥，模拟平台 JWKS 与 access token；不会读取 `.env`、client secret、yucer session 或真实用户数据。弱密钥负例有两条预期的 SecurityWarning。I1 仍未把认证门禁装配到 `serve_nyu_flow_preview.py` 的公开 HTTP 路由，演示服务继续保持内部工程预览行为。

可对已有样本目录执行只读验证，output 必须是新的独立目录：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_platform_access --output var/validation/platform-access-i1-rerun
```

该工具校对历史195文件基线，读取3个空间及9个发布，用临时本地签名身份验证授权适配器，输出前后摘要、合成策略和19项检查。它不验证真实登录、不发起HTTP授权请求、不轮询任务、不重新检查采集资料、不导出数据包，也不修改源目录。测试密钥和token不写盘。

下一批顺序：

1. 注册 CoSpace 独立 OIDC client，接入授权回调、PKCE、会话 Cookie、中央 session-status 与全局登出。
2. 为平台工作区建立空间绑定和产品成员授权持久化。
3. 把同一 request principal 接入目录、发布/资产、查询、下载、构建、关联和发布路由，再用两个隔离用户做正负 HTTP 验收。
