# 本地工作台与迁移运行

当前仅合成验证，使用专用数据库并仅绑定本机；没有认证或正式交付能力。

## 可复跑临时演示

准备Python3.14、uv、Node24、pnpm和Docker，本地需要postgres:18镜像。从仓库根目录执行：

```powershell
uv sync --locked
pnpm --dir apps/workbench install --frozen-lockfile --ignore-scripts
pnpm --dir apps/workbench run build
./experiments/stack/run-workbench-demo.ps1
```

脚本创建独立限额数据库、应用迁移、登记并激活合成样例，然后在http://127.0.0.1:8766/workbench/提供工作台。Ctrl+C停止服务后清理本次容器；数据是临时演示数据，不保留。若运行被强制终止，先确认脚本输出的精确容器名，再清理该容器，不清理其他项目。

点击读取当前发布，再查询[5,3,1]为占据，[8,4,1]为未知，[1,0,1]为已观测空闲；这些是合成测试结果，不代表现场空间事实。

点击“加载 / 刷新人视图”可旋转、缩放合成空间，核对对象锚点与状态分区；[3.5,0.5,0.5]所在冲突区仍为未知。浏览器显示实际使用的WebGPU或WebGL2后端；渲染不可用时仍可核对对象列表与分区明细。刷新人视图先清除上一条点结果，再查询可重新标记查询点。

2026-10-26的人视图增量扩展了内部持久快照，保存已校验对象及人视图描述。旧快照继续支持原有查询与追溯，但读取人视图返回409/human_view_unavailable；旧库直接重新登记相同release_id可能触发immutable_conflict，不自动改写历史。需使用新release_id登记增强快照，或在明确可丢弃的演示环境重建临时库。当前新增快照重复登记仍幂等，无数据库表结构变化。

## 专用持久开发库

由操作者配置COSPACE_DATABASE_URL至专用PostgreSQL，凭据不写入仓库。依次执行：

```sh
uv run --locked alembic upgrade head
uv run --locked python -m apps.cli.releases register examples/indoor-spatial
uv run --locked python -m apps.cli.releases activate --scene synthetic-equipment-corridor --release release-spatial-sample-001 --expected-revision 0 --actor engineer
uv run --locked uvicorn apps.api.managed:managed_app --factory --host 127.0.0.1 --port 8000
```

访问http://127.0.0.1:8000/workbench/。后续激活使用实际revision，不能盲重试。撤回命令见[CLI说明](../../apps/cli/README.md)。页面已固定版本也不能绕过服务器撤回检查。

## 迁移边界

0001_sample_lifecycle以冻结定义创建样例表，不依赖未来模型的当前定义。重复upgrade head不重建或清空已有数据；降至base仅允许空库，有任何样例、指针或事件记录时拒绝删除。自动降级不是恢复策略，备份恢复仍需后续演练。

此前只用create_all建表且没有alembic_version的数据库不能直接自动接管。应先核对结构和数据、备份，再制定基线接管步骤；本轮不自动stamp或迁移未核验的既有库。

## 资料与本体核对

选择固定发布后点击“加载 / 刷新资料与本体”，可查看7份合成资料的角色、大小和SHA256，以及3类类型规则和3个实例的属性/坐标。登记校验时点未记录；页面不会把当前读取时刻写成校验时间。没有对象级证据关联时明确显示未登记。

本次内部快照新增inspection.version=1，保存固定manifest和本体原始文本；表结构未变化。旧快照读取核对接口返回409/inspection_unavailable，继续支持原查询与历史追溯；不要覆盖旧发布，应使用新release_id登记。新建演示脚本自动登记当前增强快照。登记字节及规则通过不等于许可或现场质量已通过。
