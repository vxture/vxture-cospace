# 空间资料来源 I5 运行

日期：2026-11-03。本轮接通数据管理的授权来源配置，六模块划分保持不变。

## 使用

1. 打开[本机授权工作台](http://127.0.0.1:8769/workbench/layout.html)，在本地模拟平台选择管理员登录。
2. 在空间卡片打开“数据管理”，点击“资料来源”。勾选需要的封存资料，填写原因并保存。
3. 点击“登记资料”，选择当前空间已启用的来源、填写资料名称并校验登记。
4. 在登记资料详情执行预检，通过后点击“用于构建”，在构建中心提交候选任务。
5. 停用来源后，新的登记请求会被拒绝；已有登记仍可按其使用状态参与构建。停用已有资料请到成果生命周期管理执行，不通过来源开关代替。

来源页显示修订、已启用项和管理历史。工程师只读查看已启用项，可以登记和构建；查看者不能访问数据管理。实际平台客户端仍待配置，本机使用明确标识的模拟身份。

配置冲突时保留未保存选择和原因，重新读取前先保留需要的内容，再核对最新配置。来源同ID改路径或适配器后，需要管理员重新确认才可再次登记。

## 部署

部署来源清单仍使用 `deploy/config/preview-sources.json`，项目相对路径、限定的两类适配器、完整格式规则保持不变。配置文件只能由服务端部署管理员维护。它是本服务可供空间管理员选择的可信目录；不要加入尚未许可分配的资料。

真实RP启动可指定 `--sources-config`；其它平台变量与启动要求沿用[I3手册](空间业务权限I3运行.md)。空清单允许启动，空间默认无启用来源；配置无效则拒绝启动。来源清单改动需重启，空间启停不需重启。

封存样本仍从已配置路径读取，登记不复制大文件。演示管理记录、登记、构建只写独立运行副本，原 `var/nyu` 受管成果不变。新登记资料记录当时来源ID、配置修订、目录摘要与已验签操作者；旧记录不会因重复登记被改写。
