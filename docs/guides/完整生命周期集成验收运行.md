# 完整生命周期集成验收（H3c）

本轮把数据管理、构建中心、态势服务和空间预览的状态控制串起来验证，语义本体与空间关联沿用已有固定快照。采用NYU RGB-D及ROS1激光单帧两类公开样本，验收范围为本机工程流程。模型精度、现场语义和生产权限仍未验收。

## 按六入口理解当前成果

| 工作面 | 当前可完成 | 生命周期中核对什么 |
| --- | --- | --- |
| 空间预览 | 项目/空间目录、固定双视图和历史版本 | 暂停的最近发布不可打开，不自动回退旧版本 |
| 态势服务 | 固定发布、查询、下载、分发暂停与恢复 | 分发状态控制新请求，同一发布恢复后字节不变 |
| 数据管理 | 登记、预检、批次封存启停、成果和引用检查 | 资料、批次各自控制；来源缺失不能当成零引用 |
| 构建中心 | 构建、比较、人工核对、选择 | 停用资料/批次不可新构建；归档候选不可新选择或派生 |
| 语义本体 | 固定版本、类型/关系约束与草稿校验 | 状态操作不改写已经固定的本体版本 |
| 空间关联 | 对象锚点、固定台账、对象关系候选 | 祖先归档不让已生成后续候选或已发布关联失效 |

页面“项目进度”是实施记录；空间卡片“查看流程”只反映保存记录。服务端不知道另一台设备是否安装、激活或恢复了离线包，消费阶段仍显示未核验。

## 组合验收顺序

1. 读取完整批次、资料、几何候选、关联候选、当前选择及匹配发布，保存对象、点/范围查询和离线包基线。
2. 停用批次，验证省略批次和旧修订都不能绕过。停用资料，验证当前所选候选仍依赖该资料时不可归档；当前候选自身也不可归档。
3. 归档历史几何候选，阻止新的选择、关联派生和发布；现有后续候选、固定发布及离线包保持可读。
4. 暂停该固定发布，查询与双视图/包入口拒绝，空间默认入口不回退。两类样本同时保持这组受限状态，再停止并重启隔离服务。
5. 重启后核对所有修订与历史。在四层均不可用于新使用时，独立的禁网消费进程从本地已安装数据恢复，结果与原在线基线一致。
6. 临时移走副本内的一份登记JSON，验证来源缺失时新旧两种恢复请求均拒绝且不追加历史，然后按原字节恢复登记。传感器原文件不参与故障注入。
7. 先恢复固定发布：相同内容重新可读，但资料仍停用、批次仍停用、祖先仍归档。再分别恢复候选、资料；批次未恢复前依然不可新构建。
8. 显式恢复批次，用新批次修订实际重建；新候选不自动选择或发布，旧发布保留原批次修订。再次重启服务检查最终状态、历史、选择和原包字节。

暂停是新分发控制。离线副本和暂停前已准入的响应不追溯撤回；恢复单个对象也不会启用其他对象。

## 复跑命令

前提是已存在H1验收副本 `var/validation/batches-h1-001`、其封存源资料及当前Python依赖。源副本应无运行/排队任务、无生命周期账本，且没有服务正在使用它。输出必须是全新的独立目录：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.verify_preview_lifecycle --source var/validation/batches-h1-001 --output var/validation/lifecycle-h3c-new
```

脚本自行复制runtime并分配环回临时端口。会在新副本提交状态变更、注入一次登记缺失并恢复、启动两次真实构建和四个禁网消费进程，期间重启隔离服务两次；最终停止全部临时服务。环回HTTP明确绕过系统代理，不修改机器代理配置。

该工具拒绝源/输出包含关系、原 `var/nyu` 输出路径和已有输出目录。它不负责从零下载源数据，不应当作健康检查在原演示区运行。失败时保留 `failure.json`、HTTP轨迹及已完成检查；修复原因后换一个新输出目录复跑，不能拿中途状态当干净基线。

成功的 `acceptance.json` 给出逐项检查、两类样本、新构建、消费进程和服务重启信息。每个样本另保存baseline、combined-blocked、after-restart、missing-evidence、publication-restored、restored和final-restart报告。报告中的点云内容及对象声明仍为待验收。

单测回归可运行：

```powershell
.venv/Scripts/python.exe -X utf8 -m pytest tests/test_preview_lifecycle_integration.py tests/test_preview_control.py tests/test_preview_distribution.py tests/test_preview_batches.py tests/test_preview_consumer_store.py -q --tb=short
```
