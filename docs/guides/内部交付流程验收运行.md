# 内部交付流程验收运行

日期：2026-10-27。合成验收，无外部密钥/现场数据输入。准备Windows、Python3.14、Node24及已锁定开发依赖，在仓库根执行：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.delivery_acceptance --output experiments/runs/delivery-acceptance-new-run
```

输出目录必须是新目录，已有目录拒绝且不覆盖。每次另取运行名称；CLI退出0表示31项本地流程检查全部通过，1表示失败。标准输出只含简要状态；以输出目录的acceptance.json、receipts.json、reports和environment.json核对详情。临时源库自动清理，最终四份报告保留以供页面复核。测试会主动注入中断、建立恢复计划并对账，只操作临时测试库，不是生产恢复命令。

缺依赖、超时或失败时查看failure.type及check_id，保留原结果，另建目录复跑。失败证据仅记录安全的类型/阶段，不保存原异常或子进程输出。旧目录拒绝不会向旧目录写失败报告；目录本身不可写时无法保证落盘。

结果中browser_executed=false是明确范围，不表示页面失败或被自动验收。独立页面复核可在另一个终端用本次报告挂载本机服务。先确保已有工作台构建；若源码未构建，执行pnpm --dir apps/workbench run build。

```powershell
.venv/Scripts/python.exe -c 'from pathlib import Path; import uvicorn; from apps.api.managed import create_managed_app; from packages.infrastructure.delivery_reports import ReportArchive; uvicorn.run(create_managed_app(None,workbench_dir=Path("apps/workbench/dist"),delivery_archive=ReportArchive("experiments/runs/delivery-acceptance-new-run/reports")),host="127.0.0.1",port=8774)'
```

此演示服务不配置发布管理器，只操作交付核对区，不能点击其他发布/查询入口评估全产品。访问http://127.0.0.1:8774/workbench/，按照[用例清单](../architecture/内部交付流程验收清单-v0.1.md)核对页面。Ctrl+C停止。

[浏览器脚本](../../experiments/scripts/delivery_acceptance_browser.js)可通过Playwright CLI run-code运行，预期8774端口提供本次4份报告，截图父目录output/playwright/delivery-acceptance须存在。独立保存浏览器结果，不覆盖acceptance.json中的browser_executed，不把人工步骤勾选写成签章或授权。

回归命令：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_delivery_acceptance.py tests/test_delivery_archive.py tests/test_delivery_reading.py tests/test_delivery_context.py -q --tb=short
```
