# 智能体恢复与文件会话实验运行

日期：2026-10-27。仅Windows合成J4开发入口，不是正式机器人SDK或生产维护接口。

从仓库根目录执行组合测试和证据生成：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_recovery_session.py -q --tb=short
.venv/Scripts/python.exe -m experiments.scripts.recovery_session_evidence
```

证据命令在临时目录创建真实FilePackages文件后端和新RecoveryStore实验库，执行幂等恢复及撤回恢复，保存运行前后会话响应和只读报告到experiments/runs/p2-recovery-session-001。固定输出会覆盖同名场景/环境文件；历史需要保留时另存或调整输出目录。只保存合成结果，不保存随机私钥。

对已有J3实验日志只读核对：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.recovery_audit --root 'D:/local-data/recovery-test' --limit 100
```

root仅为示例，替换为已有user_version=3实验库目录；命令不创建目录/库，不改mode，不接管进程。退出码0表示读取完成且无待处理观察，退出码2表示未决/活跃恢复、不完整结果或非法参数。0不表示内容、签名、时间或机器人授权通过。需要保存报告时，将stdout写入库外独立证据目录。

组合会话使用experiments/scripts/recovery_session.py中的RecoverySession(files, scene, ledger, binding, clock)。ledger必须是RecoveryStore，files为FilePackages，binding必须完整匹配活动包。query逐次检查门禁；close释放内存内容。原R1的open_session与CLI不自动使用该封装。

恢复begin、resume和完成后，旧会话不能刷新复用；显式新开日志对象、新装配有效测试时间锚并新开会话。已撤回或过期仍会拒绝，不存在强制空间查询或降级返回“空闲”。生产可信时间来源尚未实现。

设计与角色边界见[组合设计](../architecture/智能体恢复与文件会话组合设计-v0.1.md)，证据见[验证记录](../validation/智能体恢复与文件会话组合验证-2026-10-27.md)。
