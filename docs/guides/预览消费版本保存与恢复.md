# 预览消费版本保存与恢复

面向内部交付工程师和消费端集成验证。适用于真实预览ZIP，Python 3.14及NumPy即可；查询时不需要服务或采集设备。此流程不是生产机器人授权。

## 1. 获取明确绑定

在“态势服务”选空间，找到固定发布，下载离线交付包，展开“本地消费”。页面读取该发布的offline.json，生成其发布ID、SHA256及空间ID对应的命令。页面只提供说明，不能查看消费机器状态。

在项目根目录运行。以下`SPACE_ID`、`PUBLICATION_ID`、`PACKAGE_SHA256`和包路径按实际值替换；不要原样复制占位符。首次选一个尚不存在的独立目录：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 init --space-id SPACE_ID
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 install "D:/Downloads/PACKAGE.zip" --publication PUBLICATION_ID --sha256 PACKAGE_SHA256
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 status
```

历史无归属包初始化时显式使用`init --legacy`，不能省略范围，也不能用legacy消费库接有空间归属的包。不同空间使用不同目录。已有目录跳过init，不能覆盖初始化。

安装只保存包，revision仍为0且saved_reference为null。所有包字节在独立SQLite中，后续删除下载ZIP不会影响已安装包；更换消费目录也不会自动从其他目录寻找活动版本。

## 2. 主动选择

读取status返回的revision，首次空库为0。将`N`替换为这个整数：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 activate --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --expected-revision N
```

成功后保存该固定引用，revision加1。CLI退出后进程内会话结束，保存引用仍在。下载新包或再次安装都不会自动切换；新版本需要显式activate。并发修改导致序号变化时，先重读状态再决定，不自动重试切换。

## 3. 重启后恢复与查询

重新执行status，会看到保存引用、`session_reference=null`、`restore_required=true`。这表示待显式恢复，不是包丢失。

核对saved_reference中的发布和摘要，将`R`替换为当前revision。含对象的0.2包：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 restore --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --expected-revision R --objects
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 restore --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --expected-revision R --object-id OBJECT_ID
```

点和范围查询也可用于旧0.1包，坐标须使用该包frame及米单位。以下`X Y Z`等是数值占位符：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 restore --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --expected-revision R --point X Y Z
.venv/Scripts/python.exe -m apps.cli.preview_consumer --root var/consumers/consumer-001 restore --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --expected-revision R --bounds MIN_X MIN_Y MIN_Z MAX_X MAX_Y MAX_Z --frame-id FRAME_ID --limit 1024
```

不加查询参数只恢复并输出本进程状态。每条CLI命令都是新进程，所以每次查询都显式restore；长期进程可用Python API保持一个固定会话：

```python
from packages.views.agent.preview_consumer_store import PersistentPreviewConsumer

store = PersistentPreviewConsumer('var/consumers/consumer-001')
state = store.status()  # 仅元数据，不自动恢复、不核对包字节
ref = state['saved_reference']  # 集成方先核对这是本次期望使用的固定引用
session = store.restore(ref['publication_id'], ref['package_sha256'], state['revision'])
result = session.objects()  # 0.2包；也可query(point)或query_range(bounds, frame, limit)
```

示例假定已有保存引用，空库的saved_reference为null，应先安装和激活。恢复重新核对包内容、本体及绑定，不增加持久序号；运行期间切换版本不会改写已取得旧会话。

## 4. 复查和失败处理

`list`列出已安装引用。复查旧包时显式activate旧发布及摘要，并使用当前revision；这会产生新选择序号。已有旧会话仍可查询原快照，直到持有它的进程结束。

正常退出0；范围超过上限输出完整拒绝响应并退出3；输入、绑定或本地存储错误退出2。超限不返回部分结果，空列表不代表空闲。异常不会自动选择其他包；损坏安装也不会被重复install静默修复，应人工排查或使用新的独立消费库。

状态只读元数据，不检查最新撤回/期限或确认设备可运行。本批没有物理断电验收、远程机器人状态或生产权限。契约见[本地消费库v0.1](../../contracts/schemas/preview-consumer-store-v0.1.md)，验证见[态势服务消费版本保存与恢复](../validation/态势服务消费版本保存与恢复-D2-2026-11-02.md)。
