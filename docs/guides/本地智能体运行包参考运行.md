# 本地智能体运行包参考运行

日期：2026-10-27。适用：R1a合成JSON包；无需PostgreSQL、ROS、Node或网络，但当前Python参考工具仍依赖仓库Python环境。

从仓库根目录运行，选择专用本地存储目录：

```powershell
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-local install examples/agent-runtime --source examples/indoor-spatial
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-local status synthetic-equipment-corridor
```

复制install返回的package_sha256，以下用占位符表示：

```powershell
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-local activate synthetic-equipment-corridor --digest PACKAGE_SHA256 --revision 0
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-local query synthetic-equipment-corridor --point 1 0 1
```

状态查询返回当前revision，下一次切换必须使用刚查询到的值，不能反复使用0。并发冲突退出2，先查询再决定下一操作。切换当前包也会生成新revision；不自动把过期请求当作成功。

install需来源配合验证；成功登记后，status、activate及query只读本地库，不再访问原来源或包目录。query每次打开新的短会话；长会话通过LocalPackages.open_session持有，查询完成后close。具体行为见[设计](../architecture/智能体运行包本地安装与会话设计-v0.1.md)。

本地状态保存在专用目录runtime.sqlite3。不要手工编辑或删除活动数据库及日志文件，也不要把var数据提交仓库；首批不提供自动清理。复制阶段遗留stage目录不算安装成功。

所有输出固定标明合成有效性及robot_ready=false，不能用于真实机器人控制。当前无签名、在线撤回、有效期检查或认证；不要将此CLI当作正式交付安装器。

## R1b文件后端

R1c可对已有files库执行只读核对；audit不初始化缺失库，结果为本次观察，不是删除依据：

```powershell
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-files --backend files audit
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-files --backend files audit --limit 500
```

无诊断退出0，有finding或失败退出2；遗留目录可使passed=false但integrity_healthy=true。complete=false表示扫描不完整。非终态安装只标记not_probed，不说明进程死亡。默认每表和每区域最多200项，最大1000；超限提高limit或另行规划大规模盘点，不能据部分列表清理。详见[设计](../architecture/智能体运行包完整性核对设计-v0.1.md)。

显式指定files并使用新根目录；默认blob模式保持兼容，不在同一根目录混用两种库：

```powershell
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-files --backend files install examples/agent-runtime --source examples/indoor-spatial
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-files --backend files installations
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-files --backend files status synthetic-equipment-corridor
```

activate和query语法沿用前文，增加`--backend files`并使用相同root。文件后端把组件写入packages/清单摘要，元数据在runtime-files.sqlite3；不要手改或分开删除这些内容。

进程中断后，先用installations找到install_id、state和revision，再查详情及标记恢复；以下为占位符，替换成实际值：

```powershell
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-files --backend files installation INSTALL_ID
.venv/Scripts/python.exe -m apps.cli.agent_local --root var/agent-files --backend files recover-install INSTALL_ID --revision REVISION
```

活进程持锁时拒绝恢复，不依据等待时长接管。恢复只标记interrupted，不登记或激活包；再次install产生新记录并重新核对固定来源。暂存、孤立目录及锁文件保留，不自动删除。文件库损坏时停止操作，不以空库替换；旧blob库迁移未实现。见[设计](../architecture/智能体运行包文件存储与恢复设计-v0.1.md)。
