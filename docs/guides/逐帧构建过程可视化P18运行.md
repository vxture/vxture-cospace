## 查看回放

1. 在构建流程点击“打开构建画布 ↗”，独立标签页打开纯底图画布，没有通用header、目录和内嵌卡片。
2. 已完成任务自动按源时间回放，默认0.1×慢放，源序列实际仅约1.87秒；减少动态偏好下停在首帧，手动播放即可。
3. 蓝色线框为该帧估计相机朝向，轨迹仅显示到当前帧。拖动时间轴回看，会同时移除后续点和轨迹；支持暂停、重播、速度、拖动旋转／平移及适配全图。
4. “已处理57/57帧，3帧未参与”说明60帧资料中只有57帧存在已有估计位姿。播放时间和倍率不表示构建耗时或后台任务百分比。
5. 画布左上显示真实模型／双视图状态，返回链接固定原场景、资料与任务。回放完成不自动选择或发布。

新任务构建时进入“跟随构建”，读取工作进程已保存的帧。手动拖动后转为回放，点击“跟随最新构建”才回到最新。网络错误暂停在最后核验画面，归属或摘要校验失败清空；失败／中断只显示保存的部分，可返回原流程使用“使用原资料重新构建”。

## 本机服务恢复

当前业务运行区`var/validation/p18-001/runtime`，8782最终代码重启后的认证区`var/validation/p18-final-001/auth`。仅当8782无监听且需要恢复时，从项目根目录执行；使用全新的output目录名：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.serve_scene_journey_demo --source var/validation/p18-001/runtime --output var/validation/p18-manual-001 --candidate build-c8445a7aa7744502 --port 8782 --existing-runtime
```

新模拟身份源启动后重新登录。原服务无需停止。

离线包的安装、显式激活、恢复命令在固定发布卡片“本地消费”内。离线交付正式模型与双视图，未包含逐帧回放分块。

本批验证流程和来源对应；数据为预录RGB-D及已有估计相机位姿，不是实时设备接入、实测机器人轨迹或精度通过。详见[P18验收](../validation/逐帧构建过程可视化-P18-2026-11-05.md)。
