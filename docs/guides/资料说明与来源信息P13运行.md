# 资料说明与来源信息 P13

## 查看

打开[8777数据管理](http://127.0.0.1:8777/workbench/layout.html#data?space=space-d7a370b8107c30f7&tab=inputs&input=input-74de27ff3c274b47)，登录“模拟场景管理员”。这是本机模拟平台和独立场景副本。

1. 点资料行，在header下方的右侧详情选择“编辑说明”。
2. 修改名称、备注、用途并填写修改原因，保存后目录更新。说明编辑不是构建前置步骤。
3. 展开“说明修改历史”查看真实修订；“原始登记名”仍为首次固定输入的名称。
4. 向下查看“坐标与时间”，展开“配套资料与证据依据”。未知信息保持未确认，清单摘要核对不代表载荷或精度验收。
5. 沿原“执行预检”“用于构建”操作继续。任务与发布保存当时固定绑定；改名不生成模型版本。

激光样本见[OS1-16资料](http://127.0.0.1:8777/workbench/layout.html#data?space=space-0004d0e3c133f5fb&tab=inputs&input=input-32fe9d0c917c4b84)。当前路线仅使用首帧，IMU只参与消息核对。

本次两个新构建已成功，但没有自动选择或发布；现有固定空间继续使用P12选定的版本。

## 冲突与错误

- 冲突时保留编辑内容，点击“重新读取资料说明”再核对；重新读取会退出当前编辑。
- 来源信息错误与未填写分开显示；恢复文件或网络后显式重新读取。原始载荷需要执行既有预检。
- 会话到期时按原入口确认或重新登录，写操作不自动重放。
- 仅有空间预览权限的“模拟查看者”不能读取工程资料说明、事实或修改历史。
