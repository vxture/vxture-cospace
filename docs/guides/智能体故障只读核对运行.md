# 智能体故障只读核对运行

日期：2026-10-27。面向开发者的合成实验入口，不是机器人授权或故障解除工具。

从仓库根目录执行，root指向已有实验ValidityStore目录：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.validity_audit --root 'D:/local-data/validity-test' --limit 100
```

路径只是示例，需替换为实际实验库。工具不会创建库或pending目录。输出JSON到stdout；退出码0表示本次读取完成且未观察到待处理项，退出码2表示观察到pending、不完整结果或非法参数。退出码0不代表验签、时间有效或机器人可用。

核对结果含配置摘要、保留证明数、pending原字节摘要和匹配类别。不打印证明正文、不清除文件、不调用任何恢复操作。摘要匹配仍需人工对账；未匹配可能是活跃事务，也可能是旧状态已被替换，不能据此删除文件。

需要保存报告时，将stdout写入库目录之外的独立证据位置。只读工具不会建立跨数据库与文件系统的一致快照；一致性取证及维护独占尚需后续协议。

无需准备持久库即可复跑合成证据：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.validity_audit_evidence
```

该命令在临时目录创建合成库、注入一次提交失败，并将报告写入experiments/runs/p2-validity-audit-001。临时库随后清理，保存结果不包含私钥。它是单独的证据生成程序，具有写临时数据行为，不能替代上面的只读核对命令。

人工恢复必要条件见[设计](../architecture/智能体故障核对与人工恢复条件-v0.1.md)。当前没有解除入口；出现问题后保留现场，待受控恢复协议实现。
