# 对象与业务台账绑定

1. 按[真实样本流程运行手册](真实样本流程运行手册.md)启动服务，从Launcher进入“空间关联”，选择工程空间。
2. 先确保已有语义对象候选。页面“对象与业务台账”独立于上方“对象标注”，默认读取当前所选候选。
3. 展开“登记设备台账版本”，输入来源系统、业务标识、台账版本与名称；资产编码、制造商、型号和序列号可选。只使用已授权且符合当前工程范围的资料；公开样本的测试台账名称注明非现场资料。
4. 点击“登记固定台账版本”。同系统/标识/版本已有相同内容时返回原记录，不覆盖；内容变化请新建版本。
5. 在“关联基础候选”确认基础，给对象选择固定台账版本。默认保留已有绑定；“不绑定台账”表示新候选解除该对象绑定。
6. 确认完整绑定集，点击“生成业务关联候选”。这一步不会改当前选择或发布。
7. 进入构建中心，点击新候选“核对并选择”，检查“业务台账绑定”新增、解除、换版及精确引用；填写说明并确认。然后进入态势服务另行固定发布。
8. 态势服务可比较旧发布与新发布的业务差异；空间预览打开新固定版本后，选择对象查看“业务台账 · 固定快照”，人视图/智能体视图共用同一记录。
9. 离线包0.3携带business.json及台账固定记录，现有本地消费库可安装、显式激活和重启恢复。完整消费命令见[消费保存与恢复](预览消费版本保存与恢复.md)。

“重新载入关联”会丢弃尚未生成的本次编辑，并重新读取当前候选与目录。切换基础或空间会清除当前草稿，不把旧空间绑定带入新空间。纯几何候选没有语义对象，不能生成业务绑定。

模型点几何与稳定对象ID是绑定基础；台账名称相似不构成自动对应。普通标注修订会保留未移除对象的固定绑定。删除台账目录不会反向删除已发布快照，但不能据此说明当前外部业务资料仍有效。

本批验证使用独立副本`var/validation/business-f2-001`，原运行区没有加入测试台账或业务候选。两类真实几何样本配合明确标注的本机流程台账验证，见[验证记录](../validation/对象业务台账绑定-F2-2026-11-02.md)。原本机页面可登记用户自己的首条台账；不会为填充页面自动植入测试记录。

字段及版本语义见[契约](../../contracts/schemas/preview-business-v0.1.md)。当前只支持每对象一个设备台账固定版本；巡检记录、实时外部系统同步、业务类型映射、本体约束的对象关系及生产授权后续实现。
