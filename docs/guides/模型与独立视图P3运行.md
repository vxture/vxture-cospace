# 模型与独立视图 P3 运行

从一个“场景空间”内的数据管理或构建中心开始，选择已经登记的资料。新几何构建仍会重新检查文件、使用状态和明确批次准入修订。

1. 发起构建。流程页依次呈现资料、模型冻结、人视图、智能体视图；模型已经冻结时，不会因为一类视图失败而显示整个模型未生成。
2. 两类视图完成后出现“核对本次模型”。候选就绪与已发布分别显示，继续人工核对和确认发布。
3. 某类视图失败／中断时，在“独立视图任务”点击相应的“重试人视图／智能体视图”。后台只读取固定模型，创建该类新任务，另一类视图引用保持不变；完成后定位新候选。
4. 已成功的视图也可“重新派生”。这会创建新的视图版本与候选组合；固定模型、原视图和已有发布均保留。需要改变几何时，应返回任务页用资料重新构建。
5. 如果提交结果未确认，点击“核对提交结果”；刷新后不会自动重发。找到任务会定位它；尚未找到时可用原请求重新提交，系统去重。
6. 检查新候选的固定模型与两类任务标识，然后人工核对发布。新候选不会自动成为当前选择，旧固定发布仍使用原组合。

“固定模型”链接可以回到模型来源任务；“视图派生来源”链接可以回到本次重派生的父候选。两类视图的任务标识和状态独立显示。服务重启后成功成果保留，未完成任务显示中断，需要显式重试。

历史一体构建继续可用，页面会标识历史执行方式。要体验独立派生，请显式用该资料发起新构建；不会自动把历史任务改成新模型。
