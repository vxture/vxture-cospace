# 共用支撑与场景工作台操作指南

适用：N1—N6 工作台。历史“三类六入口”“七阶段”的文档保留作历史验证记录，当前导航和业务操作以本指南为准。

## 进入工作范围

登录后，通过功能菜单进入“共用支撑”或“场景工作”。数据管理、语义本体可直接使用，不要求先选场景。数据目录按原始／过程／成果分类，显示当前身份可管理的数据；它不会扩大查看权限，也不会把文件搬到公共目录。查看者能预览某个场景，不代表能进入该场景的数据管理目录。

构建中心、空间关联、发布与服务、空间预览使用上方“操作场景”。左栏选择当前板块的能力。首次进入没有场景时明确选择；新建场景仅对有创建权限的身份开放。不可访问的场景不会被自动替换。

普通功能切换保留场景，清除旧记录。使用“用于构建”“返回本次构建”等业务按钮会携带所需的资料、任务或版本。切场景会清除旧资料、批次、任务与发布引用。每个浏览器标签页分别保持自己的地址与编辑。

## 完成首次交付

1. 进入数据管理，选择明确场景后上传资料包或使用允许的来源。核对资料说明、局部坐标、来源和必要配套资料；已有点云属于成果输入，不等同原始现场观测。
2. 选中本次资料执行预检。若采用采集批次，先保存成员、说明原因并封存，构建时选择对应批次修订。预检通过仅说明文件及引用满足检查条件。
3. 进入构建中心，明确本次资料和任务。模型冻结后分别生成两类视图，两类视图同源核验通过才可核对候选。失败时打开原任务，按实际状态使用恢复入口，不用最新任务替代原目标。
4. 核对变化、填写核对说明并确认，选择当前工作候选。这一步不会自动发布。
5. 进入发布与服务，核对当前候选后确认固定发布。在线预览、查询与离线导出均针对明确的发布版本。消费端安装、启用、换版和回切须在消费端明确执行。

页面的“资料准备 → 模型构建 → 核对确认 → 发布交付”是保存记录的只读投影。没有依据会显示未核验或需处理；它不会替你创建、取消或发布任务。语义本体、对象标注、台账和对象关系按业务需要增强，非首次发布的强制前提。

## 更新与历史版本

同场景补充资料后，明确跟进新的输入或任务。未发布的新候选与可用的旧固定发布可以并存。候选核对选择后，再单独发布新版本。

历史发布深链保持其原候选与来源，不自动换到当前候选。暂停分发后，该版本的新预览、查询和导出被阻断；恢复须显式操作。退役与替代关系遵循版本生命周期门禁。任何服务状态都不证明设备已经启用该版本，也不证明现场精度或可通行性已验收。

## 编辑与会话恢复

离开有修改的工作面时，选择保存后继续、放弃修改或取消离开。缺少原因、权限或必要核查时，返回原工作面补齐；生成候选、导入、封存和发布须在原工作面显式执行。多项编辑依次保存，前项成功、后项失败时前项保持已保存。

草稿仅保留于当前标签页内存。刷新、关闭或离开网站会触发浏览器提醒，但不保证随后找回草稿。平台或订阅状态暂不可确认时，工作面被遮挡；恢复同一身份后可继续，保存、构建与发布不会自动重放。切换组织、工作区或用户会清理旧上下文与草稿。

确认有效期内的平台缓存可以继续操作；缓存过期须重新检查。看到读取失败时先检查会话与网络，再核对记录，不把空列表、无权限与失败混为一谈。上传连接中断后，请按相同资料包或资料目录核对登记结果，避免误判为没有提交。

## 权限速查

| 身份 | 主要能力 | 需留意 |
| --- | --- | --- |
| 场景查看者 | 预览、查询授权固定发布 | 无构建、数据管理、导出和发布权限 |
| 场景工程师 | 数据管理、构建、关联、预览查询及导出 | 不因可构建而获得发布或空间管理权限 |
| 场景管理者 | 工程能力、固定发布及空间管理 | 不因场景管理而获得工作区本体维护权限 |
| 工作区所有者／规则维护者 | 工作区规则维护；在绑定到当前工作区的场景内享有所有者基线能力 | 不越过组织、工作区与场景绑定；不是一个新增的场景角色 |

最终权限由服务端当前策略和平台权益共同校验。URL、菜单显示、旧会话及目录缓存均不是授权依据。
