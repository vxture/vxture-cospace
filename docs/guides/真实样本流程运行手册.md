# 真实样本流程运行手册

本手册面向内部交付工程师，覆盖资料登记→预检→构建→对象标注→候选选择→固定发布→离线消费→来源追溯。当前验证目标是跑通真实样本流程，精度未验收，不能用于机器人导航放行。

## 1. 准备运行环境和资料

在项目根目录PowerShell执行。运行环境为Python 3.14、Node.js 24、pnpm 10.32.1及uv。

```powershell
uv sync --locked --extra preview --extra input
```

在 `apps/workbench` 目录执行前端安装与构建，完成后回到项目根目录：

```powershell
pnpm install --frozen-lockfile
pnpm run build
```

`preview`包含NumPy，使用已有锁定版本2.5.4；`input`提供激光适配器所需rosbags。仅运行NYU时可省略input。主流程使用FastAPI、Pydantic、Uvicorn；采集批次和独立消费库使用Python内置SQLite，不需要额外数据库服务、Open3D隔离环境或ROS设备。

**资料和已有轨迹是运行前置条件，不在Git中。** 本机当前已有：

| 产物 | 项目相对路径 | 用途 |
| --- | --- | --- |
| 封存RGB-D | `var/nyu/office-0001a-short-001` | report.json及raw图像，60个接受帧 |
| 已有轨迹 | `var/nyu/office-0001a-interior-0-002/comparison.json` | 可用57帧位姿 |
| 初始预览 | `var/nyu/office-0001a-flow-001` | 服务启动时需要，非默认活动发布 |
| 激光封存样本 | `var/samples/multi-1-os1-lidar-1s-001` | sample.json与sample.bag；10帧输入，仅首帧用于候选 |
| 来源配置 | `deploy/config/preview-sources.json` | 页面允许登记的资料组合 |

新机器需要先取得封存资料；NYU另需匹配轨迹。按[来源配置指南](本机预览来源配置.md)修改项目内路径。仅克隆代码不能重现缺失的采集数据。当前适配器支持NYU封存PGM/PPM＋已有轨迹，以及ROS1受限激光样本的单帧局部候选；不会自动为任意资料生成SLAM轨迹。启动服务仍需下述初始预览目录。

若初始预览缺失，可从上述已有输入生成。输出目录必须尚不存在：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.build_nyu_flow_preview --snapshot var/nyu/office-0001a-short-001 --tracking var/nyu/office-0001a-interior-0-002/comparison.json --output var/nyu/office-0001a-flow-new
```

使用新目录时，后续检查加 `--model var/nyu/office-0001a-flow-new`，服务启动第一个参数也改成该目录。不要覆盖已有发布或旧结果。

## 2. 只读检查

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_doctor --full-check
```

输出JSON，全部通过退出码0，失败退出码1，并给出处理建议。检查Python、依赖导入、Node/pnpm版本、来源配置及图像完整性、初始模型成员摘要、dist/layout.html存在。不联网、不创建目录登记或任务，不判断端口是否占用，也不证明浏览器或模型质量验收通过。前端文件存在不代表源码与dist完全同步，改前端后仍须构建。

只检查来源配置时：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_sources --full-check
```

## 3. 启动与停止

```powershell
.venv/Scripts/python.exe -m experiments.scripts.serve_nyu_flow_preview var/nyu/office-0001a-flow-001 --port 8767 --sources-config deploy/config/preview-sources.json
```

保持终端运行。浏览器打开 [资料目录](http://127.0.0.1:8767/workbench/layout.html#data)，认证尚未接入时点击“预览界面”。工作台静态文件及模型API都由此服务提供，不必同时启动8766。停止时在该终端按Ctrl+C；修改来源配置后重启。

## 4. 页面操作

Launcher统一为三类六入口：使用（空间预览、态势服务）、构建（数据管理、构建中心）、定义（语义本体、空间关联）。空间预览可展开六模块进度；身份及服务端空间授权尚未接入，本机目录未按用户权限过滤。

| 步骤 | 页面与操作 | 应看到的成果 |
| --- | --- | --- |
| 选空间 | 空间预览→创建或选择项目/空间→数据管理 | 独立空间ID，数据管理/构建中心/态势服务共享空间上下文 |
| 登记 | 数据管理→登记资料→选择来源、填写名称→校验并登记 | 新登记ID及空间归属；同一空间重复内容定位原记录且不更名 |
| 预检 | 资料详情→执行预检 | 本次结果及时间，失败有原因与建议 |
| 构建 | 用于构建→确认所选资料→发起构建 | 新build任务与独立候选；NYU复用已有轨迹，激光仅选首帧且不配准 |
| 标注 | 空间关联→对象标注→选择基础候选与固定本体→加入对象→生成标注候选 | 复用固定几何，生成含待核实对象的独立候选；不自动选择或发布 |
| 选择 | 候选已生成→构建中心→核对并选择→填写依据并确认 | 当前空间候选选择更新，旧候选保留；不自动发布 |
| 发布 | 态势服务→确认当前候选→发布所选候选 | 独立preview发布ID及固定链接 |
| 核对 | 该发布→流程核对 | 本次文件检查、保存记录及缺口分别显示 |
| 追溯 | 该发布→来源追溯 | 登记资料、任务、发布和离线包绑定状态 |
| 消费 | 下载离线交付包、查看离线包信息 | ZIP、预期发布ID、SHA256及字节数 |

### 4.0 全屏浏览真实空间

从“空间预览”的工程空间卡片点击“打开空间”，会新开标签页进入该空间最近的固定预览发布；态势服务列表“打开固定版本”可打开指定历史发布。URL明确携带space和publication，打开后不自动跟随新候选或发布。

左上切换真实空间；右上立方体/芯片图标在完整人视图与智能体表面视图之间切换，复位恢复整体视角。拖动旋转、右键平移、滚轮缩放。通过两侧图形手柄展开对象列表和空间概览；概览中显式选择历史发布。点击画面对象或列表项，定位锚点并在列表旁查看属性与模型点证据。左下开关仅控制几何和标注显示。

读取失败、摘要不匹配或跨空间错误发布会显示原因并清空画面；点击重试重新读取同一固定版本。没有标注的旧发布显示“尚无对象标注”，不会继承其他版本对象。Avatar中的“空间预览”可新开目录页。当前仍是本机预览身份，非真实账户授权。

NYU的人视图为彩色点云，OS1-16为激光强度灰度。两者使用各自原始坐标声明，智能体表面视图没有自由空间或距离场。详见[C验证记录](../validation/真实双视图DS全屏接入-C-2026-11-02.md)。

资料、构建与发布列表按空间显示；历史未关联范围单独保留，新登记请先选择空间。空间预览入口打开该空间最近一次固定预览发布，其他历史发布从态势服务打开，均使用独立标签页。

登记、构建、候选选择和发布都是显式操作。登记不构建，构建不自动切换空间，选择不自动发布，下载不自动切换消费方。查看历史记录不会变更这些选择。第一次启动空目录不会自动登记样本。

旧模型缺少登记绑定时追溯显示缺失；新发布没有版本切换实验记录时，流程核对显示待补齐。这些缺项不等于当前文件完整性失败，也不能自动补造。

工程CLI登记到指定空间时，使用已有空间ID：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_inputs --space-id SPACE_ID --label "资料名称" --snapshot "封存目录" --tracking "轨迹JSON路径"
```

激光资料须显式选择格式，省略tracking：

```powershell
.venv/Scripts/python.exe -m apps.cli.preview_inputs --format ros1_lidar_single_frame --space-id SPACE_ID --label "OS1-16 单帧局部样本" --snapshot var/samples/multi-1-os1-lidar-1s-001
```

已配置来源也可从页面登记窗口选择。激光输入核对149条消息与10帧点云，仅首帧12,884点构建本机候选；这是当前封存样本的数值，不是通用数量要求。人视图灰度来自强度；传感器局部坐标不转换为NYU相机坐标或全局坐标。详细成果见[验证记录](../validation/激光单帧候选与双视图流程-2026-11-02.md)。

空间目录默认 `var/nyu/preview-directory`，可用 `--directory` 指定。省略 `--space-id` 只登记为历史未关联资料；不能直接用于已归属空间的构建，应在目标空间重新登记。API列表省略space_id同样表示历史范围。

### 4.1 本体版本与对象草稿校验

从Launcher进入“语义本体”，显式选择基础词表的固定版本。页面读取真实封存规则，展示类型ID、属性、必填与长度要求、版本和SHA256；不把本体类型数量当作现场对象数量。

点击“填入校验示例”或输入对象数组JSON，点击“校验草稿”。可把type_id改为unknown，或删除必填name，检查错误是否定位至具体对象和JSON Pointer。修改草稿会清除旧结论；校验不保存对象，也不为NYU发布增加语义。

默认规则源为 `configs/ontology/indoor-equipment-v0.1.json`和`indoor-equipment-v0.2.json`两版，服务启动时封存到 `var/nyu/preview-ontologies`。更改同一ID及版本的内容会导致启动拒绝；应保留旧源，创建新版本文件，再通过服务启动参数 `--ontology-seed 新规则文件路径` 登记。新版本不会自动替换旧空间或模型的解释。页面选定版本后，URL包含ID、版本及摘要，可用于复查固定规则。

当前支持小型字符串类型规则及0.2关系规则；未实现在线编辑、单位校验、IFC/CIM映射或自动本体迁移。B2对象候选使用这些固定规则，操作如下。

### 4.2 模型对象标注与修订

1. 从Launcher进入空间关联，先选择工作空间，在“对象标注”选择已完成的基础候选和固定本体版本。
2. 填写稳定ASCII对象ID（例如`inspection-point-001`）、类型及本体要求的属性；中文名称放在name属性。
3. 输入从0开始的模型点索引，点击“读取锚点”。坐标由服务从固定模型生成；目前尚未提供画面点选。该坐标不是独立测量值，也不证明类型正确。
4. 点击“加入本次标注”，核对完整对象集，再点击“生成标注候选”。每批支持1至100个对象，所有确认状态固定为待核实。
5. 点击“前往构建中心核对”，使用“核对并选择”比较当前及目标候选；填写核对依据并确认限制后，前往当前空间的态势服务，单独发布。旧候选与发布不变。

基础候选已有标注时，页面加载其完整对象集与固定本体引用。点击“修订”可保持同一ID修改类型、属性或锚点，读取锚点后保存本次修订；生成结果是完整集合的新版本，非单个对象补丁。ID应保持稳定。切换空间会清空当前未保存编辑，重新读取该空间候选。

候选/固定发布的`api/objects`列出对象，`api/objects/OBJECT_ID`查询单一对象。双视图使用同一objects.json和ontology.json；旧无对象版本返回明确缺失状态。模型点证据仅证明来源，不能把公开样本测试点称为已确认现场设备。契约见[对象标注候选](../../contracts/schemas/preview-objects-v0.1.md)。

### 4.3 候选更新比较与人工核对（E1）

构建中心“核对并选择”比较当前空间所选候选与目标候选，展示表面单元、本体及对象新增/移除/修改。填写依据并知悉未完成精度验收后才可确认；选择序号变化时重新读取，不自动合并。坐标或分辨率不兼容时阻止本路径确认。新发布保存核对记录，旧发布不补造。完整流程见[候选更新核对运行](候选更新核对运行.md)。

## 5. 离线消费与独立验证

从离线包信息复制发布ID和SHA256，将下载文件放到本机任意可读位置。以下大写值须替换：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.query_preview_offline "下载的离线包.zip" --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --point -10.85 -1.25 4.35
```

上述示例点为此NYU样本首帧深度相机坐标（米，右/下/前）。激光包须使用model.json声明的sensor frame及本包点坐标，不能套用该示例点或轴定义。离线查询需要代码与NumPy，不需要图片、人视图或服务。未知区域返回unknown，表面证据返回surface_candidate，均不表示可通行自由空间。

含对象但无业务快照的固定发布导出`cospace.preview-offline/0.2`，在旧0.1包基础上增加objects.json和ontology.json；含业务绑定快照则导出0.3，另加business.json。含关系快照则导出0.4，另加relations.json并可保留business.json；当前读取器兼容四版。对象查询和点查询三选一：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.query_preview_offline "下载的离线包.zip" --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --objects
.venv/Scripts/python.exe -m experiments.scripts.query_preview_offline "下载的离线包.zip" --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --object-id OBJECT_ID
```

离线包验证模型、发布、本体及对象的固定绑定，返回与在线相同的对象记录；因不包含完整点云，离线不重新计算锚点或核实现场语义。

服务运行时可执行独立下载与网络禁用消费对照；该命令写入指定证据目录，但不构建、不发布：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.verify_preview_offline PUBLICATION_ID --output var/nyu/offline-check-new
```

版本更新完整实验命令见[版本切换记录](../validation/真实预览版本切换与历史复查-2026-10-29.md)，它会创建新任务、选择并发布，勿当成只读健康检查。旧PreviewConsumer类的活动引用仍只在内存中；需要持久版本和重启恢复时，使用下节独立消费库。摘要核对不等于可信签名或设备授权。

### 5.1 智能体范围查询（D1）

在“态势服务”选择空间，展开某一固定发布的“范围查询”。页面读取该发布坐标系，初始范围包围模型；填写最小/最大XYZ与数量上限后点击“查询范围”。默认1024、最多4096个表面单元；整图通常超过上限，请缩小至关心的局部范围。每轴最小值必须小于最大值，坐标单位米，不能混用NYU相机轴和激光传感器轴。

接口为 `POST /publications/PUBLICATION_ID/api/query-range`，请求包含bounds_m、frame_id、limit。按单元中心选择 `[min,max)` 范围。result_complete=true表示此固定表面证据枚举完成，不表示空间完整或可通行。超限返回result_complete=false、空单元列表和明确原因，不能由空列表推断未知或没有障碍物。当前不提供自动分页，按范围拆小后查询。

离线使用同一个既有ZIP，无须重新发布或下载人视图。以下点位仅用于当前OS1-16传感器局部样本：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.query_preview_offline "下载的离线包.zip" --publication PUBLICATION_ID --sha256 PACKAGE_SHA256 --bounds -4.45 -0.25 0.94 -3.94 0.26 1.45 --frame-id os1_16/os_sensor --limit 1024
```

bounds、point、objects、object-id四种模式互斥。bounds必须提供frame-id；limit只用于bounds。完整返回退出0，超限打印JSON后退出3，输入/完整性错误退出2。见[范围查询契约](../../contracts/schemas/preview-range-v0.1.md)及[D1验证](../validation/智能体范围查询-D1-2026-11-02.md)。

### 5.2 消费版本保存与重启恢复（D2）

态势服务中展开固定发布的“本地消费”，获取该包的实际空间、发布ID和SHA256命令。独立消费库先init、再install；只有activate切换保存引用。重启后status显示有保存引用但无查询会话，需显式restore并提交预期序号。支持点、对象及范围查询；旧查询会话继续固定在原版本。

页面仅生成操作说明，不读取消费端状态。库内保存完整ZIP字节，恢复不依赖下载路径或在线服务；每空间使用独立目录。完整命令与失败处理见[预览消费版本保存与恢复](预览消费版本保存与恢复.md)。

### 5.3 固定发布变化追溯（E2）

态势服务在目标固定发布下点击“版本比较”，显式选择同空间的基线发布，查看几何、对象、本体差异及保存核对记录。可下载报告、打开两方固定空间、定位来源与构建；不改变当前候选、发布或消费引用。仅有一个发布时显示缺少比较基线。完整操作、样例和错误处理见[固定发布变化追溯](固定发布变化追溯运行.md)。

### 5.4 空间成果目录与分类（F1）

数据管理默认显示“成果目录”，按登记资料、模型候选、固定发布、按需离线包四类搜索和筛选。点击成果查看上下游来源，跳转登记预检、构建任务或态势服务；旧“登记资料”标签与input链接保留。目录不轮询任务、不生成ZIP或改变候选选择，缺失/不一致来源单独提示。见[空间成果目录运行](空间成果目录运行.md)。

### 5.5 对象与业务台账绑定（F2）

空间关联新增“对象与业务台账”。登记设备资料的固定版本，给已有语义对象选择记录，显式确认完整绑定集并生成新候选；构建中心查看业务新增、解除和换版后人工核对，态势服务独立发布。双视图对象面板及离线0.3读取相同固定记录，新增台账版本不改变历史发布。外部系统同步与现场核实尚未实现；对象间关系见下节。见[对象业务台账绑定运行](对象业务台账绑定运行.md)。

### 5.6 本体关系与空间对象关系（F3）

语义本体可查看0.2.0的关系方向、端点与约束。空间关联在固定对象集上录入包含、位于、连接，校验完整集合后生成关系候选；核对关系与本体差异后独立发布。空间预览可点击关联对象，离线0.4使用同一关系快照，旧版本保持固定。单父与无环检查不等于现场几何包含，连接不代表可通行。见[空间对象关系运行](空间对象关系运行.md)。

### 5.7 当前空间流程状态与可复跑验收（G1）

在空间预览的真实工程空间卡片点击“查看流程”，按当前选择查看资料、构建、本体、关联、发布、双视图及离线消费七阶段。新选择未发布时不借历史发布完成当前阶段；当前服务不观察消费端，离线阶段保持未核验。模块“项目进度”与单个空间“流程状态”分别展示，详见[三类六入口流程验收运行](三类六入口流程验收运行.md)。该指南提供全新隔离输出目录的真实HTTP及断网跨进程消费验收命令。

### 5.8 采集批次与成果追溯（H1）

数据管理新增“采集批次”：创建整理批次、选择登记资料、预检封存、停用和恢复。构建中心显式携带封存批次及读取的修订，来源固定继承到后续关联候选、发布和离线包。批次详情显示保存的构建尝试和发布，不把同资料的历史成果自动归入。批次停用不撤回历史发布或消费版本。操作与独立完整验收命令见[采集批次与成果追溯运行](采集批次与成果追溯运行.md)。

### 5.9 成果生命周期引用影响（H2）

数据管理“成果目录”中选择资料、候选或固定发布，点击“检查生命周期影响”；离线包则检查来源发布。查看保存的批次、构建尝试、后续候选、发布与导出入口，逐项核对停用/归档/停止分发的阻断及历史保留范围。此检查入口仅做规则预检；资料和候选另由下节H3a入口受控变更，固定发布分发控制见H3b。操作和失败刷新处理见[成果生命周期影响检查运行](成果生命周期影响检查运行.md)。

### 5.10 资料与候选使用状态（H3a）

数据管理成果详情点击“管理使用状态”，核对限制、填写操作原因并确认，可停用/归档/恢复资料、归档/恢复候选。服务重新检查修订和引用，保存独立状态历史并执行新使用门禁。旧固定发布、离线包和已生成后续成果保留。发布分发控制见下节H3b。失败后先刷新读历史，不重复提交旧请求。完整操作与隔离验证见[成果使用状态管理运行](成果使用状态管理运行.md)。

### 5.11 固定发布暂停与恢复（H3b）

态势服务按空间找到固定发布并点击“管理分发”，核对引用、填写原因并暂停或恢复。暂停阻断新查询、双视图资产和离线下载，目录保留历史且不自动回退到旧发布；既有离线副本不撤回。失败先刷新修订和历史。完整操作与隔离复跑见[固定发布分发管理运行](固定发布分发管理运行.md)。

### 5.12 完整生命周期集成验收（H3c）

批次、资料、候选和发布的组合状态、来源缺失、服务重启和独立断网消费已联合验证。恢复发布不启用上游，新构建需逐层恢复并使用新批次修订；新构建不自动选择或发布。六入口能力说明、验收顺序和隔离复跑见[完整生命周期集成验收运行](完整生命周期集成验收运行.md)。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| NumPy缺失 | 在项目根目录执行 `uv sync --locked --extra preview` |
| 激光预检缺少rosbags | 在项目根目录执行 `uv sync --locked --extra preview --extra input` |
| doctor缺少资料或初始模型 | 准备封存资料与匹配轨迹，必要时生成新初始预览目录 |
| 页面404 | 先构建apps/workbench，确认从项目根目录启动服务 |
| 端口占用 | 停止已有同项目服务后重启；目前页面API默认8767，改端口需同步VITE_MODEL_PREVIEW_URL并重建前端 |
| 没有登记来源 | 检查配置sources和enabled，修改后重启；已有登记不受来源停用撤回 |
| 资料变化或轨迹不匹配 | 恢复封存文件，或将匹配的新资料和轨迹重新登记，不修改旧发布 |
| 构建失败 | 查看 `var/nyu/preview-builds/BUILD_ID/build.log`；失败候选不可选择 |
| 切换/发布冲突 | 刷新读取当前选择，重新确认目标，不盲目重试旧修订号 |

本手册验证基于当前本机已有数据与依赖，不声称已在全新机器完成依赖下载、原始采集或生产部署验收。
