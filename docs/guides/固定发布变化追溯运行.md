# 固定发布变化追溯

1. 启动[真实样本流程](真实样本流程运行手册.md)，从Launcher进入“态势服务”。
2. 选择工作空间，在目标发布下点“版本比较”。
3. 显式选择同一空间的另一个固定发布作为基线，再点“比较版本”。页面不自动选择最新或最早发布。
4. 查看几何/表面、对象标注与本体引用变化；展开明细可看对象前后值和本体引用。
5. 查看基线和目标各自的保存核对记录，区分未记录、内部绑定一致、绑定不一致；留意目标核对基线是否与本次基线模型一致。
6. “打开基线/目标”在新标签页预览固定空间；“来源追溯”和“构建记录”定位原记录；“下载比较记录”保存JSON报告。

原激光样本可直接验证：空间`space-6fe7d4c455774cb2`，基线`preview-7a62782ab6e4438b`，目标`preview-9b422a246ffb4ea5`。预期复用同一几何、新增1个测试标注、本体引用变化，两方均未保存更新核对。

原NYU样本：空间`space-30515836b1cd4d55`，基线`preview-2a1515de9aad4378`，目标`preview-a3b6737363fb4a64`。预期几何不变、1个标注修改，核对未记录。

有核对记录的样例在已有独立运行副本`var/validation/update-e1-002`。其激光基线`preview-9b422a246ffb4ea5`、目标`preview-a65b349c941a4b6d`；NYU基线`preview-a3b6737363fb4a64`、目标`preview-1c58fcac7c32475b`。仅用于验证已有核对记录的追溯，无须在原运行区新增发布。

可复现只读四组检查：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.evidence.2026-11-02.preview-publication-e2-001.verify_real
```

API与字段见[契约](../../contracts/schemas/preview-publication-changes-v0.1.md)。只有一个发布时先完成真实候选更新、人工核对与另行发布，再比较；不要为填充列表创建虚假版本。坐标或网格不兼容时只看能比较的记录，不能把null视为零差异。

此步骤仅为本机工程预览。它不改变候选、发布或消费引用，不执行回滚，不构成质量验收或机器人运行授权。
