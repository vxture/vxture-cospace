# 空间业务权限 I3 运行

日期：2026-11-03。六模块现有流程已接服务端空间授权。本轮真实HTTP、页面与重启验证采用本地模拟平台；真实accounts客户端尚待配置。

## 1. 本机查看

打开[带权限的工作台](http://127.0.0.1:8769/workbench/layout.html)，点击登录，在明确标识的“本地模拟平台”选择身份：

| 模拟身份 | 授权范围 | 可以验证 |
| --- | --- | --- |
| 查看者A | 测试空间A | 仅一个空间、双视图新标签页、查询可用、离线导出被拒绝 |
| 工程师B | OS1-16单帧局部样本 | 另一个空间、资料/构建/关联和导出可用、发布被拒绝 |
| 管理员 | 三个已绑定样本空间 | 多空间、发布、暂停和恢复 |

退出入口使用平台全局登出。换身份请退出后重新登录，或使用独立浏览器会话。演示变化只写隔离副本；不写原`var/nyu`。新启动必须指定不存在的独立目录：

```powershell
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.serve_platform_workbench_mock --runtime var/validation/platform-access-i3-demo-rerun --port 8769
```

先停止占用该端口的旧演示进程。模拟身份源端口、client secret和会话密钥临时生成，不复用生产凭据，进程结束后不提供模拟登录恢复。`demo.json`只保存公开模拟身份及空间ID。

原8767是无认证的内部工程预览，8768是I2登录验证；它们不是8769的权限模式开关。

## 2. 真实平台装配

沿用[I2运行手册](平台登录与中央会话I2运行.md)的环境变量及平台登记要求，使用CoSpace独立confidential client，不复用yucer客户端或cookie。登记`{COSPACE_ORIGIN}/auth/callback`与`{COSPACE_ORIGIN}/workbench/layout.html`登出返回。凭据和稳定加密密钥通过本机环境配置，不进前端或聊天。

先准备独立样本副本，例如复制`var/nyu`下的`preview-directory`、`preview-builds`、`preview-inputs`、`preview-ontologies`到`var/platform-business-sample`；不移动原目录。`--initial`选该副本中实际已完成候选的output目录。身份runtime另用`var/auth/cospace-business`，不能与样本目录嵌套。

在受控本机保存完整策略JSON。以下形状仅作说明，需替换为真实平台issuer/组织/工作区/完整subject及已存在空间ID；字段定义见[策略契约](../../contracts/schemas/space-access-policy-v0.1.md)：

```json
{
  "profile": "cospace.space-access-policy/0.1",
  "bindings": [{
    "issuer": "https://accounts.vxture.com",
    "org_id": "org_example",
    "workspace_id": "ws_example",
    "space_id": "space-0123456789abcdef"
  }],
  "grants": [{
    "issuer": "https://accounts.vxture.com",
    "subject": "usr_example",
    "space_id": "space-0123456789abcdef",
    "role": "engineer"
  }]
}
```

受信任本机管理员应用策略；首次revision为0，之后用当前revision，不要强行覆盖冲突：

```powershell
.venv/Scripts/python.exe -m experiments.scripts.manage_space_policy --runtime var/auth/cospace-business --policy var/private/space-policy.json --expected-revision 0 --actor local-admin --reason initial-binding
.venv/Scripts/python.exe -X utf8 -m experiments.scripts.serve_platform_workbench --runtime var/auth/cospace-business --sample var/platform-business-sample --initial var/platform-business-sample/preview-builds/EXISTING_CANDIDATE/output --port 8769
```

最后一条中的`EXISTING_CANDIDATE`必须替换。服务仅环回监听；正式HTTPS由代理终止。配置缺失或策略读取失败拒绝启动，不回退匿名。策略存储每次请求重读，撤权下一次准入生效；全工作区owner基线仅对显式绑定空间有效，不能仅删grant来撤销该基线。
