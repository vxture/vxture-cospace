# 场景进度与版本上下文 P12

## 查看入口

使用[8776当前版本](http://127.0.0.1:8776/workbench/layout.html#delivery?space=space-d7a370b8107c30f7&job=build-c8445a7aa7744502&publication=preview-ee4e7c3b487041cd)，登录“模拟场景管理员”。这是独立场景副本，原8775业务运行区保持原样。

首页登录会保留链接指定的场景与发布。查看者可用“模拟查看者”验证，只能浏览授权空间与固定发布，不能构建、发布或默认导出。

## 如何读页面

| 区域／提示 | 含义 |
| --- | --- |
| 工作候选 | 工程师显式核对选择的版本；新任务成功不会自动替换 |
| 跟进任务 | 链接指定的任务；任务失败不代表已有固定发布失效 |
| 当前查看发布 | 正在浏览的固定版本；历史版本保持自己的来源与双视图 |
| 服务端流程已完成 | 当前候选的模型、双视图、核对和匹配发布具备；质量仍待验收 |
| 可用固定发布 | 本空间当前可读取的固定发布数量，不表示消费端已启用 |
| 消费端未观测 | 服务不掌握机器人／外部进程的安装或激活状态 |

日常先看紧凑摘要和主操作；需要检查资料、候选、可选本体／关联及技术引用时，再展开“流程明细”。语义本体维持共用规则库，其版本应用到具体场景时再固定引用。

查看[历史版本](http://127.0.0.1:8776/workbench/layout.html#delivery?space=space-d7a370b8107c30f7&publication=preview-ff05c24196a74d44)时，卡片排在前面，摘要明确历史关系。点击“打开当前查看版本”会在新标签页打开该固定版本，保留原工作台。

六模块导航和Launcher保留明确场景／资料／批次／任务／发布上下文；切换左侧场景时清除旧记录。没有指定任务时，摘要不会随意把最新任务当成本次目标。

## 读取失败或会话确认到期

读取失败显示错误，不代表场景没有资料或没有发布。先点击“确认会话并重试”或恢复网络后刷新。平台暂不可用时会话保留；确认成功后读取原目标，不自动重建、选择或发布。若平台已结束登录，重新登录仍保留当前页面路径及固定版本；服务端重新校验权限。

暂停发布只限制该版本分发，不会自动改用旧版。恢复分发必须由有权限的管理员显式执行，已下载副本不被远程撤回。

npx --yes --package @playwright/cli playwright-cli -s=flow-p12 run-code --filename output/playwright/verify-flow-batch-p12.cjs
