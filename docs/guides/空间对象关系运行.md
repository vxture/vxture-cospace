# 空间对象关系操作

1. 按[真实样本流程运行手册](真实样本流程运行手册.md)构建前端并启动服务。默认保留类型词表0.1.0，另封存关系词表0.2.0；旧候选和发布不自动升级。
2. 从Launcher进入“语义本体”，显式选择“设备间与走廊关系词表 · V0.2.0”，查看关系端点及归属规则。类型规则与旧版一致。
3. 进入“空间关联”选择工作空间。先在“对象标注”准备至少两个有稳定ID的对象，生成语义候选；公开样本只作待核实流程对象，不能把测试名称当作现场识别。
4. 在“对象间关系”选择该候选。旧0.1本体基础须显式选择关系词表0.2.0；已有关系候选默认恢复完整关系集及其固定本体。
5. 输入稳定关系ID，选择关系类型和两端对象，填写说明，再点击“加入本次关系”。包含的来源为父空间；位于的目标为父空间；连接没有方向上的区别。
6. 点击“校验完整关系集”。反向等价重复、多重归属、循环、缺失端点和类型不匹配须先处理。校验不创建候选；修改已加入的关系会清除旧校验结论。
7. 确认完整集合，生成关系候选。移除关系表示新候选解除；空集合表示全部解除。原候选、选择及发布保持固定。
8. 前往构建中心“核对并选择”，检查关系新增、解除、修订及本体版本变化；填写说明后确认，再到态势服务另行发布。
9. 空间预览打开新固定发布，选中对象查看“对象关系 · 固定快照”，点击关联名称切换对象；人视图/智能体视图使用相同记录。态势服务“版本比较”可以追溯关系差异。
10. 含关系的离线包为0.4，已有本地消费库可安装、显式激活及重启恢复，断网查询仍使用固定关系。见[消费版本保存与恢复](预览消费版本保存与恢复.md)。

每次编辑的关系需先加入完整集合，才进入校验和保存；尚未加入的表单不是候选内容。“重新载入关系”或切换空间/基础会丢弃本次未保存编辑。旧版0.1规则不能承载关系，即使提交空集合；需要清除已有关系时使用支持关系的固定版本并提交空集合。

对象改名不改变稳定ID关系。对象移除时清除其相关关系；类型改动造成规则冲突则整批拒绝。设备台账绑定继续独立保存，不由关系名称推导业务归属。

本批真实样本验证在独立副本 `var/validation/relations-f3-001`执行。原运行区仅新增内置关系词表的固定版本文件，未植入测试对象、关系候选、选择或发布。原空间对象不足时需要工程师先标注相应对象。见[F3验证记录](../validation/空间对象关系-F3-2026-11-02.md)及[关系契约](../../contracts/schemas/preview-relations-v0.1.md)。

这些关系是人工声明，未验证几何边界、现场真实性或机器人通行能力。生产身份/空间授权、OWL/SHACL、行业本体映射和跨空间关系后续细化。
