当前独立本机入口：[数据管理](http://127.0.0.1:8779/workbench/layout.html#data?space=space-0004d0e3c133f5fb&tab=inputs&input=input-792af17634b0433e)。使用“模拟场景管理员”；真实平台联调未完成。

## 常用路径

1. 在数据管理左侧选择真实场景对应的场景空间，点击“导入资料”。
2. 有已启用来源时默认该方式；没有来源时默认“上传资料包”，无需先配置来源。当前接受RGB-D＋已有轨迹、ROS1激光短样本、PLY＋坐标声明三类受控ZIP，具体支持范围及大小以当前服务能力显示为准。
3. 点击资料，右侧详情查看类别、处理方式、所需信息及坐标来源；执行预检。
4. “导入资料 → 检查整理 → 用于构建”显示当前下一步。已入批次的资料需要明确选择封存批次；整理中、停用或不匹配批次先处理。未入任何批次的资料可直接进入构建。
5. 构建中心保留场景、资料及明确批次引用，点击“发起构建”。源文件与准入条件在提交时重检。
6. 固定模型和双视图就绪后，明确核对选择，再到态势服务确认发布。打开固定版本为独立标签页，离线下载不自动激活消费版本。
