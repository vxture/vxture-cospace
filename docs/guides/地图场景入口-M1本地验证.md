# 地图场景入口 M1 本地验证

此页为独立设计实验，不接认证或真实业务API，不写场景，不变更登录后默认入口。六个合成场景包括国内、海外、完全同址和无位置情况。列表、搜索与确认按钮可评审；确认仅显示验证结果，不进入真实业务。

2026-11-09 用户已确定正式地图供应商采用高德，当前先推进场景入口功能。以下天地图配置仅用于既有实验页过渡验证，不代表后续生产选型。

## 功能联动验证（2026-11-09）

地图布局补充：状态筛选移到顶部居中的滑块式分段选择，包含全部、已发布、构建中、待验证、不可用、已暂停、已归档。左侧只保留搜索、清单和底部定位统计；标题后展示状态标签，单位与地址降为 12px 辅助信息。目录背景不透明度降至 58%。左下角图例和地图点位复用 DS 语气色及符号，暂停为灰色暂停符号，归档为灰色空心方框，聚合另用数字圆标。点位支持键盘聚焦与选择。

本次实际验证 916px 默认视口及 390px 窄屏布局；六阶段分别筛出 1 项，全部恢复 6 项，搜索上海得到 1 个定位场景、0 个待补充。点击地图“生产车间 · 不可用”打开对应详情，点位与图例读取到相同 DS 色值。类型检查与独立构建通过。高德接入仍独立待办，此次沿用既有底图验证交互。

- 清单模式不创建地图实例；进入地图模式创建实例，返回清单销毁地图。此项减少后台地图请求，地图脚本尚未按需拆包。
- 搜索、状态筛选共用结果集，不匹配的选中场景详情隐藏；清除筛选后保留原选中记录。标题常驻总数，操作区显示筛选数量。
- 无匹配结果提供“清除筛选”，同时清空关键词和状态条件。
- Escape 优先关闭地图配置，再关闭同址选择，再关闭场景详情。同址选择同时提供关闭按钮。
- 地图结果集使用稳定引用，打开详情或配置等重绘不再触发结果范围重新适配；地图资源加载失败提供重新加载入口。
- 本机浏览器已验证：初始清单地图 canvas 数量为 0；进入地图为 1；返回清单为 0；筛选从 6 项到 1 项再到 0 项，清除恢复 6 项；配置与详情按 Escape 顺序关闭。类型检查及 build:map-lab 通过。
- 已知限制：真实场景权限与工作台交接仍待接入；高德凭据及 SDK 尚未接入。资源故障重试入口已实现，本轮未注入网络故障验收。浏览器出现主题依赖相关 React script 标签警告，需后续定位；构建仍有既有 @source 和第三方 use client 警告。

## 启动和构建

在`apps/workbench`目录运行`pnpm install --frozen-lockfile`、`pnpm dev`，打开`http://127.0.0.1:5173/workbench/map-lab.html`。正常生产构建不包含此页及其地图脚本；M1专用打包使用`pnpm exec vite build --mode map-lab --outDir ../../var/m1-map-build`，用来核对引擎/worker构建，不能替代正式业务入口验收。该专用模式使用独立的空env目录`var/map-lab-empty-env`，不读取本机`.env.local`中的地图key；不要在空env目录存放配置。

未配置底图时，引擎显示合成点位和明确的未配置提示，不请求公共或演示瓦片。背景不代表实际地图。聚合点击展开，完全同址提供场景列表；地图故障演练移除地图，列表仍可选择；重试重建引擎。窄屏切换列表/地图共享选中状态。

## 可选真实底图配置

仅在取得服务授权并核对瓦片矩阵后，通过本机忽略的`apps/workbench/.env.local`设置：

```dotenv
VITE_MAP_LAB_RASTER_URL=https://YOUR_AUTHORIZED_HOST/tiles/{z}/{x}/{y}.png
VITE_MAP_LAB_LABEL_URL=https://YOUR_AUTHORIZED_HOST/labels/{z}/{x}/{y}.png
VITE_MAP_LAB_ATTRIBUTION=服务商要求的实际来源署名
VITE_MAP_LAB_CRS=WGS84
```

注记URL可选；国内验证采用天地图文档的`vec_w`街道底图及`cva_w`中文注记，均通过HTTPS请求。该实验适配器只接HTTPS、256像素XYZ、Web Mercator瓦片，坐标数据明确为WGS84，不能将GCJ-02数据靠更改声明冒充。WMTS须先核对具体矩阵、级别与行列规则，再形成对应模板，不能机械替换参数。WGS84数据声明与瓦片EPSG:3857投影分别验证。

`VITE_*`会被浏览器读取和打包，只能配置服务商允许公开、已限制域名权限的浏览器key；服务端秘密不得放入。不要把配置、密钥、带key的请求日志或授权状态提交到Git。M1不默认填入天地图key，不自动切换服务商。字体及sprite服务未接入，点位与聚合无需远程字体。

真实底图验收尚需：天地图兼容产品及使用授权、浏览器域名配置、CORS、指定控制点对齐、服务署名、配额、目标网络加载与失败恢复。无key的引擎验证不能替代这些项目。国内外正式配置切换与场景权限数据接入留待后续批次。
