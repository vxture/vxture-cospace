# 候选更新核对运行

本流程跨空间关联、构建中心、态势服务三个工作面。重点验证版本与对象变更，不涉及建模精度提升。

1. 空间关联选择工作空间和基础候选，加载固定本体与已有完整标注集。
2. 点击对象行“修订”。稳定对象ID锁定，可修改类型、属性和点索引；点击“读取锚点”，再“保存本次修订”。取消修订保留原对象。修订尚未保存时不能生成候选。
3. 也可新增或移除标注。每个新候选仍提交1～100个对象的完整集合；本批暂不支持生成零对象语义快照，移除不等于现场设备拆除。
4. 点击“生成标注候选”。这只创建独立候选，不修改当前选择或发布；通过“前往构建中心核对”定位新候选。
5. 构建中心点击目标候选“核对并选择”。基准是当前空间所选候选，未选择时显示首次选择。核对几何来源、表面单元差异、坐标/网格、本体及对象新增/移除/修改；明细给出修改前后数据。
6. 填写核对说明，明确勾选知悉“未完成精度验收或机器人放行”，再“确认核对并选择”。坐标/分辨率不兼容时不能直接确认。核对期间选择变化会使确认失效，必须“重新读取差异”并重新确认。
7. 态势服务另行点击“发布所选候选”，确认固定发布。新发布显示“更新核对已保存”及说明；publication.json保存完整比较与核对依据。旧发布显示历史未记录状态，不能补造审签。
8. 浏览或下载新固定发布，核对对象及版本；旧固定发布和原先已取得的离线消费会话仍保持原版本。需要切换消费方时，继续执行[保存与显式恢复流程](预览消费版本保存与恢复.md)。

表面单元减少只表示证据移除，未知不能当作空闲；对象变更仅是标注变化。坐标相同的声明不证明两次测量已独立配准。当前本机预览身份不是生产审签人，也未接入空间ACL。

候选比较读取失败或确认被拒绝时不继续发布。重新读取差异后核对新基准；不要忽略错误反复提交旧摘要。原工程兼容API仍可直接选择，相关历史记录不一定包含人工核对，界面已区别展示。
